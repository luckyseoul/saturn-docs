■パターンネームコントロールレジスタ

　パターンネームコントロールレジスタは、パターンネームデータサイズ、キャラクタナンバー補助モード、パターンネーム補助データを指定します。書き込み専用の16ビットのレジスタで、180030H～180038H番地にあります。電源投入後またはリセット後、値は0にクリアされますので必ず設定してください。

パターンネームデータサイズビット：Pattern name data size bit (N0PNB, N1PNB, N2PNB, N3PNB, R0PNB)

　セル形式で表示する場合の、パターンネームデータサイズを指定します。

N0PNB180030Hビット15NBG0用（またはRBG1用）
N1PNB180032Hビット15NBG1用
N2PNB180034Hビット15NBG2用
N3PNB180036Hビット15NBG3用
R0PNB180038Hビット15RBG0用
