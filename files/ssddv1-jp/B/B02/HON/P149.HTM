カラーRAMモードビット：Color RAM mode bit (CRMD1, CRMD0)、ビット13、12
「3.4　カラーRAMモード」を参照してください。
　CRKTEビットを1にしたときには、カラーRAMモードをモード1にしてください。その際、カラーRAMの後半(100800H～100FFFH)は、係数テーブルデータ用に使用されるので、カラーデータを格納できなくなります。

VRAMモードビット：VRAM mode bit (VRAMD, VRBMD)、ビット9、8
「3.2　VRAMバンク分割」を参照してください。

回転データバンク指定ビット：Data bank select bit
(RDBSA01, RDBSA00, RDBSA11, RDBSA10, RDBSB01, RDBSB00, RDBSB11, RDBSB10)
　回転スクロール画面での、VRAMの使用目的を指定します。このビットは、回転スクロール画面を表示する場合にのみ有効です。

RDBSA00,RDBSA0118000EHビット1,0VRAM-A0用（またはVRAM-A用）
RDBSA10,RDBSA1118000EHビット3,2VRAM-A1用
RDBSB00,RDBSB0118000EHビット5,4VRAM-B0用（またはVRAM-B用）
RDBSB10,RDBSB1118000EHビット7,6VRAM-B1用

RDBSx1RDBSx0VRAM使用目的
00RBG0用RAMとしては使用しない
01RBG0の係数テーブル用RAM
10RBG0のパターンネームテーブル用RAM
11RBG0のキャラクタパターンテーブル（またはビットマップパターン）用
RAM
[注]ビット名のxには、A0、A1、B0、またはB1が入ります。

　VRAMをバンク分割しない場合は、VRAM-A0用のビットがVRAM-A用に、VRAM-B0用のビットがVRAM-B用に使われます。
　ドットごとに係数データを必要としない場合には、係数テーブル用RAM(01B)を設定する必要はありません。
　ビットマップ形式で表示する場合には、パターンネームテーブル用RAM(10B)を設定する必要はありません。
　回転スクロール用RAMに指定したVRAMバンクのVRAMサイクルパターンレジスタの設定は無視されます。
　画像データの読み出しアドレスが、指定したバンク内にない場合は、データが読み出されないので正しい画面表示ができなくなります。
　RBG1を表示する場合には、VRAM-B0用とVRAM-B1用ビットに必ず00Bを設定してください。
　係数データの読み出しアドレスが、指定したバンク内のアドレスでなかった
