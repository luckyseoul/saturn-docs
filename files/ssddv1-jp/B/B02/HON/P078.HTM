特殊カラー演算ビット(パターンネーム補助データ用)：Supplementary special color calculation bit
(N0SCC, N1SCC, N2SCC, N3SCC, R0SCC)
　パターンネームデータサイズが1ワードの場合の、パターンネーム補助データとしての特殊カラー演算ビットを指定します。

N0SCC180030Hビット8NBG0用（またはRBG1用）
N1SCC180032Hビット8NBG1用
N2SCC180034Hビット8NBG2用
N3SCC180036Hビット8NBG3用
R0SCC180038Hビット8RBG0用

　このビットの使い方は、「12.2　特殊カラー演算機能」を参照してください。

補助パレットナンバービット：　Supplementary palette number bit
(N0SPLT6～N0SPLT4, N1SPLT6～N1SPLT4, N2SPLT6～N2SPLT4, N3SPLT6～N3SPLT4, R0SPLT6～R0SPLT4)
　パターンネームデータサイズが1ワードの場合の、パターンネーム補助データとしてのパレットナンバービットを指定します。補助パレットナンバービットは、パターンネームデータのパレットナンバービットに3ビット付加されます。

N0SPLT6～N0SPLT4180030Hビット7～5NBG0用（またはRBG1用）
N1SPLT6～N1SPLT4180032Hビット7～5NBG1用
N2SPLT6～N2SPLT4180034Hビット7～5NBG2用
N3SPLT6～N3SPLT4180036Hビット7～5NBG3用
R0SPLT6～R0SPLT4180038Hビット7～5RBG0用

補助キャラクタナンバービット：Supplementary character number bit
(N0SCN4～N0SCN0, N1SCN4～N1SCN0, N2SCN4～N2SCN0, N3SCN4～N3SCN0, R0SCN4～R0SCN0)
　パターンネームデータサイズが1ワードの場合の、パターンネーム補助データとしてのキャラクタナンバービットを指定します。補助キャラクタナンバービットは、パターンネームデータのキャラクタナンバービットに5ビット付加されます。

N0SCN4～N0SCN0180030Hビット4～0NBG0用（またはRBG1用）
N1SCN4～N1SCN0180032Hビット4～0NBG1用
N2SCN4～N2SCN0180034Hビット4～0NBG2用
N3SCN4～N3SCN0180036Hビット4～0NBG3用
R0SCN4～R0SCN0180038Hビット4～0RBG0用
