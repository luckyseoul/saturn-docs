パラメータリードイネーブルビット：Parameter read enable bit
(RAXSTRE, RBXSTRE, RAYSTRE, RBYSTRE, RAKASTRE, RBKASTRE)
　係数テーブルスタートアドレスKAst、スクリーン画面スタート座標Xst、Ystを、そのラインで回転パラメータテーブルから読み込むかどうかを指定します。

RAXSTRE
1800B2H
ビット0
回転パラメータAのXst用
RBXSTRE
1800B2H
ビット8
回転パラメータBのXst用
RAYSTRE
1800B2H
ビット1
回転パラメータAのYst用
RBYSTRE
1800B2H
ビット9
回転パラメータBのYst用
RAKASTRE
1800B2H
ビット2
回転パラメータAのKAst用
RBKASTRE
1800B2H
ビット10
回転パラメータBのKAst用
 

RxSTRE
処　　　　　理
0
指定されたパラメータをそのラインで読み込まない
1
指定されたパラメータをそのラインで読み込む
[注]ビット名のxには、AX、BX、AY、BY、AKA、またはBKAが入ります。

●係数テーブルコントロール

係数ラインカラーイネーブルビット：Coefficient line color enable bit (RAKLCE, RBKLCE)

　係数データ中のラインカラー画面データを使用するかどうかを指定します。

RAKLCE
1800B4H
ビット4
回転パラメータA用
RBKLCE
1800B4H
ビット12
回転パラメータB用
 

RxKLCE
処　　　　　理
0
係数データ中のラインカラー画面データを使用しない
1
係数データ中のラインカラー画面データを使用する
[注]ビット名のxには、AまたはBが入ります。

係数データモードビット：Coefficient mode bit (RAKMD1, RAKMD0, RBKMD1, RBKMD0)
　係数データを何のパラメータとして使用するかを指定します。

RAKMD1,RAKMD0
1800B4H
ビット3,2
回転パラメータA用
RBKMD1,RBKMD0
1800B4H
ビット11,10
回転パラメータB用
