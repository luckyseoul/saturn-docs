オブジェクト

オブジェクトの書式を図5.4～図5.5に示します。項目の詳細を表5.4に示します。

（ムービの場合）
ObjectData        オブジェクトの番号            オブジェクトの種類↓
        Type          ムービの種類↓
        Duration      ムービの再生時間↓
        ObjectBodyNo  オブジェクト本体の番号↓
        Size          ムービＸサイズ      ムービＹサイズ↓
        DataPos       データＸ座標        データＹ座標↓
        DataSize      データＸサイズ      データＹサイズ↓
        DispPos       表示Ｘ座標          表示Ｙ座標↓
        DispSize      表示Ｘサイズ        表示Ｙサイズ↓
        DispPlane     表示プレーン↓
        Priority      優先度↓
EndObjectData
　
（ピクチャの場合）
ObjectData        オブジェクトの番号            オブジェクトの種類↓
        Type          ピクチャの種類↓
        Duration      ピクチャの再生時間↓
        ObjectBodyNo  オブジェクト本体の番号↓
        Size          ピクチャＸサイズ    ピクチャＹサイズ↓
        DataPos       データＸ座標        データＹ座標↓
        DataSize      データＸサイズ      データＹサイズ↓
        DispPos       表示Ｘ座標          表示Ｙ座標↓
        DispPlane     表示プレーン↓
        Priority      優先度↓
EndObjectData
（カーソルの場合）
ObjectData        オブジェクトの番号            オブジェクトの種類↓
        Type          カーソルの種類↓
        Duration      カーソルの再生時間↓
        ObjectNo      オブジェクト番号↓
        Action↓
            EventNum        イベント数↓
            ActionTotal     アクション総数↓
        ActionData↓
                EventVal    イベント値↓
                ActionNum   アクション数↓
                ActionVal   アクション値↓
                        ;
            EndActionData
                ;
        EndAction↓
EndObjectData
