5.6　レイアウトファイル

レイアウトファイルの書式を図5.9に、項目の詳細を表5.11に示します。

Format   フォーマット名↓
Version  バーション番号↓
　
Collision↓
        FileName  コリジョンファイル名↓
            ;
EndCollision↓
　
ObjectDirectory  CDディレクトリ名↓
Layout↓
        File  CDファイル名↓
            FileName  ファイル名↓
        EndFile↓
　
        ChannelInterleaveFile  CDファイル名  インタリーブファイル名↓
            InterleaveFrame  インタリーブ間隔↓
            Channel  チャネル番号↓
                FileName  ファイル名↓
                SplitTime  開始時間　分割時間↓
                DataRate  再生データ速度↓
                DataForm  フォーム↓
            EndChannel↓
                ;
        EndChannelInterleaveFile↓
            ;
EndLayout↓
図5.9　レイアウトファイルの書式

表5.11　レイアウトファイルの項目内容
項目
内容
フォーマット名
Author-Layoutが入る
バージョン番号
サターンオーサのバージョン番号
［Collision］に関係する項目
コリジョンファイル名
バイナリに変換するコリジョンファイルの名称


［Layout］に関係する項目


CDファイル名
CD上のファイル名。


ファイル名
配置する元ファイルの名前。


インタリーブファイル名
動画ファイルとコリジョンファイルをインタリー
ブするファイルの名前。


インタリーブ間隔
動画ファイルとコリジョンファイルをインタリー
ブする間隔をフレーム単位で指定する。


チャネル番号
インタリーブするチャネル番号


開始時間
配置元のファイルの先頭時間。


分割時間
配置元のファイルの分割する長さ。


再生データ速度
動画再生のデータ速度


フォーム
CDセクタのフォームを指定する。
