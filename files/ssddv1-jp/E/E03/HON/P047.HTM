5.3　シナリオファイル

シナリオファイルの書式を図5.3に、項目の詳細を表5.3に示します。

Format フォーマット名↓
Version バーション番号↓
Option
    ObjectDirectory ディレクトリ名↓
EndOption
　
ObjectBody
    ObjectBodyTotal オブジェクト本体の総数↓
    ObjectBodyData オブジェクト本体の番号↓
        FileName ファイル名↓
        CollisionFrameStep フレーム間隔↓
    EndObjectBodyData
    ;
EndObjectBody
　
Object
    ObjectTotal オブジェクトの総数↓
    ObjectData オブジェクト番号  オブジェクトの種類↓
        （オブジェクトの内容が入る）
    EndObjectData
        ;
EndObject
　
Scenario
    TagTotal タグの総数↓
    Tag タグ番号 タイムコード タグ名↓
    ObjectNoTotal オブジェクト番号数↓
        ObjectNo オブジェクト番号↓
        ；
    EndTag
        ;
EndScenario
