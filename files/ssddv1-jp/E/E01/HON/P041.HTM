Data Name
CPK_SetDecodeAddr
No
4.1
 

書式　　void　CPK_SetDecodeAddr(CpkHn cpk, void *dec_addr, Sint32 dec_line_size)
入力　　cpk          ：ムービハンドル
　　　　dec_addr     ：画像展開先のアドレス
　　　　dec_line_size：画像展開先バッファの1行のバイト数
出力　　なし
関数値　なし
機能　　展開した画像イメージを転送するアドレスを指定します。
　　　　画像展開先のアドレスが NULL の場合は画像展開を行いません。
　　　　デフォルトは NULL です。
　　　　本関数はムービを再生する前にコールしてください。
