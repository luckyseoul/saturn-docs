■3.7　SCU制御レジスタ

■SDRAM選択レジスタ

　SCUには、SDRAMの構成を指定するレジスタが存在します。図3.31にSDRAM選択レジスタを示します。このレジスタはSCU内の25FE00C4H番地に位置しています。

図3.31　SCU SDRAM選択ビット(レジスタ：RSEL)　初期値 00000000H

SDRAM選択ビット(図3.31中、1［bit 0］)
　　RSEL(Ｒ／Ｗ)　　RAM SELect bit
RSEL=0 : 2Mbit×2を指定します。 RSEL=1 : 4Mbit×2を指定します。

■SCUバージョンレジスタ

　SCUには、チップバージョンを表すレジスタが存在します。このレジスタはSCU内の25FE00C8H番地に位置しています。図3.32に、バージョンレジスタを示します。

図3.32　SCUバージョンレジスタ(レジスタ：VER)　初期値 00000000H

バージョンナンバ(図3.32中、1～4［bit 3～0］)
　　VER3-0(Ｒ)　　VERsion number bit3-0
　SCUチップのバージョンを表します。4bitありますので0～15のチップのバージョンをサポートしています。
