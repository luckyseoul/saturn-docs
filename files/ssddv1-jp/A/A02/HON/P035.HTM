　以下に表4.9の分類に基づいて、音源部レジスタについてビットの意味を説明します。レジスタ名の後に付記してある記号について、(Ｒ)は読み込み専用、（Ｗ）は書き込み専用、（Ｒ／Ｗ）は読み書き可能を表しています。
　書き込み専用レジスタ(ビット)からデータを読み出す場合、その値は"0B"になります。読み出し専用レジスタ（ビット）にデータを書き込む場合、必ず"0B"を書いて下さい。

■ループ制御レジスタ

KYONEX(Ｗ) ; KeY ON EXecution
　"1B"を書き込むことにより、全スロットのKEY_ON,OFFが実行されます。

KYONB(Ｒ／Ｗ) ; KeY ON Bit
　KEY_ON,OFFを登録します。(同時にKEY_ONさせたい場合には、ONさせたいスロットの"KYONB"を"1B"にセットします。)

表4.10　KYONB機能
　ビット　機能
0KEY_OFFを登録
1KEY_ONを登録

　"KYONEX"と"KYONB"は、各スロットに存在します。KEY_ONとKEY_OFFのシーケンスは、図4.8のようになります。
　"KYONEX"は、"1B"をライトした後に"0B"をライトする必要はありません。どのスロットで"1B"にしても全てのスロットに対して作用しますので、特定のスロットで"1B"にしなければならないということはありません。

図4.8　KEY_ONおよびKEY_OFF機能

SBCTL[1:0](R/W); Source Bit ConTroL
　サウンド入力データのビット反転操作を指定します。
　"1B"が書き込まれたビットの反転機能が有効となります。
