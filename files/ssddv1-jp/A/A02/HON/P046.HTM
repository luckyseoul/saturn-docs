■FM変調制御レジスタ

SOUS[15:0](Ｒ／Ｗ) ; SOUnd Stack
　スロット出力用のデータバッファです。64ワードのリングバッファで、2世代分のサンプリングデータを保持することができます。これは、変調およびスロット間の加算処理に使用します。

MDL[3:0](Ｒ／Ｗ) ; MoDuLation level
　変調入力ソースの変調への影響(変調度)を指定します。

表4.15　レジスタ設定値による変調度
MDL[3:0]0～456789ABCDEF
変調度(±nπ)01/161/81/41/21248163264

MDXSL[5:0](Ｒ／Ｗ) ; MoDulation input-X SeLect
　変調入力Xとして使用するソースを指定します。変調入力Xのソーススロットを現スロットからの相対番号を２の補数で指定します。また、この値が"1CH"から"3BH"の範囲内である時は最新世代を表し、範囲外である時は最新世代より1サンプル過去のソースであることを表します(表4.16参照)。

MDYSL[5:0](Ｒ／Ｗ) ; MoDulation input-Y SeLect
　変調入力Yとして使用するソースを指定します。変調入力Yのソーススロットを現スロットからの相対番号を２の補数で指定します。また、この値が"1CH"から"3BH"の範囲内である時は最新世代を表し、範囲外である時は最新世代より1サンプル過去のソースであることを表します(表4.16参照)。

STWINH(Ｒ／Ｗ) ; STack Write INHibit
　このビットが"1B"のとき、スロット出力をサウンドスタック(SOUS)へ書き込むことを禁止します。通常は、"0B"で構いません。
