●乗加算

@ pM * pC ± ( pM * pC ± ( ... ( pM * pC ± ( pM * pC + pA ) ) ... ) )

pM：被乗算数
pC：乗算係数
pA：披加算数

※左カッコ「(」と「)」の個数は一致していなければなりません。
※最も右側の「(」は、最も左側の「)」よりも左側になければなりません。

  • pMとpAの組み合わせには次表のような制限があります。

    pM
    pA
    INPUTS
    [PEG, TEMP00-TEMP7F]
    TEMP00-TEMP7F
    [REG,T]※
    		 

    ※pMで{TEMP00-TEMP7F}を指定し、なおかつpAにもTEMPを指定する場合には、
　同一の添字を持つTEMPしか使用できません。このためpAの方には“T”と指
　定します。

  • 乗算係数としてYREGの値を引数に使用する場合、{YREGH, YREGL｝のいずれかの表記とします。この２通りの表記による違いは次表を参照してください。

    表記
    乗算機に渡されるデータ（13bits）
    YREGH
    YREG bit23-bit11
    YREGL
    0YREG bit15-bit4
