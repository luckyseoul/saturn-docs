IFNB～ENDIF


フォーマット　IFNB ＜文字列＞
　　　　　　　ENDIF

説明　　　　　’＜’と’＞’の間に何か文字があればELSEまたはENDIFまでアセンブルします。
　　　　　　　IFB～ENDIFの逆の機能です。
　　　　　　　文字列は’＜’と’＞’で囲まれていなければなりません。

[例]　　　　　ifnb ＜abc＞
　　　　　　　     move.w    d0,d1-----------------アセンブルされる
　　　　　　　endif

IFE ～ ENDIF

フォーマット　IFE ＜式＞

説明　　　　　＜式＞の値が０であればELSEまたはENDIFまでアセンブルします。

[例]　　　　　bbb  equ   1
　　　　　　　ife  bbb-1
　　　　　　　     move.w    d0,d1-----------------アセンブルされる
　　　　　　　endif

IF ～ ENDIF, IFNE ～ ENDIF

フォーマット　IF ＜式＞ または IFNE <式>

説明　　　　　＜式＞の値が０以外であればELSEまたはENDIFまでアセンブルします。
　　　　　　　IFE～ENDIFの逆の機能を持っています。

[例]　　　　　bbb  equ   1
　　　　　　　if   bbb-1
　　　　　　　     move.w    d0,d1-----------------アセンブルされない
　　　　　　　endif
