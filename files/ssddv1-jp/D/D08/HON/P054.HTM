6．アセンブラ・リンカのエラーメッセージ一覧

出力メッセージ                            内容
Assemble error　            　　　　　　　アセンブルファイルにエラーがあることを示す。ファイル
                            　　　　　　　名を伴って表示される。
Line invalid　              　　　　　　　行が正しくない。
No source file specified    　　　　　　　ソースファイルの指定がない。
Could not open file　       　　　　　　　ソースファイルがオープンできない。
Could not create file   　  　　　　　　　ファイルがクリエイトできない。
Too many nesting files　    　　　　　　　ファイルのネスティングが深すぎる。(includeのネスト)
Too many nesting macros　   　　　　　　　マクロのネスティングが深すぎる。
Label buffer full　         　　　　　　　ラベルの数が多すぎる。
Macro buffer full　         　　　　　　　マクロの数が多すぎる。
Unterminated conditional　  　　　　　　　＃if等のコントロールが閉じていない。
Unterminated macro　        　　　　　　　マクロが閉じていない。
Not enough memory for SDSS　　　　　　　　SDSSの起動に必要なメモリ容量がない。
Many errors　               　　　　　　　エラーが多すぎる。
Relative branch out of range　　　　　　　相対ジャンプの距離が遠い。
Constant was expected　     　　　　　　　定数があるべき場所にない。
Reference to multi defined　　　　　　　　二重定義が行われた。
Extra characters on line　  　　　　　　　理解不能な文字が存在する。
Already had ELSE clause　   　　　　　　　ELSEに対応するIFがない。
Illegal expression　        　　　　　　　誤った表現。
Label was expected　        　　　　　　　ラベルが必要な場所にない。
Symbol is multi defined　   　　　　　　　シンボルの二重定義が行われた。
Operand was expected　      　　　　　　　オペランドがない。
Permanent label was expected　　　　　　　固定ラベルがない。
Symbol is reserved word　   　　　　　　　予約語を使用した。
Unexpected end of strings　 　　　　　　　予期しない場所で文が終了した。
Too complex expression　    　　　　　　　複雑過ぎる表現を用いた。
Symbol not defined　        　　　　　　　未定義シンボル
Value is out of range　     　　　　　　　数値が範囲を超えた
Symbol already external　   　　　　　　　外部シンボルをローカルで使用した。
Syntax error　              　　　　　　　文法エラー
Division by 0　             　　　　　　　0で除算した。
Unexpected end of file　    　　　　　　　ファイル終端が見つからない。
BAD D8 RELATIVE　           　　　　　　　8bit相対アドレスの範囲を超えた。
BAD D16 RELATIVE　          　　　　　　　16bit相対アドレスの範囲を超えた。
