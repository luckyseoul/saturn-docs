ORG

フォーマット　ORG＜式＞

説明　　　　　ロケーションカウンタに＜式＞の値をセットします。生成されるコードはその値の
　　　　　　　番地から割当てられます。＜式＞は既に値が決定している絶対式でなければなりません。

[例]　　　　　
　　　　　　　

BSEG,CSEG,DSEG,COMMON

フォーマット　BSEG
　　　　　　　CSEG
　　　　　　　DSEG
　　　　　　　COMMON

説明　　　　　これらの命令はメモリ内のコードリラティブ番地をロケーションカウンタにセットします。
　　　　　　　命令の後で、ＯＲＧによってロケーション値を変えない限り、ロケーションカウンタ値は
　　　　　　　各セグメントの最後のアドレスになっています。
　　　　　　　また、各セグメントのロケーションカウンタ値は起動時にオプションで設定した値に初期
　　　　　　　化されます。

[例]　　　　　DSEG
　　　　　　　dw      $0001
　　　　　　　dw      $0002
　　　　　　　dw      $0003
　　　　　　　CSEG
　　　　　　　move    d0,$8000
　　　　　　　jmp     start
　　　　　　　　　・
　　　　　　　　　・
　　　　　　　　　・
