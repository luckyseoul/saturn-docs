●Filter

現在編集している波形についてフィルタをかけます。次のウィンドウが表示されます。

このウィンドウで設定するパラメータは、次のとおりです。

Frequency
どの周波数以下をカットするのかHzで入力します。
1～65535までの数値を設定することができます。

Width
どの周波数以下をカットするのかHzで入力します。
1～65535までの数値を設定することができます。
Filter TypeがBPFの時のみ有効です。それ以外はグレイ表示されます。

Cut/Boost
どの周波数帯をカットするのかdBで入力します。
1～255までの数値を設定することができます。

Filter　Type
設定するフィルターを選択します。
LPF、HPF、BPFをラジオボタンで選択します。
