Wave Edit画面
このウィンドウはOpenの度に開かれ、メモリーの許すかぎり表示します。
New画面よりSCSPで得たウェーブデータおよび、Open画面よりオープンされたウェーブデータがこのウィンドウに表示されます。
  • LoopStartおよびびLoopEndポイントを、画面の範囲内でマウスカーソルで移動することによって設定することができます。
  • 波形をドラッグすることによって選択範囲全体がハイライト表示で表現されます。選択範囲を越えて移動しようとした時は表示内容が自動スクロールします。選択されたポイントは、ドラッグ終了後自動的に内側のゼロクロスポイントに移動します。
  • ズームボックスがクリックされると、ウィンドウ及びウィンドウ内の波形表示が拡大します。
  • サイズボックスをドラッグし拡大すると、マウス移動方向にウィンドウ及び波形表示が拡大します。またサイズボックスをドラッグし縮小すると横方向に対しては、波形表示サイズはかわらずウィンドウのみ縮小します。縦方向に対しては、波形表示サイズ及びウィンドウも縮小します。
  • ループポイントを移動させると、Loop Edit画面、ヘッダー表示画面も変更されます。

Loop Edit画面
    • 左側がループの終点となり、右側が始点となります。
    • ループポイントを移動させると、Wave Edit画面、ヘッダー表示画面も変更されます。

    ヘッダー表示画面
    ヘッダー表示画面の各項目の意味は次のとおりです。

    Sample Size
    データのサンプリング数を設定します。

    Sampling rate
    サンプリング周波数を表示します。

    Loop Mode
    SCSPまたはMacintoshでならすときのループモードを指定します。

    Forward Loop
    ノーマルに再生します。

    Reverse Loop
    波形データを逆から読みだし再生します。

    Alternate　Loop
    ループ部分の正／逆方向の繰り返し読みをします。
    OptionでSCSPが選択されている時のみ有効です。Macintoshが選択されている場合はAlternate Loopが選択されていても再生はForward Loopになります。
