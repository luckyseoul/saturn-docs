●インバータウィンドウ

Slotウィンドウのインバータブロックをダブルクリックすることで開くことができます。

このウィンドウはサウンド入力データのビットの反転、ループ形式、レイヤーのサンプルノート、ファインチューンの編集をします。
このウィンドウで設定するパラメータは、次のとおりです。

SIGNFRAGINVERT(SPCTL1)
サウンド入力データの符号ビット反転します。

DATAINVERT(SPCTL0)
サウンド入力データを符号ビット以外反転します。

LOOP SELECT
ループの形式を選択します。

・FORWARD
・REVERSE
・ALTERNATE
・OFF

BASE NOTE
ベースノートを設定します。
0～127までの数値を設定することができます。
このデータはAIFFファイルを読み込むとAIFFに含まれるBASENOTEを自動的にロードし、設定します。

FINETUNE
ファインチューンを設定します。
-64～63までの数値を設定することができます。
このデータはAIFFファイルを読み込むとAIFFに含まれるFINETUNEを自動的にロードし、設定します。
