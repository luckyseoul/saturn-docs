■SCSPBINフォーマット

SCSPBINフォーマットは次のようになっています。

Mixer top ofset：ミキサーデータの開始位置のオフセットアドレス
VL top offset  ：ベロシティレベル変換データの開始位置のオフセットアドレス
PEG top offset ：PEGデータの開始位置のオフセットアドレス
PLFO top offset：PLFOデータの開始位置のオフセットアドレス
Voice offset   ：各Voiceデータのオフセットアドレス
Mixer data     ：ミキサーのデータ
VL data        ：ベロシティレベル変換データ
PEG data       ：ピッチエンベロープデータ
PLFO data      ：ピッチLFOデータ
Voice data     ：ボイスデータ
Wave data      ：ウェーブデータ
