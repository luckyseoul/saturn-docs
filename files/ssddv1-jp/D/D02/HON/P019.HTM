Function Key Setup

Function Key Setupを選択すると、次のウィンドウが表示されます。
１～８のテンキーとフルキーにQWERTYUIのキーにサウンドドライバーの各機能を割り付けます。

PrintControl：ModeとStatus更新の割り込み間隔を調整します。1Tickは1/60秒です。
C           ：選択されたファンクションキーの内容をクリアーします。
New         ：新しいマップページを用意します。
<-- / -->   ：キー割付のページを選択します。ファンクションキーのテーブルは番号と名前で判別します。
            　テーブルの名前は矢印キーの間にあるエデットテキストで任意に設定できます。
Use         ：<--  --> でページを選択して Use でアクティブなキー割付を確定します。
Ok          ：中段の入力ボックスで設定した入力データを選択中の一つのキーに割り付けます。
Exit        ：ウィンドウを閉じます。

なお、コマンドのコードや各種パラメータについてはSATURN Sound Driverサウンド組み込みマニュアルを参照してください。
