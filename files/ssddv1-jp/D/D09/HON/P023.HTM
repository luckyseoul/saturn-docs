SD


    フォーマット　SD　[regexp]
    
説明          regexpにマッチするシンボルを削除します。


SA


    フォーマット　SA　name,expr
    
説明          シンボル名nameのシンボルを値exprで登録します。すでに同じ名前が登録されている
              場合は、値が更新されます。
    
              ●すべてのシンボル表示コマンドでは最大16384個がソート可能です。ソート付きのコ
                マンドでは16384個以上のシンボルを表示することはできませんが、SRコマンドだけ
                はシンボル数が16384個以上のときでも利用できます。

■マクロ操作

マクロは、任意個のステートメントを１つのコマンドとしてユーザ定義を可能にしたものです。マクロの実行は、マクロ名をコマンド名として他の組み込みコマンドと同様に行います。 引き数を持たせたい場合は、マクロ定義中に文字 '`' を用いて参照させます。仮引き数を記述する必要はありません。

MACRO


    フォーマット　MACRO　name
    
説明          名前nameのマクロを設定します。空行を入力することにより定義が終了します。


EXITM


    フォーマット　EXITM　expr
    
説明          マクロ展開中でのみ実行可能なコマンドです。exprの値が0ならば現在実行中のマクロ
              を抜け出します。


MLIST


    フォーマット　MLIST　[regexp]
    
説明          regexpにマッチするマクロ名とその内容を表示します。マクロ名の辞書順にソートして
              から表示します。
              regexp省略時には、文字列"*"が採用されます。
    
              ●ソート表示に関して、シンボル操作コマンドと同様の制限があります。


WM


    フォーマット　WM　[filename]
    
説明          現在登録されているマクロをファイルfilenameに書き出します。
