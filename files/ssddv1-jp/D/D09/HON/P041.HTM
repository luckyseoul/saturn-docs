6．使用上の制限事項

■SCSI割り込み上の問題

SSBugとサウンドボードとの通信は、SCSI (level 1 auto vector) により行われます。このため、長時間にわたってサウンドボード側が割り込みレベル1以上になった場合、「応答がありません」というダイアログが表示されます。


このときサウンドボード側がハングアップしてしまうとSCSIバスを占有されたまま停止してしまうため、Macintosh側も動作が止まってしまいます。この結果、「応答がありません」のダイアログを表示しようしてウィンドウを開くものの、SCSIバスが占有されているためリソースを読み込むことができず、内容がないウィンドウが表示されたまま停止するという状況になります。
このような場合は、次のいずれかを行ってSCSIバスがいったん解放されるのを待ってから、再実行するなどしてください。

  • サウンドボードをリセットする
  • メイン側からブレークを上げる

■SSBugがフックするベクタ

SSBugが使用する(ユーザ実行時に書き換える)例外ベクタは、次のとおりです。 
    reset
bus error
address error
illegal instruction
zero divide
chk instruction
trapv instruction
privillege violation
trace
uninitialized interrupt
spurious interrupt
level 1 auto vector
level 7 auto vector
これらのベクタを動的に書き換えたり実行時に参照するプログラムは、SSBug下での動作が保証されません。ただし、静的にベクタテーブルを持っているものは問題ありません。
