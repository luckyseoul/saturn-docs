RM


    フォーマット　RM　[filename]
    
説明          ファイルfilenameからマクロ定義を読み込みます。
    
[例]        　引数の記述と展開例は次のとおりです。
              n番目のマクロ引数はマクロ定義中で"`n"のように記述します。ただし、nは文字[0-9]です。
              マクロ定義
                  MACRO　wordwrite
                  mew　`0,`1
              コマンド入力
                  wordwrite　100,123
              展開結果
                  mew　100,123

■バッチジョブ

バッチジョブとは、任意個のステートメントが記述されたファイルを読み込み、実行することです。このファイルをバッチファイルと呼びます。

BA


    フォーマット　BA　[filename]
    
説明          バッチファイルfilenameを実行します。
              コマンドRMとBAは実際は同じものです。バッチファイル中でマクロ定義を行うことも、
              マクロファイル中で他のステートメントを実行することもできます。

■スタートアップファイル

スタートアップファイルとは、SSBugの起動時に自動的に実行されるバッチファイルのことです。SSBugは、起動時のワーキングディレクトリにSSBug Startupという名前のTEXTファイルがあると、スタートアップファイルとみなして実行します。

■その他

HELP


    フォーマット　HELP
    
説明          ヘルプウインドウを開きます。


VERSION


    フォーマット　VERSION
    
説明          SSBug本体、ターゲットプログラム、SCSPのバージョンを表示します。


MEMFREE


    フォーマット　MEMFREE
    
説明          マクロ、シンボル、バッチ等に利用可能なメモリ残量を表示します。
