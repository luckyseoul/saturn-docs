2．セットアップ

■動作環境

実行に必要な環境は以下のとおりです。
  • Apple Macintosh コンピュータ(SCSIインターフェイス搭載機種)および漢字Talk7またはSystem7以降のMacOS
  • サターン開発システム(サウンドボードのみでも動作可能)

SSBugは、漢字Talk7等の日本語環境(正確には日本語スクリプトが動作している環境)を判別し、日本語が使用可能なときは日本語表示を、そうでないときは英語表示を行いますので英語システムでも十分動作します。

■セットアップ

Macintoshとの接続はサウンド開発マニュアルを参照してください。SSBugを使用するだけなら、SCSIの接続のみでかまいません。また、SSBugはサウンドボードのSCSI IDを自動判別しますので、SSBug側のSCSIに関する設定は必要ありません。

■インストール

SSBugは以下の4つのファイルによって提供されます。

それぞれのファイルの内容は以下のとおりです。

  • SSBug - Macintosh側のデバッガプログラム本体です。
  • SSBug Target Code - サウンドボード側のデバッガプログラムです。
  • SSBug Startup - 後述するスタートアップファイルのサンプルです。
  • SSBug/ReadMe - SSBugに関する最新情報が書かれています。

インストールは、次のように行います。

  1. ファイルSSBug Target Codeを起動ディスクのシステムフォルダにドラッグしてコピーします。

  2. 残りのファイルを任意の場所にドラッグしてコピーします。
    これでインストールは完了です。Macintoshを再起動する必要はありません。
