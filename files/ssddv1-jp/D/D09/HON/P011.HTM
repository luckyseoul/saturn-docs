SCOPE


    フォーマット　SCOPE  [arg]
    
説明          SSBugユーザプログラム実行中のCPUレジスタの状態を、定期的にレジスタウイン
              ドウに表示することができます。SCOPEコマンドによりこの設定を行います。
              argには次の文字列を指定します。
                ON　    表示をONにする
                OFF     表示をOFFにする
                省略時　現在の設定状態を表示する


■レジスタ操作


X


    フォーマット　X
    
説明          CPUレジスタの値を一覧にします。



X


    フォーマット　X  reg,expr
    
説明          CPUレジスタregに、値exprを設定します。
              このコマンドでは、レジスタ名にピリオドをつけません。


■メモリ操作


D, DB, DW, DL


    フォーマット　D   [range]
              DB　 [range]
              DW　 [range]
              DL　 [range]
    
説明          指定されたアドレス範囲rangeをダンプ表示します。
              DB DW DLコマンドはそれぞれバイト表示、ワード表示、ロングワード表示となり、
              デフォルト表示サイズをバイト、ワード、ロングワードに変更します。
              Dコマンドはデフォルト表示サイズで表示します。
              なおSSBugでは、奇数アドレスからのワード、ロングワード表示も可能になっていま
              す。
              rangeはfromとtoのいずれも省略可能です。fromが省略されたときは前回D、DB、DW、
              DLのいずれかのコマンドが終了した次のアドレスとなります。toが省略されたときは
              from+$7Fとなります。


F, FB, FW, FL


    フォーマット　F   range,expr
              FB   range,expr
              FW   range,expr
              FL   range,expr
    
説明         アドレス範囲rangeをデータexprでフィルします。フィルとは埋め尽くすことです。
             FB FW FL
             コマンドはそれぞれバイト、ワード、ロングワード操作となり、デフォルトフィルサ
             イズをバイト、ワード、ロングワードに変更します。
             Ｆコマンドはデフォルトフィルサイズでフィルを実行します。
