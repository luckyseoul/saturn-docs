HBC


    フォーマット　HBC　bpnum
    
説明          チャンネルbpnumのハードウェアブレークを解除します。
              bpnumに文字'*'を指定すると、全チャンネルが解除されます。


HBE


    フォーマット　HBE　bpnum
    
説明          チャンネルbpnumのハードウェアブレークを有効にします。
              bpnumに文字'*'を指定すると、全チャンネルが有効になります。
    
              ●HBEコマンドは、設定内容に関知せずにブレークを有効にします。
              ●ハードウェアブレークのパスカウントは、ユーザ実行再開ごとに初期化されます。

■アクセスブレーク

アクセスブレークは、4Kbyteごとの全CPU空間に対して読み書きまたは読み込みが可能かどうかを設定し、外部ハードウェアの監視によってこの設定に違反するバスサイクルを検出するものです。
ハードウェアブレークと同様、ブレーク発生時には該当バスサイクルは終了している点にご注意ください。

MAP


    フォーマット　MAP
    
説明          アクセスブレークの設定状況の一覧を表示します。


MAP


    フォーマット　MAP　range, acc
    
説明          アドレス範囲rangeに、アクセスブレーク条件accを設定します。
              accは、次のいずれかの文字列を指定します。
    
              RW　読み書き可能
              RO　読み込み専用、書き込みアクセスでブレーク発生
              NO　読み書き不可、任意のアクセスでブレーク発生
    
              なお、rangeが4Kバイト境界にない場合はまるめ込まれます。
    
              ●通常の使用では、ユーザプログラムで用いるエリア以外に以下のエリアもRWとし
                て設定してください。
    
                $600000-$67FFFF　(ROM実装エリア)
                $800000-$82BFFF　(エミュレータ部実装エリア)
                $A00000-$A00FFF　(MB89352A実装エリア)
                $E00000-$E07FFF　(デバッガエリア)
                $F00000-$FFFFFF　(サウンドツール使用エリア　ただしサウンドツールと共存する場合のみ)
    
              付属のスタートアップファイルSSBug Startupに、この設定が書かれています。参考にしてく
              ださい。
