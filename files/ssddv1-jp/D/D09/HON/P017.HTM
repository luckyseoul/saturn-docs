                   maskは後述します。省略値は0です。
               cntは1から65535まで指定できます。省略すると1になります。
               ＜fc＞には次のいずれかの文字列を指定します。省略時には、任意のモード
               になります。
    
                    user 　(ユーザモードアクセス)
                    super　(スーパバイザモードアクセス)
                    data 　(データアクセス)
                    prog 　(プログラムアクセス)
                    ud 　　(ユーザデータアクセス)
                    up 　　(ユーザプログラムアクセス)
                    sd 　　(スーパバイザデータアクセス)
                    sp 　　(スーパバイザプログラムアクセス)
    
               ＜ds＞には次のいずれかの文字列を指定します。省略時には、任意のバス幅
               となります。
    
                    low　　(下位バイトアクセス、奇数アドレス)
                    high 　(上位バイトアクセス、偶数アドレス)
                    word 　(ワードアクセス)
    
               ＜rw＞には次のいずれかの文字列を指定します。省略時には読み書き両方が
               対象になります。
    
                    read 　(読み込みアクセス)
                    write　(書き込みアクセス)
    
               マスクとは、一般のICE等での不定ビット(Don't care ビット)に相当するも
               ので、マスクが1になっているビットはアドレスの比較の際に無視されます。
    
               たとえば、アドレスに$1000を指定してマスクに$00FFを指定した場合、実際
               にブレークが発生するアドレスは$1000から$10FFまでの任意のアドレスとな
               ります。


HB


    フォーマット　HB 　bpnum, adr,[mask],[cnt],PF
    
説明          プログラムフェッチに対してブレークをかけたい場合は、このように
              cntの後ろに文字列"PF"を書くと面倒な指定を省くことができます。
    
              ●この場合は、ユーザモードとスーパーバイザモードの両方が対象となります。


HB


    フォーマット　HB 　bpnum, [level],[cnt],IA
    
説明          割り込みアクナリッジサイクルに対してブレークをかけたい場合は、このように
              cntの後ろに文字列"IA"を書いて指定できます。levelには割り込みレベルを指
              定します。省略時にはDon't careとなります。
    
              ●Don't careおよびlevel1、level7は指定しないでください。
