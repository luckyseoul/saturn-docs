8.2.4 CD-ROMデバイス

Title
関数仕様
Function
CDデバイスの接続先の設定
Function Name［SR］
CDC_CdSetCon
No
4.1
 

書式　　　　Sint32　CDC_CdSetCon(Sint32 filtno)
入力　　　　filtno：接続先絞り番号(CDC_NUL_SEL：切り離しを示す)
出力　　　　なし
関数値　　　エラーコードを返します。
終了フラグ　ESELフラグ
機能　　　　CD-ROMデバイスの接続先(絞り)を設定します。CDC_NUL_SELを指定すると、接続を切り離し
　　　　　　ます。

Title
関数仕様
Function
CDデバイスの接続先の取得
Function Name［S-］
CDC_CdGetCon
No
4.2
 

書式　　　　Sint32　CDC_CdGetCon(Sint32 *filtno)
入力　　　　なし
出力　　　　filtno：接続先絞り番号(CDC_NUL_SEL：未接続を示す)
関数値　　　エラーコードを返します。
機能　　　　CD-ROMデバイスの接続先(絞り)を取得します。未接続の場合はCDC_NUL_SELを返します。

Title
関数仕様
Function
最終リードセクタのバッファ区画の取得
Function Name［S-］
CDC_CdGetLastBuf
No
4.3
 

書式　　　　Sint32　CDC_CdGetLastBuf(Sint32 *bufno)
入力　　　　なし
出力　　　　bufno：格納先バッファ区画番号(CDC_NUL_SEL：未格納を示す)
関数値　　　エラーコードを返します。
機能　　　　CD-ROMから最後にリードされたセクタの格納先のバッファ区画番号を取得します。バッファ
　　　　　　区画に格納されなかった(消去された)場合はCDC_NUL_SELを返します。
備考　　　　割り込み要因レジスタのCSCTフラグに同期して実行することにより、CD-ROMから読み込んだ
　　　　　　ストリームを1セクタずつ処理することができます。
