ステータスの取得
 
Function Name
BUP_Stat
 
No
4
 

書式　　Sint32　BUP_Stat(Uint32 device,Uint32 datasize,BupStat *stat)
入力　　device：装置番号
　　　　　　　　０：内蔵メモリ
　　　　　　　　１：メモリカートリッジorパラレルインタフェース
　　　　　　　　２：シリアルインタフェース
　　　　datasize：書き込みたいデータのサイズを単位で指定
出力　　stat：ステータス情報
関数値　装置の状態を返す
　　　　０：成功
　　　　BUP_NON：未接続
　　　　BUP_UNFORMAT：未フォーマット
機能　　ステータス情報を取得します。

Title
関数仕様
 
Function
データの書き込み
 
Function Name
BUP_Write
 
No
5
 

書式　　Sint32　BUP_Write(Uint32 device,BupDir *dir,Uint8 *data,Uint8 owsw)
入力　　device：装置番号
　　　　　　　　０：内蔵メモリ
　　　　　　　　１：メモリカートリッジorパラレルインタフェース
　　　　　　　　２：シリアルインタフェース
　　　　dir   ：ファイル管理情報(dir.blocksize以外の入力)
　　　　data  ：書き込みデータのポインタ
　　　　owsw  ：オーバーライトチェックモード
　　　　ON    ：同名のファイルが存在したら書き込まない。
　　　　OFF   ：同名のファイルが存在したら上書きする。
出力　　なし
関数値　0                ：成功
　　　　BUP_NON          ：未接続
　　　　BUP_UNFORMAT     ：未フォーマット
　　　　BUP_WRITE_PROTECT：ライトプロテクト有り
　　　　BUP_FOUND        ：同名のファイルが存在する。
　　　　他               ：失敗
機能　　バックアップ記憶装置へデータを書き込む
