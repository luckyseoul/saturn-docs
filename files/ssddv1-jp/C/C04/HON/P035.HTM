イントバック初期化
 
Function Name
PER_Init
 
No
14
 

書式　　Uint32 PER_Init(PerKind kind, PerNum num, PerId id, PerSize size,
　　　　                                                   Uint32 work[n], Uint8 v_blank)
入力　　kind：イントバック種別
　　　　num：必要ペリフェラル数
　　　　id：ペリフェラルID
　　　　size：ペリフェラルサイズ
　　　　work：ワーク領域(ペリフェラルデータ取得に使用します。必ずグローバル変数で宣言してください)
　　　　v_blank：V-BLANKスキップ数

　　　　　・ワーク領域の計算方法

　　　　　　　n＝(num×データA)/4＋データB
　　　　　　　　切り上げ

　　　　　　データＡ、データＢはペリフェラルによって変化します。

出力　　なし
関数値　実行状態

      定  数

      説  明

      PER_INT_ERR
      イントバックコマンド発行ができませんでした。
      		 
      PER_INT_OK
      イントバックコマンド発行ができました。
      		 

機能　　イントバックの初期化とイントバックコマンド発行を行います。必ず実行規則を守ってください。
　　　　必要のないパラメータには、NULLか０を設定してください。
　　　　PER_GetPer(), PER_GetTim(), PER_GetSys()実行の前に1回以上実行してください。
備考　　一般的にV-BLANK処理直後に実行してください。SMPC割り込み中は他の割り込みを禁止しています。
注意　　この関数は割り込み処理内で行わないようにしてください。必ずメイン処理で行ってください。
