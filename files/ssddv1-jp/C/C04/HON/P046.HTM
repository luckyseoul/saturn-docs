データの読み込み
 
Function Name
BUP_Read
 
No
6
 

書式　　Sint32　BUP_Read(Uint32 device, Uint8 *fname,Uint8 *data)
入力　　device：装置番号
　　　　　　　　０：内蔵メモリ
　　　　　　　　１：メモリカートリッジorパラレルインタフェース
　　　　　　　　２：シリアルインタフェース
　　　　fname ：ファイル名の指定(必ずアスキーで11文字必要)
出力　　data  ：読み込み先バッファのポインタ
関数値　0            ：成功
　　　　BUP_NON      ：未接続
　　　　BUP_UNFORMAT ：未フォーマット
　　　　BUP_NOT_FOUND：ファイルが見つからない
　　　　BUP_BROKEN   ：ファイルがこわれている
　　　　他           ：失敗
機能　　バックアップ記憶装置からデータを読み込む。

書式　　Sint32　BUP_Delete(Uint32 device, Uint8 *fname)
入力　　device：装置番号
