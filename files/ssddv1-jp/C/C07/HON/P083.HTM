デバッグサポートライブラリ

1．ガイド

1.1　目的

　開発中のシステムにこのライブラリを組込むことにより、画面上に文字列を表示したり、ソフトウェアキーボードによるデータ入力、メモリ内容の読み書きができます。

1.2　解説

  • 本ライブラリは、VDP2グラフィックライブラリを使用して、ノーマルスクロール画面のNBG0を上に簡易デバッグ環境を構築します。VDP2グラフィックライブラリを使用しなければ本ライブラリを使用することはできません。
  • 本ライブラリは、専用パッドのみに対応しています。ペリフェラルライブラリを使用しなければ本ライブラリを使用することはできません。

1.3　プログラム記述例

　C言語による実際のプログラム例を以下に示します。

#include          "sega_scl.h"
#include          "sega_dbg.h"



void   err(Uint8 *mess);
Uint16 PadData;

main()
{
          SCL_Vdp2Init();
          DBG_Initial(&PadData,RGB16_COLOR(31,31,31),0);

          ..........          /*     プログラム     */

          if(......)     
                    err("main()の～関数でエラーがでました");
          ..........          /*     プログラム     */



}

void err(Uint8 *mess)
{
          DBG_Printf("%s\n",mess);　 /*     メッセージを表示する       */
          DBG_Monitor();　　　　　　　/*     簡易デバッグ環境にする     */

}
