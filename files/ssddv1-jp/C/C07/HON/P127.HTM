Function
再生開始
Function Name
PCM_Start
No
3.1
 

書式　　　　void　PCM_Start(PcmHn pcm)
入力　　　　pcm：ハンドル
出力　　　　なし
関数値　　　なし
機能　　　　再生を開始します。
備考　　　　再生は、生成されたハンドルに対して1回だけできます。
　　　　　　同じファイルを何度も繰り返し再生したい場合は、その都度ハンドルを生成してください。
