SCU関数登録
Function name
INT_SetScuFunc
No
9
 

書式　　　　void INT_SetScuFunc(Uint32 num, viod* hdr)
入力　　　　num：ベクタ番号(SCUベクタ番号のみ指定可能)
　　　　　　   ：SCU関数アドレス
出力　　　　なし
関数値　　　なし
機能　　　　指定されたベクタ番号のSCU割り込み関数へSCU関数アドレスを登録します。登録したSCU
　　　　　　関数はSCU割り込み発生時に実行されます。指定された割り込みルーチンアドレスがNULL
　　　　　　の場合は、SCUダミー関数を登録します。SCUダミー関数はリターン処理のみ行う関数です。
備考　　　　本関数は、マスタSH2のみ使用可能です。マスタSH2でこの関数を実行してください。INT_
　　　　　　SetFuncで割り込み関数を登録した場合、そのベクタのSCU割り込みルーチンは無効となり、
　　　　　　登録関数は呼び出されません。
