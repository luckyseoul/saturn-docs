7.1　初期化

Title
関数仕様
Function
ストリームシステム初期化
Function Name
STM＿Init
No
1.1
 

    書式　　　　Bool STM_Init(Sint32 grp_open_max, Sint32 stm_open_max, void *work)
入力　　　　grp_open_max：同時に開くストリームグループの最大数(1から24まで)
　　　　　　stm_open_max：同時に開くストリームの最大数(1から24まで)
　　　　　　work        ：作業領域
出力　　　　なし
関数値　　　TRUE ：正常に初期化できた場合
　　　　　　FALSE：正常に初期化できない場合
機能　　　　プログラム起動直後、ストリームシステムを使用する為の初期化を行います。
備考　　　　(ａ)必ず、GFS_Initの直後に行わなければなりません。GFS_Initで指定する、同
　　　　　　　　時に開くファイルの最大数(open_max)はstm_open_max以上にしてください。
　　　　　　(ｂ)作業領域の大きさは、STM_WORK_SIZE(grp_open_max,stm_open_max)バイト
　　　　　　　　により求めます。workは４バイト境界に配置してください。
