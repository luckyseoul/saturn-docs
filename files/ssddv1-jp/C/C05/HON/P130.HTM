Function Name
MPG＿MvSetTermCond
No
2.3
 

    書式　　　　void　MPG_MvSetTermCond(MpgMv mpgmv, Sint32 vcnd, Sint32 acnd)
入力　　　　mpgmv：MPEG動画ハンドル
　　　　　　vcnd ：MPEGビデオストリームの終了条件
　　　　　　acnd ：MPEGオーディオストリームの終了条件
出力　　　　なし
関数値　　　なし
機能　　　　各ストリームの転送終了条件を設定します。以下の値の論理和を取ることができ
　　　　　　ます。

        (1) MPEGストリームの終了条件(ビデオ／オーディオ共通)

        • MPG_TCND_EOR ：EORビットの立っているセクタを転送したとき

        • MPG_TCND_SEC ：ストリーム中にシステムエンドコードが現れたとき

        • MPG_TCND_NONE：終了条件を設定しない

    書式　　　　void　MPG_MvSetVideoDest(MpgMv mpgmv, Sint32 dst)
入力　　　　mpgmv：MPEG動画ハンドル
　　　　　　dst  ：出力先
出力　　　　なし
関数値　　　なし
機能　　　　動画の出力先を設定します。

        (1)出力先

        • MPG_OUTDST_DRCT：VDP2直接出力
