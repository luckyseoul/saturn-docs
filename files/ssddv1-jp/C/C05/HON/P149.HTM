Function Name
MPG＿WnSetLumiKey
No
4.16
 

    書式　　　　void　MPG_WnSetLumiKey(MpgWn mpgwn, Sint32 y_lvl, Bool bdr)
入力　　　　mpgwn：MPEGウィンドウ
　　　　　　y_lvl：輝度信号のレベル(0：通常、1：64、2：96、3：128)
　　　　　　bdr  ：透明領域を拡大するか否か(ON：拡大、OFF：通常)
出力　　　　なし
関数値　　　なし
機能　　　　ルミネッセンスキー処理を行うか否かを設定します。ルミネッセンスキー処理と
　　　　　　は、y_lvl 以下の輝度の画素を透明にする処理です。
　　　　　　bdrの指定によって透明領域を拡大するか否かを指定できます。
