Function Name
STM＿GetSctInfo
No
5.2
 

    書式　　　　Bool STM_GetSctInfo(StmHn stm, Sint32 spos, StmSct *sinfo)
入力　　　　stm ：ストリームハンドル

No
6.2

入力　　　　stm：ストリームハンドル
