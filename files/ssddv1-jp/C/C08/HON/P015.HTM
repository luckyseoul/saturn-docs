4.2　コマンドの詳細

    サウンドコントロールコマンドは再生するサウンドの種類によって下記の4種類があります。各コマンドがどの再生に関連するかはコマンド名称欄に ( S P C ) で記述してあります。

    S:	シーケンス再生に対するコマンド、またはシーケンス再生に関連するコマンド
P:	PCMストリーム再生に対するコマンド、またはPCMストリーム再生に関連する
	コマンド
C:	CD-DA再生に対するコマンド、またはCD-DA再生に関連するコマンド
S/P/C:	上記の全て(またはいくつか)に関わるコマンド、その他

    また、各パラメータの詳細は「4.2.1　各パラメータの説明」にありますので併せて参照してください。
