7.2　68000エラーステータスビットマップの詳細

ビット位置
エラー内容
bit31
68K CPU address error
bit30
68K CPU bass error
bit29
68K CPU 例外処理
bit28-bit24
reserved
bit23
Effect change時、指定DSP用RAM領域が不正。
bit22
Effect change番号が不正。
bit21-bit17
reserved
bit16
Note-on実行時にKey Spritによる発音すべきLayerが存在しない。
bit15
reserved
bit14
未定義MIDI Control change Number input
bit13
Effect change時、該当DSP用RAM領域が不足。
bit12
Effect change時、該当DSP用RAM設定値が不正。
bit11
Effect change時、該当DSP用RAMがMap内に存在しない。
bit10
Effect change時、該当DSP Programがダウンロードされていない。
bit9
Effect change時、該当DSP ProgramがMap内に存在しない。
bit8
シーケンススタート時、該当シーケンスバンクがダウンロードされていない。
bit7
シーケンススタート時、該当シーケンスソング番号がシーケンスバンク内に存在しない。
bit6
シーケンススタート時、該当シーケンスバンクがMap内に存在しない。
bit5
MIDI Prg change時、該当プログラム番号が音色バンク内に存在しない。
bit4
MIDI Prg change時、該当管理番号& MIDI channelの音色バンクが設定されていない。
bit3
MIDI Control change（mixer change）時該当管理番号& MIDI channelの音色バンクが設定され
ていない。
bit2
Mixer change時、または音色バンクチェンジ時、該当音色バンクがMap内に存在しない。
または音色バンクがダウンロードされていない。
bit1
Map change時、該当マップが（A000h～）に存在しない。
bit0
Mixer change時、該当Mixerが音色バンク内に存在しない。または音色バンクが設定されて
いない。
 

    注意：bit24-31は自動的にクリアされませんので必要に応じてホスト側でクリアしてください。
　　　bit0-23は次の正常動作で自動的にクリアされます。
