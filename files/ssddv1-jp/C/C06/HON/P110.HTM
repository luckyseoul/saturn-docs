データリード
 
Function Name
DSP_ReadData
 
No
3
 

    書式　　　　void DSP_ReadData(Uint32 *dst, Uint8 src, Uint16 count)
入力　　　　dst  ：DSPデータ格納アドレス
　　　　　　src  ：DSPデータRAM内のアドレス
　　　　　　count：転送回数（ロングワード単位）
出力　　　　なし
関数値　　　なし
機能　　　　指定されたDSPデータRAMアドレスのデータを転送回数分（ロングワード単位)、
　　　　　　DSPデータ格納アドレスへ転送します。DPSデータRAMアドレスはRAMページ選択
　　　　　　フラグを含めた8bitで指定してください。
