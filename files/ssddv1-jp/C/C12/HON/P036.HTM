    一般的に各コマンド行は以下のような構造を持ちます。
    ＜コマンド行＞ ::=　＜キーワード＞ ＜パラメータリスト＞ [CR].

    キーワードやパラメータなどの各語句(トークン)は１つ以上の空白で区切られます。
    ここでいう空白とは以下を意味します。
    ・スペースコード(0x20)
    ・水平タブコード(0x09)
    ・垂直タブコード(0x0b)
    ・ホームフィード(0x0c)
    ・ラインフィード(0x0a)
    また、各コマンド行は改行コード(0x0d)で１つのコマンド行を構成します。

    以下に各コマンド行の定義を示します。
    ＜＞で囲まれていない単語は実際に入力する予約語やオペレータを意味します。
    [CR]は改行コード(0x0d)を示します。[SPACE]は空白(0x20)を示します。
    ＜ａ１文字＞、＜ｄ１文字＞の正確な定義は規格書「JIS X 0606」を参照してください。
    制限事項として、
    　　＜ｄ１文字＞ ::= ＜シフトJIS文字＞
    　　＜ａ１文字＞ ::= ＜シフトJIS文字＞
    とします。
    その他制限事項は別途説明します。

    ＜Disc行＞ ::= Disc ＜出力ファイル名＞ [CR]
    ＜EndDisc行＞ ::= EndDisc [CR]
    ＜LeadIn行＞ ::= LeadIn ＜トラックタイプ＞[CR]
    ＜EndLeadIn行＞ ::= EndLeadIn [CR]
    ＜Session行＞ ::= Session ＜ディスクタイプ＞ ＜出力ファイル名＞opt [CR]
    ＜EndSession行＞ ::= EndSession [CR]
    ＜LeadOut行＞ ::= LeadOut ＜トラックタイプ＞ [CR]
    ＜EndLeadOut行＞ ::= EndLeadOut [CR]
    ＜CatalogNo行＞ ::= CatalogNo ＜数字列＞ [CR]
    ＜Track行＞ ::= Track ＜トラックタイプ＞ [CR]
    ＜EndTrack行＞ ::= EndTrack [CR]
    ＜Volume行＞ ::= Volume ＜ボリュームタイプ＞ ＜出力ファイル名＞ [CR]
    ＜EndVolume行＞ ::= EndVolume [CR]
    ＜SystemArea行＞ ::= SystemArea ＜MS-DOSファイル名＞ [CR]
    ＜PrimaryVolume行＞ ::= PrimaryVolume ＜相対時間＞ [CR]
    ＜EndPrimaryVolume行＞ ::= EndPrimaryVolume [CR]
    ＜SupplementaryVolume行＞ ::= SupplementaryVolume ＜相対時間＞ [CR]
    ＜EndSupplementaryVolume行＞ ::= EndSupplementaryVolume [CR]
    ＜BootRecord行＞ ::= BootRecord ＜相対時間＞ [CR]
    ＜EndBootRecord行＞ ::= EndBootRecord [CR]
    ＜Pause行＞ ::= Pause ＜ブロック数＞ [CR]
    ＜PreGap行＞ ::= PreGap ＜ブロック数＞ [CR]
    ＜PostGap行＞ ::= PostGap ＜ブロック数＞ [CR]
    ＜Empty行＞ ::= Empty ＜ブロック数＞ [CR]
    ＜Directory行＞ ::= Directory ＜ディレクトリ名＞ [CR]
    ＜EndDirectory行＞ ::= EndDirectory [CR]
