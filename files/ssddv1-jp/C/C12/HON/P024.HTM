第3章　データの作成

    データをCD上にどのように配置するかということは、「スクリプト」というものを用いて表現します。この章では、このスクリプトについて説明します。
    スクリプトを保存してあるDOSファイルを「スクリプトファイル」と呼びます。
    スクリプトファイルはバーチャルCDエミュレータの前処理プログラム(VCDPRE.EXE, VCDBUILD.EXE,VCDUTL.EXE)で参照され、処理されます。
    スクリプトは、主にアルファベットと数字で記述される「コマンド行」の集まりです。
    コマンド行はキーワードと、それに続く０個以上のパラメータから成ってます。
    キーワードによって必要とするパラメータは異なり、複数のパラメータを持つキーワードのパラメータは、その順序が決まっています。また、それぞれのコマンド行は任意の位置に置くことはできず、キーワードによってスクリプト内の位置が決まっています。

    コマンドの使用方法は第3.1項でディスクの構成の決め方として説明します。コマンド行の形式的な表現を第3.2項に示します。またキーワードは、それが必要とするパラメーターと共に表1から表5に示します。コマンド行がどこに置けるかも、第3.2項で述べます。

3.1　ディスクの構成の決め方

■Defineの使用方法

    　　Define　　AB    ; Bの文字列をAとして定義します。
これを使用する場合、Aを[ ]で囲んで使用します。
　　File [A]        ; これはFile B となります。
　　File A          ; これはFile B とはなりません。File Aのままです。
Defineはスクリプトのどの行に記述されても受理され、これが定義された場所以降のスクリプトに
対して有効となります。

■Includeの使用方法

    　　Include "a.scr"　　; この場所に"a.scr"をインクルードします。
    Includeはどの行に記述されても受理されます。ただし、Includeは2階層まで
    (Includeしているファイルの中からIncludeすることまで)が有効となります。
