■コメントについて

    コメントは ; を使用します。; 以下、行末まで書かれた文字はコメントとなります。
    ISO9660ファイル名のバージョン番号をつけるための ;と区別するため、行の先頭以外は ; の前に空白文字がなければなりません。
      空白文字：
      ・スペースコード(0x20)
      ・水平タブコード(0x09)
      ・垂直タブコード(0x0b)
      ・ホームフィード(0x0c)
      ・ラインフィード(0x0a)
    例：
      ;		これはコメントです。行の先頭の場合、前に空白文字は必要ありません。
File A　;	これもコメントです。Aと; の間に空白文字が入っています。
File A;		Aと; の間に空白文字が入っていないとコメントとして認識しません。
    ディスクの構成を決めるコマンドのパラメータで指定するものの一部を次に説明しておきます。

    ●セッション内での相対位置
    ディスク上の位置は「セッション内での相対位置」で表します。セッション内での相対位置は分、秒、フレームの値をそれぞれの間を「:」(コロン)で区切って表し、LeadInが終了した直後の時間を00:00:00としたディスク上の位置を意味します。
    実際のディスクイメージ上ではセッションの位置に対応して、適当なアドレスに変換されます。

    ●ファイル内での相対位置
    ファイル内での位置を指定する場合は、ファイルの先頭からの相対位置で指定します。その形式は「分:秒:フレーム」です。つまりファイルの先頭は00:00:00になります。

    ●識別子
    ボリュームディスクリプタセットの定義中では、いくつかの識別子の指定を行います。
    プライマリボリュームディスクリプタでは、アルファベット(大文字)と数字及びアンダースコア文字の並びで表します。補助ボリュームディスクリプタでは漢字コードが使えることになっています。漢字コードを使用する場合は、使用するコード体系をディスクの使用者側と製作者側との協議によって決めることになります。

    ●日付
    日付は年(YY)、月(MM)、日(DD)をDD/MM/YYという形で表し、その後にスペースで区切って時刻をhh:mm:ss:cc:ggという形で指定します。ここでhhは時、mmは分、ssは秒、ccは１００分の１秒単位、ggはグリニッチ標準時(GMT)との差（15分単位）です。日本国内の場合、GMTとの時差が＋9時間ですからggは36となります。

    ●(ISO9660)ファイル名
    ISO9660ファイル名は、間にセミコロン(;)でつなげたファイル名とバージョン番号からなります。
