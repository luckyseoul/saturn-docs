■本バインダの構成

プログラマーズガイド

  • ソフトウェアシステムガイド

      開発ターゲットボックス、および、商品ゲーム実機で動作するプログラムを作るための基本的知識を説明します。

  • ソフトウェアライブラリガイド

      アプリケーションプログラムを短期間で開発するために、利用価値の高いプログラムを集めてライブラリ化しました。そのライブラリの動作環境と使用方法を説明します。ソフトウェアライブラリは、ゲーム開発に必要な機能を提供します。もちろん、ソフトウェアライブラリを使用せず、独自のプログラムを使用して頂くことも可能です。ソフトウェアライブラリの多くのライブラリは、ソースコードを開示します。
      このソースコードを利用することにより、本ゲーム機でのプログラミングを早く習得でき、またカスタマイズすることにより、開発するゲームの特徴にあうライブラリにすることもできます。

  • CDツールガイド

      CDを実際に作成しなくてもデバッグができるように、そのデバッグフェーズに合わせたツールを用意しました。そのツールの動作環境と使用方法を説明します。

ソフトウェアシステムガイド

  • BOOT ROMユーザーズマニュアル

      BOOT ROMの機能、アプリケーションのブートアップのしくみを説明します。

  • DISCフォーマット規格仕様書

      GAME-CDを作成するために必要な、守らなければいけない事項を説明します。

ソフトウェアライブラリガイド

  • システムライブラリユーザーズガイド

      • システムプログラム
      • SMPC I/F
      • CD通信I/F

      これらのライブラリは、それぞれのハードウェアを利用する時には、必ず使用しなければなりません。

  • プログラムライブラリユーザーズガイド１　CDライブラリ

      • ファイルシステムライブラリ
      • ストリームシステムライブラリ
      • MPEGライブラリ

      CDライブラリは、目的に応じてインテリジェントな関数からプリミティブな関数まで、使いわけることができます。インテリジェントな関数は、ゲームだけでなくいろいろなマルチメディアソフトにも、使いやすくなっています。
