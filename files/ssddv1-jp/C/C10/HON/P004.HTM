■フォントファイル

    本ゲーム機上で文字表示を行うためのビットマップフォントです。提供するフォントファイルには、8×16ドットで1バイトコードフォントと、16×16ドットで2バイトコードの漢字フォントがあります。

●フォントの仕様
    ・１バイトコードフォント　８×16ドット　ASCIIフォント
　　　　　　　　　　　　　　　　　　　　諸外国フォント
　　　　　　　　　　　　　　　　　　　　カタカナフォント
    
・２バイトコードフォント　16×16ドット　JIS第1水準漢字フォント
　　　　　　　　　　　　　　　　　　　　JIS第2水準漢字フォント
●提供ファイル一覧
    フォント
    フォントファイル
    備考

    Code table1
    ASCII＋カタカナフォント

    Code table2

    KANJI.FON

●ファイル形式
    ・ASCII.FON、KANA.FON
　先頭から16バイト単位でフォントデータが入っています。
　
    
・KANJI.FON
　JIS第1水準、第2水準漢字のフォントです。先頭から32バイト単位でフォント
　データが入っています。
