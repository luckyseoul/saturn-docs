4．基本機能プログラム

  • 基本機能プログラムはゲームシーケンスのプログラムセレクトからスクロールサンプル、スプライトサンプル、ウィンドウサンプル、ゲームサンプルとして選ばれることにより実行されます。最初にプログラムセレクトと同様の選択画面が表示されるので、十字ボタンで選択し、Cボタンで実行します。
  • スクロールサンプル、スプライトサンプル、ウィンドウサンプルのメニューには次の項目があります。このメニューには各自が作成したプログラムを簡単に組み込むことができるようになっています。
  • 各プログラムの内容はソースコードを参照してください。

スクロールサンプル

  1. BITMAP SCROLL
    点、線、箱を描く。(NBG0を使用、ビットマップ形式、RGB32768色モード)
  2. NORMAL SCROLL
    上下左右にスクロールをする。(NBG0を使用、セル形式、256色モード)
  3. LINE SCROLL
    縦横に揺れながらスクロールする。(NBG0を使用、セル形式、256色モード)
  4. MULTI SCROLL
    スクロールに優先順位(プライオリティー)を持たせて複数枚同時に表示する。
    (NBGO０～３を使用、各面セル形式、16色モード)
  5. LINE COLOR SAMPLE
    ラインごとに色演算をおこない、画面の中心に行くほど半透明の割合が低くなる。
  6. ROTATE SCROLL
    スクロールを縦横斜めに回転させる。(RBG0を使用、セル形式256色モード)
  7. 〈EXIT〉

スプライトサンプル

  1. POLYGON TEST
  2. POLYLINE TEST
  3. TEXTURE TEST
    ポリゴン、ポリライン、テクスチャを回転、拡大、縮小させる。
    (スプライト構造体の中身を変化させる)
  4. HENKEI TEST
    スプライトの辺を伸縮させる。(4点を定義し、その中のテクスチャを変形させる)
  5. LINE TEST
    色を変えながら画面内でラインを動かす。(4点の位置と移動速度を設定しその中のテクスチャを変形させていく)
  6. SHADOW TEST
    スプライト、ポリゴンを影にして表示する。(ノーマルシャドウMSBシャドウを表示し、スプライトは自動カラー演算をしながらフェードインフェードアウトする)
