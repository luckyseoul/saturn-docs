SMSL_ModeSel()　プログラムセレクト実行

　図６のようなプログラムセレクト画面を表示します。
　十字ボタンの上下で選択し、Cボタンでサンプル、ゲームなどのプログラムを実行します。
　プログラムが終了したら、ゲームモード変数をSELECT_MODEにしてリターンしますので、無条件にプログラムセレクト実行に移行します。
　また、〈EXIT〉が選択されたときは、ゲームモード変数をLOGO_MODEにしてリターンしますので、無条件にセガロゴ表示に移行します。

図６　デモ実行

　プログラムセレクトメニューには次のようなものがあります。

  1. SCROLL SAMPLE
  2. SPRITE SAMPLE
  3. WINDOW SAMPLE
  4. GAME SAMPLE
  5. EASY SOUND TEST
  6. 〈EXIT〉
