void *SMTA_MakeActionX(void *execadd, Uint8 start, Uint8 count)

    　配列のstart番目からcountの数だけ未使用のアクションをさがし、空きがあれば登録します。つまり範囲指定してアクションをセットするわけです。使い方としては、ショットのアクションなど、同じアクションが複数セットされる場合があげられます。配列の何番目から何番目に入っていることがわかればコリジョンを取ることも容易です。

void *SMTA_SetAction(void *execadd, Uint8 start)

    　配列のstart番目に強制的にアクションをセットします。使用中であろうがなかろうがセットします。
    　使い方としては、プレーヤーのアクションなど、一つしか存在しないアクションをセットする場合があげられます。

void SMTA_ActionLoop(void)

    　配列の先頭から最後までを順にサーチし、アクティブであるアクションを実行します。アクション構造体へのポインタを引き数として、アクションに渡します。

[マクロ]

SMTA_DefActWk( actname, member)

    　専用アクション構造体を宣言します。自由設定メンバの用途を指定することとなります。例は下のプログラムを参考にしてください。このマクロはあくまで構造体の宣言しかしません。アクション構造体の情報の使用用途を規定するものです。

SMTA_CheckAction(ACTWK *ptr)

    　アクションが登録できたとき真(1)、失敗したときに偽(0)の値を持つマクロです。使用法は例を参考にしてください。

    [例]
    　ACTWK *ptr;
    　ptr = SMTA_MakeActionX(ShotAct, 0, 8);
    　if (SMTA_CheckAction(ptr))
    　　　/* 登録Ok */
    　else
    　　　/* 登録失敗 */

SMTA_KillAction(ACTWK *ptr)

    　アクションをノンアクティブにするマクロです。idに0を書き込みます。
    通常はアクションの中で記述して、自らアクションをノンアクティブにします。次のactionloopからはそのアクションは実行されません。

    [例]
    　void PlayerAct(ACTWK *ix)
    　{
    　　　if (Deadflag)　/*　プレイヤーやられ　*/
    　　　　　SMTA_KillAction(ix);
    　}
