プログラムのロード・実行

デバッガを使って実行プログラムをICEにロード、実行するための方法を解説します。

注意
前項で説明した“PRESET”の様な初期化ファイルを使用しない場合は、【FILE】メニューの“HOST”を選択し「HOSTダイアログ」を開き、HOST NAME, USER NAME, PASSWORD を入力してください。また、デバッガのコマンドエリアに“rs [return] g [return]”と入力し、ターゲットのリセットを行ってください。

１）【FILE】メニューから［LOAD］→“PROGRAM FILE”を選択し、ファイル名をフルパスで入力します。

２）“LOAD”をクリックします。

これで実行プログラムがロードされました。

注意
USER の LOGIN SHELL にtcsh を使ってる場合、ホストマシンの /etc/shells ファイルに tcsh が登録されていないとFTP が動作できず、実行プログラムはロードされません。
詳しくは FTP に関する参考書籍等を見てください。

３）【EXECUTION】メニューから“GO”を選択します。

４）「GOダイアログボックス」で“START ADDRESS”の入力領域をクリックし、文字用カーソルを移動させ、同領域に“6004000”と入力します。次に、“START MODE”ボタンのプルダウンメニューから“order”を選択し、“Done”をクリックします。

これで実行プログラムが動き始めます。
