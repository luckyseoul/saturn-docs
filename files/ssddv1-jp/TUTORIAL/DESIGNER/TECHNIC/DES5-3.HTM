5-3. 面分割のためのエッジが引けないときの対策

５角形以上のポリゴンを３角形か４角形のポリゴンに分割しようとしたとき、【Mesh】→［Edge］でエッジが引けないことがよくあります。
そのとき、画面下に、
"Error : * Can not create an edge that intersects existing edges."
とエラーメッセージが表示されます。これは分割しようとするポリゴンがねじれているときに起こる現象です。どうしても「任意の２点を線で結びたい」という場合、どうすればよいのでしょうか？実際にどうすればよいのかを、以下に実例で示します。

前準備（ねじれポリゴンの作成）

【Get】→［Primitive］→［Grid］
でウィンドウが出たら、サイズを
X Cell Size：1.0
Z Cell Size：1.0
X Cell Count：1
Z Cell Count：1
にして、“Polygon”のところをチェックし、“OK”をクリックしてください。
下図のような１枚ポリゴンができます（図5-20）。

図5-20　１枚ポリゴンの作成

【Mesh】→［Vertex］→マウス中ボタン（Add middle vertex）
で、下図のように中点を打ってください（図5-21）。

図5-21　中点を打つ

次にOBJモードからTAGモードに変更してください（画面右下のウィンドウを直接クリックしてください）。 そして、下図の示す点にTAGをつけてください（図5-22）。（“T”キー＋マウス左ボタンで囲む）。

図5-22　TAGをつける

ここで、“Scale”アイコンの三角形部分をクリックして、数値入力のウィンドウを出します。そして、X：1、Y：1、Z：2を入力して、“Add”をクリックしてください（“Set”ではないので、注意してください）。すると下図のようになります（図5-23）。

図5-23　１枚ポリゴンの変形

TAGを外してください（“T”キー＋マウス中ボタンで囲む）。 次に、TAGモードのままで、さらに下図の示す点にTAGをつけます（図5-24）。

図5-24　TAGをつける

ここで、“Trans”のアイコンの三角形の部分をクリックして、数値入力のウィンドウを出してください。 <そして、X：0、Y：-0.2、Z：0を入力して、“Add”をクリックしてください（“Set”ではないので、注意）。 すると下図のようになります（図5-25）。

図5-25　ねじれたポリゴンの完成

TAGを外してください。（“T”キー＋マウス中ボタンで囲む）。
さて、これでねじれたポリゴンができました。ここで実験をしてみましょう。
下図（図5-26）で示した点Aと点Bを、
【Mesh】→［Edge］→マウス左ボタン
で結びます。（今後の便宜上、他の残りの点にも記号をつけてあります。）

図5-26　AB間をいきなり結ぶことはできない

おそらく結べずに、
"Error : * Can not create an edge that intersects existing edges."
とエラーメッセージが表示されたと思います。
しかし、どうしてもAB間を結びたいときは、どうしたらよいのでしょうか？
次の解決策その1、その2に進んでください。

解決策その１：端から三角形で切っていく方法

下図で示すBC間をエッジで結んでみてください（このポリゴンの場合、ここは結べます）（図5-27）。

図5-27　まずBC間を結ぶ

次に、いままで結べなかったAB間を、
【Mesh】→［Edge］→マウス左ボタン
で、２点をクリックしてみると…なんと！結ぶことができます。
ここで先に結んだBC間を
【Mesh】→［Edge］→マウス右ボタン
で、消してください。
このように目的の点（この場合、点Aか点B）を１つ含めた三角形をまず作ることによって、いままで引けなかった線が引けるようになるのです。
三角形を１つ作った程度ではうまくいかないときは、どんどん端から三角形を作ってみてください。

それでも、うまく行かない場合には、次の方法を試してみてください。

解決策その２：目的点を含まない２点から始める方法

目的点を含まない２点をまず結びます。
このポリゴンについては、結べる組み合わせはいくつかありますが、今回はCD間を結ぶことにします（図5-28）。

図5-28　CD間を結ぶ

次に線分CD上に、
【Mesh】→［Vertex］→マウス左ボタン（Add vertex）
で、適当に点を打ちます。これを点Gとします（図5-29）。

図5-29　点Gを打つ

そして、AG間を結びます。

図5-30　AG間を結ぶ

ここでGB間を結ぶことができれば完成に近づくのですが、今回のポリゴンではGB間に線を引くことはできません。
ここで、「解決策その１」で使った方法を思い出してください。
とりあえず三角形を作ります。ここではBC間が結べます（図5-31）。

図5-31　BC間が結ばれる

こうすると、なんと！GB間に線を引くことができるようになります。
GB間を線で結んだら、BC間の線は、
【Mesh】→［Edge］→マウス右ボタン（Remove edge）
で消去してください（図5-32）。

図5-32　GB間を結び、BC間を消去

続いて、線分CGとGDを、
【Mesh】→［Edge］→マウス右ボタン（Remove edge）
で消去してください（図5-33）。

図5-33　線分CGとGDを消去

さて、最後の仕上げです。
【Mesh】→［Vertex］→マウス右ボタン（Remove vertex）
で点Gを消去してください（図5-34）。

図5-34　点Gを消去

どうしても結ぶことのできない頂点間もこれらの方法でチャレンジしてみてください。
