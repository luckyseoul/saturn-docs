ペリフェラル制御関数

slSetPortMode1,2

ペリフェラルポート１・２のポートモードを設定

書式

Bool slSetPortMode1(mode)
Bool slSetPortMode2(mode) Uint8 mode;

パラメータ

mode      ペリフェラルポートのポートモード

機能

ペリフェラルポート１・２のポートモードを設定します。

戻り値

実行結果
      OK ... 成功
      NG ... 失敗

備考

セマフォの取得ができない（他プロセスにてロック中）時は、実行に失敗します。
パラメータには以下の値が使用できます。
SMPC_PORT_15...１５バイトモード（初期値）
SMPC_PORT_255..２５５バイトモード
SMPC_PORT_ZERO...０バイトモード

参照：HARDWARE MANUAL vol.1 (SMPC)
