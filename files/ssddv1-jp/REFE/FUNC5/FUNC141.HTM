ペリフェラル制御関数

slSetOptimize

ペリフェラル取得時間最適化モードを設定

書式

Bool slSetOptimize(mode)
Uint8 mode;

パラメータ

mode      ペリフェラル取得時間最適化モード

機能

ペリフェラル取得時間最適化モードを設定します。

戻り値

実行結果
      OK ... 成功
      NG ... 失敗

備考

セマフォの取得ができない（他プロセスにてロック中）時は、実行に失敗します。
パラメータには以下の値が使用できます。
SMPC_OPT_ENA..取得時間最適化許可（初期値）
SMPC_OPT_DIS...取得時間最適化禁止

参照：HARDWARE MANUAL vol.1 (SMPC)
