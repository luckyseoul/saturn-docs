Bool
システム管理関数

slResetDisable

リセットディスエーブル（ノーウエイトモード）

書式

Bool slResetDisable()

パラメータ

なし

機能

リセットボタンの押下によるシステムリセットを禁止します。

戻り値

実行結果
      OK ... 成功
      NG ... 失敗

備考

セマフォの取得ができない（他プロセスにてロック中）時は、実行に失敗します。
ＳＭＰＣのコマンド実行終了を待ちません。
インタラプトバックが発行されていたら、コマンドキャッシュにキューイングされます。
コマンドキャッシュオーバーフローの時は、実行に失敗します。

参照：HARDWARE MANUAL vol.1 (SMPC)
