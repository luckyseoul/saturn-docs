void
グラフィック関数

slLight

光源の設定

書式

void slLight(light)
VECTOR light ;

パラメータ

light　　光源ベクトル

機能

光源の設定を行います。
パラメータには、光源の方向を表すベクトル値（単位ベクトル）を代入してください。

戻り値

なし

備考

光源ベクトルは単位ベクトルで指定する必要があります。BR> 仮に、光源ベクトルの大きさが１を超えた場合、オーバーフローが発生し、ポリゴン面色は正しく描画されません。
また、カレントマトリクスにスケーリング操作が実行されている場合、ポリゴンの法線ベクトルもこの影響を受けるため、輝度もこれに伴って変化してしまいますから、注意が必要です。

参照：第３章　光源
