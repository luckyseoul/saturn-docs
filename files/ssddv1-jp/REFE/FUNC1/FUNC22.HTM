スクロール関数

slColRateNbg0,1,2,3

ＮＢＧのカラー演算割合セット

書式

void slColRateNbg0(rate)
void slColRateNbg1(rate)
void slColRateNbg2(rate)
void slColRateNbg3(rate)
Uint16 rate ;

パラメータ

rate カラー演算の割合

機能

各画面毎に、カラー演算で使用するカラー演算比率を設定します。

戻り値

なし

備考

パラメータに指定する演算比率の値は、0x00～0x1fです。
この値１つ１つが、演算比率を代表しており、例えば“rate=0x0f”を代入した場合、TOP画像と2ND画像の演算比率は、16：16になります。
代入値と演算比率の関係については、“HARDWARE MANUAL vol.2”の（VDP2ユーザーズマニュアル：Ｐ244）の表を参照してください。

参照：第８章　スクロール
