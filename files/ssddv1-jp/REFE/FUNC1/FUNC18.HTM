slColorCalcOn

カラー演算コントロールイネーブルセット

書式

void slColorCalcOn( flag )
Uint16 flag ;

パラメータ

flag カラー演算を行う画面を指定

機能

カラー演算コントロールの影響を受ける画面を設定します。
また、ｏｒ演算子“｜”を用いて複数のパラメータを連結し、複数面の同時設定も可能です。

戻り値

なし

備考

注）上表の値は、システム付属の“sl_def.h”で定義されています。
