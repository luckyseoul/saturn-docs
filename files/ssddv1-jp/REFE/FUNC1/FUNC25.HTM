void
スクロール関数

slDispCenterR

ＲＢＧの回転中心座標セット

書式

void slDispCenterR(x , y)
FIXED x ;
FIXED y ;

パラメータ

x          回転スクロール回転中心座標のＸ成分（画面座標系）
y          回転スクロール回転中心座標のＹ成分（画面座標系）

機能

回転スクロールの、回転中心座標を設定します。
回転中心座標とは、画面に対してどの位置を中心に、回転スクロールを回転させるかを決定するためのものです。

戻り値

なし

備考

回転スクロールの表示位置は、スクロールマップ上の配置座標に、回転中心座標を基準点としたモニターを配置することにより決定されます。
回転スクロールの配置座標決定には、関数“slLookR”を使用します。
回転と配置の関係は、下図を参照してください。

注）スクロール面のＺ軸は画面手前が正方向

参照：第８章　スクロール
