void
スクロール関数

slColRAMMode

カラーＲＡＭモードをセット

書式

void slColRAMMode(mode)
Uint16 mode ;

パラメータ

mode      カラーＲＡＭモードに対応したUint16型数値
          modeには“sl_def.h”で定義された次の値を代入してください
　　　　    CRM16_1024：カラーRAMモード0 
　　　　    CRM16_2048：カラーRAMモード1
　　　　    CRM32_1024：カラーRAMモード2

機能

カラーＲＡＭモードを決定します。
カラーRAMへのカラーデータの格納は、必ずカラーRAMモードを設定してから行ってください。
パラメータへはカラーＲＡＭモードに対応した値を代入してください。
各カラーRAMモードの詳細は下表を参照してください。

戻り値

なし

備考

カラーＲＡＭモードはデフォルトで、モード１に設定されています。
また、各モードは下表のような内容になっています。
カラーRAMモードの詳細は、“HARDWARE MANUAL vol.2”（VDP2ユーザーズマニュアル：Ｐ43）を参照してください。

注）モード０は、カラーＲＡＭを２分割しそれぞれに同じカラーデータを格納します。
