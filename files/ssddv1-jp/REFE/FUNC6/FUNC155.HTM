Sint8
サウンド関数

slPCMOn

ＰＣＭ音源による演奏開始

書式

Sint8 slPCMOn(Pdat , Data , Size)
PCM *Pdat ;
void *Data ;
Uint32 Size ;

パラメータ

Pdata     ＰＣＭ型構造体データ
Data      ＰＣＭデータテーブルのアドレス
Size      ＰＣＭデータテーブルのサイズ

機能

ＰＣＭ音源による音楽(効果音)の再生を行います。

戻り値

関数は、通常終了の場合０～７、コマンドバッファが足りない場合－１、ＰＣＭのチャンネルが空いていない場合－２、ＰＣＭ用のバッファが足りない場合－３を返します。

備考

ＰＣＭ型構造体については、別記の「構造体リファレンス」を参照してください。 この関数で開始されたＰＣＭ再生はデータ終了をもって停止します。

参照：第14章　サウンドライブラリ
