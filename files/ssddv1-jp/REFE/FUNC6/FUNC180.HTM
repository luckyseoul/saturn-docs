slCheckOnScreen

指定された座標が視野内にあるかを調べる

書式

FIXED slCheckOnScreen(pos , size)
FIXED *pos ;
FIXED size ;

パラメータ

pos[XYZ]  オブジェクトポジションを表すＸＹＺ座標値
size      オブジェクトサイズ

機能

指定されたオブジェクトのポジションをカレントマトリクスを通して変換し、その位置で指定されたサイズの物体が画面に表示されるかどうかをテストし、結果を返します。

戻り値

表示領域からＺ方向にはみ出している場合：
　　-1(FFFFFFFF)
上下左右にはみ出している場合：
　　-2(FFFFFFFE)
画面内に納まっている場合：
　　Z_position
