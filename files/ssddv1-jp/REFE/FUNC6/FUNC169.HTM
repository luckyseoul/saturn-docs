slSndMixChange

音色バンクに対応するミキサの切替え

書式

Bool slSndMixChange(Tbank , Mixno)
Uint8 Tbank ;
Uint8 Mixno ;

パラメータ

Tbank     トーンバンク番号
Mixno     ミキサ番号

機能

音色バンクに対応するミキサを切替えます。

戻り値

コマンドバッファに空きがない場合、関数は FALSE を返します。

備考

パラメータ "Tbank" には０から１５までの範囲を指定します。
パラメータ "Mixno" には０から１２７までの範囲を指定します。
