slDMACopy

CPUDMAを用いたブロック転送

書式

void slDMACopy(src , dst , cnt)
void *src ;
void *dst ;
Uint32 cnt ;

パラメータ

src       転送元メモリー領域の先頭アドレス
dst       転送先メモリー領域の先頭アドレス
cnt       ブロック転送量（バイト）

機能

CPUに内蔵されたDMAを使用してブロック転送を行います。
パラメータ“cnt”には、何バイト分転送するかを指定します。
キャッシュ領域への転送が行われた場合にキャッシュを初期化します。

戻り値

なし

備考

関数“slDMACopy”は、DMA起動後すぐに終了します。
転送完了を待つ場合は、関数“slDMAWait”を使用してください。
関数“slDMACopy”は、他にDMA転送が起動されている場合、その終了を待ってから、新たなDMA転送を起動します。
