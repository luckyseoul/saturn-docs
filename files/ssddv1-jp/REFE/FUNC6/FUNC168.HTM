サウンド関数

slSndMapChange

カレントサウンドマップ変更

書式

void *slSndMapChange(Map)
Uint8 Map ;

パラメータ

Map       マップナンバー

機能

カレントのサウンドマップを変更します。

戻り値

通常終了の場合には、関数はパラメータをセットしたコマンドバッファのアドレスを返します。
コマンドバッファに空きがない場合、関数は FALSE を返します。

備考

サウンドデータを転送後、ワーク領域の転送済みビットをセットしてください。
