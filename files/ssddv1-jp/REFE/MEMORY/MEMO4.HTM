4. VDP2 VRAMのメモリマップ

0x25E00000から始まるVDP2のVRAMはシステム初期化の際、以下の様に区分されています。

図4-1　VDP2 VRAMのメモリアップ

システム初期化の際の設定値：
キャラクタ・ジェネレータはどのスクロールも256色モードで、パターンネームは[１ワード/１セル]になっています。

NBG0は各セルごとに反転のフラグを持つ10ビットモードで、NBG0以外の面は反転を面ごとに使用する12ビットモードとなっています。

カラーRAMは16ビット2048色モードで、オフセットは使用していません。

バック面は単色で、25E3FFFEにカラーデータ(0000)を入れています。
