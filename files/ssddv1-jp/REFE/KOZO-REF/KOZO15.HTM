構造体

PerAnalog

アナログデバイス

構造

typedef   struct {
          Uint8     id;
          Uint8     ext;
          Uint16    data;
          Uint16    push;
          Uint16    pull;
          Uint8     x;
          Uint8     y;
          Uint8     z;
} PerAnalog;

メンバー

id        ペリフェラルＩＤ
ext       拡張データサイズ
data      ボタン現在データ
push      ボタン押下データ
pull      ボタン引上データ
x         Ｘ軸データ絶対値
y         Ｙ軸データ絶対値
z         Ｚ軸データ絶対値

解説

アナログデバイスを参照するための構造体です。

備考

システム変数“Smpc_Peripheral”を型キャストして、アナログデバイスとして参照する時に使用します。

参照：HARDWARE MANUAL vol.1 (SMPC)
