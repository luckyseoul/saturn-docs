構造体

PerPoint

ポインティングデバイス

構造

typedef   struct {
          Uint8     id;
          Uint8     ext;
          Uint16    data;
          Uint16    push;
          Uint16    pull;
          Uint16    x;
          Uint16    y;
} PerPoint;

メンバー

id        ペリフェラルＩＤ
ext       拡張データサイズ
data      ボタン現在データ
push      ボタン押下データ
pull      ボタン引上データ
x         Ｘ座標
y         Ｙ座標

解説

ポインティングデバイスを参照するための構造体です。

備考

システム変数“Smpc_Peripheral”を型キャストして、ポインティングデバイスとして参照する時に使用します。

参照：HARDWARE MANUAL vol.1 (SMPC)
