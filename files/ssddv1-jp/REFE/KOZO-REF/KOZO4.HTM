構造体

PICTURE

テクスチャー登録テーブル

構造

typedef   struct    {
                    Uint16 texno ;
                    Uint16 cmode ;
                    void *pcsrc ;
          } PICTURE ;

メンバー

texno     テクスチャー番号
cmode     カラーモード
pcsrc     登録されるテクスチャーデータの先頭アドレス

解説

テクスチャーデータを、VRAM中に転送・登録するための情報テーブルです。

備考

Programmer’s Tutorial“第7章:ポリゴンの面属性”の Texture を参照してください。
