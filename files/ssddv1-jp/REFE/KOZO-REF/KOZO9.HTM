構造体

SPRITE

スプライトデータ

構造

typedef   struct    {
                    Uint16 CTRL ;
                    Uint16 LINK ;
                    Uint16 PMOD ;
                    Uint16 COLR ;
                    Uint16 SRCA ;
                    Uint16 SIZE ;
                    Uint16 XA ;
                    Uint16 YA ;
                    Uint16 XB ;
                    Uint16 YB ;
                    Uint16 XC ;
                    Uint16 YC ;
                    Uint16 XD ;
                    Uint16 YD ;
                    Uint16 GRDA ;
                    Uint16 DMMY ;
          } SPRITE ;

メンバー

CTRL      コントロールファンクション
LINK      リンクアドレス
PMOD      プットモード
COLR      カラーデータ
SRCA      ＣＧアドレス
SIZE      キャラクタサイズ
XA        表示位置ＡのＸ座標成分
YA　　　     〃　　Ｙ座標成分
XB        表示位置ＢのＸ座標成分
YB　　　     〃　　Ｙ座標成分
XC        表示位置ＣのＸ座標成分
YC　　　     〃　　Ｙ座標成分
XD        表示位置ＤのＸ座標成分
YD　　　     〃　　Ｙ座標成分
GRDA      グーローシェーディングテーブル
DMMY      サイズ合わせ用ダミーデータ

解説

VDP1に直接データを渡すためのデータ型で、スプライトを表示するためのデータテーブルを意味します。
スプライトのピクチャーデータは、事前にVRAM中に格納・登録しておく必要があります（テクスチャーデータ、スクロールデータも同様）。
詳細は、Programmer’s Tutorial “第7章：ポリゴンの面属性”のTextureを参照してください。

備考

セガサターンで使用するテクスチャとスプライトは、非常によく似たデータ構造を取っていますが、表示方法が次のように異なっています。 テクスチャー：ポリゴン表面に張り付けて表示 スプライト　：スプライト単独で表示

参照：第７章　ポリゴンの面属性
