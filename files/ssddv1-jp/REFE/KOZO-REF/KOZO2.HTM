構造体

EVENT

イベント管理

構造

typedef   struct    evnt {
                    WORK *work ;
                    struct evnt *next ;
                    struct evnt *before ;
                    void (*exad)() ;
                    Uint8 user[EVENT_SIZE - (sizeof(WORK *)
                                     + sizeof(struct evnt *) * 2 + sizeof(void (*)()))] ;
          } EVENT ;

メンバー

work      ワークエリアのポインタ
next      次のイベントの先頭アドレス
before    直前のイベントの先頭アドレス
(exad)()  関数の実行アドレス
user[]    ワークエリア

解説

イベント管理用テーブルを定義します。
メンバー“work”には、ライブラリ関数“slGetWork”で得られたアドレスをセットしてください。
デフォルトは“NULL”です。

備考

メンバー“user[]”中の、“EVENT_SIZE”は、128byteです。
そのため、user領域は、112byteとなります。
