マクロ

ATTRIBUTE

ポリゴン属性の指定

構造

#define   ATTRIBUTE(plane,sort,texture,color,gouraud,mode,dir, option)
                　　　　   {
                   　　　　 plane,(sort)｜(((dir)>>16)&0x01c)｜(option), 
                  　　　　  texture,(mode)｜(((dir)>>24)&0xc0,color, /
                   　　　　 gouraud,(dir)&0x03f
                 　　　　   }
                 Uint8 plane ;
                 Uint8 sort ;
                 Uint16 texture ;
                 Uint16 color ;
                 Uint16 gouraud ;
                 Uint16 mode ;
                 Uint32 dir ;
                 Uint16 option ;

メンバー

plane     表裏属性
sort      Ｚソート指定
texture   テクスチャー番号または、No_Texture
color      C_RGBマクロ指定色、カラーパレット番号または, No_Palet
gouraud   グーローテーブルまたは、No_Gouraud
mode      ポリゴンに対する各種モードの指定
dir       テクスチャーの表示方向などの指定
option    ポリゴンに対するその他設定

解説

ポリゴン描画に関わる面属性設定（特にポリゴン表面）を行います。
各パラメータの意味及び代入値の詳細については、 Programmer's Tutorial“第７章：ポリゴンの面属性”を参照してください。
また、構造体リファレンス巻末の“ATTRIBUTEマクロ代入値一覧”も、同時に参考にしてください。

備考

メンバ“color”は、テクスチャー使用の場合、カラーバンク番号を指定することもあります。

参照：第７章　ポリゴンの面属性
