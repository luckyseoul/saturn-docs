構造体

ATTR

面属性リスト

構造

typedef   struct    {
                    Uint8 flag ;
                    Uint8 sort ;
                    Uint16 texno ;
                    Uint16 atrb ;
                    Uint16 colno ;
                    Uint16 gstb ;
                    Uint16 dir ;
          } ATTR ;

メンバー

flag      表裏設定
sort      ソート設定
texno     テクスチャーナンバー
atrb      属性データ
colno     カラーナンバー
gstb      グーロー設定
dir       テクスチャー反転設定およびタイプ

解説

ポリゴンの面属性リストを定義します。

備考

面属性の詳細及び実際の使用法は、Programmer's Tutorial“第７章：ポリゴンの面属性”を参照してください。
