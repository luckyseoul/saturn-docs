構造体

SmpcStatus

ＳＭＰＣステータス

構造

typedef   struct {
          Uint8              cond;
          SmpcDateTime  rtc;
          Uint8              ctg;
          Uint8              area;
          Uint16             system;
          Uint32             smem;
} SmpcStatus;

メンバー

cond      状態ステータス
rtc       ＲＴＣ時刻
ctg       カートリッジコード
area      エリアコード
system    システムステータス
smem      ＳＭＰＣメモリ保持データ

解説

ＳＭＰＣシステムステータスを参照するための構造体です。

備考

システム変数“Smpc_Status”を参照する時に使用します。
メンバ“rtc”は構造体“SmpcDateTime”として参照できます。
メンバ“smem”については、専用の取得・設定関数が用意されています。

参照：HARDWARE MANUAL vol.1 (SMPC)
