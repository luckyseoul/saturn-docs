構造体

PerKeyBoard

キーボードデバイス

構造

typedef   struct {
          Uint8     id;
          Uint8     ext;
          Uint16    data;
          Uint16    push;
          Uint16    pull;
          Uint8     cond;
          Uint8     code;
} PerKeyBoard;

メンバー

id        ペリフェラルＩＤ
ext       拡張データサイズ
data      ボタン現在データ
push      ボタン押下データ
pull      ボタン引上データ
cond      状態データ
code      キーコード

解説

キーボードデバイスを参照するための構造体です。

備考

システム変数“Smpc_Peripheral”を型キャストして、キーボードデバイスとして参照する時に使用します。

参照：HARDWARE MANUAL vol.1 (SMPC)
