構造体

WORK

ワークエリア管理

構造

typedef   struct    work {
                    struct work *next ;
                    Uint8 user[WORK_SIZE - sizeof(struct work *)] ;
          } WORK ;

メンバー

next      次のワークエリアへのポインタ
user[]    ユーザーがWORK内で使用できるフリーエリア

解説

イベント内で使用できるワークエリアの構造を表します。
メンバー“user”は、WORKサイズ（WORK_SIZE = 64byte）からメンバー“next”の大きさ（4byte）を引いたもので、60byteとなります。
詳細は、Programmer's Tutorial“第10章：イベントコントロール”を参照してください。

参照：第10章　イベントコントロール
