構造体

PerDigital

デジタルデバイス

構造

typedef   struct {
          Uint8     id;
          Uint8     ext;
          Uint16    data;
          Uint16    push;
          Uint16    pull;
} PerDigital;

メンバー

id        ペリフェラルＩＤ
ext       拡張データサイズ
data      ボタン現在データ
push      ボタン押下データ
pull      ボタン引上データ

解説

デジタルデバイスを参照するための構造体です。

備考

システム変数“Smpc_Peripheral”を参照する時に使用します。
すべてのデバイスはデジタルデバイスとして扱うことができます。

参照：HARDWARE MANUAL vol.1 (SMPC)
