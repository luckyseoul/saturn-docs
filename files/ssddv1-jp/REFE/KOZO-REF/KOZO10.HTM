構造体

TEXTURE

テクスチャーデータ

構造

typedef   struct    {
                    Uint16 Hsize ;
                    Uint16 Vsize ;
                    Uint16 CGadr ;
                    Uint16 HVsize ;
          } TEXTURE ;

メンバー

Hsize     テクスチャーの横サイズ
Vsize     テクスチャーの縦サイズ
CGadr     テクスチャーのＣＧアドレス／８
HVsize    横サイズ／８、縦サイズ（ハード用）

          ((H SIZE/8)<<8) | (V SIZE)

解説

SGLでテクスチャーを使用するためのテクスチャー管理テーブルです。

備考

詳細は、Programmer's Tutorial“第7章：ポリゴンの面属性”を参照してください。
