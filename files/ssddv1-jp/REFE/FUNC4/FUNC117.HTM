void
イベント管理関数

slReturnWork

WORK領域をシステムに返す

書式

void slReturnWork(wkptr)
WORK *wkptr ;

パラメータ

wkptr     システムに返却するワーク領域の先頭アドレス

機能

ワークとして使用していたRAM領域をシステムに返却します。

戻り値

なし

備考

システムに戻されたポインタは、システムのバッファに再登録されますが、システムは返却されたポインタが登録済であるかどうかのチェックを行いません。そのため、同じポインタを複数回返却すると、この後に実行される“slGetWork”において、複数のイベントが同じワークを使用するなどの不具合が発生しますので、注意が必要です。

参照：第10章　イベントコントロール
