EVENT *
イベント管理関数

slSetEvent

イベントの登録

書式

EVENT *slSetEvent(func)
void (*func)() ;

パラメータ

func      イベントとして登録する関数のポインタ

機能

イベント領域を取得し、イベントリストの末尾に追加します。
このイベントの実行関数として指定された“func”が、登録されます。

戻り値

イベントの取得に成功した場合、関数は、登録されたイベント領域の先頭アドレスを返します。
イベント領域が残っていない場合、関数は、NULLコードを返します。

備考

イベント領域は128バイトの領域として確保されますが、先頭16バイトはシステムにより使用されます。

参照：第10章　イベントコントロール
