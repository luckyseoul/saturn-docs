イベント管理関数

slReturnEvent

関数“slGetEvent”で取得された領域を解放

書式

void slReturnEvent(evptr)
EVENT *evptr ;

パラメータ

evptr     解放する領域の先頭アドレス

機能

関数“slGetEvent”で取得された領域を解放し、システムに返します。

戻り値

なし

備考

イベントとして登録されている領域を関数“slReturnEvent”で解放してしまった場合、領域はシステムに返還されますが、イベントリストは変更されないため（イベントであるかどうかのチェックは行っていない）、その後に実行される関数“slGetEvent”、“slSetEvent”、“slSetEventNext”などにおいて不具合が発生します。 このため、必ず関数“slCloseEvent”を呼んでイベント登録を削除した後に、“slReturnEvent”で領域を解放してください。
