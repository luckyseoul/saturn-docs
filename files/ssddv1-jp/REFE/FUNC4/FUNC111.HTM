void
イベント管理関数

slCloseEvent

イベントの削除

書式

void slCloseEvent(evptr)
EVENT *evptr ;

パラメータ

evptr     削除するイベントが格納される領域の先頭アドレス

機能

実行リストに登録されたイベントをリストから切り離し、領域を解放します。また、ワークが確保されている場合、これも解放します。

戻り値

なし

備考

実行リストに登録されていないイベントを指定すると、リスト情報が正しくないため、不当なイベントに対してリスト変更処理を実行することになり、予測できないアドレスに対する書き込みが発生し、最悪の場合、CPUが停止することがあります。

参照：第10章　イベントコントロール
