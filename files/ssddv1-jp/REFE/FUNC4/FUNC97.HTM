演算関数

slAng2Hex

ANGLE型角値を16進数に変換

書式

Uint16 slAng2Hex(ang)
ANGLE ang ;

パラメータ

ang       ANGLE型角値

機能

ANGLE型角値を16進数に変換します。

戻り値

16進数に変換された角度データ。

備考

例）
    ang = 0x4000   →   0x005A
    ang = 0x1000   →   0x0016
