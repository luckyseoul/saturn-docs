FIXED
演算関数

slAng2FX

ANGLE型角値をFIXED型数値に変換

書式

FIXED slAng2FX(ang)
ANGLE ang ;

パラメータ

ang    ANGLE型角値

機能

ANGLE型角値をFIXED型数値に変換します。

戻り値

FIXED型に変換された角度データ。

備考

例）
    ang = 0x4000   →   0x005A0000（90.0）
    ang = 0x1000   →   0x00168000（22.5）
