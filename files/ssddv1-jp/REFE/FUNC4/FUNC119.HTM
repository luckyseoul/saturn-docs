EVENT *
イベント管理関数

slSetEventNext

指定したイベントの後ろに新しいイベントを追加

書式

EVENT *slSetEventNext(evptr , func)
EVENT *evptr ;

パラメータ

evptr     新規イベントを挿入する直前のイベント領域の先頭アドレス
func      イベントとして登録する関数のポインタ

機能

イベント領域を取得し、イベントリストに挿入・追加します。
新規イベントは、パラメータとして指定されたイベントの次に実行されるように、イベントリスト中に登録されます。

戻り値

関数は、登録されたイベント領域の先頭アドレスを返します。
イベント領域が残っていない場合イベントは登録されず、関数は、NULLコードを返します。

備考

イベント領域は128バイトの領域として確保されますが、先頭16バイトはシステムにより使用されます。

参照：第10章　イベントコントロール
