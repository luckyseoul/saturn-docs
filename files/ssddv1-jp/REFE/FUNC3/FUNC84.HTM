マトリクス関数

slRotAX

原点を通る任意軸回りの回転

書式

void slRotAX(vctx , vcty , vctz , anga)
FIXED vctx ;
FIXED vcty ;
FIXED vctz ;
ANGLE anga ;

パラメータ

vctx      回転軸ベクトルＸ成分
vcty      回転軸ベクトルＹ成分
vctz      回転軸ベクトルＺ成分
anga      回転角値

機能

原点を通る任意軸回りの回転を加えます。
回転軸を決定する回転軸ベクトルは必ず単位ベクトルで指定してください。
回転マトリクスは、下図のように表現されます。

戻り値

なし

備考

下図は、任意軸回りの回転を行うための回転マトリクスです。

注）Nx,Ny,Nzは、回転軸ベクトルのＸＹＺ成分。
Ｓ及びＣは、角値“anga”を代入したSin,Cos。
