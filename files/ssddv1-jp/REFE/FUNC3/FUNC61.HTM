スクロール関数

slZoomModeNbg0,1

ＮＢＧの拡大縮小モード決定

書式

void slZoomModeNbg0(mode)
void slZoomModeNbg1(mode)
Uint16 mode ;

パラメータ

mode      ズームモード指定に対応したUint16型数値

機能

ノーマルスクロールの内、拡大縮小可能な“NBG0,NBG1”の拡大縮小モードを縮小イネーブルレジスタに設定します。
パラメータへの代入値は、下表を参照してください。

戻り値

なし

備考

縮小設定によって、拡大縮小可能範囲は次のように変化します。
　　
　　縮小設定1/1倍：（1/1倍～256倍）
　　縮小設定1/2倍：（1/2倍～256倍）
　　縮小設定1/4倍：（1/4倍～256倍）
注）上表の値は、システム付属の“sl_def.h”で定義されています。

参照：第８章　スクロール
