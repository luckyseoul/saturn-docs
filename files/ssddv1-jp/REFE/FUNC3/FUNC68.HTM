スプライト関数

slSpriteType

スプライトデータのタイプ指定

書式

void slSpriteType(type)
Uint16 type ;

パラメータ

typeスプライトタイプ（0～15）

機能

スプライトデータのタイプを指定します。

戻り値

なし

備考

０～７は低解像度（３２０または３５２）、８～１５は高解像度（６４０、７０４）用で、データ幅がそれぞれ１６bitと８bitになります。

参照：HARDWEAR MANUAL vol.2 (VDP)
