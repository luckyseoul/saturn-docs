文字表示関数

slLocate

表示位置の計算（パラメータはセル指定）

書式

void *slLocate(xpos , ypos)
Uint16 xpos ;
Uint16 ypos

パラメータ

x          posテキスト表示位置のＸ座標（範囲：0～63セル）
y          posテキスト表示位置のＹ座標（範囲：0～63セル）

機能

テキスト表示用のアドレス値を返します。
パラメータは、画面上でのセル単位でのＸＹ座標位置を表します。
１セルは、８×８ドットで構成され、通常のスクロール面は64×64セルで構成されます。

戻り値

テキスト表示用のアドレス値

備考

関数“slLocate”使用例：
Uint16 x = y = 2 ;
slPrint ( "ABC" , slLocate ( x , y ) ) ;

・左図のマス目のセル単位で区切られています。
・１セルは8×8ドットで構成され、画面左上を原点とします。

参照：第８章　スクロール
