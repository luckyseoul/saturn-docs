void
マトリクス関数

slLookAt

視線マトリクスをカレントマトリクスに掛ける

書式

void slLookAt(camera , target , angz)
FIXED *camera ;
FIXED *target ;
ANGLE angz ;

パラメータ

camera[XYZ]   カメラ位置を表すＸＹＺ座標
target[XYZ]   ターゲット位置を表すＸＹＺ座標
angz          カメラアングル角

機能

指定されたカメラ位置からターゲットを、指定されたアングルで見るようなマトリクス（視線マトリクス）を、カレントマトリクスに掛け合わせます。

戻り値

なし

備考

Ｙ軸に対して平行な視線方向を選択した場合、ＸＺ平面上のベクトルが小さくなり（Ｙ軸回りの回転が決定できない）、正しく描画されない場合がありますので視線方向はＹ軸に平行にならないように値を調整して使用してください。下図は、視線のイメージモデルです。

参照：第６章　カメラ
