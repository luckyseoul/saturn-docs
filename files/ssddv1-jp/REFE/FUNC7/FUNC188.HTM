slTransferEntry

ブランキング中のデータ転送リクエスト

書式

void slTranferEntry(str , dst , size)
void *str ;
void *dst ;
Uint16 size ;

パラメータ

str       転送元の先頭アドレス
dst       転送先の先頭アドレス
size      データ転送量（バイト）

機能

V_BLANK中に、データ転送を行います。
パラメータ“size”には、データを何バイト分転送するかを指定します。

戻り値

なし

備考

SCUに内蔵されたDMAの間接モードを使用してデータ転送を行うため、同一バス間でのデータ転送はできません。
詳細は、“HARDWARE MANUAL vol.1：SCUの章”を参照ください。
