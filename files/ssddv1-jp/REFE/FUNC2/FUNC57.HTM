slScrWindowModeNbg0,1,2,3

ＮＢＧのウィンドウ使用モード設定

書式

void slScrWindowModeNbg0(mode)
void slScrWindowModeNbg1(mode)
void slScrWindowModeNbg2(mode)
void slScrWindowModeNbg3(mode)
Uint16 mode ;

パラメータ

mode      ウィンドウ使用モードフラグ

機能

NBG0～3のウィンドウ使用モードを設定します。

戻り値

なし

備考

パラメータには、下図の値を代入してください。
また、各グループのパラメータをｏｒ形式で連結することで、複数のパラメータの同時設定が行えます。
下図パラメータ中、“*_IN”は、ウィンドウの内側を表示、“*_OUT”は、ウィンドウの外側を表示させます。

注）上記値は、システム付属の“sl_def.h”で定義されています。

参照：HARDWEAR MANUAL vol.2 (VDP2)
