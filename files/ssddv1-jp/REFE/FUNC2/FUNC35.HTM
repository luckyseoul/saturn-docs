スクロール関数

slOverRA

ＲＢＧの画面オーバー処理セット（回転パラメータＡ使用）

書式

void slOverRA(mode)
Uint16 mode ;

パラメータ

mode          画面オーバー処理モード指定に対応したUint16型数値
              0：エリア外は、表示エリアに設定された画像を繰り返す
              1：エリア外は、指定したキャラクタパターンを繰り返す
              2：エリア外は、全て透明
              3：縦512×横512のエリア外は全て透明

機能

回転スクロールの画面オーバー処理モードを設定します。
画面オーバー処理とは、回転スクロールの描画が表示エリアを越えて行われようとした場合、表示エリアを越えた部分をどのように処理するかという設定で、回転スクロールのプレーンサイズレジスタに対して設定します。

戻り値

なし

備考

回転スクロールがビットマップ形式の場合、モード0及びモード1は、設定できません。

参照：第８章　スクロール
