スクロール関数

slScrDisp

パラメータ指定されたスクロールの描画設定

書式

void slScrDisp(mode)
Uint32 mode ;

パラメータ

mode      表示するスクロール面に対応した表示フラグ
機能

パラメータとして指定されたスクロール面の描画設定を行います。
パラメータへの代入値は、下表を参照してください。
複数のスクロールの描画設定を同時に行う場合は、ｏｒ演算子“｜”で、パラメータを連結していってください。

戻り値

なし

備考

描画設定とは、スクロール登録されたスクロールの内、実際に描画演算処理を行うかどうかを設定するものであり、描画設定をＯＮにされたスクロール面のみが、描画開始宣言で実際にモニターに描画されます。
また、関数“slAutoDisp”でスクロール登録されたスクロール面は、登録時点で描画設定がＯＮになっています。 

ＯＮ　：スクロール画面を描画する。
ＯＦＦ：スクロール画面を描画しない。
注）上表の値は、システム付属の“sl_def.h”で定義されています。

参照：第８章　スクロール
