slPlaneNbg0,1,2,3

ＮＢＧのプレーンサイズセット

書式

void slPlaneNbg0(type)
void slPlaneNbg1(type)
void slPlaneNbg2(type)
void slPlaneNbg3(type)
Uint16 type ;

パラメータ

type      プレーンサイズ指定に対応したUint16型数値

機能

ノーマルスクロールのプレーンサイズを設定します。
パラメータへの代入値は下表を参照してください。

戻り値

なし

備考

縮小設定を1/4倍までにしている場合、プレーンサイズとして２×２を指定しないでください。
これは、縮小設定が1/4倍の場合のマップサイズが通常と異なるためです。
１×１、２×１設定なら問題なく使用できます。

注）上表の値は、システム付属の“sl_def.h”で定義されています。
