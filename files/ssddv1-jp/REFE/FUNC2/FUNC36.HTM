スクロール関数

slOverRB

ＲＧＢの画面オーバー処理セット（回転パラメータＢ使用）

書式

void slOverRB(mode)
Uint16 mode ;

パラメータ

mode          画面オーバー処理モードに対応したUint16 型数値
              0：エリア外は、表示エリアに設定された画像を繰り返す
              1：エリア外は、指定したキャラクタパターンを繰り返す
              2：エリア外は、すべて透明
              3：縦512×横512のエリア外はすべて透明

機能

回転スクロールの画面オーバー処理モードを設定します。
画面オーバー処理とは、回転スクロールの描画が表示エリアを越えて行われようとした場合、表示エリアを越えた部分をどのように処理するかという設定で、回転スクロールのプレーンサイズレジスタに対して設定します。

戻り値

なし

備考

回転スクロールがビットマップ形式の場合モード０と１は設定できません。

参照：第８章　スクロール
