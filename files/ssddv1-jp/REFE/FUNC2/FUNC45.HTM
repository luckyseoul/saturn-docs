スクロール関数

slRparaMode

回転パラメータモード設定

書式

void slRparaMode(mode)
Uint16 mode ;

パラメータ

mode      回転パラメータモード

機能

回転パラメータのモードを指定します。
回転パラメータＡ、Ｂをどのように使用するかを指定できます。

戻り値

なし

備考

回転パラメータモードは、次の値のいずれかを指定できます。
      RA：回転パラメータＡのみ使用
      RB：回転パラメータＢのみ使用
      K_CHANGE：回転パラメータＡの係数データによって画像切り替え
      W_CHANGE：回転パラメータウィンドウで画像切り替え
注）上表の値は、システム付属の“sl_def.h”で定義されています。
