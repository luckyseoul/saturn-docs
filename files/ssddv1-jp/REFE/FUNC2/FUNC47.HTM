スクロール関数

slScrCycleSet

サイクルパターンの設定

書式

void slScrCycleSet(a , b , c , d)
Uint32 a ;
Uint32 b ;
Uint32 c ;
Uint32 d ;

パラメータ

a        バンクＡ－０のサイクルパターン
b        バンクＡ－１のサイクルパターン
c        バンクＢ－０のサイクルパターン
d        バンクＢ－１のサイクルパターン

機能

各バンクのサイクルパターンを設定します。各バンクが分割されている場合には、aとb、cとdにサイクルパターンを設定することができます。バンクが分割されていないときには、a と cにサイクルパターンを設定することができます。 設定する値についての詳細は、“HARDWARE MANUAL vol. 2”VDP2ユーザーマニュアル：P31～を参照してください。

戻り値

なし

備考

関数“slScrAutoDisp”を使用すると、その時に指定されたスクロール画面を表示するためのサイクルパターンを自動的に設定することができます。

参照：HARDWEAR MANUAL vol.2（VDP2）
