スクロール関数

slPriorityNbg0,1,2,3

ＮＢＧのプライオリティ・セット

書式

void slPriorityNbg0(num)
void slPriorityNbg1(num)
void slPriorityNbg2(num)
void slPriorityNbg3(num)
Uint16 num ;

パラメータ

num       描画プライオリティナンバー（0～7の８種類）

機能

ノーマルスクロール画面“NBG0,NBG1,NBG2,NBG3”に、プライオリティをつけます。
プライオリティナンバーの大きいものが表示順位が高く、プライオリティナンバーが小さいほどより背面に描画されます。
プライオリティナンバーが0の場合、スクロール面は透明とみなされ描画されません。

戻り値

なし

備考

他のスクロール面及びポリゴン面と同じプライオリティナンバーが指定された場合の優先順位は、下図を参照してください。

注）POLYGONは、SPRITEに含まれます。
