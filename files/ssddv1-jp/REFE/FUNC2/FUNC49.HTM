スクロール関数

slScrLineWindow0

ラインウィンドウテーブル0をセットする

書式

void slScrLineWindow0(adr)
void *adr ;

パラメータ

adr       ラインウィンドウのVRAM上のデータアドレス

機能

ラインウィンドウデータテーブル０のVRAM上のアドレスを設定します。

戻り値

なし

備考

ウィンドウを有効にするには、最上位ビットを１にしてください。
ウィンドウを無効にする場合は、はNULLを渡してください。 

例）アドレス＝0x25e3f000（定数指定の場合）
　　ウィンドウ使用　：slLineWindow0( (void *)(0x25e3f000 | 0x80000000)) ;
　　ウィンドウ不使用：slLineWindow0( (void *)NULL ) ;
　　アドレス＝0x25e3f000（アドレス指定の場合）
　　ウィンドウ使用　：Sint16 *lptr ;
　　　　　　　　　　lptr=(Sint16 *)0x25e3f000) ;
　　　　　　　　　　slLineWindow0( (void *)(lptr + 0x40000000));
　　　　　　　　　　　　lptrがSint16（2バイト変数）のポインタだから
　　ウィンドウ不使用：slLineWindow0( (void *)NULL ) ;

参照：HARDWEAR MANUAL vol.2(VDP2)
