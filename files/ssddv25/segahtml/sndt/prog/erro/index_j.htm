シーケンスに関するエラー集

■STANDARD MIDI FILEのコンバート時に発生するエラーとその対応法について

（SndSimulator Ver.1.25以降）

  1. could not open song file.
  2. could not open output file.
    ディスクエラーです。NORTON UTILITYなどを使用してハードディスクの チェックをしてください。

  3. seek error.
    シークエラーです。ディスクエラーと同様の対応をしてください。

  4. there is more than 32 tracks.there is XX tracks ( including tempo track ).
    スタンダードMIDIファイルのトラック数が多すぎます。サターン用のシーケンストラックはテンポトラックを含め、最大32までです。

  5. resolution is written as absolute time.
    分解能が絶対時間で書かれています。シーケンサのスタンダードMIDIファイル保存時のオプションを切り替えてください。

  6. unknown event in out file.
    未知のイベントが存在します。データがこわれていることがかんがえられますので、スタンダードMIDIファイルの保存をやり直してください。

  7. distance of 2 events is over XX ,too far to reference other event and omit. turn ' find same data ' option off.
    ファイル内のデータが多すぎて繰り返し検出ができません。繰り返し検出オフをオフにしてコンバートしてください。

  8. not enough memory.
    メモリが足りません。同時に動いているアプリケーションを閉じてみてください。もし、それでもこのエラーがでる場合はMacintoshをリスタートしてみてください。

  9. could not release memory space.
  10. memory access error.
    メモリーに関するトラブルが発生しました。Macintoshをリスタートしてみてください。

  11. illegal block type in header block.
  12. could not find ' MThd '.
    データがこわれていることが考えられますので、スタンダードMIDIファイルの保存をやり直してください。

  13. can not convert this type of SMF" this program require ' FORMAT 1 '.
    スタンダードMIDIファイルのフォーマットがTYPE1以外です。シーケンサでTYPE1の保存をしてください。

  14. illegal block type in track block.could not find ' MTrk '.
  15. illegal event in SMF" "track No = XX
    未知のイベントがXXトラックに存在します。
    データがこわれていることがかんがえられますので、スタンダードMIDIファイルの保存をやり直してください。

  16. too many events.there is more than XX events"
    イベントが多すぎます。65536/1シーケンスまでデータ減らしてください。

  17. tempo < xx.xx bpm.
    テンポが遅すぎます。

  18. tempo > xx.xx bpm. this song is xx.xx bpm.
    テンポが早すぎます。
    シーケンスのテンポは40から300の範囲にしてください。

  19. Loop command must appear 0 or 2 times. it appeared %d times.
    コントロールチェンジ31番のループコマンドが1個あるいは3個以上あります。

  20. Tempo event appeared after other event.tempo event must appear in top of song.
    テンポイベントが他のイベントより後に存在します。シーケンサでデータを修正してください。

  21. Note off appeared before 1st bank change ( = bank select ).
    Note on appeared before 1st bank change ( = bank select ).
    Poly - Key Pressure appeared before 1st bank change ( = bank select ).
    Ch - Pressure appeared before 1st bank change ( = bank select ).
    Program change appeared before 1st bank change ( = bank select ).
    トラック先頭のbank change(Control change#32= bank select)の位置が遅すぎます。

  22. Note off appeared before 1st program change.
    Note on appeared before 1st program change.
    Poly - Key Pressure appeared before 1st program change.
    Ch - Pressure appeared before 1st program change.
    トラック先頭のprogram changeの位置が遅すぎます。

    *各トラック先頭の基本的なデータ配置（Version1.25以降の標準仕様です）

    　1/1/000（小節/拍/クロック）
    テンポイベント（通常はシーケンサが自動的に挿入）、bank change(#32)

    　1/1/001（小節/拍/クロック）
    プログラムチェンジ、コントロールチェンジ（MAIN VOLUME#7、ループ時のループコマンド#31など）

    　1/1/002（小節/拍/クロック）
    ノートオン

    1拍が何クロックかは各シーケンサの分解能により異なります。また、各トラック先頭部にはControl change#7のMAIN VOLUMEの設定を行ってください。
    シーケンサによっては、同じ小節/拍/クロックにイベントデータを複数置いた場合、シーケンサの画面上に表示される順序とStandard MIDI Fileに書き込まれる順序が変わる場合があります。イベントの順序を明確にしたい場合は、データを1クロックずらして置いてください。
    　サターンのサウンドドライバの処理は2msecが基準ですので、１拍を480クロックと扱うシーケンスデータを作成しても、コンバート再生を行うと１拍が250相当（テンポが120の場合）の分解能になり、クオンタイズをかけたように再生されます。

  23. Note on appeared without note off 音程 in track X,
    データがこわれていることが考えられますので、スタンダードMIDIファイルの保存をやり直してください。

  24. Note on must be more than 2 clocks distant from same-pitch-note on.¥n Or, gate time is too short. 音程 in track %d , %ld clocks from end of song.
    同じ音程のNOTE-ONとNOTE-ONの間はシーケンサでの分解能で最低2クロックずらしてください。

  25. there is too many songs.　must less than 300 songs in a same folder.
    Full Auto CNVの変換はフォルダ内に300までです。

  26. There is too many tempo events.
    テンポイベントが多すぎます。テンポイベントは1シーケンス中8190個までです。

■シーケンスバンク作成時のエラーについて

  1. Couldn't open temporary file
    作業用テンポラリファイルが作れません。
    すでに Song collecter temporary file と同名のファイルを他のアプリケーションがカレントフォルダで使っている場合に起こります( ほぼあり得ない )。

  2. Couldn't open output file
    出力ファイルが作れません。
    すでに同名のファイルがあるときは上書きしますが、他のアプリケーションが同名ファイルを開いている場合、このエラーが出ます。

  3. Couldn't open song file
    曲ファイルが存在しません。
    設定後に曲ファイルの位置を移動したり消去したことが考えられます（リードオンリーで開けますので、曲ファイルをシーケンサなどが開いていても、Song collecter は見ることができます）。
