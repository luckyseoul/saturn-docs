 0x25A007C0
 32B
 Slot status
 Slot monitor for 32 bytes. Each slot is 1 byte, and the slots are arranged in ascending order of address, such as 0, 1, 2, etc. When bit 8 is set, the 3 bits 0 to 2 indicate 8 release levels during note-on. However, currently (2.10) bits 0 and 1 are ignored.

 unused


 0x25A007F0
 2B
 just work
 Work for programs to see releases.


 0x25A007F2
 2B
 Number of times over 32 voices
 Since it is 16 bits, it can only count up to 65535 times.


 0x25a007F4
 2B
 Maximum polyphony
 Supports Model-M only. From this work, you can find out the maximum number of simultaneous polyphony in a song. It is cleared to 0 when a sequence start is performed.
