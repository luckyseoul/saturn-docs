Sound Driver Programmer's Guide

Introduction

This manual is a revised version of the " Sound Embedded Manual " and is written targeting sound driver version 2.20.

This manual contains detailed explanations for those who want to program all of the sound controls themselves, but you can easily create sounds using the " Sound I/F Library ", a program library provided by SEGA. There are also ways to incorporate it. Please use them as necessary.
Please refer to the " Sound I/F Library User's Manual " for details and usage.

Limitations

  1. The unsupported function "P4 Priority level (0-31)" of "Sequence start command (01h)" described in the previous manual is not supported in Ver2.10 either.

explanation of words

phrase meaning of the phrase
SCSP An abbreviation for Saturn Custom Sound Processor, which is a sound source LSI that is the core of Saturn's sound system. Built-in DSP for sound. There is too much information about SCSP to describe here, so please refer to the ` `SCSP User's Manual .''
sound data There are three types of data stored in sound memory: tone data, sequence data, and DSP program.
tone data This is the tone part data for playing the sequence data. It consists of PCM waveform data and sound parameters. Also includes FM tones.
sequence data This is the performance data of the song. This is song data composed using MIDI that has been compressed for the Saturn, and consists of performance information such as the strength and pitch of the sound, and the start and end of pronunciation. Sound effects are also created in exactly the same format.
DSP program This is a DSP micro program for operating sound DSP. Effect programs such as reverb and surround are available.
DSP work RAM Area for DSP delay RAM and effect coefficients, used in DSP internal processing. The size of this area changes depending on the microprogram.
sound creator A person in charge of the sound production part of a sound system, such as creating tones, composing music, and creating sound effects.
main system This refers to the game program on the SH side. Think of the 68000's sound driver as the sound subsystem, and the game program that controls it as the main system.
The number of samples One sample depends on the data width of the PCM waveform, so it is 1 byte for 8-bit PCM and 2 bytes for 16-bit PCM. Therefore, for a 4K sample, it will be 4096 bytes for 8 bits and 8192 bytes for 16 bits.

Differences between Version 1.xx and 2.xx

  • Volume calculation is now faster. However, the algorithms are not compatible.

  • Improved the issue where fade or volume changes only responded at the note off timing. Smooth changes are now possible.

  • Compatible with damper pedal.

Differences between version 2.xx and 2.10

  • Since noise is generated when FM is forcibly crushed, the sound of the FM sound source is restricted. This has been found to occur when a slot currently wired as FM is assigned to another FM immediately after note-off, with the release remaining. When this slot is a carrier, the volume will be abnormal, and when it is a modulator, the tone will be abnormal. We have taken a solution to this problem by not allowing it to be used as an FM slot until the release level has fallen to a certain level (the current level is 4 out of 8, and it will take a considerable amount of time to complete the release, so in reality ). However, this leaves the possibility that it violates the current specification of ``always giving priority to the last arrival'', and in rare cases, pronunciation will be canceled if note-on is being performed by all slots FM. In this case, an error will be returned (see the error status section), but directors should be careful when designing specs.
    Also, due to the complexity of checking the slots, if you use a lot of FM sound sources, the operation will inevitably become slower.

  • Previous drivers used note-off to determine whether a slot was empty, but now this is determined at the release level. The program to view the release is running within LEVEL 2 INT. The pronunciation steps are as follows.

    step 1
    Find and assign a slot that is keyed off and has a release level of 4 or lower. If no slot matching this condition is detected, proceed to step 2.
    step 2
    Find the slot with the same pronunciation control number that is keyed off, and assign it. If no slot matching this condition is detected, proceed to step 3.
    step 3
    Searches for identical pronunciation management numbers starting from the lowest slot number and forcibly uses them. If no slot matching this condition is detected, proceed to step 4.
    step 4
    The slot that was keyed on the most in the past is searched for and forcibly assigned, regardless of the pronunciation control number. Passing through this routine is basically an error because it means exceeding the maximum polyphony. However, slots currently being used as FM sound sources will not be used. Only in this case, the pronunciation will be canceled. be careful.

  • Eliminated small noise when changing maps.
