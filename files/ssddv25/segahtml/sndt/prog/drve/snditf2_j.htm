サウンドドライバプログラマーズガイド/７．システムインターフェース(ワークエリア)

システムインターフェースワーク　(480H-4FFH: 128B)

OffsetSizeData内容説明
0x25a004801B割り込みControl Word
( Host ---> Sound )
Bit7: IPT ENABLE
0: PCM再生アドレス更新割り込み禁止
1: PCM再生アドレス更新割り込み許可
0x25A004411B割り込み種別 (1-127)
( Sound ---> Host )
1
: PCM再生アドレス更新割り込み
2-127
: 未使用
0x25A004421B該当ストリーム再生番号
( Sound ---> Host )		 PCM再生アドレス更新割り込み時の該当ストリーム再生番号
□ Bit0-7 が PCM再生番号0-7 に対応
(Bit=1で更新有り)
0x25A004431BSound Mode Control Word
( Host ---> Sound )
Bit7: Sound mode
0: Sound output STEREO mode
1: Sound output MONO mode
0x25A004441B3D sound Control Word
( Host ---> Sound )
Bit7: 3D 1ch mode
0: 使用しない
1:使用する
Bit6: 3D 2ch mode
0: 使用しない
1:使用する
Bit5: Qsound 4ch mode
0: 使用しない
1:使用する
Bit4: Qsound 8ch mode
0: 使用しない
1:使用する
0x25A004451BQ sound COEF PointerQ sound COEF Pointer
0x25A004461B3D sound COEF Pointer3D sound COEF Pointer
0x25A004471B3D sound MADRS Pointer3D sound MADRS Pointer
0x25A0044832B3D sound パラメータ3D sound パラメータ格納エリア
0x25A0046848B3D sound program work3D sound プログラム用ワークエリア (30h)
0x25A004988Breserved-
0x25A004A01BCommand Sequence
Timing Flag
( Host <---> Sound ) 		Bit7: Timing Flag 0: Idle 1: Command Set完了
0x25A004A11BCommand Sequence
Control Word
( Host ---> Sound )
Bit7: Command mode
0: Handshake OFF (V1.00-1.29)
1: Handshake ON (V1.30- )
Bit6:SCSP MIDI出力
0:OFF
1:ON
Bit5:使用不可
常に0
0x25A004A214Breserved-
0x25A004B016BST-V's workST-V互換用予約領域（SATURNでは使用不可）
