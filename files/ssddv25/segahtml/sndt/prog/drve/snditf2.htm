Sound driver programmer's guide/7. System interface (work area)

System interface work (480H-4FFH: 128B)

Offset Size Data content explanation
0x25a00480 1B Interrupt Control Word
( Host ---> Sound )
Bit7: IPT ENABLE
0: PCM playback address update interrupt disabled
1: Enable PCM playback address update interrupt
0x25A00441 1B Interrupt type (1-127)
( Sound ---> Host )
1
: PCM playback address update interrupt
2-127
: unused
0x25A00442 1B Corresponding stream playback number
( Sound ---> Host )		 Corresponding stream playback number at PCM playback address update interrupt
□ Bit0-7 corresponds to PCM playback number 0-7
(Updated with Bit=1)
0x25A00443 1B Sound Mode Control Word
( Host ---> Sound )
Bit7: Sound mode
0: Sound output STEREO mode
1: Sound output MONO mode
0x25A00444 1B 3D sound control word
( Host ---> Sound )
Bit7: 3D 1ch mode
0: not used
1: Use
Bit6: 3D 2ch mode
0: not used
1: Use
Bit5: Qsound 4ch mode
0: not used
1: Use
Bit4: Qsound 8ch mode
0: not used
1: Use
0x25A00445 1B Q sound COEF Pointer Q sound COEF Pointer
0x25A00446 1B 3D sound COEF Pointer 3D sound COEF Pointer
0x25A00447 1B 3D sound MADRS Pointer 3D sound MADRS Pointer
0x25A00448 32B 3D sound parameters 3D sound parameter storage area
0x25A00468 48B 3D sound program work 3D sound program work area (30h)
0x25A00498 8B reserved -
0x25A004A0 1B Command Sequence
Timing Flag
( Host <---> Sound )		 Bit7: Timing Flag 0: Idle 1: Command Set completed
0x25A004A1 1B Command Sequence
Control Word
( Host ---> Sound )
Bit7: Command mode
0: Handshake OFF (V1.00-1.29)
1: Handshake ON (V1.30- )
Bit6:SCSP MIDI output
0:OFF
1:ON
Bit5: Unusable
always 0
0x25A004A2 14B reserved -
0x25A004B0 16B ST-V's work Reserved area for ST-V compatibility (cannot be used with SATURN)
