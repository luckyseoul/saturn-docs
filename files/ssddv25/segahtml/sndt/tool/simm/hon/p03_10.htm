■File menu

The File menu is used to open and save sound area maps.

new

Select when creating a new map.

open

Select to open a map that has already been created.

close

Select to close the map you are editing. The simulator will not exit.

keep

Select when saving the map being edited.

Save as another name

Select this to save the map you are editing under a different name.

Creating a map binary file

Create a Binary format (data that is actually sent to the target) of the file currently being edited
When to choose.

collect file

Manages the input/output of data files in the MIDI file converter list and collect file list.
This menu has the following three submenus.

Open collect file
Open the collection list file.
Selecting Open Collect List opens the following dialog box.

Existing collection list files are displayed.
A collection list is a collection of multiple file names that saves you the trouble of selecting files each time. Used when converting standard MIDI files and creating sequence banks. The file opened here contains both of the above two types of collection lists separately.

Save collect file
Saves the currently active collection list file.

Save as another name
Saves the currently active collection list file under a different name.

function key file

Manages input/output of function key configuration files.
This menu has the following three submenus.

Open function key file
Recalls the saved function key setup settings.

Saving function key files
Saves all settings made in function key setup.

Save as another name
Save the settings configured in function key setup under a different name. Function keys are saved in a map file. Use these menus if you want to use key settings in another map file.

Creating a text file of map information

The currently selected map will be the active map. From now on, the sound driver will operate with this map as the current map (currently valid map). At this time, if the map file information is set to automatically send, the file data will be transferred automatically.

Starting the sound system

Starts the sound system based on the data such as the sound driver that was transferred in advance.

system send

Use this when the target board becomes unusable for some reason and needs to be reset. This saves you the trouble of sending the system and restarting SoundSimulator.
If you wish to send a customized driver, please place the driver file with the file name "SDDRV.TSK" in the same folder as the sound simulator and run this menu.

Send file

Transfers the currently selected file data onto the target. When you click on the file you want to transfer, it will be highlighted in black, indicating that it has been selected. If you want to specify multiple files at the same time, hold down the Shift key and click the next file. Click the selected file again to deselect it and return it to its normal white display.

Change effects

Switches between DSP programs when there are multiple DSP programs on the current map. Click on the DSP program you want to switch to, and it will be highlighted in black, indicating that it has been selected.

Change mixer

Changes the mixer number 0 of the bank file selected from multiple bank files on the current map. If multiple mixers exist in the bank file, if you want to change to a mixer other than number 0, you will need to change it from the sound simulator described below.

end

Exit the sound simulator and close the window.
