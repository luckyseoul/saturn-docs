Creating banks of sequences

Selecting this will open the following dialog box.

What is displayed here is a list of compressed file names converted using [ Convert Standard MIDI File ], and is called a collection list. At first, nothing will be displayed, then use [Add] or [Insert] to add/insert.
If you load the collection list using [File] [Collect File] [Open Collect File], you do not have to register using [Add] or [Insert] each time.
You can select multiple files and convert them at once using Shift + mouse operation.

addition
Selecting Add will open the following dialog box.
Now add the compressed file name to the collection list. Select the compressed file name you want to add, and the compressed file name will be added to the end of the collection list.

insert
Selecting Insert will open the following dialog box.
Now insert the compressed file name into the collection list. Click where you want to insert on the collection list, then select the compressed file name. The compressed file name selected here will be inserted immediately before the compressed file name selected in the collection list.

folder
Similar to the Add button, a standard selection dialog will be displayed. All converted files that exist in the folder containing the file selected here will be entered.
