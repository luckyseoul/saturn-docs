Function key settings

If you select here, the following window will appear.
Assign each function of the sound driver to the [Q], [W], [E], [R], [T], [Y], [U], [I] keys of 1 to 8 numeric keys and full keys. .

Pop-up menu (insert function key pop PICT here)
Add or change function key tables.

edit text
The edit text at the top is for changing the table name.
Click on the parameter you want to change, and the edit text for changing the parameter will appear, so change the parameter there.
Edit text for changing parameters can be moved using the cursor keys.

clear
Return all table data to initial values. (0)

setting
Sets the current table as the table in use and exits this dialog.
