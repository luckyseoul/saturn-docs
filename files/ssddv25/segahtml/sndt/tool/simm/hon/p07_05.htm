PCM stream playback

If you select this, a dialog like the one below will appear.

Add/insert
Entry a new file for PCM stream playback. AIFF files and BIN files can be selected.

Swap files
Changes only the file without changing the [Direct Level], [Direct Pan], etc. settings assigned to the file.

Load settings file/save settings file
Saves the full path of the entered file and the settings assigned to that file in a save file.

Creating data for SGL
Creates pure PCM data without headers.

start
Start PCM Stream Play according to the settings.

stop
Stops PCM stream playback.

setting change
Change the settings of the currently playing PCM data. The parameters that are valid for changing settings are [Direct Level], [Direct Pan], [Playback Pitch], [Left and Right Eff Select], and [Left and Right Eff Send Level].

Hz> Hex
It calculates the frequency into mixed OCT and FNS data (a format that the target can recognize).

end
Exit PCM Stream Play mode and close the dialog.

About various parameters

○16Bit ○8Bit
Select whether the PCM data to be played is 16it or 8Bit.

○Mono ○Stereo
Select whether the PCM data to be played is monaural or stereo.

○Left playback
○Right play
Valid only for stereo files, and only the right or left channel will be played. (However, since it is managed by the application, the driver, hardware, etc. do not have this function.)
The above three data will be automatically set if the settings are included when reading the data.

direct level
Set the playback volume. The setting value is from 0 to 8.

direct pan
Set the pan during playback. The setting value is from 0 to 31. Ignored when in stereo.

buffer address
This is the start address where the PCM data to be played is stored. Setting values in the 1's place from 0 to 0xffff0 are ignored.

buffer size
Set the buffer of PCM data to be played. The setting value is set from 0 to 0xf000 in units of 0x1000. This value indicates the number of samples.

playback pitch
Set the playback pitch. The setting value is 0 → 0xffff.
To set the playback pitch by frequency, set the frequency in the edit text on the left and click [Hz> Use the [Hex] button to display the calculation result in the edit text on the right.

Eff Select
Select effects for each left and right channel. The setting value is 0->15.

Eff Send Level
Set the Effect Send Level. The setting value is from 0 to 7. In the case of monaural, these effects are set on the right channel.

total level
Set the total level. You can make more detailed volume settings than [Direct Level]. The setting width is 0 → 255.
