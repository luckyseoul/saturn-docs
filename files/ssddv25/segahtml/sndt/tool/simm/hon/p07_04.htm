sound simulator manual

sound simulator

If you select here, the following window will appear.

If a sequence bank has been transferred to the currently active current map, you can select the sequence bank from the pull-down menu above the file list box. When you select a sequence bank, the sequence names contained in the bank will be listed as shown above. Select the sequence you want to play here, and use the buttons below to control the sound.

Pronunciation control number
Set the pronunciation control number. The setting range is 0→7.

stereo mode
Switch between stereo or mono mode. Disabled for mono songs.

start
Start pronunciation.

stop
Stop pronunciation.

priority
Specify the sequence's pronunciation priority. 0→127, with 0 being the highest priority.

Pause
Pause pronunciation.

Continue
Restart from pause.

mode
Various modes can be set. Please refer to the SATARN Sound Driver manual for details.

volume
Set the sequence's volume level and Fade in (out) speed.

volume level
Set the volume. 0 → 127 127 is the maximum volume Use in combination with Fade Level

fade level
Specify the Fade Level for Fade In/Fade Out. 0→255, 255 is the slowest change.

Tempo change
Change the playing tempo.
Specify the tempo value you want to change. Positive values make it faster, negative values make it slower.
-32768 → +32767 is 4096, which is 2 times (1/2 when negative).

effect change
Switch DSP programs. You can select from the pull-down menu.

mixer change
Switch mixers. You can select from the pull-down menu.

No
Set MixerNumber. 0→127

Mode
0x00
Displays what kind of work the Sound Driver is currently doing.

Status
0x00
Displays the current status of the Sound Driver.

68kERRStst
0x00000000
Refers to and displays the contents of the 68000 status bits in the sound driver.

Display interval
Set the interrupt interval for Mode Status. From 8Tick to 200Tick, 1Tick is 1/60 seconds.

end
Exit Sound Simulation and close the window.

For details on the contents of each control command, please refer to the "Sound Driver Programmer's Guide/ Sound Control Command Details ".
