sound simulator manual

Standard MIDI file conversion

Selecting this will open the following dialog box.

What is displayed here is a list of song names selected using [Add] or [Insert], and is called a collection list. At first, nothing will be displayed, then use [Add] or [Insert] to add/insert.
If you load the collection list using [File] [Collect File] [Open Collect File], you do not have to register using [Add] or [Insert] each time.
You can select multiple files and convert them at once using Shift + mouse operation.

addition
Now add the song name to the collection list. When you select the song name you want to add, that song name will be added to the end of the collection list.

insert
Now insert the song name into the collection list. Click on the collection list where you want to insert it, then select the song name. The song name selected here will be inserted immediately before the song name selected in the collection list.

folder
The same standard selection dialog as when Add appears. All MIDI files in the folder containing the file selected here will be entered.

stop
Close this dialog box.
