■Edit map menu

When you open this menu, the following display will appear.

Select the area map you want to switch to here. What you are switching here is the area map to be edited, and this operation does not switch the current map.
The difference between the Map menu and the Window menu is that the Window menu only displays other map windows for reference; it does not select the map itself.
The sound simulator can register up to 128 map data.
