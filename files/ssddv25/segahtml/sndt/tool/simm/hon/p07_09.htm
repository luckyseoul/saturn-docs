Memory write

Writes data in byte, word, or long size to the specified address on the target.
When you select this menu, the following dialog will be displayed.
(Please insert the PICT of the memory edit dialog)

address
Specify the address to send to.

data
Enter the data to be sent in hexadecimal code.

○Byte (1byte)
○Word (2bytes)
○Long (4bytes)
Specify the size to send. If the data exceeds the sending size, the last data takes priority.

for example
If data = FEFF01 and the size is word, the transmitted data will be FF01.

pop-up menu
You can register addresses that you use regularly. The usage is exactly the same as "DumpMemory" mentioned above.
