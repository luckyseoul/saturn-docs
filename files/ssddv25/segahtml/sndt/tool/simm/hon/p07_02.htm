Converter preferences

When you select "Converter Preferences" from the function menu, the following dialog box opens.

The meaning of each checkbox is as follows.

□ Repeated detection
Configure settings for repeated detection.

○Binary output ○ASCII output
Select whether to output the final output file in ASCII or binary format. If you output in ASCII format, you can easily check MIDI note information and control changes.
