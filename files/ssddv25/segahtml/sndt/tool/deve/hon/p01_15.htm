Sound Development Manual/1. Overview

■Available MIDI commands

Among the events included in the standard MIDI file, the events that are converted by the converter (started from the sound simulator) are as follows. These will be converted without any loss, unless PitchBend's preferences have been specified to preserve them.

 Note on/off
 Note Off is replaced by GateTime.
 Poly-Key Pressure
 Control Change
 (Bank select must always exist at the beginning of each track.)
 Program Change
 Must exist at the beginning of each track.
 Channel Pressure Pitch Wheel Change
 Supports both 7Bit and 14Bit representation.
 Meta Event
 Compatible with tempo only.
 System Message
 Excusive, Start, Stop, and Song Position are not supported.

If the following conditions are not met, the converter will issue an error message and stop the conversion process.

  • Do not include System Messages in standard MIDI files. System Messages include Excusive, Start, Stop, Song Position Pointer, and Song Select.

  • The number of events included in the standard MIDI file before conversion should be 6143 events or less per track. However, after conversion, Note Off is absorbed into GateTime, resulting in a much lower number of events. Similarly, the number of MetaEvents should be 256 or less. Furthermore, make sure that the length of one MetaEvent does not exceed 127 Bytes.

  • Be sure to convert standard MIDI files to Type #1.

  • Only one loop start command (control change number 31) can exist on each track.

  • Be sure to set Bank Change and Program Change at the beginning of each track (this does not apply to empty tracks). Please note that you cannot specify a non-existing VOICE number or BANK number using Program Change or Bank Select.
