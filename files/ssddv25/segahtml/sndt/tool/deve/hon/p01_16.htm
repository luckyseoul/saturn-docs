Sound Development Manual/1. Overview

■MIDI channel and voice

The Saturn Sound System can handle up to 32 channels (tracks) of MIDI data at the same time, so if one MIDI channel is considered one instrument, it can handle up to 32 instruments at the same time. But in other words, all the songs and sound effects have to play in this. This is not a problem when a song or sound effect is being played alone, but if a song and a sound effect, a song and a song, or a sound effect and a sound effect are being played at the same time, it is necessary to assign each to a different channel. This system dynamically assigns (DVA) 32 MIDI channels to generate sounds.
Therefore, each sequence data must have this information at the beginning of the track. In order to perform with the correct tone, be sure to specify the bank (Bank Select in Control Change) and voice (Program Change) for each track of sequence data.
