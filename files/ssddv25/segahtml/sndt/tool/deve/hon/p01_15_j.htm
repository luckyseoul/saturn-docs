サウンド開発マニュアル/1.概　要

■使用可能なMIDIコマンド

スタンダードMIDIファイルに含まれるイベントのうち、コンバータ(サウンドシミュレータから起動される)での変換対象となるイベントは以下のとおりです。これらは、環境設定でPitchBendの劣化保存をするように指定されていない限り、全く劣化されずに変換されます。

Note on/off
Note OffはGateTimeに置き換えられます。
Poly-Key Pressure
　
Control Change
(なおBank selectは各トラック先頭に必ず存在しなければなりません。)
Program Change
各トラック先頭に必ず存在しなければなりません。
Channel Pressure Pitch Wheel Change
7Bit、14Bit表現の両方に対応。
Meta Event
テンポのみに対応。
System Message
ExcusiveやStart、Stop、Song Positionには対応していません。

以下の条件を満たさないときは、コンバータはエラーメッセージを出し、変換作業を中止します。

  • スタンダードMIDIファイル内にSystem Messageを含まないこと。 System Messageとは、ExcusiveやStart、Stop、Song Position Pointer、Song Selectなどを言います。

  • 変換前のスタンダードMIDIファイルに含まれるイベント数は、1トラックあたり6143イベント以下にしてください。ただし、変換後は、Note OffがGateTimeに吸収されるため、これよりはるかに少ないイベント数になります。同様に、MetaEventは256個以下にしてください。さらに、MetaEvent1個の長さが127Byteを超えないようにしてください。

  • スタンダードMIDIファイルは、必ずType#1に変換してください。

  • ループ開始コマンド(コントロールチェンジの31番)は、各トラックに1個までしか存在できません。

  • 各トラックの先頭にBank ChangeとProgram Changeを必ず設定してください(空のトラックはこの限りではありません)。なお、存在しないVOICEナンバーやBANKナンバーを、Program ChangeやBank Selectで指定することはできません。
