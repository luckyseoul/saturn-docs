3.Files handled by the linker

●Link information file (YLI)

This is the file that is targeted by “Open” or “Save” from the File menu. This file records information about links, such as which modules are linked and how.

●Link information result file (LRI)

Information about hardware resource usage, memory allocation information, etc. is recorded when the executable file is transferred to SCSP.

●Executable file (EXL)

This is a file with the file name, ring buffer size, number of coefficient tables, and coefficient table data added to the DSP microprogram body. Output when saving the link information file.

●Binary executable file (EXB)

This is a binary file formatted to output an executable file to the spare program area on the target board.
