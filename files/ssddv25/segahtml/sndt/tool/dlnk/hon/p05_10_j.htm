5.SCSP/DSPリンカ各種エラーメッセージ

■DSPアルゴリズムに関する問題

　No module.
アルゴリズムエディットウインドウ内にモジュールが１つも配置されていません。

　Cannot use Coef table when ring buffer is '64k'.
リングバッファサイズが64kに設定されている場合は、係数テーブルは使用できません。

　COEF overflow.
アルゴリズムに含まれる全モジュールをリンクした結果、DSP係数データの必要数が許容数(64個)を超えたため、処理を中止しました。DSPプログラムのアルゴリズムを変更してください。

　ADRS overflow.
アルゴリズムに含まれる全モジュールをリンクした結果、DSPアドレス定数データの必要数が許容数(32個)を超えたため、処理を中止しました。DSPプログラムのアルゴリズムを変更してください。

　PROG overflow.
アルゴリズムに含まれる全モジュールをリンクした結果、プログラムの必要ステップ数が許容数(128ステップ)を超えたため、処理を中止しました。DSPプログラムのアルゴリズムを変更してください。

　Ring buffer too small.
アルゴリズムに含まれるモジュールのリングバッファ使用量の合計に対して、Linker上でのリングバッファサイズの設定の方が小さいため、リンク処理を中止しました。Linker上でのリングバッファサイズの設定を変更するか、またはDSPプログラムのアルゴリズムを変更してください。

　The number of MODULATOR is not specified.
モジュレータ信号の入力が必要なモジュールに対して、モジューレータ番号の設定が行われていません。

　Outport of IN module unconnected.
「IN」モジュールの出力側が接続されていません。必ず接続してください。

　Unconnected module exists.
正常な接続が行われていないモジュールが存在します。全ての入力ポートはいずれかの出力ポートに接続されている必要があります。

■開発環境に関する問題

　SATURN SOUND BOARD not connected.
開発用ボードが接続されていません(Linkerアプリケーション起動時のみ)。

■ターゲット上のメモリマッピングに関する問題

　DSPRAM Size too small.
ダウンロードしようとしているDSPプログラムが必要としているDSP外部RAMのサイズに対して、メモリマップ設定において確保されているDSP外部RAMの領域(開発ボード上)の方が小さいため、ダウンロードを中止しました。メモリマップ設定、またはDSPプログラムのアルゴリズムを変更してください。

　ModElementSize too small.
ダウンロードしようとしているDSPプログラムにリンクされたSoftwareEG/LFOエレメントデータのサイズに対して、メモリマップ設定において確保されているSoftwareEG/LFOエレメントデータ用領域(開発ボード上)の方が小さいため、ダウンロードを中止しました。メモリマップ設定を変更するか、またはSoftwareEG/LFOエレメントの数を減らしてください。

　DSP SpareProgramArea too small.
スペア領域にダウンロードしようとしているDSPプログラムのサイズに対して、メモリマップ設定において確保されているスペアDSPプログラム用メモリ領域(開発ボード上)の方が小さいため、ダウンロードを中止しました。メモリマップ設定を変更するか、またはDSPプログラムにリンクする係数テーブル、SoftwareEG/LFOエレメントの個数を減らしてください。

■リンカアプリケーション動作上の問題

　Out of Memory.
Linkerが各種処理を行うためのメモリ領域が確保できません。

　Can't get Temporary Memory for "size to fit".
「size to fit」コマンドの実行に必要なメモリが確保できません。

　Can not allocate TableBuffer.
係数テーブルデータをファイルから読み込むためのメモリ領域が確保できません。

　Table file ' filename ' not found.
係数テーブルファイルが見つかりません。

　EXL file not found.
実行形式ファイル(EXL)が見つかりません。

　Cannot send EXL file (-1).
実行形式ファイル(EXL)が正常に生成できません。

　Cannot send EXL file (-2).
実行形式ファイル(EXL)がオープンできません。

　Cannot send EXL file (-3).
実行形式ファイル(EXL)に含まれるリングバッファサイズ（RBLen）、係数テーブルの個数等の情報が読み出せません。

　Cannot send EXL file (Out of memory) (-5).
実行形式ファイル(EXL)に含まれる係数テーブルデータを読み込むためのメモリ領域が確保できません。

　Cannot send EXL file (-6).
実行形式ファイル(EXL)に含まれる係数テーブルデータが読み出せません。

　Cannot send EXL file (-7).
実行形式ファイル(EXL)に含まれるSoftwareEG/LFOエレメントデータが読み出せません。

■操作に対する警告

　You have not done "Link"&"Download"yet. If you continue to save,"YLI"file will be out of accord with"EXL"file.
「Link」、「Download」を実行せずにセーブしようとしています。このままセーブを実行すれば、アルゴリズムファイル(拡張子YLI)と実行形式ファイル（拡張子EXL）の内容にくい違いが生じる可能性があります。

■各種データのダウンロード(SCSI経由)時の問題

　Cannot send data to Target (1).
実行形式ファイルのファイル名をシステム領域に書き込もうとした際にエラーが発生しました。

　Cannot send data to Target (2).
DSP用リングバッファサイズ設定データ(RBLen)をシステム領域またはDSPハードウエアに書き込もうとした際にエラーが発生しました。

　Cannot send data to Target (3).
DSPプログラムをダウンロードしようとした際にエラーが発生しました。

　Cannot send data to Target (4).
係数テーブルに関する情報をダウンロードしようとした際にエラーが発生しました。

　Cannot send data to Target (5).
係数テーブルデータをダウンロードしようとした際にエラーが発生しました。

　Cannot send data to Target (6).
SoftwareEG/LFOエレメントデータをダウンロードしようとした際にエラーが発生しました。

　Cannot send data to Target (7).
SoftwareEG/LFOエレメントの個数に関する情報をダウンロードしようとした際にエラーが発生しました。

　Cannot send data to Target.
DSPプログラム(EXB)のスペア領域へのダウンロードができません。
