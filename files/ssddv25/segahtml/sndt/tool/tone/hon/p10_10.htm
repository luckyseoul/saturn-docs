■About how to calculate the size

Each layer and voice has an update flag and a parameter to store the calculated size. As I wrote in the initial settings section, this is to avoid unnecessary calculations when updating.

The application flags the layer or voice containing the parameter that has been edited or added to the waveform as an update. When recalculating, only the data with the update flag set will be recalculated and the result will be saved in the size parameter, and the calculated size will be displayed for the data whose update flag is not set.
