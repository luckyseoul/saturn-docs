Tone Editor User's Manual

2. overview

●File operations
Basically performs file operations related to project file input/output, output of transmission data to the target board, bank file input/output, etc.

●Edit
We perform general editing tasks such as cutting and pasting banks, voices, and layers, as well as special editing tasks such as deleting banks, inserting new banks, changing bank names, and replacing waveform data.

●Synthesizer data
Easily edit Sega Saturn parameters. However, parameters that are used extremely infrequently or that are easily confused are omitted in this SEGA ToneEditor and summarized for easier understanding.

●Data transmission
Sends data to the specified bank in the target, and also sends pinpoint data when parameters change.

Initial setting
You can set the environment at a simple level, such as language settings and sending-related settings.
