4. About output files

●Project file
This is a file that stores project data. In principle, this file becomes the work base file.

●Bank file
This file contains one bank file. This file is used to move banks in a project file to another project file.

●Binary file
This is a file that can be used with Sega Saturn targets. When actually sending it to the target, please be careful about Mac binaries. This file cannot be edited.
