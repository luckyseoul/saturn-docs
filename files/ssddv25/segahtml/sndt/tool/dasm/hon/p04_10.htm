■Program grammar

All mnemonics and parameters must be separated by one or more of the following defined delimiters: ``space'', ``comma (,)'', ``tab'', or ``newline''.

●Reading external memory and specifying the load destination MEMS (LDI)

LDI MEMSxx, MR[AddressElement(s)/NF]

  • Do not include delimiters in the description of the external memory read parameter "MR[...]".

  • "AddressElement(s)" represents a concatenation of separately indicated "address description elements" using the symbol "+".

  • One address constant symbol (address symbol name defined by the user) must be included in the address description element of "AddressElement(s)".

●Multiplication and addition

@ pM * pC ± ( pM * pC ± ( ... ( pM * pC ± ( pM * pC + pA ) ) ... ) )

pM: Multiplicand
pC: Multiplication coefficient
pA: aryl addition number

  • The number of left parentheses "(" and ")" must match.

  • The rightmost "(" must be to the left of the leftmost ")".

  • There are restrictions on the combination of pM and pA as shown in the table below.

     pM
     pA
     INPUTS
     [PEG, TEMP00-TEMP7F]
     TEMP00-TEMP7F
     [REG,T]※

    If you specify {TEMP00-TEMP7F} in pM and also specify TEMP in pA, only TEMP with the same subscript can be used. For this reason, pA is designated as “T”.

  • When using a YREG value as an argument as a multiplication factor, use one of the notations {YREGH, YREGL}. Please refer to the table below for the differences between these two notations.

     Notation
     Data passed to multiplier (13bits)
     YREGH
     YREG bit23-bit11
     YREGL
     0 YREG bit15-bit4
