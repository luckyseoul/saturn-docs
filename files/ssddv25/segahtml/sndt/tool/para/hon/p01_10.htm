SCSP/DSP Parameter Editor User's Manual

1.First of all

■About this manual

This manual explains how to use the SCSP/DSP parameter editor "pEdit".

■pEdit functions

pEdit has the ability to rewrite coefficient data and address constant data included in DSP programs downloaded onto SCSP/DSP hardware.

In addition, in the SCSP/DSP assembler "dAsms", several notation modes such as integer and decimal numbers can be specified in the coefficient/address constant definition part of the source code, but pEdit uses the notation mode information specified on the dAsms side. Since it is read from an executable file, coefficient/address constant data can be displayed/input in the same notation mode as in the dAsms source code.
