SCSP/DSP Parameter Editor User's Manual

2. Menu structure

■File menu

Open...
Select an assembled (executable) DSP program from the standard file dialog and download it to SCSP. The only files that pEdit can handle are DSP program executable format files (extension ".EXC") created with the SCSP/DSP assembler "dAsms".

Save
Save the DSP program modified with pEdit in executable format without changing the file name.

Save As...
Save the DSP program modified with pEdit in executable format after setting a new file name from the standard file dialog.

RevertToSaved
Returns the currently edited parameter to its state before editing (the last time it was saved).

Close
Finishes editing the currently open DSP program. If changes have been made to the parameters but have not been saved, you will be asked if you want to save them. When executing Close, pEdit discards internal data, but does not clear programs and data on the DSP hardware.

Quit
Exit pEdit.

■Edit menu

Find
Search for symbol names of coefficients and addresses defined on the DSP program. For details on the Find function, please refer to the " Find Function " section below.

Window menu

Address
Opens an edit window for address constants used by the DSP to access external memory.

Coef
Opens the edit window for the coefficients used by the DSP for calculations.

■Option menu

SCSI ID
When pEdit first executes Download after startup, it automatically recognizes the SCSI ID of the development hardware (board), and thereafter sends and receives data to that SCSI ID. Therefore, there is usually no need to use this command.

caveat
 The SCSI ID of the development hardware (board) must be set to a different number from all other connected SCSI devices. If the settings are incorrect, problems such as data loss on the SCSI device may occur.
