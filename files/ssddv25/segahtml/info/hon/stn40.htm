■Addition of character codes for compatible peripherals

Compatible peripheral characters will be added to the system area of the Sega Saturn CD-ROM. The characters in bold are additional peripheral characters.

●Compatible peripheral character list

A = Analog controller (mission stick)
J = control putt
K = keyboard
M=mouse
S = steering controller
T = multi tap
C = Battle cable (additional)
D=modem (additional)
E = Multi-controller (Additional)
F=FDD (addition)
G=Gun (Virtual Gun) (Added)
P=MPEG (Additional)
X=XBAND (addition)

■Supplementary information

"XBAND" is not a peripheral, but by writing "X"
"This application is an XBAND compatible application"
