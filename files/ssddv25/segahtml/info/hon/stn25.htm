Contents

When using sprites in palette format, the picture may not be displayed depending on the palette code and color bank values. This is because the dot data is judged as VDP2 shadow function dot data (normal shadow data).

Sprite data that is determined as normal shadow data will look like the table in the attached document, depending on the sprite type set in VDP2.
