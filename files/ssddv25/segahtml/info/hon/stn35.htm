■Changing the loadable area of the 1st read file

The loadable area of the 1st read file has been changed to the area below. Additionally, this change has no impact on anyone else.

＜ Figure 1 Memory map 1＞
→

60FF0000H to 60FFFFFH are used by the system, so do not load the 1st read file.

After loading the 1st read file, it will be released to the application.

■System work area and area released to applications

6000000H to 6001FFFH are used by the system and should not be used by applications. However, the use of stacks from 6000E00H to 6001FFFH is permitted.

After the IP processing is completed and the application starts,

  • If you prepare another master SH stack, you can use up to 6001000H in your application.
  • If you prepare another slave SH stack, you can use up to 6000E00H in your application.
