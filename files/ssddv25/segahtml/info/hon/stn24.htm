STN-24

Precautions when setting VDP2 to high resolution mode

Contents

These are the precautions when setting the TV screen mode of VDP2 to high resolution mode.

  1. The normal scroll screen (NBG0 to 3) is displayed as if the normal mode picture was scaled down by 1/2 in the horizontal direction.

  2. The rotating scroll surface (RBG0,1) can be displayed, but the resolution of the picture is the same as in normal mode.

  3. The VRAM cycle pattern register is valid only for T0 to T3 and invalid for T4 to T7.

  4. Vertical cell scrolling function cannot be used.

  5. Color calculation functions will be limited.
    Reference: "HARDWARE MANUAL" VDP2 User's Manual 12.1 Color calculation function

  6. Extended color calculation function and blur calculation function cannot be used.
