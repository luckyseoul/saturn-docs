Supplement about HDD usage of virtual CD

 Subject supplement:

Contents

When building or preprocessing a disk image using a virtual CD, the following temporary files are created in addition to the generated files. Please be careful when determining the required HDD capacity.

■ For VCD BUILD

In addition to the [*.dsk] and [*.rti] files, the following files will be created.
Additionally, temporary files are deleted when the processing of the corresponding IOS file is completed.

●For MPEG IOS files, files of the following sizes
12Byte × (Number of sectors of IOS file)

●For IOS files with channel interleaving, temporary files of the following size
2Byte × (Number of sectors of IOS file)

■For VCDPRE

In addition to the [*.pvd] and [*.rti] files, the following files will be created.
Additionally, temporary files are deleted when the processing of the corresponding IOS file is completed.

●For MPEG IOS files, files of the following sizes
12Byte × (Number of sectors of IOS file)

●For IOS files with channel interleaving, temporary files of the following size
2Byte × (Number of sectors of IOS file)

●For audio tracks, create the following [*.qsb] file for each source DOS file.
98Byte × (number of sectors)
