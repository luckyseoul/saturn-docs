Restrictions regarding SCU/addition value register

Contents

■Restrictions

Prohibition of SCU-DMA indirect mode transfer for CD block data transfer.

■Details

Only 4-byte addition (DxRA=1) can be specified as the read address addition value in SCU-DMA indirect mode. Even in the A-Bus CS2 space, it is not possible to specify "Do not add (DxRA=0)".
However, this restriction does not exist for SCU-DMA direct mode.
