Contents

We provide materials that describe how to use two CPUs (SH2) installed in Sega Saturn.
This document assumes that you have general knowledge of Sega Saturn hardware and software. Please have the following manual ready before reading.

We currently do not provide support regarding this matter.
When using dual CPUs, we recommend using "SGL".
