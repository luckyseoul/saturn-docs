The following Write Once related equipment is currently approved by Sega when creating CD-ROMs for Sega Saturn.

Writers, writing software, and media other than those listed below cannot be used.
If you wish to use it in any other way, you will need SEGA 's approval.

◆Right One Writer
・YAMAHA CD EXPERT CDE100

◆Write once writing software
・SEGACDW.EXE
- It is located in the following directory of the software library.
\SATURN\SEGABIN\BINCD\SEGACDW.EXE

◆Media
・SEGA Private Media Model number CDM12PS71 (with Sega Saturn logo)
・SEGA MEGA CD-R 1.25m/sec (Blue label disc with SEGA logo for MEGA-CD)

The product names and model numbers above are those handled by the sales company .
