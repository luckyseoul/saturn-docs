Regulations regarding stereo/mono settings and language settings

 Subject supplement:

Contents

For stereo settings and language settings, please strictly adhere to the regulations regarding the contents of the user settings below.

■Reference to default setting values

The contents of the user settings set in the following multiplayer can be referenced from the application.
Be sure to use this value as the default setting value in your application.

  • Audio output (stereo/monaural)
  • Language settings
  • Setting date and time

■Items where setting values can be changed

The following user settings for multiplayer can be changed from the application.
In the application, if the user changes the setting value, be sure to set the changed setting value.

  • Audio output (stereo/monaural)
  • Language settings

■Items whose settings are prohibited from being changed

The following user settings for multiplayer must not be changed from the application.

  • Setting date and time
  • Help window (Show/Hide)
  • Sound effect (ON/OFF)
  • reserved area
