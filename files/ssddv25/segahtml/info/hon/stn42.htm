Precautions when using SMPC

■Prohibition of use of SH-2 direct mode

Be sure to use the peripheral library to obtain peripheral data.

●Related information
STN-6 “Regarding software libraries that must be used”

●Special notes
However, the above does not apply to the Virtua Gun (STN-41) as it will not work unless you use direct mode.

■Prohibition of use of reserved bits during peripheral data formatting

Do not use peripheral data that is currently set to " extension bit " or " 1 ".

●Reason
These data, including "extension bits," are reserved for future new peripherals, so when using data that includes extension bits, do not perform programming that uses the extension bits by masking them.
