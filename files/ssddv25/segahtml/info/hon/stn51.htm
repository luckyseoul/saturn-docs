■About the order prohibiting the use of the sound CPU “MC68EC000”

The use of the following instruction codes in programming the Sound CPU 68000 installed in the Sega Saturn is prohibited.

“RESET” instruction
“TAS” instruction

The Sega Saturn does not support the above instructions, so problems may occur if you use them. Also, if you need to reset a sound block, always use the main system SMPC reset.

■Supplementary information

If you are using the sound driver provided by Sega, there is no problem.
Applications that use proprietary sound drivers on the 68000 must strictly adhere to the above restrictions.
