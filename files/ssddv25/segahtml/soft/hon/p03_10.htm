Tone Editor User's Manual

3. Glossary

project
This file is a collection of several banks. All the data needed for the included voice, such as waveform data and synthesizer parameters, is included here.

bank
This is a collection of the minimum data used as a tone file on each Sega Saturn target. This is a collection of voices.

voice
This is tone data. The number at the top left of this window is the same number as the MIDI program change.

layer
This is sound data. A number of these voices come together to form a single voice. In the case of FM, each module and carrier is treated as a layer.
