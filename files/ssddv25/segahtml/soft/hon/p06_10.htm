Tone Editor User's Manual

6. About each window

SatToneEd consists of four types of large windows with a "maybe tree" structure. We will introduce each window starting from the root part.

●Project window
Information about each bank is displayed in the window at the top of the tree structure. You can open the voice window by double-clicking each bank.

●Voice window
Indicates the contents of one bank.
Clicking on the voice whose parameters you want to edit will select it and display the edit dialog.

To select multiple voices, hold down the shift button and click on another voice to select all voices in between. However, only the first voice is subject to parameter editing.

●Layer window
The layer window is divided into PCM or FM depending on the voice settings.
PCM layer window
Although there are differences in the displayed content, the handling method is exactly the same as voice.

●FM layer window
It is now possible to edit the FM algorithm graphically. Data cannot be selected simultaneously in this window.

To connect the lines, click on the black rectangle above each block and drag it to another block. If you end the drag somewhere other than the block, the wire will be automatically connected to you.

To call up the layer parameter window (described later), double-click the text part of each block.

●Layer parameter window
Set more detailed parameters for the layer. This content does not change whether PCM or FM.
