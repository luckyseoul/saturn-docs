9. About error messages

SatToneEd has various error messages. There are some that users can avoid.
Here are the error messages, contents, and workarounds.

●What seems to be a bug in the application.

If you see this error, please contact us with the details of the error.

"Communication is about to occur while the SCSI ID is the startup disk. Save the data and exit the application."
Due to some bug, the SCSI device to be communicated with is set on the startup disk and you are attempting to communicate with it.

"System error."
"A system error has occurred."
Inconsistent values have been assigned to internal variables. A message for the person in charge may be displayed after this.

"Memory status is abnormal. Please save the current data."
"Failed to copy memory."
This is a memory related bug. Please tell us what you did.

"Failed to save data."
"Failed to load data."
"Data structure and file size are inconsistent."
"The data format is abnormal."
A problem occurred regarding file input/output.
If you have installed file input/output related enhancements, this error may occur repeatedly.

●Errors that can be avoided depending on the user

The following errors are user avoidable. Follow the solution.

"Alias Manager is unavailable. The application will close."
"The extended dialog manager is unavailable. The application will close."
"Apple Event Manager is unavailable. The application will close."
"Popup menu is unavailable. The application will close."
"The new standard file manager cannot be used. The application will close."
"Unable to check compatibility. Application will close."
These are features you will definitely use with SatToneEd. Please install the latest system (Kanji Talk 7.12 or higher) and restart.

"Could not allocate memory. Please give up on this feature or expand the memory and try again."
Application memory allocation is extremely small relative to the size of the data. “File” in Finder＞ Please increase the memory usage of the application from the "View Info" menu.

"You have too many windows open. Please close another window and try again."
You are trying to open more windows than the limit. Please close unnecessary windows.

"This data is the last data and cannot be deleted"
Data recalled from the “Settings” menu, voices for banks,
You must have at least one layer. I'm trying to delete that last data.

"The bank address is incorrect. Please send correct bank data."
There is an invalid destination address.
This error often occurs when the target board is not properly initialized.
Please use the SatSndSim application to set the correct address.

"The driver may not have been started."
The driver is not started with the target board connected.
This error occurs if no address is obtained. Occurs when starting up the target board immediately after resetting it.

"The sending address or sending size is abnormal."
The data size is too large for the setting address allocated in the target board. Please reset the data size to a sendable size before sending.

"There are no waveforms that can be edited."
" Edit " when there is no waveform＞ This error occurs when you call up the "Edit Waveform" menu.

"This file cannot be opened with ToneEditor."
You are trying to open a file other than SatToneEd's data file.

``To delete a bank, select `` Delete Bank '' from the `` Edit '' menu. ”
Deleting banks is not supported by shortcut keys to prevent accidents.

●Branch type message

"If you delete this data, the settings in the layer may be misaligned."
Appears as a confirmation when Velocity, PEG, and PLFO are deleted. For details, see " Settings "＞ See Velocity menu.

"There is a Voice that does not have any layers. If you continue working as is, it may cause an error. Do you want to replenish layers? (If you replenish layers, the bank size will increase.)"
YAMAHA's tone editor can generate voices without any layer. Eliminate data discrepancies.
This conflict is not supported, so if you do not resolve it here, it will freeze in the worst case.

"If the user performs the size check, it will no longer be possible to communicate with the target. Would you like to discard the SCSI ID at the same time?"
You can set it to update the size manually in the initial settings.
For details, see " Function "＞ See " Initial Settings " menu.
