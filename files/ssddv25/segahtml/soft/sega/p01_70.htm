Sega Saturn Software Creation Standards/Sega Brand Version/Ver3.00

7. option

1) Options
Include options as much as possible, unless it detracts from the gameplay or is a port and doesn't exist in the original game.

2) Optional items
The items shown below are standard.

 LEVEL
 Difficulty setting
 PLAYER
 Number of players setting
 CONTROL
 control settings
 (RAPID
 rapid fire setting)
 AUDIO
 Audio output settings
 SOUND TEST
 sound test
 EXIT
 exit from options

* Enter audio output settings (switching between stereo and monaural) as much as possible.
( 9. Supplement 3＞ (See About audio output settings )

* It is desirable that the CONTROL settings be of the type that allows settings to be made for each button one by one.

3) How to operate
The standard operation is to select the item to be changed using the ``up and down direction buttons'' and change the item contents using the ``left and right direction buttons''.

 4) Retaining settings
 It is recommended to back up the contents set in the options. Even if you do not back up, the option contents should be retained when resetting "A+B+C+Start button" during the game.


 5) Proceed to the next screen
 If you select "EXIT" and press any decision button, or if you press the "start button" at any position, you will immediately return to the start/option selection screen. Do not return to the "SEGA logo" or "title screen"; be sure to return to Start/Options selection.
