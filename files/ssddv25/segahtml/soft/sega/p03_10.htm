Sega Saturn Software Creation Standards/Sega Brand Version/Ver3.00

Attachment 2

"About license display when using libraries and patents"

When using a library prepared in advance by another company, or when using a patent owned by another company, the company name logo, permission notice, etc. of that company must be displayed in a designated place based on the license agreement. .

1. Video playback library “TrueMotion” (The Duck Corporation)

When using this library, the logo shown in Figure Attachment 2-1 must be displayed in the following location.

  1. Displayed alone for 2 seconds or more in the title loop (in the movie or elsewhere)＜ duty＞

  2. 1 location on the package (back inlay)＜ duty＞

  3. One location on the instruction manual (back side or last page)＜ duty＞

Figure Appendix 2-1 TrueMotion logo

* You can skip to the next screen by pressing the start button.

* Monochrome reversal is also possible.

2. sega sports logo

For sports titles and race titles, the logo shown in Figure Attachment 2-2 must be displayed in the following locations.

  1. Immediately after the Sega logo in the title loop＜ duty＞

  2. One location on the surface of the instruction manual (front inlay for multi-cases)＜ duty＞

Figure Attachment 2-2 Sega Sports Logo

*Please refer to ( 3. SEGA logo ) for display method.

3. sega ageis logo

For Sega Ages titles, the logo shown in Figure Attachment 2-3 must be displayed in the following locations.

  1. Immediately after the Sega logo in the title loop＜ duty＞

  2. One location on the surface of the instruction manual (front inlay for multi-cases)＜ duty＞

Figure Attachment 2-3 Sega Ages logo

*Please refer to ( 3. SEGA logo ) for display method.

4. Sound library for Sega Saturn “Cyber Sound” (InVision Interactive)

When using this library, the logo shown in Figure Attachment 2-4 must be displayed in the following location.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 place on the ending (staff roll) screen＜ duty＞

  3. It is desirable to display other title loops and sound tests.＜ Recommendation＞

Figure Appendix 2-4 Cyber Sound logo

* At a minimum, all characters used in the logo must be displayed in a size that is legible.

5. Video playback library “Cinepak” (Radius)

When using this library, please include the following text in the package (back inlay).

"Cinepak for SEGA Cinepak is a registered trademark of Radius."

6. 3D sound library “Q-Sound” (Qsound Labs, Inc.)

When using this library, the logo and text shown in Figure Attachment 2-6 must be displayed in the following locations.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 location on the instruction manual (back side)＜ duty＞

  3. 1 place on CD label＜ duty＞

Figure Appendix 2-6 QSound logo

7. 3D sound library “Y-Sound” (YAMAHA Corporation)

When using this library, the logo and text shown in Figure Attachment 2-7 must be displayed in the following locations.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 location on the instruction manual (back side)＜ duty＞

  3. 1 place on CD label＜ duty＞

Figure Appendix 2-7 Ysound logo

8. Personal life game system patent (Hudson Co., Ltd.)

When using this patent, the logo shown in Figure Attachment 2-8 must be displayed in the following location.

  1. 1 place in the package＜ duty＞

  2. 1 place in the instruction manual＜ duty＞

Figure Appendix 2-8 PLGS logo

9. Ghost patent (ATARI GAMES CORPORATION)

If you use this patent, please include the following text on the package.

"US Patent Nos. 5,269,687 and 5,354,202"

11. sega digital studio logo

When using SEGA Digital Studio, the logo shown in Figure Attachment 2-11 must be displayed in the following locations.
