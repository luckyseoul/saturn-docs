This standard has been established in order to create a user-friendly environment for all software by unifying basic functions and terminology related to backup.
This creation standard applies only to applications that use backups.

1＞ Unification of terminology (backup-related standard glossary)

Regarding backup-related terms for Sega Saturn, the terms listed below should be used in the software's screen displays and instruction manuals. Also, terms written in the taboo column (those with a strikeout line) are not suitable for use in the game. Do not use this forbidden word. Also, do not use product names such as "Power Memory" as is.

＜ Hard name＞

Note) Use of the following forbidden phrases is prohibited.

  1. "Sega Saturn"

    *This name, which is a trademarked name, is generally used.
    Taboo) x Saturn

  2. "Backup RAM" "Backup"

    *General name that combines body RAM and cartridge RAM.
    taboo) x RAM, x RAM cartridge

  3. "Body RAM" "Built-in backup RAM"

    (Forbidden word)×Built-in RAM

  4. "Cartridge RAM"

    taboo) x external backup RAM, x power memory, x backup RAM cartridge

  5. "Extended memory"

    *The storage device connected to the Sega Saturn's expansion port is called this in the main unit's BOOT ROM.
    Forbidden words) × hard disk

＜ Hardware function name＞

Note) Use of the following forbidden phrases is prohibited.

  1. "Multiplayer screen"

    *Basic operation screen in BOOT ROM
    taboo) x control screen, x control panel

  2. "Saved data management screen"

    *Referring to the backup operation screen in BOOT ROM.
    Taboo) × Backup RAM tool

  3. "Record" "Data" "Save data"

    Forbidden words) x file

  4. "(record) name" "data name"

    Forbidden words) x file name

  5. "Capacity", "Used amount", "Free capacity", "Remaining capacity"

    Forbidden words) x area, x free area

  6. "block"

    *It refers to the unit of capacity, but it is preferable not to include it (no unit) as much as possible.
    taboo) x byte, x bit
