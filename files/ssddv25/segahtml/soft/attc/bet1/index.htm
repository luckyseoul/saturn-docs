Standards for creating backup compatible software

(Sega Saturn version)

These standards have been established in order to create a user-friendly environment for all software by unifying basic functions and terminology related to backup. This creation standard applies only to applications that use backups.

Structure of this standard

1＞ Unification of terminology (backup-related standard glossary)
2＞ System regulations
  • Initialization check
  • Presence/capacity check
  • Load
  • save
  • Comment support
  • Time stamp support
  • Body RAM/Cartridge RAM selection
3＞ Warning messages and sequences
  • Example message when checking initialization
  • Example message when checking presence/capacity
  • Example message when loading
  • Example message when saving
    Reference 1) Example message when erasing/copying
    Reference 2) Terminology used in the backup tool
