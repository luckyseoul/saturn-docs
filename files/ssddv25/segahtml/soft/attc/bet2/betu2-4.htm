4. racing controller

All racing controller compatible software must also be operable with the CONTROL PAD.

1) Specifications

  • The ``Racing Controller'' is a peripheral that allows analog input only in the left and right directions by rotating the steering wheel.
  • Up and down inputs are made using the ``butterfly shift'' located behind the steering wheel.
    (The “top” of the pad shifts to the right, and the “bottom” shifts to the left)
  • The A, B, and C buttons are operated with the right hand, and the X, Y, and Z buttons are operated with the left hand.
  • There is no button equivalent to the "LR button" on the CONTROL PAD.

2) Button settings

(a) Racing controller button setting principles

“Software Creation Standards”〈 Button setting principles〉 In addition, the following principles must be observed (→Software Creation Standards "8. Main Game 2〉 (See "Pad Settings/Button Settings").

＜ Racing controller button setting principles＞

・ As much as possible, operations that are possible with the CONTROL PAD will also be possible with the racing controller . Please take into consideration in advance that the racing controller does not have an "LR button".

・ On menu screens, etc., input up and down using "butterfly shift" .
(Right shift is “above” the pad, left shift is “down”)

(b) Default settings 《Recommended specifications》

The default allocation of operations to the buttons on the racing controller is as follows, with accelerator and brake operations concentrated on the right hand.

Handle Handle operation shift Gear change, special operation (center of gravity movement, etc.)
A button: Brake, special operations (weapon firing, etc.)
B button Accelerator C button Brake, special operations (weapon firing, etc.)
X, Y, Z buttons Change perspective, etc.
