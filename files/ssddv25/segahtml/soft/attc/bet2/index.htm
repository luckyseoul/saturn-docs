Software creation standards for input peripherals

(Sega Saturn version)

"This article is a standard for creating software compatible with each input peripheral for SEGASATURN. The basic specifications are based on the SEGASATURN Software Creation Standards, and terminology and other terms are also shall comply with the "Software Creation Standards".

* "Game Sequence" "Pad Check" "Main Game" in "SEGASATURN Software Creation Standards" ＞ Please refer to sections such as "Pad Settings".

What is presented in this creation standard is only a minimum guideline, and does not cover all aspects of how to deal with all situations that may arise from players, or regulations that are compatible with all applications with various game characteristics. There is no such thing, and that is not the responsibility of this paper. Regarding detailed responses, I would like the production side to make a decision after careful consideration.
However, in doing so, we must not forget the idea underlying all regulations : ``Be as user-friendly as possible.'' At the very least, the basic principle is to not run out of control during game play, no matter what application or situation .
