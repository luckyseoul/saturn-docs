2. Replacing the disk

1＞ Strict compliance matters and basic procedures

1) Strict compliance matters

When exchanging "Disc 1" and "Disc 2", please strictly observe the following matters.

《Matters to be observed when replacing disks》

  • Be sure to swap via the multiplayer screen in the main unit's BOOT ROM (both processing and screen display)
  • Settings such as scores and options should be retained even if the disk is replaced (this means saving or saving settings to backup RAM).

2) Basic procedure for replacing disks

The replacement of "Disk 1" and "Disc 2" is performed according to the < > shown below.

《Basic procedure for replacing disks》

  1. Display a message on the game screen prompting you to change the disc.

    [Please change the disk. Press the open button on the main unit to proceed to the multiplayer screen. After replacing disc 1 and disc 2, close the CD door of the main unit and restart the game. ] (User takes out “Disc 1” = presses the open button on the main unit)

  2. Shift processing to multiplayer screen
    (User sets "Disc 2" = closes the CD door of the main unit)
  3. Perform CD check of inserted disc
  4. Display the required information (license SEGA logo)
  5. If there is no abnormality, return to the application immediately.

    *The procedure for saving (saving) necessary data to backup RAM has been omitted.
