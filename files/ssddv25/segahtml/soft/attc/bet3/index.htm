Software creation standards for multi-disc applications

(Sega Saturn version)

"Multi-disc set" applications covered by this creation standard are those in which it is essential to use two or more discs to play the game to the end, and those two or more discs contain stories, etc. Shows things that are related to each other through connections. Even if the game is in the form of a multi-disc set, games in which the game can be played independently on each disc are not eligible.
Also, to make the explanation easier to understand, the text is written in the case of a 2-disc set, but for applications with 3 or more discs, please expand the explanation to match the content.

Please pay attention to the following expressions within this standard.

  • The first and second discs are referred to as "disc 1" and "disc 2," but they may also be "disc A" and "disc B." This must match the description on the label side of each application's CD.

  • The messages shown in brackets [ ] are just examples, but follow this example and use messages that do not mislead users.

  • The expression ``launched'' with ``disk ○'' means that ``disc ○'' was the first disc inserted when playing the game, and that disc is currently in the tray. ” represents the state.

  • 2＞ If there is no free space in the backup RAM
