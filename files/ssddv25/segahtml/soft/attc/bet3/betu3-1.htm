1. basic design

1＞ Specification conditions

As a basic design, the specification conditions imposed on the second and subsequent discs are summarized below.

＜ Requirements＞

  • Be sure to start the disc from the multiplayer screen
    (→To ensure CD check = pass security check)
  • Always use backup RAM for data storage required between disks.
    (→Because there is no other way to pass information to the second and subsequent copies)

    *Continuation to the second and subsequent sessions using a "password" is permitted as a special exception. In that case, there may be specifications that do not use backup RAM.

＜ sufficient condition＞

  • Each disc must have a "title screen" that is the jump destination for the software reset.
    (→To prevent frequent disk replacement)
  • The "SEGA logo" and "title screen" must be present on each disc.
    (→Because it is desirable that trademark/copyright notices (or data) exist on each disc)

    *Soft reset refers to a reset using the pad's "A+B+C+start button"

Also, from the backup system requirements

  • Must have main body RAM/cartridge RAM selection function
  • Must have a save data selection function (only for systems that handle multiple data)

2＞ title sequence

Considering the specification conditions, the title sequence for the second and subsequent discs requires at least the following.

  • CD check
  • "License SEGA logo" display
  • pad check
  • Application "SEGA logo" display
    *However, it will be skipped immediately after the "License Sega logo" is displayed.
  • "title screen"
    *Title logo, "PRESS START BUTTON" display, (C) notation

The following items normally included in the sequence do not need to be included.

  • ×Demonstration
  • × “Start/Option Selection Screen”
  • × "Option"

    *In case of game over, continue, or clear the game, return to the "Sega Logo" application on each disc.

    *If you omit the demonstration, there is no need to use the title "Loop".

    *Options are left to the discretion of each application. However, it should be included if there is a high possibility that the settings will be changed frequently while disc 2 is being played.

    *If you do not include "Options", some specifications may not have the "Start/Option Selection Screen".
