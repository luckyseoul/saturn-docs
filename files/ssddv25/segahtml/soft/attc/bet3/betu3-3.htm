3. reset

Please note that the title sequence exists on both "Disc 1" and "Disc 2", so the destination of the reset will be partially changed.

1＞ Reset using the reset button on the main unit

In all cases, it is treated as normal and the same as turning the power OFF → ON.

2＞ Reset by pad “A+B+C+Start button”

The destination will be as follows.
“Disc 1” title loop → Normal (“Multiplayer screen”)
"Disc 1" Main game → Normal ("Disc 1" "Title screen")
"Disc 2" title (loop) → Normal ("Multiplayer screen")
“Disc 2” main game → “Disc 2” “title screen”

*While the disc replacement process is in progress (while a message for disc replacement is being displayed), it is considered to be the main game, and the game will jump to the title screen of each disc at that point.

*If you do this reset during the main game, be sure to keep the settings such as score and options.

3＞ Reset by opening the CD door

In all cases, you will be redirected to the "Multiplayer screen" of the main unit's BOOT ROM as usual.
