Sega Saturn Software Creation Standards Ver3.00/Licensee Version

Attachment 1

"About license display when using libraries and patents"

When using a library prepared in advance by another company, or when using a patent owned by another company, the company name logo, permission notice, etc. of that company must be displayed in the designated place based on the license agreement. .

1. Video playback library “TrueMotion” (The Duck Corporation)

When using this library, the logo shown in Figure Attachment 1-1 must be displayed in the following location.

  1. Displayed alone for 2 seconds or more in the title loop (in the movie or elsewhere)＜ duty＞

  2. 1 location on the package (back inlay)＜ duty＞

  3. One location on the instruction manual (back side or last page)＜ duty＞

Figure Appendix 1-1 TrueMotion logo

* You can skip to the next screen by pressing the start button.

* Monochrome reversal is also possible.

2. Sound library for Sega Saturn “Cyber Sound” (InVision Interactive)

When using this library, the logo shown in Figure Attachment 1-2 must be displayed in the following location.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 place on the ending (staff roll) screen＜ duty＞

  3. It is desirable to display other title loops and sound tests.＜ Recommendation＞

Figure Appendix 1-2 Cyber Sound logo

* At a minimum, all characters used in the logo must be displayed in a size that is legible.

3. Video playback library “Cinepak” (Radius)

When using this library, please include the following text in the package (back inlay).

"Cinepak for SEGA Cinepak is a registered trademark of Radius."

4. 3D sound library “Q-Sound” (Qsound Labs, Inc.)

When using this library, the logo and text shown in Figure Attachment 1-4 must be displayed in the following locations.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 location on the instruction manual (back side)＜ duty＞

  3. 1 place on CD label＜ duty＞

Figure Appendix 1-4 QSound logo

5. 3D sound library “Y-Sound” (YAMAHA Corporation)

When using this library, the logo and text shown in Figure Attachment 1-5 must be displayed in the following locations.

  1. 1 location on the package (back inlay)＜ duty＞

  2. 1 location on the instruction manual (back side)＜ duty＞

  3. 1 place on CD label＜ duty＞

Figure Appendix 1-5 Ysound logo
