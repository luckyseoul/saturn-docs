6. Start/Option selection

* “Options” belongs to “after game start”. The game after game start is selected on this start/option selection screen is referred to as the "main game."

1) Distinction from the title screen (game start screen)
The start/option selection screen must not be used as the "game start screen" (after the "start button" is pressed on the title screen, the start/option selection "menu" is displayed again).
It doesn't matter how many things other than "menu" can be used for the same purpose.

2) Menu selection restrictions
Judging from the CONTROL PAD connection status and the start status from the title screen (which "start button" was pressed), etc., set restrictions so that items that cannot be played in that situation cannot be selected.

Example) For restricted items such as "2 PLAYSTART" when the CONTROL PAD is only connected to "Terminal 1", instead of not displaying the menu itself, the cursor should not go to menus that cannot be selected ( (Change the shape and color of the letters so that they can be visually distinguished.)

3) Proceed to the next screen
Use the ``direction buttons'' to select and the ``start button'' to make decisions, and proceed to the main game or options respectively.
