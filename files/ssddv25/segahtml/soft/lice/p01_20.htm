2. pad check

* Before starting the game, check the CONTROL PAD connected to the main unit using software.

1) Check timing
Pad check processing is performed not only at the start of the game, but also frequently within the title loop (see Figure 1-1 in the previous section).
Also, check the CONTROL PAD in places where it is possible to replace it even during the game, and be prepared for unexpected changes or insertions of input devices.

2) Check items
If a valid CONTROL PAD for the application is not inserted, or if the CONTROL PAD is only connected to "terminal 2", the game cannot be started. However, things such as competitive fighting and falling object puzzles that can be used as 1P games in ``Terminal 2'' are excluded.
If the CONTROL PAD that is effective for operation is removed during the game, take measures such as determining that no buttons are pressed in the same way as above, or placing the game in a "pause" state and displaying a warning message on the screen. It is desirable to do so.

Even if the CONTROL PAD is subsequently reconnected, it can be operated without any problems in the same way as before it was disconnected. If you have taken measures to put the game in a "pause" state, it is desirable to release the "pause" and restart the game by pressing a button afterward, rather than at the moment of reconnection.

3) Support for other input peripherals

  • "Fully compatible input peripherals"
    Something that needs to work properly in all applications.

    "Control Pad"
    "Virtual Stick"
    "Multi-controller" (digital mode)

  • "Temporarily supported input peripheral"
    Something that needs to be accommodated in order for it to work.

    "Multi Terminal"

    * The following methods are recommended as temporary support for multi-terminals in 1P and 2P games.

    "Only terminal 1 (1P) of the multi-terminal accepts input; other terminals (2P to 6P) are treated as unconnected."

    When accepting input from all terminals (such as when used as a selector), ensure operation throughout the game and take care to avoid any inconvenience.

  • "Unsupported input peripheral"
    If the application does not use the operation function at all, and if it is used, it may cause problems, it is desirable to treat it as unconnected.

    For example, if ``Shuttle Mouse'', ``Mission Stick'', and ``Racing Controller'' are supported, ensure that they work throughout the game and take care to avoid any inconvenience.

    (Refer to Creation Standards - Separate Volume 2 - "Input Peripheral Compatible Software Creation Standards")
