■Format

[object]
(WORD) Attribute information
0 :COL16 ↑
1 :COL16 lookup | Palette mode
2 :COL64 |
3 :COL128 |
4 :COL256 ↓
5 :COL32KRGB ｜RGB mode
(WORD) Palette information
(WORD)Texture x width
When the X width is 0, the texture is not registered.
(WORD)Texture Y width
(----)Texture information
palette mode
Size: X*Y+256*3
RBG mode
Size: X*Y*2
(Note) If the X width is 0, the texture information size will be 0.
