SGTX file format 1996.7/12
SYSTEM R&D DEPT.
****************************************************

■Layout

[header]
[Texture](0)
[Texture](1)
[texture]...
.............


■IFF format

See SG3 format


■Format

[header]
Contents: File identification information
Chunk: "SGTX"
Size: 256
Data: Type Content
DWORD version (0x00010000)
DWORD number of textures
DWORD[62] Reserved

[texture]
Contents: Texture data
Chunk: "SSTx"
Size: 8 + texture data size
Data: Type Content
DWORD ID(0~n)
WORD texture H size
WORD texture V size
WORD[V][H] Texture data
Note: Texture data is 1bR5G5B5
IDs do not have to be consecutive
