3D Editor User's Manual

1.First of all

■Overview

"3D Editor" opens 3D data files in "SEGA 3D" and "DXF" formats, and allows you to refer to saved 3D images from any direction. You can then paste textures or add colors to the polygon faces contained in these and save them in the SEGA 3D format.

■Restrictions

●Connection target
Version 1.71J (1.72J) supports the following SEGA development targets.

  • Sega Saturn Target Model-S Graphics Box
  • Sega Saturn Cartridge Development System (commonly known as CartDev)

For precautions when making connections, please refer to the manuals that come with each target.

●Power PC compatible
When "3D Editor" is started on a Power Macintosh, it operates in native mode.

■Basic operations

When you start the application, the following screen will be displayed. Select the target box you want to connect to and click OK. You can also change the size of your TV screen if you wish.

■About input files

Both ``SEGA 3D'' and ``DXF'' formats are text format files, but the ``3D Editor'' open dialog only lists the file names of these formats, omitting other text files.
