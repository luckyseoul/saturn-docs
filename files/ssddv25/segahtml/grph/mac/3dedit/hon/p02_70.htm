3D Editor User's Manual/2. How to use

■Option menu 

 Note
 The "Options" menu is added when the model list window is on top.

●Display all models

All models in the scene file are displayed.

●Display only specified models

Only the specified model will be displayed; other models will be hidden.

●Display models other than the specified model

Hides the specified model and shows other models.

●Select all models

Select all models.

●Deselect

Deselects all models.
