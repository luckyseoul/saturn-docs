3D Editor User's Manual/2. How to use

■Scene menu

●Camera settings

Currently not supported.

●Light source settings

The following window will be displayed. Please specify the position of the light source.

The light source will be set at the position you clicked on the spherical surface with the mouse. Drag to adjust the position.
Note that you can go back and forth between the front and back sides by moving out from the edge of the sphere and then returning to the inside while dragging. You can choose between a parallel light source and a point light source for the sphere type.

●Wire frame

This is a toggle menu. If this menu is checked, the wireframe of the 3D image will be displayed.

●Hidden side erasure

This is a toggle menu. If this menu is checked, hidden areas will not be displayed in wireframe display. Also, parts hidden behind other polygons will be erased.

●Flip the whole thing

This is a toggle menu. In the case of images such as "DXF files", the entire front surface may be reversed. At this time, if you check this menu, the image will be displayed correctly as a 3D image.

●Gouraud shading
flat shading
flat color
custom color
transparent

This is a check menu to select one. Gouraud shading, flat shading, and flat color specify the shading method. If you have selected these. Shading methods set per material are ignored.
Custom colors are displayed using the shading method set for each material.
If you select transparent, a wireframe will be automatically set and only the wireframe will be displayed.
Gouraud shading gives a display similar to flat shading on the Macintosh, but Gouraud shading is used on the Sega Saturn.

●Target stop

This is a toggle menu. If this menu is checked, no further transfer to the target will be performed.

●Expansion

Enlarges the image in the scene window.

●Reduction

Reduces the image in the scene window.

●Zoom

Displays the image at the specified zoom using the hierarchical menu.
