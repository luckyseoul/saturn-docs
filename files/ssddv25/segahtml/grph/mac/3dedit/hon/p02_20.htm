3D Editor User's Manual/2. How to use

■File menu

●Open

Displays an open dialog with a file format specification pop-up menu. Displays the files specified by the file format pop-up menu in the list. In addition, by checking the checkbox "Join triangular polygons", you can join approximate triangular polygons when reading. Other functions are similar to the normal application open menu.

●Close

Close any open windows. (The window close box works in the same way.) If there are any changes to the file, you will be asked if you want to save it or just discard it. If you want to save it, click the "Save" button. Performs the same operation as "Save". (If multiple windows are displayed, this operation is performed when closing the last window, pressing the command key ( ) and option key (option) at the same time, or when exiting.)

●Save

If there is a change in the open window, save it again with the changed contents (file is overwritten; no conversion is performed).

●Save as another name

Displays a save dialog with a pop-up menu to specify the file format. Specify the format of the file using the File Format pop-up menu. If a file format different from the original file is specified, it will be converted and saved.

●Return

Revert to saved content.

●Environmental settings

The following dialog will be displayed. Please perform each setting.

◆Combining triangular polygons
Configure the default settings for the "Join triangle polygons" checkbox in the file open dialog. This checkbox is often overlooked, so it's useful to set it to your preference by default.

◆Display settings on Mac side
  • Texture display
    If set to "Display", an image similar to the TV screen will be displayed on your Mac when you paste a texture onto a material.

  • gouraud display
    If set to Display, an image similar to the TV screen will be displayed on your Mac when Gouraud shading is specified.
    If you want a comfortable operation while editing, please set it to "Hide".

    ◆Unit settings
  • Auto rotation angle
    Use the following tools on the tool palette to set the angle at which the 3D image will be automatically rotated.

    Y-axis automatic rotation tool
    X-axis automatic rotation tool
    Z-axis automatic rotation tool

  • Vertex movement rate
    Set the movement rate of the vertex data change function.

    ◆Wire settings
  • color
    Set wireframe color.

    ◆Background settings
  • color
    Set the background color.

  • paste a picture on the background
    Set the image data to be pasted on the background.

    • ●End

    Exit the application. If a modified file is open, a dialog box will appear asking if you want to save it.
