3D Editor User's Manual/2. How to use

■Window menu

●Material settings

This is a toggle menu for turning on/off the display of the material settings window. If the material settings window is hidden behind another menu, it will appear first when this menu is selected, regardless of whether it is already displayed or not.

●Material list

This is a toggle menu for turning on/off the display of the material list window.

The material list window displays a list of all material names in the currently displayed scene file. By double-clicking each material name, you can change the material of the polygons selected by the polygon selection tool in the scene window.
Also, when using the polygon selection tool in the scene window, you can select multiple polygons by pressing shift + click. This allows you to paste the same material to multiple selected polygons at once.

●Model list

This is a toggle menu for turning on/off the display of the model list window.

The model list window displays a list of all model names in the currently displayed scene file. Double-clicking each model name will toggle display/hide of that model.
You can also select multiple models by selecting them using shift + click. This allows you to switch the display/hide state of multiple selected model names at once.

●Texture list

The following open dialog will be displayed, so select the folder where the texture you want to open is saved.

Textures are displayed in the list window as shown below. When setting materials, you can paste textures by dragging and dropping from this window. The icon displayed in the folder is used on the list, so adding a custom icon to the file will make it easier to see. Double-click on this window to open the texture window and view the texture.

●New window

When viewing a 3D image in one file, you can open a separate window so that you can view it from various directions.

●Window list

A list of currently displayed windows appears below the New Window menu. The window selected in this menu will come to the front.
