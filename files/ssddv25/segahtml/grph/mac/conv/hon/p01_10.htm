Sega Converter User's Manual

■Release notes

● 4.79J → 4.83J version upgrade information
●Some obstacles have been resolved.
●Power PC compatible
"Sega Converter" operates in native mode when started on a Power Macintosh.

■Introduction

"SEGA Converter" is an application that displays image data saved in formats such as PICT, DGT, RGB, BOB, etc., and converts these files between each other. You can also perform simple retouching and editing such as copy and paste.

■Caution

If the image data saved on the clipboard is too large when copying and pasting with other applications, the application may not be able to start. In this case, select "SEGA Converter" on the Finder, and then increase the application size by selecting "Get Info" from the file menu.

■File menu

●New...
Displays a dialog and creates a new window with the specified image.

◆Image size Specify the size of the newly created window. Width: Enter the horizontal size. Height: Enter the vertical size. ◆Color mode Specify the color mode (BitDepth) of the newly created window. RGB Color: Create in 32bit (RGB mode). Index Color: Create with 8bit (palette mode). ◇ System: Uses the Macintosh system palette. ◇ Custom: Uses the palette saved on the clipboard.

●Open...
Displays an open dialog, reads a file in the specified format, and displays it in the window.

●Close
Close any open windows. If there are any changes to the file, you will be asked if you want to save it or just discard it. If you want to save it, click the "Save" button. Performs the same operation as ``Save as..''.

●Save
Overwrites and saves the window contents with the same name.

●Save as...
Displays the save dialog and converts and saves the file in the specified format. If you specify Save Selection, only the selected range will be saved.

●Catalog
Displays the catalog dialog and displays, saves, etc. all files in the specified format in the specified folder. Click the "Do it" button to execute the catalog, and the "Cancel" button to close the dialog.

◆New Displays an open dialog and catalogs files of the specified format in the specified folder. ◆Continuous display Displays files registered in the catalog continuously. ◆Save Saves cataloged files continuously in the specified format.

●Environmental settings...
Display a dialog and set the save environment.

◆Automatically generated palette When converting from a format without palette information (PICT, RGB, etc.) to a format with palette information (DGT, BOB, etc.), a palette is automatically generated. Specify how. ◇System Uses the Macintosh system palette. ◇Match to colors in use Generates a palette optimized to match the image. ◆Dither type Specify the type of dither processing when the above processing is performed. ◇None No dither processing is performed. ◇Error Diffusion Performs dither processing using the error diffusion method. ◇Pattern Performs pattern dither processing. ◆Icon ◇Preview icon creation Paste an image onto the icon of a saved file.

●Quit
Exit the application.

■Edit menu

●Cancellation
●Cut
●Copy
●Paste
●Erase
●Select all
Each command is based on general paint applications. You can copy and paste between other applications.

■Option menu

Perform operations related to displaying the first file (current file).

●View information
Display information about the current file. Clicking the zoom box expands the window to display the contents of the palette, if the current file uses it.

●Magnification
Specify the display magnification of the current file.

●Grid
Display a grid in the current file.

●Horizontal selection unit
●Vertical selection unit
Set the selection (movement) unit for the horizontal and vertical selection tools, respectively.

●Data calculation
Calculates the data capacity of the selected range.

■Window menu

Select the current file.

■Tool palette

Each tool is based on common paint applications.

●Selection tool
Specify a rectangular range by "drag". After selection, proceed to general floating operation. You can expand the selection range by pressing Shift+drag. Specify the expansion method by double-clicking.

◆Act as Add The specified range is added to the current selection range. ◆ Act as delete The specified range will be deleted from the current selection range. ◆Operation as inversion The current selection range is inverted (XOR) according to the specified range.

●Magnifying glass tool
The image will be enlarged 2 times centered around the clicked point. Press Option+Click to reduce the size by 1/2. Double-click to display at full size.

●Dropper tool
The color of the clicked point becomes the foreground color (drawing color). The background color is specified with Option+Click.

●Pencil tool
Draw in the foreground color. Option+Click works the same way as the eyedropper tool. Double-click to change the pen size.

●Foreground color/background color box
Displays the current foreground and background colors. Click the arrow to swap the foreground and background colors. "Double-click" to display the color picker and change the color. If the current file uses a palette, select the palette by clicking and dragging.
