Sega Painter User's Manual/2. Menu
File | Edit | Image | Options | Special | Window

■Option menu

Configure display settings for the document you are working on and various settings for editing functions.
You can also change the document size, color, and palette data here.

●Document size
Change the size of the document you are currently working on.

  • vertical:
    Horizontal: Enter the change value for the document size.
  • □Fix aspect ratio: If you change the horizontal or vertical size, the size of the non-input side will be automatically adjusted to maintain the aspect ratio of the original document size.
  • Placement: Click to specify the position of the image data in the document after resizing.

●Document palette
Changes the base palette of the document you are currently working on.

Click the position you want to change on the color list to specify the reference palette.

  • □Color overwrite: Overwrites the palette data of the original document to the specified palette position.

●Palette editing
Edit the palette information of the selected image.
For details, please refer to the document " 4. Color Palette ".

●Color editing
Edit the color palette information managed by SegaPainter.
For details, please refer to the document " 4. Color Palette ".

●Display magnification
Specify the magnification when displaying the image.

  • x1: Display at the same size.
  • x2: Display at 2x magnification.
  • x4: Display at 4x magnification.
  • x8: Display at 8x magnification.

●Grid display G
Displays a grid of fixed units in the current document.

●Monitor display position
Specifies where the currently active document is displayed in the monitor window.

Specify the display position by dragging the displayed monitor frame.

  • Cursor button: Moves the monitor frame vertically and horizontally with each button click.
  • Init: Initialize the display position to the (0,0) position of the image data.

●Various settings
Configure settings for each tool on the tool palette and each function on some menus.

◆Pencil tool
Set the shape and size of the pencil tool.

  • Shape: Select the shape of the pencil.
  • Size: Select the pencil size.

◆Brush tool
Set the shape and size of the brush tool.

  • Shape: Select the brush shape.
  • Size: Determine the brush size using the scroll bar.
  • Make background color transparent: Draws with a transparent background color.

◆Eraser tool
Set the shape and size of the eraser tool.

  • Shape: Select the shape of the eraser.
  • Size: Select the eraser size.

◆Line tool
Set the thickness and drawing method of the line tool.

  • Shape: Select the shape of the line.
  • Thickness: Select the line thickness.
  • Specification method: Select the drawing specification method.
    • Drag specification: Draw a straight line connecting the drag start and end points.
    • Specify 2 points: Draw a straight line connecting the two clicked points.
    • Horizontal scan: Draws a horizontal line in a continuous area with the same palette code as the clicked point.
    • Vertical Scan: Draws a vertical line in a contiguous area with the same palette code as the clicked point.
  • Make background color transparent: Draws with a transparent background color.

◆Airbrush tool
Set the thickness and density of the airbrush tool.

  • Size: Specify the size of the airbrush using the scroll bar.
  • Density: Specify the airbrush density using the scroll bar.
  • Make background color transparent: Draws with a transparent background color.

◆Rectangle tool
Set the thickness and drawing method of the rectangle tool and rectangle fill tool.

  • Thickness: Specify the thickness of the rectangle drawing. This setting has no effect on the Rectangle Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws a rectangle with vertices at the start and end points of the drag.
    • From center: Draws a rectangle centered on the starting point of the drag, with the ending point as the vertex.
  • Make background color transparent: Draws with a transparent background color.

◆Rounded rectangle tool
Set the thickness and drawing method of the rounded rectangle tool and rounded rectangle fill tool.

  • Thickness: Specify the thickness of the rounded rectangle drawing. This setting has no effect on the Rounded Rectangle Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws a rounded rectangle inscribed in a rectangle with vertices at the drag start and end points.
    • From center: Draws a rounded rectangle centered on the drag start point and inscribed in a rectangle with the end point as the vertex.
  • Corner radius: Specify the radius of the rounded corner.
  • Make background color transparent: Draws with a transparent background color.

◆Ellipse tool
Set the thickness and drawing method of the ellipse tool and ellipse fill tool.

  • Thickness: Specify the thickness of the oval drawing. This setting has no effect on the Elliptical Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws an ellipse inscribed in a rectangle with vertices at the start and end points of the drag.
    • From center: Draws an ellipse inscribed in a rectangle with the drag start point as the center and the end point as the vertex.
  • Make background color transparent: Draws with a transparent background color.

◆Selection tool settings
Use this when you want to apply the selection tool to a certain unit.

  • Selection unit: Specify the unit to be adsorbed.
  • Always adsorbs: Always works by adsorbing to the selected unit.
    " +J" shortcut has been assigned.

◆Grid settings
Set the grid units and colors.

  • 1 pixel:
  • 8 pixels:
  • 16 pixel: Displays a grid for each checked unit.
  • ? pixel: Displays a grid of units entered.

If you want to change the grid color for each unit, click on the color box to call up the color picker.
