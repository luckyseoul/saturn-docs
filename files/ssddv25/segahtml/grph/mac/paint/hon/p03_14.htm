Sega Painter User's Manual/3.Tool Palette

■Special tools

●Drag and drop tools
Various functions can be achieved by dragging and dropping items within a window or between windows.

◆ Standard window selection range → Standard window:
This is the same function as copy and paste.

◆Palette window → Standard window:
Fills the continuous area of the same palette code as the dropped point with the drag source palette code.

◆Palette window → Palette window:
Sets the drag source color code to the dropped palette code.

◆Palette window → Color pit window:
Set the color picker's edit color to the color code of the drag source.

◆Color box in color picker window → Palette window:
Sets the color picker's edit color to the dropped palette code.

◆Palette editing window → Palette editing window:
◆Color editing window → Color editing window:
Sets the drag source color code to the dropped palette code.

◆Palette editing window → Palette window:
◆Color editing window → Palette window:
Sets the drag source color code to the dropped palette code.

◆Palette window → Palette editing window:
◆Palette window → Color editing window:
Sets the drag source color code to the dropped palette code.

◆Palette editing window → Color picker window:
◆Color edit window → Color picker window:
Set the color picker's edit color to the color code of the drag source.

◆Color picker window color box → Palette editing window:
◆Color box in color picker window → Color edit window:
Sets the color picker's edit color to the dropped palette code.
