Sega Painter User's Manual/3.Tool Palette

■Object tool

object tools

drag:
Add objects.

Control+??+drag:
The above functions are adsorbed to the selected unit.

Double-click the icon:
Set selection conditions.

click:
Select an object.

◆Function after selection
After selection, the object tool functions as shown below using key operations.

drag:
Move the selected object's position.

Drag control points:
Resizes the selected object.

Option+drag:
Adds an object of the same size as the selected object
