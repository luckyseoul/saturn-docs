Sega Painter User's Manual

1.First of all

■Overview

"Sega Painter" is an application that reads multiple image data saved in PICT, DGT2, etc. formats and edits it as a general painting tool.
Edited data can be registered as an object and played as a simple animation.
It is also possible to display real-time data on a home TV monitor using a target box.

■Caution

"Sega Painter" requires approximately 4MB of memory at startup, but may require more "temporary memory" during operation. Make sure you have enough memory on your Macintosh before using it.

■Restrictions

"Sega Painter" is compatible with the following Sega development targets.

  1. Saturn Target Model-S Graphics Box
  2. Saturn Cartridge Development System (commonly known as CartDev)

For precautions when making connections, please refer to the manual that comes with the target.

■Start screen

When you start the application with the target box connected, the following screen will be displayed.
Select the target box you want to connect to and click OK.

You can change the size of your TV screen.

  • Saturn (320 x 224): Displays in 320 dots x 224 dots.
  • Saturn (352 x 224): Displays in 352 dots x 224 dots.
  • Saturn (320 x 240): Displays in 320 dots x 240 dots.
  • Saturn (352 x 240): Displays in 352 dots x 240 dots.

■Operation screen

"Sega Painter" displays various windows.

●Document (drawing/editing) window
This is a window that performs standard drawing and editing operations, and multiple displays are possible. Edits made to this window will be saved as a document (file).
The document window has two layers depending on the purpose of the work, called the drawing (paint) layer and the editing (edit) layer. The drawing layer performs drawing according to general paint tools. The editing layer specifies the object (pattern) that will be registered in the animation. You can switch between individual layers as you work, and your edits are interconnected.

●Tool palette
Determines the functionality of editing operations for each window.
For details, please refer to the document " 3. Tool Palette ".

●Monitor window
This window is used to simulate the target monitor. An image of the closest document window (current window) is displayed.
The animation will be displayed in this window.

●Information window
Information about the current window is displayed.

●Color picker window
Displays Sega Color Picker.

●Palette window
The palette table for the current window is displayed. The palette code set as the foreground color is displayed as a marquee (animated dotted line frame).
For more information, see Menu .

●Pattern window
The currently set pattern is displayed. The currently selected pattern (current pattern) is displayed in a marquee.
For more information, see Menu .

●Panel window
Control animation.
For details, please refer to the document " 5. Animation ".

●Color editing window
Edit the color.
For details, please refer to the document " 4. Color Palette ".

●Palette editing window
Edits the palette of the selected document window.
For details, please refer to the document " 4. Color Palette ".

●Animation registration window
Register objects to be played as simple animations.
For details, please refer to the document " 5. Animation ".

●Template
This is a window with some of the functions of ``Sega Painter'' converted into buttons.
A brief explanation of the function will be displayed when you hover over each button.
