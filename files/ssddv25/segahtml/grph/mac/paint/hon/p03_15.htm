●Pattern display box
Specify the drawing pattern using the pop-up palette.
Palettes can be torn off to create floating windows (pattern windows).

●Foreground color display box
●Background color display box
Specify the foreground color or background color using the pop-up palette.
Palettes can be torn off to create floating windows (palette windows).

●Foreground/background exchange switch
Swaps the background color with the foreground color.

●Layer switching switch
Switch between the drawing (Paint) layer and the editing (Edit) layer.
The editing layer is used to register animation data.
(See " 5. Animation " for details)
