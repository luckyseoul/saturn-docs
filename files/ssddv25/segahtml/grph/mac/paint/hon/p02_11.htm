Sega Painter User's Manual/2. Menu
File | Edit | Image | Options | Special | Window

■Edit menu

Edit images in a Macintosh-like manner, such as redoing work or copying and pasting.
You can also adjust the selection range.

●Cancellation
Cancels the previous editing operation. Also, redo the ``undoed'' operation.

●Cut
Saves the selected image to the clipboard. The original image will be erased with the background color.

●Copy
Saves the selected image to the clipboard.

●Paste
Paste the image stored on the clipboard into the active document.
Pasted images can be moved freely (floating).

●Delete delete key
Erases the selected area of the image with the background color.

●Select all
Select all areas.

●Cancel selection
Clears selection.

●Invert selection range
Swaps the current selection and non-selection.

●Extend selection range
Extends selection by 1 pixel.

●Selection of selection range
Recall the recorded selection.

●Recording selection range
Records the current selection.

●Synthesis control
Adjust the display of the pasted or floating image and the original image.
