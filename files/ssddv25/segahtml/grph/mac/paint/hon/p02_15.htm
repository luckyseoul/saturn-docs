Sega Painter User's Manual/2. Menu
File | Edit | Image | Options | Special | Window

■Window menu

●Monitor display
Display the monitor window. If it is already displayed, move it to the front.

●Display of information I
Show an information window.

●Color picker display
Display the color picker window.

You can change the color code of the currently selected palette.
Change the RGB values by clicking or dragging each RGB color bar.

●Palette display
Display the palette window.

Select the foreground color for drawing by clicking on each colored area.
You can also call up the color picker and change the color code by double-clicking on the color part.

●Pattern display
Display the pattern window.

Select a pattern for drawing by clicking on the pattern area.

●Panel display
Display the animation panel.
For details, please refer to the document " 5. Animation ".

●Display template
View template.

Print
Print documents.

keep
Save the document.

background color transparent
Set/cancel whether to treat the background color as transparent when pasting image data.

Optimize images
Set/cancel whether to optimize color information when pasting image data.

Show grid when moving
Set/cancel whether to display the grid when dragging floating image data.

grid
Set/cancel whether to display the grid.

grid settings
Configure grid settings.

Always adsorbed
Set/cancel grid adsorption processing.

Selection tool settings
Configure selection tool settings.

Target SW
Disconnect and reconnect with the target.
(This button cannot be operated if the target is not connected)

Monitor display position
Specifies where the currently active document is displayed in the monitor window.
(This button cannot be operated if the target is not connected)

●Pattern editing
Display the pattern editing window and edit the pattern.
Note that the pattern to be edited is the pattern that is selected at that time.
If necessary, select the pattern you want to edit from the pattern window.

You can edit pixel units by clicking and dragging in the editing area.

  • Invert: Inverts pixel ON/OFF.
  • H Flip: H flips the entire pattern.
  • V Flip: V flips the entire pattern.
  • Revert: Return to the state where editing started.

●Selection of documents
Select the currently open document.
