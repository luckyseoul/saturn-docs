Sega Painter User's Manual

2. Menu

File | Edit | Image | Options | Special | Window

■File menu

Performs file management such as document input and output.
You can also print and close applications here.

●New
Displays a new dialog and opens a new document.

  • Color list: Specify the palette to assign to new documents.
  • Image size: Enter the size.
  • Palette Mode: Select the palette mode from 16 colors or 256 colors.

●Open
Open an existing document file.

  • Color list: Specify the palette to assign to the document.
  • Color Override: Overrides the color palette used in the document with the palette specified in the list.
  • Use dither: Apply dither when removing color.
  • Optimize: This is an effective option if you do not want to overwrite the palette.
    Opens the file using the palette specified in the list to optimize the document's image.
  • Palette Mode: Select the palette mode from 16 colors or 256 colors.
    If the mode of the specified file is different from the mode specified here, color compression (color removal) will be performed.
    * For documents saved with SegaPainter, the last edited palette and palette mode will be automatically assigned.

●Close
Close the document you are currently working on.

●Save
Save the document you are currently working on in a file with the same name.

●Save as another name
Rename the document you are currently working on and save it as a separate file.

●Export
Automatically saves each object set in the current window.

●Paper settings
Set various conditions for printing.

●Print
Print the document.

●End
Close "Sega Painter".
