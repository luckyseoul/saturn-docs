4.Palette color

■Palette editing

Edit palette information.
The images in the document you are currently working on (or within the selected area, if a range has been selected) will be edited.

□Preview
Confirm the editing results by displaying them in the selected document window (to be edited) before actually committing them.

□Color change
When you make the next edit, edit the color along with the palette number.

Change:
Specify the specified range of pallet numbers as the copy source.
Click the destination and overwrite the palette code.
Swap：
Specify the pallet number in the specified range as the replacement source.
Click the replacement destination and replace the palette code.

●Sort

Click the Do It button to rearrange the palette.
If a range is selected on the displayed color table, sorting will occur within that selection range.
If a range is selected in the currently active document window, only the palette codes within that selection will be sorted.

frequency of use:
Sort the palettes in order of frequency of use.

Colors used:
Sort the palette by colors used.

Duplicate color:
Sort the palette by sorting the same colors among the colors used.
At this time, if the key is pressed, the palettes after the one cleared by sorting are moved forward.

Color ascending order:
Sorts the palette in descending order of color brightness.

Descending color order:
Sorts the palette in descending order of color brightness.

Color arrangement:
Arranges used colors at the front and unused colors at the back.

●Reset
Returns the palette you were currently working on and the document window being edited to the state they were in when you started editing.
All work you have done up to that point will be discarded.

●Revert
Returns the palette you were currently working on and the document window being edited to their last saved state.
Any work you have done up to that point will be discarded.

●Entry
Convert and confirm the palette and document to be edited based on the work done to date.

●Cancel
Discards all the work you have done so far and ends palette editing.

●OK
Convert and confirm the palette and the document to be edited based on the work done so far, and finish palette editing.

■Palette editing tools

The selectable tools for palette editing are as follows.

selection tools

rectangular selection tool

drag:
Select the rectangle.

click:
Clears selection.

special tools

drag and drop tools

Palette editing window → Palette editing window:
Sets the drag source color code to the dropped palette code.

Palette editing window → Palette window:
Sets the drag source color code to the dropped palette code.

Palette editing window → Color picker window:
Set the color picker's edit color to the color code of the drag source.

Palette window → Palette editing window:
Sets the drag source color code to the dropped palette code.

Color picker window color box → palette editing window:
Sets the color picker's edit color to the dropped palette code.

■Color editing

Edit the color palette information managed by SegaPainter.

□Preview
Before actually converting the editing result, display it in the document window (to be edited) and check it.

●RGB color/HSL color/V (intensity) button
Adjust the RGB value, HSL value, and V value of the selected range.
Click the up arrow on each button to increase the value, and click the down arrow to decrease the value.

●Copy
Specifies the specified range of colors as the copy source.
Click the destination and overwrite the color code.

●Move
Specifies the specified range of colors as the source of movement.
Click the destination and overwrite the color code. The specified source color will be erased.

●Swap
Specify the specified range of colors as the replacement source.
Click on the replacement destination and replace the color code.

●Blend
Adds gradation to the first and last colors within the selection range.

●Color

Click the Colors button to convert colors, etc.

System color:
Converts the colors in the selection range to colors from the system palette.

Negative/positive reversal:
Inverts the colors within the selection.

Right shift:
Shifts each color in the selection one position to the right.

Left shift:
Shifts each color in the selection one position to the left.

Red←→Green:
Swaps the R and G values of the colors within the selection range.

Green←→Blue:
Swaps the G and B values of the colors within the selection range.

Blue←→Red:
Swap the B and R values of the colors within the selection range.

Swapping the array:
Swaps the vertical and horizontal alignment of the color array.

●Sort

Click the Do It button to rearrange the palette.

Color ascending order:
Sorts the palettes within the specified range in descending order of brightness.

Descending color order:
Sorts the palettes within the specified range in descending order of brightness.

Duplicate color:
Delete colors from palettes with duplicate color codes within the specified range.

●Load
Load Photoshop CLUT format files.
The data will be loaded into the palette for one index currently being edited.

●Save
The palette for one index currently being edited will be saved as a CLUT file in Photoshop format.

●Reset
Returns the color table you are currently working on and the document window being edited to the state they were in when you started editing.
All work you have done up to that point will be discarded.

●Revert
Returns the color table you are currently working on and the document window being edited to their last saved state.
Any work you have done up to that point will be discarded.

●Entry
Convert and finalize the color table and the document to be edited based on the work to date.

●Cancel
Discards all work done up to now and ends color editing.

●OK
Convert and confirm the color table and the document to be edited based on the work done so far, and finish palette editing.

■Color editing tools

The selectable tools for color editing are as follows.

selection tools

rectangular selection tool

drag:
Select the rectangle.

click:
Clears selection.

drawing tools

dropper tool

click:
Displays the color of the clicked point in the color picker.

eraser tool

drag:
Erases the color of the clicked point.

Double-click the Option+icon:
Clears the entire palette (or within the selected range, if a range is selected) of the colors at the displayed index.

special tools

drag and drop tools

Color editing window → Color editing window:
Sets the drag source color code to the dropped palette code.

Color editing window → Palette window:
Sets the drag source color code to the dropped palette code.

Color edit window → Color picker window:
Set the color picker's edit color to the color code of the drag source.

Palette window → Color editing window:
Sets the drag source color code to the dropped palette code.

Color box in color picker window → Color edit window:
Sets the color picker's edit color to the dropped palette code.
