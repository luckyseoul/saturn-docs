Sega Painter User's Manual/2. Menu
File | Edit | Image | Options | Special | Window

■Image menu

You can change the image by changing its size and shape.

●Mirror image
Inverts the selected area of the image as if it were reflected in a mirror. The flipped image will be floating.

  • Horizontal flip: Flip horizontally.
  • Vertical flip: Flip vertically.

●Rotation
Rotates the selected image around the center. The rotated image will be floating.

  • +90 degrees: Rotate 90 degrees counterclockwise.
  • -90 degrees: Rotate 90 degrees clockwise.
  • Free rotation: Rotate by entering an angle.

●Scale
Enter the size of the image and scale it based on the center. The scaled image will be floating.

  • After change: Enter the image size after change.
  • □Fix aspect ratio: If you change the horizontal or vertical size, the size of the side that is not input will be automatically adjusted to maintain the aspect ratio of the original image size.
  • 50%:
    72%:
    144%:
    200%: Scales by the specified magnification while maintaining the aspect ratio of the image data before operation.
  • Init: Return to the image data before starting the scaling operation.
  • Cell: Adjust the changed size to be a multiple of 8 pixels horizontally.
  • Preview: If you manually input the image size, you can check the scaling result using this button.

●Special deformation
Transforms and maps an arbitrary 4-point range image to a separately specified 4-point range.
Immediately after selecting "Special Transformation", the mouse cursor changes to a shape waiting for vertex input.
If you click and set any four points on the image before transformation on the document window, and then set any four points after transformation in the same way, the transformation results will be displayed.

●Plug-in
Select the functionality added as a plugin module.
For functions and operating procedures, please refer to the documentation at the time of each module release.
