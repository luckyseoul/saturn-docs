Sega Painter User's Manual/3.Tool Palette

■Selection tools

rectangular selection tool

drag:
Select the rectangle.

click:
Clears selection.

Shift (hold) + drag:
Select the range with a square.

Control+??+drag:
The above functions are adsorbed to the selected unit.

Option+Shift+ +Drag:
Functions as a drag and drop tool (described later).

Double-click the icon:
Set selection conditions.

  • Selection unit: Specify the unit to be adsorbed.
  • Always adsorbs: Always works by adsorbing to the selected unit.
    " +J" shortcut has been assigned.

(For palette editing window/color editing window)

drag:
Select the rectangle.

click:
Clears selection.

Lasso (free shape selection) tool

drag:
Select a range using freeform shapes.

click:
Clears selection.

Option+Click:
Select a polygon.

Control+??+drag:
The above functions are adsorbed to the selected unit.

Double-click the icon:
Set selection conditions.

automatic selection tool

click:
Selects a contiguous area of the palette code of the clicked point.

Option+Click:
Selects the area of the same palette code as the clicked point.

◆Calculation function for selected area
With selection tools, the selection range is calculated as follows by key operation when selecting.

Shift+drag:
Add a selection.

+Drag:
Delete the selection.

Shift+ +Drag:
Select Common Area.

◆Function after selection
After selection, selection tools function as shown below by key operations.

drag:
Move the image in the selected area. The source area will be filled with the background color.

Option+drag:
Copies the image of the selected area. The source image remains unchanged.

click:
Commit the image you are moving or copying.

Option+ +Drag:
Move the selection frame.
