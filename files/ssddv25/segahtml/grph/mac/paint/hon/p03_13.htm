Sega Painter User's Manual/3.Tool Palette

■Drawing tools

◆Drawing area mask function
For drawing tools, if there is a selection range, only the inside will be drawn (the drawing area will be masked by the selection range).

dropper tool

click:
Makes the palette code of the clicked point the foreground color.

Option+Click:
Sets the palette code of the clicked point as the background color.

+Click:
Changes the area drawn in the foreground color to the palette code of the clicked point.

(For color editing window)
Click: Displays the color of the clicked point in the color picker.

magnifying glass tool

click:
The image will be enlarged twice centered on the clicked point.

Option+Click:
Reduces the display by 1/2 times centering on the clicked point.

Double-click the icon:
Display at the same size.

brush tool

drag:
Draw a free curve in a pattern.

Shift+click:
Draws a straight line in a pattern from the last clicked point.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Set brush style.

  • Shape: Select the shape of the brush.
  • Size: Determine the brush size using the scroll bar.
  • Make background color transparent: Draws with a transparent background color.

pencil tool

drag:
Draw a free curve in the foreground color.

Shift+click:
Draws a straight line from the last clicked point in the foreground color.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Set pencil style.

  • Shape: Select the shape of the pencil.
  • Size: Select the pencil size.

line tools

drag:
Draw straight lines in a pattern.

Shift+drag:
Draws in a fixed horizontal, vertical, or diagonal direction of 45 degrees.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Set line style.

  • Shape: Select the shape of the line.
  • Thickness: Select the line thickness.
  • Specification method: Select the drawing specification method.
    • Drag specification: Draw a straight line connecting the drag start and end points.
    • Specify 2 points: Draw a straight line connecting the two clicked points.
    • Horizontal scan: Draws a horizontal line in a continuous area with the same palette code as the clicked point.
    • Vertical Scan: Draws a vertical line in a contiguous area with the same palette code as the clicked point.
  • Make background color transparent: Draws with a transparent background color.

eraser tool

drag:
Draw a free curve with the background color.

Shift+click:
Draws a straight line from the last clicked point using the background color.

Option+Click:
Acts as an eyedropper tool. Set the background color.

Double-click the Option+ icon:
Erases the entire window with the background color.

Double-click the icon:
Set the eraser style.

  • Shape: Select the shape of the eraser.
  • Size: Select the eraser size.

(For color editing window)

drag:
Erases the color of the clicked point.

Double-click the Option+ icon :
Entire palette of visible indexes
(or within the selected range if a range is selected)
Erase the color of.

Bucket (fill) tool

click:
Fills a contiguous area with the same palette code as the clicked point with a pattern.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

airbrush tools

drag:
Draw in a pattern like an airbrush.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Set airbrush style.

  • Size: Specify the size of the airbrush using the scroll bar.
  • Density: Specify the airbrush density using the scroll bar.
  • Make background color transparent: Draws with a transparent background color.

Rectangle Fill Tool/Rectangle Tool

drag:
Fill and draw a rectangle with a pattern.

Shift+drag:
Fill and draw a square with a pattern.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Set the rectangle style.

  • Thickness: Specify the thickness of the rectangle drawing. This setting has no effect on the Rectangle Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws a rectangle with vertices at the start and end points of the drag.
    • From center: Draws a rectangle centered on the starting point of the drag, with the ending point as the vertex.
  • Make background color transparent: Draws with a transparent background color.

Rounded Rectangle Fill Tool/Rounded Rectangle Tool

drag:
Fill and draw a rounded rectangle with a pattern.

Shift+drag:
Fill and draw a rounded square with a pattern.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Sets the rounded rectangle style.

  • Thickness: Specify the thickness of the rounded rectangle drawing. This setting has no effect on the Rounded Rectangle Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws a rounded rectangle inscribed in a rectangle with vertices at the drag start and end points.
    • From center: Draws a rounded rectangle centered on the drag start point and inscribed in a rectangle with the end point as the vertex.
  • Corner radius: Specify the radius of the rounded corner.
  • Make background color transparent: Draws with a transparent background color.

Ellipse Fill Tool/Ellipse Tool

drag:
Fill and draw an oval with a pattern.

Shift+drag:
Fill and draw a perfect circle with a pattern.

Option+Click:
Acts as an eyedropper tool. Set the foreground color.

Shift+Option+click:
Acts as an eyedropper tool. Set the background color.

Double-click the icon:
Sets the oval style.

  • Thickness: Specify the thickness of the oval drawing. This setting has no effect on the Elliptical Fill tool.
  • Specification method: Select the drawing specification method.
    • From vertices: Draws an ellipse inscribed in a rectangle with vertices at the starting and ending points of the drag.
    • From center: Draws an ellipse inscribed in a rectangle with the drag start point as the center and the end point as the vertex.
  • Make background color transparent: Draws with a transparent background color.

font tools

click:
Displays the character settings dialog and draws the specified font in a pattern at the clicked point.

  • Font: Specify the font type from the pop-up menu.
  • Size: Specify the font size.
  • Style: Specify the font style.
