2. Menu explanation

■Tool palette

The basic operations of the tool palette are similar to those of general graphics applications. While the editing target of general applications is pixels, in "MapEditor" and "Screen Editor", the editing target is composed of images that are characters.

 rectangular selection tool


 ◇When selected


 drag: Select the rectangle.


 Shift+drag: Adds the specified range to the selection.


 Apple + drug: Removes the specified range from the selection.


 Shift+Apple+drag: Selects the common area of the specified range and selection range.


 click: Clears selection.






 ◇After selection (selection range)


 drag: Move the selected data.


 Option+drag: Copy and move the selected range of data.


 click: Clears selection.






 selection tool


 ◇When selected


 click: Makes the specified character the selection range.


 Shift+click: Adds the specified character to the selection range.


 Apple + Click: Removes the specified character from the selection range.


 Shift+Apple+Click: Selects the common area of the specified character and selection range.






 ◇After selection (selection range)


 drag: Move the selected data.


 Option+drag: Copy and move the selected range of data.


 click: Clears selection.






 eraser tool




 drag: Draw with erased data.


 Double click: Erases the data in the selected range.






 pencil tools




 drag: Draw with the specified data.


 Option+Click: Specify the data at the click position.






 magnifying glass tool




 click: Displays 2x magnification.


 Option+Click: Displays 1/2 times smaller size.






 rectangle tool




 drag: Draws a rectangular area with the specified data.


 Option+Click: Specify the data at the click position.






 dropper tool




 click: Specify the data at the click position.






 drag drop tool


 Transfer the selected image data to another window or other tools that support the drag-drop function using drag-drop operations. This function is valid for the area selected on the image window or CG window. Please note that the information related to the palette may be destroyed as it is transferred to other tools as PICT data.
