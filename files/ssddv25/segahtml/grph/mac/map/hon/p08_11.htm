MAP/SCREEN Editor User's Manual

■Editing the character

New character data is created by pasting from the image window. You can also copy and paste from other applications.
Specify the range with the rectangular selection tool/selection tool, and perform various edits using Copy & Paste, rearrangement, or in combination with the image menu.
As an optional feature, you can copy the selection array to the Map window as is.

●Attribute settings
Attributes are auxiliary information assigned to each character. Basically, you can set arbitrary data for the map to be processed by the program.

Select "Attribute" from the image menu to open the attribute settings dialog. The value entered here will be set as attribute data for the specified range of characters.

To check the set attribute data, check the attribute section of the option menu "Display".

●Display palette
Since the CG data itself does not have palette information, the characters on the CG window are displayed in the temporarily set palette colors.
When registering a character with the assumption that multiple palettes will be used, if the set palette interferes with editing work, select "Display Palette" from the image menu to change the display palette. please.

Palette changes always affect the entire character area of the CG window. Additionally, the palette information specified at that time is added to the data registered to the map.

●Sort
Search for duplicate characters with some conditions and combine them into one character. First, specify the range to be sorted on the CG window and select "Sort" from the image menu. A dialog for specifying sorting conditions will be displayed.

Set the necessary conditions and perform the sort.

Information about each character moved by sorting will be reflected in the map data.

●Offset
Moves the registration position (character number) of all registered characters backward by the specified number of characters. When you select "Offset" from the image menu, a dialog for entering the offset value will be displayed.

Information about each character moved by offset specification is reflected in the map data.

●Usage check
Replaces unused registered characters as map data with character number 0. After this operation, if you need to move the unused character area forward, please use "Sort" together.
