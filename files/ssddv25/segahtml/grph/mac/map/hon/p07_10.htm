MAP/SCREEN Editor User's Manual

■Window menu

●Image window
Show or activate the image window.

●CG window
Show or activate the character window.

●Map window
Show or activate the map window.

●Palette editing...
Display the palette editing window and edit color palette data.

◆R
Changes the red intensity of the selection color.

◆G
Changes the green intensity of the selection color.

◆B
Changes the blue intensity of the selection color.

◆H
Changes the hue of the selection color.

◆S
Changes the color saturation of the selection.

◆L
Changes the brightness of the selected range's color.

◆V
Changes the intensity of the selection color.

◆Copy
Copies the selected range's color table to the specified palette starting point.

◆Swap
Exchanges the color table of the selected range with the color table of the position starting from the specified palette.

◆Entry
Reflects the editing results in the character window and map window.

◆Revert
Redo the edit. Returns to the last "Entry" state.
