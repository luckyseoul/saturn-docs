MAP/SCREEN Editor User's Manual

■Option menu

●Grid
Displays a grid for each character in each editing window. The map window also displays a grid of pages.

●Magnification
Specify the display magnification (×1,×2,×4) of each editing window. The map window can also be displayed in reduced size (1/2, 1/4).

●Display
Specify the data type to be compositely displayed in each editing window.

◆Attribute
The attribute number is displayed.

◆Special priority
A blue checkered pattern will be displayed on characters with special priority flags.
Special priority display can only be displayed in the map window.

◆Special color calculation
A red checkered pattern is displayed on characters with the special color calculation flag.
Special color calculation display can only be displayed in the map window.

●View information...
Displays an information window when "character editing" or "map editing".

◆Character window information

◆Map window information

For both information windows, you can select the display format from decimal or hexadecimal.

◆Dec.
Displays information in decimal.

◆Hex.
Displays information in hexadecimal.

●Grid color
Set the display color of the grid. Attribute numbers will also be displayed in the color set here.
Different colors can be set individually for both character and map windows. The image window uses the display color set in the character window.
