MAP/SCREEN Editor User's Manual

■Flag menu

Available when the map window is active. Set various flags for Sega Saturn VDP2.

●H inversion
Sets the H inversion flag for the pattern name in the specified range.

●V inversion
Sets the V inversion flag for the pattern name in the specified range.

●Special priority
Sets special priority flags for the specified range of pattern names.

●Special color calculation
Sets the special color calculation flag for the pattern name in the specified range.

●Palette...
Changes the palette of pattern names in the specified range.
Please note that the settable range changes depending on the "color mode" and "pattern name size" of the edit file.

●Map size
Change the editing area of the map window. Enter the map size in pages.
Please note that if the changed size is smaller than the map size currently being edited, the editing area will be cut off.
