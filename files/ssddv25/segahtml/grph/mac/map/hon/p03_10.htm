MAP/SCREEN Editor User's Manual

■Edit menu

Edit in each window. The basic operations are similar to those of general Macintosh applications. The functions of "Character editing (Screen Editor)" and "Map editing (Map Editor)" may differ.

●Cancellation
Cancels the previous editing operation. It also redoes the ``undo'' operation.

●Cut
◆When editing a character
Saves the selected range character image and pattern name array to the clipboard. Characters in the selection range will be erased with #0 code.

◆When editing the map
Saves the selected pattern name array to the clipboard. The pattern name of the selection is filled with #0 characters.

●Copy
◆When editing a character
Saves the selected range character image and pattern name array to the clipboard. The characters in the selection remain as they are.

◆When editing the map
Saves the selected pattern name array to the clipboard. The pattern name of the selected range remains unchanged.

●Paste
◆When editing a character
Paste the character image stored on the clipboard into the character window.

◆When editing the map
Paste the pattern name array stored in the clipboard into the map window.

●Erase
◆When editing a character
Erase the selected range of characters with #0 code.

◆When editing the map
Fills the selected pattern name with #0 characters.

●Select all
Select everything in the window.

*Character images saved on the clipboard when editing characters can be copied and pasted between other applications as PICT data. However, in this case, please be careful as the palette information may be destroyed.

*The pattern name array saved on the clipboard when editing a character can of course be pasted into the map window.
