MAP/SCREEN Editor User's Manual

■File menu

Performs file management such as file input/output. You can also close the application here.

●New...
Displays a new dialog and opens a new file. Please note that parameters other than map size cannot be changed during editing.

  • map size
    Enter the map size in pages (1 page = 512 x 512 dots).

  • color mode
    Specifies the color mode for new files.

  • Pattern name size Specify the pattern name size of the new file.

●Open...
Load the existing "SEGA2D" file.

●Close
Temporarily closes the currently active window.

●Save
Save the edited file in the "SEGA2D" format with the same name.

●Save as...
Save the edited file in the alias "SEGA2D" format.

●Import...
Loads an image file in the specified format and opens an image window. Specifies the palette if the character is being edited in palette mode.

◆Color overwrite
If specified, the palette data of the image file will be used. If the image file does not have palette data (such as a full-color image), an optimal palette will be automatically created. If not specified, the palette data of the character currently being edited will be used.

◆Palette mode
Specifies palette mode. Selection is limited by the color mode of the edit file.

◇16
This can be selected if the editing file is in 16-color mode. Open an image window with 16 colors.

◇16×16
This can be selected if the editing file is in 16-color mode.
Opens an image window assuming that the image file is created with multiple palettes in mind and uses up to 16 colors per character.

◇256
If the editing file is in 256 color mode, it will be forcibly selected. Opens an image window with 256 colors.

●Export...
Saves the map window image to an image file in the specified format. Saving is done by dividing the page into individual pages.

●End
Exit the application.
