3.Basic operations

■Before starting editing work

There are some settings in "Map Editor/Screen Editor" that cannot be changed once editing is in progress.
When creating a new map, please carefully check the setting information that is checked at startup before proceeding.
*For details on color mode and pattern name table, please refer to the VDP2 documentation in the hardware manual.

■Character registration procedure

Select "Import" from the file menu to load the image file for character registration and open the image window.
Next, specify a range on the image window using the rectangle selection tool/selection tool and copy and paste it into the CG window to register it as a character.

It is also possible to paste image data copied from other applications directly into the CG window.
