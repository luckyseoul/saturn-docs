MAP/SCREEN Editor User's Manual

1.First of all

"Map Editor" and "Screen Editor" are applications that load multiple images saved in formats such as PICT and DGT2 , separate pixels by character, and place them in an arbitrary area (map). Used for data creation.

The edited data will be saved in "SEGA2D" format .

  • "Map Editor" supports "character size = 2 cells x 2 cells" mode.

  • "Screen Editor" supports "character size = 1 cell x 1 cell" mode.

 Note
 In this manual, "Map Editor" and "Screen Editor" are collectively referred to as the "MAP/SCREEN Editor User's Manual." We will explain each editor's unique features, if any.
