MAP/SCREEN Editor User's Manual

■Edit map

Character data is placed on the template. Specify this and place it on the map using the pencil tool/rectangle tool.

It is also possible to select multiple characters on the template at once by dragging and place them in the map window.

In addition, specify a range using the rectangular selection tool or selection tool on the map window, and set various flags by copying and pasting, changing the layout, or in combination with the Flag menu.

If you want to reflect the imported image data as is on the map, register the image data as a character in the CG window, then copy the data in the CG window and paste it in the map window. By performing such steps beforehand and sorting the characters, you can reduce to some extent the trouble of reassembling characters that have been separated by sorting.

●H inversion, V inversion
Change the map data layout of the selected range and set or cancel the H/V inversion flag. Map data with flags set will be highlighted according to the settings.

●Special priority, special color calculation
Set or clear special priority and special color calculation flags for the selected range. In addition, there is a mode to display the results of each setting under "Display" in the option menu.

*Blue: Special priority setting area / Red: Special color calculation flag setting area

●Palette...
Assign a palette to each character to the map data.
After specifying the range in the map window, select "Palette..." from the image menu to display a dialog for changing the palette. Please enter the starting address of the palette numerically, or click on the relevant part of the palette list to select the palette you want to change.

↓

*The selectable address unit ($10/$100) is determined by the color mode at the time of initial setting.
