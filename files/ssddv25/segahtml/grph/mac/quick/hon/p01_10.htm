■Release notes

●3.1J → 3.17J version upgrade information
  • We've fixed some obstacles.
  • Now compatible with Saturn Cartridge Development System.

●Restrictions
Version 3.17J supports the following SEGA development targets.

  1. Saturn Target Model-S Graphics Box
  2. Saturn Cartridge Development System (commonly known as CartDev)

For precautions when making connections, please refer to the manual that comes with the target.

If other applications using the development target (including a copy of "Quick Viewer") are running, normal operation cannot be guaranteed. When using Quick Viewer, be sure to make sure that no other applications are using the development target.

Also, if you start another application compatible with the development target while using "Quick Viewer", be careful not to connect to the target (click the [Discard] button in the "Target Selection" dialog). .
However, this does not apply if multiple development targets are connected with different IDs.

●Notes
  1. Please note that reducing the automatic transfer interval will make Macintosh processing more difficult.
  2. High resolution mode is only available when using Saturn CartDev.

■Introduction

"Quick Viewer" is an application that captures the Macintosh monitor screen and displays it using the Sega development target.
You can immediately check the display of images from any Macintosh application on the target TV screen without using files etc.

■Restrictions

Version 3.17J supports the following SEGA development targets.

  1. Saturn Target Model-S Graphics Box
  2. Saturn Cartridge Development System (commonly known as CartDev)

For precautions when making connections, please refer to the manual that comes with the target. >>P>

■Basic operations

When you start the application, the following dialog will appear. Set the development target and display mode you want to connect to, and click "OK".

If Saturn CartDev is connected, high resolution box will be enabled. If you select high resolution mode, each H size display will be doubled.

If communication with the target box is successful, the following window will be displayed.

Click inside the window to display the image in the capture area on the Macintosh monitor screen on the target TV screen.

If you want to change the capture area, follow the steps below.

  1. Drag the mouse pointer in and out of the window.
  2. A marquee of the target TV screen size will be displayed, so just move it to the position you want to display.
  3. When you release the mouse button, the capture area is set.

Display operations can also be performed automatically (automatic transfer) using a background task. Follow the steps below.

  1. When you select "Automatic Transfer Settings" from the "File" menu, the following dialog will be displayed.

  2. In the pop-up menu, select the interval for automatic forwarding.
    Please note that reducing the automatic transfer interval will make Macintosh processing more difficult.
