SpriteEditor User's Manual

3.About each window

●Main window

Displays an information list of already registered sprites and patterns.
Mainly used for editing sprites and pattern selection.

●Pattern editing window

This is a window for editing sprite placement, etc.
Each time a pattern is selected on the main window, the display changes to the corresponding pattern.

●Pattern information window

Information such as offset coordinates, inversion state, rotation center point coordinates, rotation angle, etc. is displayed for each sprite registered in the pattern.
In addition, you can change the registration order (display priority) and call the rotation center setting function from this window.

●Import window

This is a window for cutting out sprites from graphic data.

●Sprite settings dialog (batch/individual)

It is displayed by double-clicking a sprite item in the window (all at once) or a sprite item in the pattern information window (individual).
Move the center point and change the palette address for rotating sprites.

●Anime settings window

This is a window for creating animation data using patterns. It is not displayed when the target is not connected.
