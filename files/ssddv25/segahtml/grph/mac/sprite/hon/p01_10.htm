SpriteEditor User's Manual

1.First of all

■Overview

The purpose of "SpriteEditor" is to import various types of graphic data as sprite data and to generate patterns by combining multiple sprites.
This document describes each function of "SpriteEditor".
For the basic operation flow, please refer to "SpriteEditor Basic Operations".

■Restrictions

●About PowerMac compatibility
"SpriteEditor" runs in native mode when started on a PowerMac.

●About target support
"SpriteEditor" supports the following targets.

  1. Saturn Target Model-S Graphics Box

  2. For precautions when connecting to the Saturn Cartridge Development System (commonly known as CartDev), please refer to the manual that comes with the target.

●About operational limitations of “SpriteEditor”

  • "SpriteEditor" requires approximately 4MB of memory at startup, but it requires memory proportional to the editing size during operation, so please ensure that you have sufficient memory on your Macintosh before using it.

  • The total number of windows that can be open at one time is up to 32.

  • The number of sprites that can be registered is up to 255.

  • The number of patterns that can be added is up to 255.

  • The maximum number of sprites that can be set in one pattern is 255.

  • The maximum number of banks that can be specified in the animation settings is 255.

  • The maximum number of patterns that can be registered in one bank is 255.

The above maximum value is the upper limit of the range that can be managed on the tool.
Depending on the size of the actual registered picture data, a value smaller than the above value may be the limit.
