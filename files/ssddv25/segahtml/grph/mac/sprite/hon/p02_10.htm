SpriteEditor User's Manual

2.About the menu

●File menu

  • New ( +N)
    Secure a new registration area.

  • open...( +O)
    Open the file saved with this tool.

  • close( +W)
    Closes the current window being edited.

  • keep...( +S)
    Save the data being edited.

  • Save as...
    Save the data being edited under a different name.

  • import...
    Loads the graphic data file for sprite registration.
    As a special feature, when a file with animation settings is loaded using SegaPainter, an auto-import confirmation dialog will be displayed.

    By specifying the registration start position and selecting "Auto" here, sprites will be automatically registered according to the object area in the file.

  • export...
    Save already registered sprites individually in DGT2 format.

  • BG...
    Loads image data for background display.

  • Environmental setting...

    • Starting point H unit, starting point V unit
      Corrects the starting position of the selection range for cutting sprite data to the specified pixel unit.

    • Selection width H units, selection width V units
      Corrects the width of the area from the starting point of the selection range where sprite data is cut in the specified pixel unit.

    • 1pixel grid, 8pixel grid
      Set the grid for each unit that is displayed when "Grid Display" is selected from the option menu.

    • center line
      Set the line for displaying the origin position in the pattern editing window.

    • pattern background color
      Specifies the background color of the pattern editing window.

    • back pattern color
      Specifies the color used for the silhouette of the previous pattern that is displayed when "Back Pattern" is selected from the option menu.

  • end...( +Q)
    Close "SpriteEditor".

●Edit menu

  • cancel( +Z)
  • cut( +X)
  • copy( +C)
  • paste( +V)
  • erase
  • Select all ( +A)
  • Clear selection ( +D)

●Option menu

  • Zoom ( +1, +2, +4, +8)
    Set the display magnification for the import and pattern editing windows

  • Grid display ( +G)
    Set whether to display the grid in the import and pattern editing windows.

  • Sprite frame display
    Set whether to display sprite frames in the import and pattern editing windows.

  • Back pattern display
    Select whether to display the previous pattern in the pattern editing window.

  • BG settings

    Configure settings for the preloaded background image.
    Specify whether to display the background image and the display position for the pattern editing window.

  • monitor settings

    Configure settings for the display image output to the target side.
    Specify the monitor display position on the pattern editing window and whether to display the center line on the monitor.

●Pattern menu

  • Add new pattern ( +K)
    Add a new pattern registration area.

  • Sprite selection...

    Selects the specified sprite in the pattern.

  • Go to previous pattern ( +F)
    Moves the pattern to be edited one position forward.

  • Go to next pattern ( +R)
    Moves the pattern to be edited one step forward.

  • H inversion

    • Based on the origin
      The sprite selected in the pattern editing window is flipped horizontally based on the pattern origin.

    • for each sprite
      Flips the sprite selected in the pattern editing window horizontally while maintaining its placement coordinates.

  • V inversion

    • Based on the origin
      Flips the sprite selected in the pattern editing window vertically based on the pattern origin.

    • for each sprite
      Flips the sprite selected in the pattern editing window vertically while maintaining its placement coordinates.

  • rotate( +T)
    Specify the rotation angle value for the sprite selected in the pattern editing window.

●Window menu

  • pattern editing
    Open the pattern editing window.

  • Pattern information ( +I)
    Open the pattern information window.

  • Main
    Makes the main window current.

  • import
    Makes the import window current.

  • Anime settings ( +M)
    Open the animation settings window.
