3D Editor User's Manual/Window

■Hierarchical structure window

This window is displayed when you select “View” → “Hierarchy” in the main window. Controls the display/hide of the models that make up the currently selected hierarchy. You can also make edits such as changing the model name here.

◆Display
Displays the models that make up the currently selected hierarchy. If the hierarchy tree is collapsed, it applies to all models below it.

◆Hide
Hides the models that make up the currently selected hierarchy. If the hierarchy tree is collapsed, it applies to all models below it.

◆Name change
Changes the name of the model that makes up the currently selected hierarchy. When saving in MDL format, please note that the name specified here will be the variable name.

◆Hierarchy information
Displays matrix information for the currently selected hierarchy.

◆Close
Close the hierarchy window.
