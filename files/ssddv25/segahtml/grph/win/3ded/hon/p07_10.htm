3D Editor User's Manual/Window

■Attribute window

This window is displayed when you select “View” → “Attribute” in the main window. Attribute data such as color and display method can be set for each polygon that makes up the model.

  • material
    Set information related to the material such as the color and texture mapping of each polygon.
  • mode
    Set information related to how each polygon is drawn.
  • Z sort
    Set the Z sort flag.
  • gouraud
    Set information related to Gouraud shading.
  • option
    Set information about other optional attributes.

The attribute standards of "3D Editor" comply with SegaSaturn's VDP1 and SGL specifications.
In order to make effective use of the attribute editing function, basic knowledge of both of the above is required.

■“Material” settings

Set information such as the color and texture mapping of the currently selected polygon. Each set of information will be applied to the target polygon by clicking the "Update" button.
  • polygon
    Draw with polygons.
  • polyline
    Draw with a polyline.
  • texture map
    Draw with a deformed sprite (texture map). The texture data to be applied is specified by number.
  • light source
    Perform light source calculations.
  • Color
    Specify a non-texture color.
  • Sprite ID
    Specify the texture data to be applied as a texture map by number.
  • H flip
    Displays texture data horizontally flipped.
  • V flip
    Displays texture data upside down.

■“Mode” setting


Sets information about the drawing method for the currently selected polygon. Each set of information will be applied to the target polygon by clicking the "Update" button.
  • replace
    Display it as is.
  • shadow
    Show shadow.
  • half brightness
    Display with half brightness.
  • Translucent
    Display semi-transparent.
  • mesh
    Display mesh.

■“Z sort” settings


Sets the reference point for Z sorting of the currently selected polygons. Each set of information will be applied to the target polygon by clicking the "Update" button.
  • Center point
    Based on the center of the polygon.
  • latest point
    Use the nearest vertex of the polygon as the reference.
  • farthest point
    Use the innermost vertex of the polygon as the reference.

■“Gouro” settings


When performing Gouraud shading processing on the currently selected polygon, set the information. Each set of information will be applied to the target polygon by clicking the "Update" button.
  • gouraud
    Performs Gouraud shading processing.
  • light source
    Perform light source calculations.
  • Gouro table #0~#3
    Specify 4 vertices of the Gouraud table.

The relationship between the Gouraud and light source checkboxes and the actual shading processing is as follows.

■ “Options” settings


Sets information about other optional attributes for the currently selected polygon. Each set of information will be applied to the target polygon by clicking the "Update" button.

"plane"
Select the hidden surface removal processing method.
  • One side
    Processed as a one-sided polygon.
  • both sides
    Processed as double-sided polygons.
  • near clip
    Forces the display of polygons near the viewpoint, even if they change shape.
