3D Editor User's Manual

1. Introduction

■Overview

"3D Editor" can read 3D object files in a proprietary format and refer to 3D models in any direction and size. You can then add attribute information such as colors and texture maps to the polygon surfaces contained in the 3D model.
Additionally, texture mapping across multiple surfaces, which was said to be difficult due to SegaSaturn's specifications, has been made possible by the automatic texture data extraction function.

■3D Editor file format

"3D Editor" can handle the following file formats for different purposes.

[Reading]
  • SG3 file
    A binary file containing object (model) information.
  • SGT file
    A binary file containing texture information.

【keep】
  • SG3 file
    A binary file containing object (model) information.
  • SGT file
    A binary file containing texture information.
  • MDL file
    This is a C language data file that contains object (model) information.
  • TXR file
    This is a C language data file containing texture information.

[Import] [Export]
This is data that serves as a BMP file and other texture mapping materials. Additional changes can be made using plugin modules.
