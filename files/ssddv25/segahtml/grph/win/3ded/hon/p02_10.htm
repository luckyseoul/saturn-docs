3D Editor User's Manual

2. Basic editing of 3D Editor

■Edit attribute data

This section explains the series of tasks for editing objects (polygons).

●Open the model file
  1. In the main window, choose File → Open.

●Change the direction in which the model is displayed
  1. Select the Rotate Model tool.
  2. Drag it on the main window.
  3. The model will rotate.

  1. Select the Move Model tool.
  2. Drag it on the main window.
  3. The model moves.

  1. Select the Camera Settings tool.
  2. Select your camera from the pop-up menu.
  3. The viewpoint moves to the camera position.

●Set color to polygons
  1. Select the Polygon Selection tool.
  2. Select the polygon you want to set color on the main window.
  3. Select View → Attributes to display the attributes window.
    (If it is already displayed, this operation is not necessary.)
  4. Click the Material tab in the Attributes window to enter Material Settings mode.
  5. Check the "Polygon" radio button.
  6. Click the Color box to display the color settings dialog.
  7. Once you have decided on the desired color, click OK.
  8. Click the Update button.
  9. The color will be set to the selected polygon.
  10. Deselect the polygon by selecting "Edit" → "Deselect".

●Set texture to polygons
  1. Select the Polygon Selection tool.
  2. Select the polygon you want to texture on the main window.
  3. Select View → Attributes to display the attributes window. (If it is already displayed, this operation is not necessary.)
  4. Click the Material tab in the Attributes window to enter Material Settings mode.
  5. Check the "Texture Map" radio button.
  6. Enter the desired texture number in the sprite "ID".
  7. Click the Update button.
  8. The texture is set on the selected polygon.
  9. Deselect the polygon by selecting "Edit" → "Deselect".

To set the texture more concisely...

  1. Select the Polygon Selection tool.
  2. Select the polygon you want to texture on the main window.
  3. Select "View" → "Texture List" to display the texture list window. (If it is already displayed, this operation is not necessary.)
  4. Double-click inside the display frame of the desired texture number.
  5. The texture is set on the selected polygon.
  6. Deselect the polygon by selecting "Edit" → "Deselect".

●Set the Z sort flag on polygons
  1. Select the Polygon Selection tool.
  2. On the main window, select the polygon for which you want to set the Z sort flag.
  3. Select View → Attributes to display the attributes window. (If it is already displayed, this operation is not necessary.)
  4. Click the Z sort tab in the attribute window to enter Z sort setting mode.
  5. Check the desired radio button.
  6. Click the Update button.
  7. The Z sort flag is set for the selected polygon.
  8. Deselect the polygon by selecting "Edit" → "Deselect".

●Save the model file
To save in SG3 format...
  1. In the main window, select File → Save.

To save in MDL format...
  1. In the main window, select File → Save As.
  2. Select "MDL Files" from the combo box.
