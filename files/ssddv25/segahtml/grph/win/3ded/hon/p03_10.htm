3D Editor User's Manual/Basic editing of 3D Editor

■Editing texture data

This section explains how to edit texture data to be mapped to objects.

●Open texture file
  1. In the texture window, select File → Open.

●Convert 2D image files to texture data
  1. In the texture window, select File → Import.

●Use the texture cutting function
  1. Select the Polygon Selection tool.
  2. Select the polygon you want to texture on the main window.
  3. Select "View" → "Texture List" to display the texture list window. (If it is already displayed, this operation is not necessary.)
  4. Click inside the display frame of the texture number you want to cut out to select it.
  5. Select "Options" → "Show cutout texture" in the texture window to display the cutout texture.
  6. Select the Move Cut Texture tool.
  7. Move the cut texture to the desired size and position.
  8. Select "Options" → "Texture Extraction" in the texture window.
  9. Set the cutting conditions in the dialog box and click OK.
  10. The texture is set on the selected polygon.
  11. Deselect the polygon by selecting "Edit" → "Deselect".

●Convert texture data to 2D image file
  1. In the texture window, select File → Export.

●Save the texture file
To save in SGT format...
  1. In the texture window, select File → Save.

To save in TXR format...
  1. In the texture window, select File → Save As.
  2. Select "TXR Files" from the combo box.
