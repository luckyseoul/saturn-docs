General purpose 3D modeling tool user's manual

1. Introduction

■Features

  • You can create model data without calculating detailed numerical values.

  • The created data can be used by incorporating it into SGL programs.

  • Each model has attribute data, and height data and collision can also be used.

  • Supports texture mapping. You can also check it directly on the Win95 screen.

  • Three types of screens: Top, Front, Right, and Perspective allow you to recognize the model from all angles.

  • It is primarily a tool for creating polygon models as backgrounds in 3D space, so it is not suitable for creating precise models like normal modeling tools.

Note
 3DME.EXE is a tool for creating models that do not require precise data, such as 3D background models.
Therefore, avoid using it to create only one object like normal 3D tools.
Also, it does not support parent-child structures.

■Installation

On a Windows95 operating environment, copy 3DME.EXE to the directory where "Segakey.DLL" is located (or whose path is in the directory where "Segakey.dll" is located).

■Start

Double-click 3DME.EXE.
