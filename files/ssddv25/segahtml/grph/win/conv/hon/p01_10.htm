SEGA CONVERTER User's Manual

1. Introduction

■Features

"Sega Converter" is an application that displays 2D image data saved in various file formats and converts these files between each other.
The displayed image can be changed using various filters. It also has a high-quality color reduction function that converts images composed of full color (approximately 16.7 million colors) or true color (32,768 colors) to images using a 256-color or 16-color color table.
Furthermore, it supports continuous processing of multiple files (catalog processing), which is not often seen in GUI applications.

All file input/output and filters of "Sega Converter" are executed by dynamically linking external modules (plug-in functions). By creating this external module, users can independently extend the functionality.

 Note
 If you have not configured the Windows printer settings, "Sega Converter" may not work properly.
