■"File" menu

Performs file management such as file input/output. You can also perform processes such as printing and closing from this menu.

◆New
Create a new file.
【dialog box】
  • size
    Enter the width (H) and height (V) of the new file.
  • color mode
    Select a color mode for new files. If you choose 16-color or 256-color mode, you also choose the color table to use for your file.

◆Open
Open an already saved file.

◆Close
Closes the file you are currently working on.

◆Save
Save the file you are currently working on.

◆Save as another name
Give the file you are currently working on a name and save it as a separate file.

◆Catalog
Prepare and execute batch processing on multiple files.
Catalog feature details

◆Page settings
Set the page layout for printing.

◆Printing
Print the file you are currently working on.

◆1～4
Four files will be displayed in order from the most recently opened or saved files.

◆End
Close "Sega Converter".

■“Edit” menu

Edit images such as cutting and pasting. You can also configure the working environment for using "Sega Converter" here.

◆Restore
Cancels the previous operation. Please note that some functions cannot be canceled.

◆Cut out
Cuts the selected area of the image. The cropped image will be stored on the clipboard.

◆Copy
Copies the selected area of the image. The copied image will be stored on the clipboard.

◆Paste
Pastes the image stored in the clipboard onto the image you are currently working on. Immediately after pasting, the image is in a movable state (floating state).

◆Delete
Erases the selected area of the image.

◆Select all
Select the entire image.

◆Deselect
Deselect. The floating image is determined to the current position.

◆Clearing the clipboard
Delete the image from the clipboard.

◆Properties
Configure environment settings for various editing tasks.
【grid】
  • unit
    Select the grid size.
  • snap
    It will now operate in the specified grid size unit during selection operations.
  • Color
    Specify the grid color.
【pasting】
  • dither
    Select the compositing method when the number of colors used in the pasting destination image is greater than the number of colors used in the clipboard image.
  • ignore palette
    Pastes only the bitmap information, ignoring the color table.

■"Display" menu

Change the display magnification of the image you are working on and decide whether to show or hide the grid.

◆Magnification
Enlarges and displays the image currently being worked on at the specified magnification.

◆Grid
Shows/hides the grid of the specified unit on the image currently being worked on.
Specify the lattice unit in "Edit" → "Properties" .

■“Options” menu

Executes mutual conversion of color modes and various filter processing.

◆Black and white
◆16 colors
◆256 colors
◆About 32,000 colors
◆About 16.7 million colors
Converts the image you are currently working on to a color mode with the specified number of colors. If the number of specified colors is less than the number of colors before conversion, you can specify the conversion method.

【dialog】
[Color table]
If the conversion color mode is 16 colors or 256 colors, specify the color table to use for conversion.
  • optimization
    Searches the color information of the image you are currently working on and generates a color table optimized with the specified number of colors.
  • custom
    Uses an already registered color table.

[Dither]
Select the dithering method to display missing colors due to conversion.
  • none
    Does not perform dither processing.
  • pattern
    Performs pattern dither processing.
  • error diffusion
    Dither processing is performed using the error diffusion method.

◆Color table
If the image you are currently working on has 16 or 256 colors, the color table used for that image will be displayed.

【dialog】
  • current
    Displays the color table used in the image you are currently working on.
  • custom
    Displays already registered color tables.
  • Registration
    Registers the displayed color table as a new one.

◆Filter
This is a plug-in function that applies various filters to the image you are currently working on.

◆Expression
This is a plug-in function that changes the expression method of the image you are currently working on.

◆Effect
This is a plug-in function that applies effects to the image you are currently working on.

◆Others
This is a plug-in function that performs other processing.
Note that the plug-in function will affect the inside of the selected area if it is selected, and the entire image if it is not selected.

■ “Window” menu

Displays the name of the window currently displayed on the screen. It also determines how each window will be arranged.

◆Display overlapping
Stack the windows starting from the top left.

◆Display vertically
Display all windows vertically.

◆Display side by side
Display all windows side by side.

◆Arranging icons
Arrange all minimized (iconized) windows.

◆Close all
Close all windows.

■“Help” menu

Displays a help file that explains how to use "Sega Converter". Also displays information on "Sega Converter".

◆Table of contents
Displays the table of contents of the help file.

◆Version information
Displays information such as the version of "Sega Converter".

■Catalog function

The catalog function is a feature of "Sega Converter" that is rarely seen in GUI applications, as it performs various processes on multiple files in succession.
Currently, it supports mutual conversion of file formats and color reduction functions.

◆Edit list
◆Display
◆Save
◆Color table

◆Edit list
Edit the list of files that are subject to the catalog function, such as adding or deleting.

【dialog】
  • addition
    Add files to the file list.
  • delete
    Delete the selected file in the file list from the list.
  • update
    Updates the file list with the latest file information. If there is an external operation such as moving a file, it will play a supporting role to prevent inconsistencies in the subsequent catalog functions.
  • keep
    Save the current file list.
  • open
    Load an already saved file list. The current file list changes to the loaded list.

◆Display
Open the files registered in the list in order.

【dialog】
  • weight
    Select the interval (in seconds) between opening the next file.
  • Close after displaying
    If checked, the window will automatically close after opening the file.

◆Save
Save the files registered in the list under a different name.

【dialog】
  • automatic
    Automatically sets the color mode of the saved file. Basically, the color mode does not change.
  • designation
    Specify the color mode of the file to be saved.
  • detail
    When specifying a color mode, you can set more detailed conditions. The settings are the same as when setting the color mode in the "Options" menu .

◆Color table
Generates an optimized color table from all files registered in the list. The generated color table will be automatically registered.

【dialog】
  • color mode
    Select the number of colors in the color table to be generated.
  • caption
    Enter the registered name of the color table.
