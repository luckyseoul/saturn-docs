SS Monitor User's Manual

2. menu

  • "File" menu
  • "Control" menu
  • "Help" menu

■"File" menu

Perform basic control of the monitor. This menu also executes termination processing.

◆Monitor load
Download the monitor program. Usually not used.

◆Open COFF (only available in SS Debug)
Download the COFF file (executable file) and run it.

◆Open binary (only available in SS Debug)
Download the binary file.
【dialog box】
  • address
    Specify the download destination address in hexadecimal.
  • VDP1
    Specify the start address ($25c00000) of VDP1.
  • VDP2
    Specify the start address ($25e00000) of VDP2.
  • SGL
    Specify the start address ($06004000) of the SGL user area.
  • COL
    Specify the start address of color RAM ($25f00000).
  • USER
    Specify the address entered in the reservation box.

◆End
Exit the application.

■“Control” menu

Perform basic control of the target.

◆Run viewer
Download and run “SS Viewer”. Usually not used.

◆PC settings (only available for SS Debug)
Set the program counter. The program will stop.
【dialog box】
  • address
    Specify the download destination address in hexadecimal.
  • SGL
    Specify the start address ($06004000) of the SGL user area.
  • USER
    Specify the address entered in the reservation box.

◆Execution (only available in SS Debug)
Executes the program from the current program counter.

◆Stop (only available for SS Debug)
Stops program execution.

◆Reset
Reset target.

■“Help” menu

Displays a help file that explains how to use "SS Monitor". Also displays "SS Monitor" information.

◆Table of contents
Displays the table of contents of the help file.

◆Version information
Displays information such as the version of "SS Monitor".
