SS Monitor User's Manual

1. Introduction

■What is SS Monitor...

SS Monitor supports dynamic data communication protocols between application targets (DevSaturn) via the CartDev system.
By using an application that supports this communication protocol, users will be able to use the Sega Saturn as if it were an external device to their PC.

■About SS Viewer

When "SS Monitor" starts up, it runs the general-purpose viewer program "SS Viewer".
The SSSDK graphic tool achieves the display function on the target by transferring data (or commands) to the reserved memory map of "SS Viewer" through inter-application communication.

"SS Viewer" supports the following display functions.

  1. 3D objects
  2. 3D animation
  3. normal scroll
  4. Rotating scroll (3 axes)
  5. bitmap

■About SS Debug

"SS Debug" does not run "SS Viewer" at startup, but instead allows you to control the target system in more detail. If you want to use a user-customized display program other than "SS Viewer" for development, we recommend using "SS Debug".

Note
 Please note that "SS Debug" cannot be used directly with the SSSDK graphic tools.

■Troubleshooting

●Runaway of “SS Viewer”
If "SS Viewer" stops responding to SSSDK graphics tools, you can restart it by following the steps below.
  1. "Control" → "Reset"
  2. "File" → "Monitor Load"
  3. "Control" → "Run Viewer"
