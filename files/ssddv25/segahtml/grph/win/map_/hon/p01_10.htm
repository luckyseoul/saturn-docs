Map Editor User's Manual

1. Introduction

■Features

"Map Editor" is an application that reads 2D image data saved in a general format, divides pixels into character units (16 pixels x 16 pixels), and places each character in an arbitrary map area.
Standards for characters, maps, etc. in "Map Editor" comply with SegaSaturn's VDP2 specifications. In order to effectively utilize "Map Editor", basic knowledge of VDP2 is required.
The current "Map Editor" allows you to edit maps in the following color modes.

  1. 256 colors/32768 colors
  2. 32768 colors

■Map Editor file format

"Map Editor" can handle the following file formats for different purposes.

[Reading]
S2D file This is a binary file containing character map and palette information.

【keep】
S2D file This is a binary file containing character map and palette information. SGL file This is a C language data file that contains information on character maps and palettes.

【import】
BMP files and other data that serves as the material for characters. Additional changes can be made using plugin modules.
