Map Editor User's Manual

2. Basic editing

■Open a new file

  1. Select File → New.

■Register a character

  1. Select the "File" → "Import" menu.
  2. In the image window, select the part you want to register as a character using the "Rectangle Selection" tool.
  3. Select the "Edit" → "Copy" menu.
  4. Bring the character window to the front.
  5. Select the "Edit" → "Paste" menu.
  6. Move the pasted character to the position you want to register.
  7. Click inside the window to position it.

■Edit the map

To place any character on the map,
  1. Select the Pen tool from the toolbox.
  2. Click any character in the character window.
  3. Drag (draw) the character in the map window where you want to place it.

To place multiple characters on the map,
  1. Select the Rectangular Selection tool from the toolbox.
  2. Select a group of characters in the character window.
  3. Select the "Edit" → "Copy" menu.
  4. Bring the map window to the front.
  5. Select the "Edit" → "Paste" menu.
  6. Move the pasted characters to the location you want to place them.
  7. Click inside the window to position it.

■Save the file

To save in S2D format,
  1. Select File → Save.

To save in SGL format,
  1. Select File → Save As.
  2. Select "SGL Files" from the combo box.

■Open file

To open a saved S2D file,
  1. Select File → Open.
