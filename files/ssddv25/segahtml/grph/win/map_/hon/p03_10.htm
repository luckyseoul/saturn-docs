Map Editor User's Manual

3. tool box

■Tool box

Rectangular selection tool pen tool
eraser tool dropper tool
tile tools

■“Rectangular selection” tool

Valid window
[Map window] [Character window] [Image window] Common

◆When selected
Select a rectangular area by dragging.

◆After selection
Move the selected data by dragging.
Use Ctrl + drag to paste and move the selected range of data.
Click to paste the selected range data and cancel the selection.

■“Pen” tool

[Map window]
◆Drag:
Places the specified character data on the map.
Note that if a selection range is set, the character data placement will be clipped within the range.

◆Ctrl+drag (click):
Specifies the character at the cursor position. Works similar to the "Eyedropper" tool.

[Character window]
◆Click:
Specifies the character at the cursor position.

[Image window]
It can not be used.

■“Eraser” tool

[Map window]
◆Drag: Place character data number 0 on the map.

[Character window]
◆Drag:
Changes the character data at the cursor position to a space character.

[Image window]
It can not be used.

■“Dropper” tool

[Map window]
◆Ctrl+drag (click):
Specifies the character at the cursor position. Works similar to the "Eyedropper" tool.

[Character window]
◆Click:
Specifies the character at the cursor position.

[Image window]
It can not be used.

■“Tile” tool

[Map window]
◆Drag:
Arranges and arranges the character data stored on the clipboard.
Note that if a selection range is set, the character data placement will be clipped within the range.

[Character window]
It can not be used.

[Image window]
It can not be used.
