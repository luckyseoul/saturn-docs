Cinepak for SEGA Saturn

Five. Film analysis utility

FA(Film Analyzer)

"Film Analyzer FA" is a utility program for analyzing Cinepak movies for SEGASATURN converted with MovieToSaturn_J.

5.1 Features

Displays the contents of Cinepak movies for SEGASATURN.
Calculates and displays data rate, compression rate, and keyframe rate.
Calculate and display the ring buffer size required when playing a movie.

5.2 Usage environment

IBM PC/AT compatible machine
MS-DOS Ver.5.0 or higher

5.3 How to operate

From the MS-DOS command prompt

C> FA filename

If you enter , the analysis results will be displayed as shown in Figure 5.1.
