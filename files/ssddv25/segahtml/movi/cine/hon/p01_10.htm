Cinepak for SEGA Saturn

1. overview

Cinepak for SEGASATURN is software that allows you to easily incorporate Macintosh QuickTime movies into SEGASATURN.
To create Cinepak movies for SEGASATURN and use them in gaming applications, you generally need the following:

  • Digitize video footage and convert to QuickTime movie
  • Edit movies using QuickTime editing tools
  • Compress edited QuickTime movies with Cinepak
  • Convert Cinepak compressed QuickTime movies to SEGASATURN format Cinepak movies using MovieToSaturn_J provided by SEGA.
  • Create an application to play Cinepak movies using the Cinepak library provided by SEGA

1.1 Features

The features of Cinepak for SEGASATURN are as follows:

  • Continuous playback and branched playback can be performed seamlessly for both sound and video.
  • You can play multiple movies at the same time.
  • The chromakey feature allows you to composite specific parts of a movie onto another movie or still image.
  • The specified frame expansion function allows you to use movie frames as still images.
  • Compatible with CD-ROM XA format (Mode2Form1), so you can interleave multiple movies and movies and data (collision data, etc.).
