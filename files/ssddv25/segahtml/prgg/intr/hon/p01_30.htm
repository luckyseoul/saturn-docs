Introduction manual

install

■Hardware setup

〈 PC version〉
Start your PC and insert the PC version floppy disk into the floppy drive.
Please be sure to read [README.DOC] located in the root directory of the FD first. Contains installation instructions.

〈 SUN version〉
Prepare your tape device.

〈 HP version〉
Get your DAT ready.

■Media

Release 2 is available on the following media:

---------------------------
PC version FD
SUN version 8mm tape
HP version DAT
---------------------------

■How to install

〈 PC version〉
In the PC version, you can install each library and tool individually.
Insert the floppy disk into the software library floppy drive and execute the [INSTALL] command. Install in the current directory. Install all libraries in a directory called [SATURN] in the current directory. If the [SATURN] directory does not exist, create it.
If the floppy drive is A drive and the installation destination is C drive, it will be as follows.


C:\USR> A:INSTALL[RET]
       ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾

A directory called [C:\USR\SATURN\....] will be created.
C:\USR> is the DOS prompt.

Installing CD tools
Insert the floppy disk into the floppy drive and execute the [install] command. Install in the current directory. If the floppy drive is A drive and the installation destination is C drive, the result will be as follows.


C:\BIN> a:install[RET]
       ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾

- When installing a virtual CD, specify the [-vcd] option.


C:\BIN> a:install -vcd[RET]
       ‾‾‾^‾‾‾‾‾‾‾‾‾‾‾‾‾‾

- When installing DXFT03DT, it is a self-extracting compressed file, so please change the current directory to the installation destination and run it.


C:\BIN> a:\saturn\segabin\dxfto3dt[RET]
       ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾

The [DXFT03DT\] directory will be generated. (See directory structure in [README.DOC])

〈 SUN version〉
Libraries, tools are installed at once.

(1)
Change the current directory to the installation directory.
(2)
If you select [tar xvf 8mm tape special file], the directory under [SATURN] will be created.


(example)
tar xvf/dev/nrst[RET]
‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾ ‾

〈HP version〉
Libraries, tools are installed at once.

  1. Insert the cartridge tape into the device.

  2. Move the current directory to the directory you want to install (e.g. /usr/bin).

  3. Run the following command.


C:¥BIN> a:install -vcd[RET]
       ‾‾‾^‾‾‾‾‾‾‾‾‾‾‾‾‾‾

  1. After reading from the tape, the [SATURN] directory and below are created.

Note
The timestamp is specified to identify the version of each file, so please do not change the timestamp.
Please be sure to read the [README.DOC] in each directory and the additional documentation in the [\MAN\] directory.
