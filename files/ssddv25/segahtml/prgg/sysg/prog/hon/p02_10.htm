System program user's manual reference

Function list

Register/reference interrupt handling routine

No1.1 Register the processing routine to the SYS_SETSINT interrupt vector

No1.2 SYS_SETUINT Register the function to the SCU interrupt routine

No1.3 SYS_GETSINT Get the registered contents of interrupt vector

No1.4 SYS_GETUINT Get the registered contents of SCU interrupt routine

Setting, referencing, and changing SCU interrupt masks

No2.1 SYS_SETSCUIM Set SCU interrupt mask

No2.2 SYS_CHGSCUIM Change SCU interrupt mask

No2.3 SYS_GETSCUIM Refer to SCU interrupt mask

Simple semaphore operation

No3.1 SYS_TASSEM Acquire semaphore

No3.2 SYS_CLRSEM Release semaphore

System clock switching

No4.1 SYS_CHGSYSCK Switch the system clock

No4.2 SYS_GETSYSCK Refer to system clock value

SCU interrupt routine priority change

No5.1 SYS_CHGUIPR Change SCU interrupt routine priority

Start CD multiplayer

No6.1 SYS_EXECDMP Start and run CD multiplayer

Power-on clear memory operation

No7.1 SYS_PCLRMEM Operate power-on clear memory
