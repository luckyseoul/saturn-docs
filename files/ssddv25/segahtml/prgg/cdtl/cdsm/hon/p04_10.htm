4.Troubleshooting

■Q&A

Q:
Memory file cannot be accessed (SIMM system)
A:
Please check the following:

  • Is the data loaded into the SIMM corrupted?

  • Is the SIMM start address set in [_GFMC_base]?

Q:
PC side does not recognize target (SCSI system)
(The message "SEGA SATURN XXXX" is not output)
A:
Check the dip switch settings. Be careful not to have ID conflicts with other SCSI devices.

Q:
[CDSIM.EXE] outputs an error message
A:
If an error message such as Illegal Request, Saturn Not Found, or Saturn GetReq Error is output, please start over from BOOT ROM.

Q:
The time on the PC calendar is incorrect.
A:
If you perform any work such as breaking the ICE on the target side while [CDSIM] is running, the time on the PC calendar may be delayed.
In this case, please reset the time on the calendar.
