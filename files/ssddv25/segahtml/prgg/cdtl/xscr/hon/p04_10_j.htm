Title
コマンド仕様
 
Command
置換文字列の定義
 
Keyword
Define
 
No
1.1

　書　式
Define name string
　パラメータ
name　：定義名
string　：置換文字列
　機　能
置換文字列stringを定義名nameとして定義します。
　備　考
スクリプト中で定義名を使用する場合は[name]のように[]で括って記述します。
　−例−
Define   dirsmp  .¥sample¥
             ：
FileSource  [dirsmp]smp_file.bin
