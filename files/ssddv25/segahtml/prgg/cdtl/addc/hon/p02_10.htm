2.3 Definition of terms

Defines terms used in this system.

disk
When simply written as a disk, in this manual it refers to a CD-R disk.

CD Builder (Disc Builder)
A tool for creating disk image files.
Refers to XBLD and VCDBUILD.

Disk image file (DSK file)
This is a file created on the hard disk that contains the same content that will be written on a CD-R disc.

Additional image file
This is a temporary file that ADDCDW creates for work.

TOC file
A file containing track information.
The main body of the file name excluding the extension is the same as the DSK file.

path name
A generic term for drive names, directory names, and file names.

subcommand
This is a command for ADDCDW.

Master disk
A disc with the same content as the commercial version disc.
It is not possible to add data to the master disk.

debug disk
Disk to create for debugging.
Multiple full and partial updates are possible.

test mode
Write mode using the CD-R drive test mode.
Simulates writing to a CD-R disc.

write on the fly
This method writes to a CD-R disc while creating a sector image of the disc (no need for a DSK file).
