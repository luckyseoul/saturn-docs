P.S. Write Once System User's Manual

8. Notes/Restrictions

  1. To replace interleaved files, you must recreate the disk image file.

  2. The subheader information of added/replaced files will have the following settings.

    Table 8.1 Subheader information of added/replaced files
    Item Setting details
    file number 0
    channel number 0
    submode For Form1 sector: DATA bit = 1
    For Form2 sector: FORM bit = 1, AUDIO bit = 1
    Coding information 0

  3. If you add a CD-DA track, the track number will change. Therefore, when playing a CD with track number specified, it is necessary to also change the track number in the CD playback parameters.

  4. When using the stream system library, if you add some of the streams that belong to the same stream group, the playback order will change. To avoid this, add all streams belonging to the stream group.

  5. When adding, you can use up to 1024 subdirectories.

  6. When adding differences, you can specify up to 1024 subcommands.

  7. INTERNAL CACHE BLOCK represents the internal cache capacity of ADDCDW, and one block is 16384 bytes. By default, EMS is used to allocate in extended memory. If EMS is not available, use conventional memory.

  8. Index information in tracks is ignored on debug disks.
    (Index 2 and later are collectively considered as index 1.)

  9. Multi-volume is not supported.

  10. Master mode does not support on-the-fly writing.

  11. On-the-fly writing does not support disks that include secondary volume descriptors and boot record descriptors.

  12. On-the-fly writing does not support discs that control submodes using CD Builder's ``Trigger'' and ``Eors'' commands.

  13. When writing at 4x speed on Windows 95 (DOS window), a buffer underrun error may occur.
    By setting the operating conditions as shown below, the frequency of errors occurring can be reduced.
    • No network connection.
    • Turn off the CD-ROM drive property "Auto-insert" in "Device Manager".
      In particular, when using CDR400, be sure to set the CDR400 property "Automatic insertion" to OFF.
      (Set "Device Manager" in "System" of "Control Panel")
    • Set the DOS window to "full screen display".
    • Finish other tasks.
    If you cannot write at 4x speed even after making these settings, please reduce the writing speed or start the program in MS-DOS mode.
