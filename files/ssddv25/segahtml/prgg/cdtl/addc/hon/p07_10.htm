P.S. Write Once System User's Manual

7. error

If an error occurs, a message is output in the following format.

Subcommand file name (line number): Error message [error code]

Error list

  • No drive connected
  • Drive not ready
  • There is a problem with the disk
  • There is an error in the subcommand
  • File does not exist on disk
  • Directory does not exist on disk
  • File does not exist on DOS
  • File size is too large
  • File is already marked for editing
  • The specified file is interleaved
  • File already exists on disk
  • Directory cannot be updated
  • Cannot create additional image file
  • disk is full
  • No more writes can be made to this disc
  • Transfer speed is too slow
  • gap size too small
  • There is an error in the TOC file
  • file cannot be accessed
  • Too many subdirectories
  • There is an error in the DSK file
  • Disk contents are invalid
  • Out of memory
  • A read error occurred
  • A communication error has occurred
  • A hardware error has occurred
  • disk is empty

▲ List

Drive not connected [fe02][fe82]
Drive is not connected

Cause
No CD-R drive is connected to SCSI.
countermeasure
Please make sure the connection and ID are not duplicated.

▲ List

Drive not ready [fe04][fe28][fe50][fe5a][fea3][feb7]
Drive is not ready

Cause
CD-R drive does not become a state.
countermeasure
Make sure the disc is set correctly.

▲ List

There is a problem with the disk [fd0b][fe31][fe33][fea9][feaf][feb2][feb3]
Something wrong with the disc

Cause The CD-R disc is abnormal.
Countermeasure Check the specifications of the CD-R disc.

▲ List

There is an error in the subcommand [fd12]
Bad Sub-command

Cause
An unsupported subcommand was specified.
countermeasure
Check subcommands.
▲ List

File does not exist on disk [fd15]
File does not exist on the disc

Cause
The specified file does not exist on the CD-R disc.
countermeasure
Specify the correct file name with full path.
▲ List

Directory does not exist on disk [fd14]
Directory does not exist on the disc

Cause
The specified directory does not exist on the CD-R disc.
countermeasure
Specify the correct file name with full path.
▲ List

File does not exist on DOS [fd07][fd13]
File does not exist on DOS

Cause
The specified file does not exist on DOS.
countermeasure
Please check the file name.
▲ List

File size is too large [fd1a]
File size is too huge

Cause
The file size specified in the system area is too large.
countermeasure
Reduce file size to 32768 bytes or less.
▲ List

File is already marked for editing [fd17]
File is specified already

Cause
A subcommand was issued twice for the same file.
countermeasure
Check the subcommands.
▲ List

The specified file is interleaved [fd1c]
Specified file is interleaved

Cause
You issued a subcommand that cannot be executed on a file that is interleaved.
countermeasure
Redo the disk build.
▲ List

File already exists on disk [fd16]
Same file name exists on the disc already

Cause
The file you tried to add already exists on the CD-R disc.
countermeasure
Rename or replace the file.
▲ List

Directory cannot be updated [fd1b]
Can't renew the directory

Cause
A subcommand was specified for a directory.
countermeasure
Fully updated.
▲ List

Cannot create additional image file [fd1d]
Can't create the image file for the additional description

Cause
Unable to create file in specified working directory.
countermeasure
Please check your working directory. Check the free space on your hard disk.
▲ List

Disk is full [feaa][feb0][feb4]
Disc is full

Cause
The write position has reached the end of the disk.
countermeasure
Use a new disk.
▲ List

No more writing can be done to this disc [fd18]
Can't write on this disc any more

Cause
An attempt was made to write to a used disk in master mode.
Or you tried to write to a disc like this:

  • Disc with 99 tracks written on it

  • Discs written in master mode (disc at once)

  • Disc with final session confirmed

  • A disk whose session has not been closed (fixed)

countermeasure
Use new disk
▲ List

Transfer speed is too slow [fead]
Forwarding Speed is too slow

Cause
The data buffer of the CD-R drive became empty during writing.
countermeasure
Slow down the write speed.
Use disk cache.
Free up more conventional memory by reducing device drivers, etc.
▲ List

Gap size is too small [fd02][fd03]
Gap size is too small

Cause
Gaps between tracks are too small.
countermeasure
225 sectors before the Mode2 track, 150 sectors or more in other cases.
▲ List

There is an error in the TOC file [fd04][fd05][fd06][fd0a][fd10]
Something wrong with the TOC file

Cause
There is an error in the TOC file.
countermeasure
Use the correct TOC file.
▲ List

Unable to access file [fd08]
Can't access the file

Cause
Failed to access file.
countermeasure
Check whether files and directories can be accessed normally.
▲ List

Too many subdirectories [fd0d]
Too many sub-directories

Cause
Too many subdirectories.
countermeasure
Reduce the total number of subdirectories to 1024 or less.

▲ List

There is an error in the DSK file [fd0c][fd0e][fd0f]
Something wrong with the DSK file

Cause
The contents of the DSK file do not comply with the ISO9660 standard.
countermeasure
Use the correct DSK file.

▲ List

Disk contents are invalid [fd19][fe21]
Illegal disc contents

Cause
The contents of the CD-R disc do not comply with the ISO9660 standard.
countermeasure
Fully updated.

▲ List

Out of memory [fd11][fec1]
Not enough memory

Cause
The memory capacity required for execution cannot be secured.
countermeasure
Free up more conventional memory by reducing device drivers, etc.

▲ List

A read error occurred [fe11][fe17][fe18][fe32][fe47][fe57][fea0][fea2]
Read Error Occurred [feab][feac][feae]

Cause
A disk read error occurred.
countermeasure
Please check the CD-R disc.

▲ List

A communication error has occurred [fd00][fe00]
Communication Error Occurred

Cause
An error occurred during communication.
countermeasure
Please check connections, cables, etc.

▲ List

A hardware error has occurred [fe08][fe09][fe15][fe29][fe40][fe42][fe44]
Hardware Error Occurred [fe53][fe83][fec0]

Cause
An error has occurred in the CD-R drive.
countermeasure
Please check your CD-R drive.

▲ List

Disk is empty [feb1]
Disc is empty

Cause
An attempt was made to add differential data to an empty disk.
countermeasure
Please replace the disc with one that has been completely appended.
