3.4 Writing on the fly

By linking with CD Builder XBLD, you can perform on-the-fly writing that does not require a disc image file.
XBLD analyzes the disk structure from the SCR file (script file) and outputs a PVD file, SCT file (sector information file), OTI file (on-the-fly interleaving intermediate file), and TOC file.
ADDCDW writes to a CD-R disc while creating a sector image of the disc from these files and the program/data source files.
