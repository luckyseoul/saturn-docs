Appendix C. ADDGEN change history

C.1 Changes from Ver.1.00 to Ver.1.01

(1) Bug fixes
  1. Fixed an issue where invalid strings were output to subcommand files.

C.2 Changes from Ver.1.01 to Ver.1.02

(1) Function expansion
  1. "-" and "/" can now be used as option prefixes.
  2. Now supports English messages.
    • Japanese/English is now automatically set depending on the DOS operating mode.
    • Added e option.

C.3 Changes from Ver.1.02 to Ver.1.03

(1) Bug fixes
  1. Fixed an issue where the program could not be executed on Windows95 DOS windows.

C.4 Changes from Ver.1.03 to Ver.1.04

(1) Function expansion
  1. Added support for Define and Include commands in builder script files.

C.5 Changes from Ver.1.04 to Ver.1.10 (1997-05-14)

(1) Function expansion
  1. Compatible with CDR400.
