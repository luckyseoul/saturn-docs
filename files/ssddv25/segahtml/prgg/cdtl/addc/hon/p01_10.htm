P.S. Write Once System User's Manual

1. overview

This document describes the external specifications of the add-on write-once system "ADDCDW".

1.1 Features

Addendum Write-once system ADDCDW is a system that allows you to repeatedly write to CD-R discs.

(1) Multiple additions can be made to a CD-R disc
With the conventional write-once system (SEGACDW), a CD-R disc can only be written once. Therefore, even if only a small amount of data was written, the disc could not be reused.
This system allows multiple additions to a single disc.

(2) Full update of disk (full addition)
You can completely rewrite the contents of a disc by adding a new disc image file. In this case, the previously written content will no longer be visible.

(3) Partial disk update (differential addition: addition, deletion, replacement)
Once you have written basic content such as volume information and directory information to a CD-R disc, you can then write only the programs and data that you want to add or change.
This can reduce disk creation time and usage.

(4) Fully upward compatible with SEGACDW
It includes the functions of SEGACDW and can also create master discs.

(5) Supports on-the-fly writing (from Ver.1.70)
You can perform "on-the-fly writing" in conjunction with the CD builder "XBLD".
On-the-fly writing eliminates the need to create a disk image, saving time and hard disk space.
