P.S. Write Once System User's Manual

Appendix B. ADDCDW change history

B.1 Changes from Ver.1.00 to Ver.1.01

(1) Bug fixes
  1. The channel number is now set to 0 correctly when adding a difference.
  2. Fixed an issue where the end process would not be completed correctly if an error such as a buffer underrun occurred during writing.

(2) Functional expansion
  1. The maximum number of subcommands that can be specified has been expanded to 1024.
  2. Now supports English messages.
    • Japanese/English is now automatically set depending on the DOS operating mode.
    • Added english subcommand.

B.2 Changes from Ver.1.01 to Ver.1.02

(1) Bug fixes
  1. Fixed an issue where the program could not be executed on Windows95 DOS windows.

B.3 Changes from Ver.1.02 to Ver.1.03

(1) Bug fixes
  1. Fixed an issue that caused the system clock to go out of order.

(2) Functional expansion
  1. Added raw append disk creation function (raw subcommand).

B.4 Changes from Ver.1.03 to Ver.1.04

(1) Function expansion
  1. Added sector type with subheader to scttype subcommand.

B.5 Changes from Ver.1.04 to Ver.1.10

(1) Function expansion
  1. Improvements have been made to errors that occur due to slow data transfer speeds.
    EMS can now be used to reserve more internal cache blocks.

B.6 Changes from Ver.1.10 to Ver.1.11

(1) Function expansion
  1. Added sector type to set submode flag to scttype subcommand.

B.7 Changes from Ver.1.11 to Ver.1.70

(1) Function expansion
  1. Supports on-the-fly writing.
    Added otf subcommand and rmv subcommand.

B.8 Changes from Ver.1.70 to Ver.1.71

(1) Bug fixes
  1. Corrected the failure to start when there is no EMS memory.

(2) Functional expansion
  1. Added testgo subcommand.

B.9 Changes from Ver.1.71 to Ver.1.80

(1) Function expansion
  1. Compatible with CDR400.

B.10 Changes from Ver.1.80 to Ver.1.81

(1) Bug fixes
  1. Addressed buffer underrun error with CDR400.
