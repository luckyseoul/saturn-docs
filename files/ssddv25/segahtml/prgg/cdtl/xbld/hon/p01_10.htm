XBLD User's Manual

1. overview

This document describes the external specifications of the CD builder "XBLD".

1.1 About XBLD

CD Builder XBLD is a tool for generating files necessary for writing to CD-R discs and for CD emulation in virtual CD systems.

1.2 Features

(1) Fully upward compatible with VCDBUILD
It uses the same script syntax as VCDBUILD, so you can use the script file for VCDBUILD as is.
It also outputs the same disk image files as VCDBUILD, allowing you to write to CD-R discs and perform CD emulation in exactly the same way.

(2) Reducing build time
Significantly reduces the work time required for disk build compared to VCDBUILD.

(3) Troubleshooting and functional improvement/expansion
It addresses the failure seen in VCDBUILD. We have also improved and expanded functionality.

(4) Cooperation with write-once system ADDCDW
By linking with the write-once system "ADDCDW", you can perform on-the-fly writing.
On-the-fly burning does not require a disk image file, which saves time and hard disk space.
