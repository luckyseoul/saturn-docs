3.Troubleshooting

This section describes what to do if an error message is displayed.

Error regarding image file

If the error message introduced in this section appears, there is a problem with the CD image. Please check if the .dsk or .emu file and .toc file are in the same directory and were created correctly by the virtual CD system. If the error still occurs, please create the CD image again.

●Error regarding image file format

The following error message means that the CD image you are trying to record is in an invalid format.

  • Bad data form
  • unknown data form in line
  • Error Data Length

The following error message indicates that the mode of the CD-ROM being created is invalid, or that the CD image is in a format that is not supported by segacdw.

  • Unknown data mode

●Error regarding ISRC length

There is a problem with the length of the ISRC stored within the image on the CD. Examine the original data and regenerate the image.

  • ISRC length error in line

●Cue sheet error

If you see an error message like the one below, there is a problem with the cue sheet. Please recreate the .dsk and .toc files using the virtual CD system.

  • Cue Sheet intermediate conversion failed
  • Cue Sheet parsing failed
  • Cue sheet conversion failed
  • Cue sheet size error
  • Cue sheet too large
  • Empty cue sheet
  • No track definitions in cue sheet
  • Can't find lead-out in cue sheet
  • Nocore for cue sheet

Also, the following error indicates that either the cue sheet has not been generated or there is no file containing the cue sheet in the same directory as the image file.

  • No cue sheet

Errors caused by the relationship between the host machine and CD-R recording device

●Errors that occur when transferring CD images

The following error message means that the I/O speed of the host's hard disk cannot keep up with the writing speed of the CD-R writer. Adjust the CD-R writing speed using command options.

  • Buffer Under Run

●Errors related to CD-R recording device settings

The following error message occurs when you specify an invalid value for write speed. Please specify the correct write speed using option -s.

  • Error: Bad speed value

The following error message will appear if the firmware version of the CDR100 is old and it is not possible to create a CD for SEGA Saturn. Please update the CDR100 firmware to the correct version.

  • Firmware upgrade of CD recorder is needed to use this software.
