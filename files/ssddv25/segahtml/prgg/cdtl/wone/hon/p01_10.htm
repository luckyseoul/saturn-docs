write once system

1.First of all

segacdw is a program that records CD image files created with the virtual CD system (command VCDBUILD) onto a CD-R using a CD-R recording device. This command is launched from the system prompt.

install

Hardware installation

Connect the CD-R recording device YAMAHA CDE/CDR100 (CDE100 is the model name of CDR100 with a housing) to the host machine via SCSI. For details on how to connect, please refer to the CDR100 manual.

If you set the SCSI ID of CDR100 to 5, there is no need to set the SCSI ID in the argument of the command segacdw each time.

Software installation

Copy the executable file segacdw from the floppy disk distribution media to the host's hard disk. Please set the path if necessary.
