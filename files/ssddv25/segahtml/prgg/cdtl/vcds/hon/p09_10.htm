Virtual CD System User's Manual/Chapter 3 CD Emulator VCDEMU

3.2.2 Menu screen function details

When you press [SPACE], "Menu" on the top bar will be displayed in white text.

You can select "Menu" or "Help" by pressing the cursor [LEFT] or [RIGHT]. The selected part is now displayed in white text.
When you press [ENTER] or cursor [DOWN], the contents of the selected menu will appear.

Select a menu item with [UP] or [DOWN] and press [ENTER] or [SPACE] to perform processing according to that menu item.

●View:
*Log Indication
Mode for viewing log information. When selected, the color of the top bar changes from purple to yellow, and "View" in the mode window changes to "LogView", indicating that you have entered "LogView" mode.
By pressing the cursor [UP], [DOWN], or [PAGEUP], [PAGEDOWN], you can view information up to 500 lines before the last displayed log information.
You can exit this mode by pressing [ESC].

-Always
Mode to display all log information. When selected, "View" in the mode window changes to "Always".

-Error Only
A mode that displays only error information. When selected, "View" in the mode window changes to "Error".

*FAD Form
Select the frame address display format of the log window.

-Decimal
It will be displayed as a decimal number.

-Hexadecimal
It will be displayed in hexadecimal.

●Information

*TOC Information
Mode for viewing TOC information. When selected, a TOC information window will open in the center of the screen.

You can view TOC information by pressing the cursor [UP], [DOWN], or [PAGEUP], [PAGEDOWN].
You can exit this mode by pressing [ENTER] or [ESC].

*REL Information
Mode for viewing correlation table information. When selected, a correlation table information window will open in the center of the screen.

You can view the correlation table information by pressing the cursor [UP], [DOWN], or [PAGEUP], [PAGEDOWN].
You can exit this mode by pressing [ENTER] or [ESC].

*FILE Information
A mode to view the currently set file information. When selected, a file information window will open in the center of the screen.

You can view the correlation table information by pressing the cursor [UP], [DOWN], or [PAGEUP], [PAGEDOWN].
You can exit this mode by pressing [ENTER] or [ESC].

●Open CD Tray
Executes the tray opening operation of a real CD drive on a virtual CD emulator.

●Close CD Tray
Executes the tray closing operation of a real CD drive on a virtual CD emulator.

●Exit
Exit the virtual CD emulator.
After selecting, press any key to end the program.
