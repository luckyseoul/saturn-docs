3.2 Emulator display

The virtual CD emulator screen consists of the following six parts.

Figure-4. Screen display example of virtual CD emulator

●Top bar
There are two pull-down menus on the top bar: "Menu" and "Help" ("Help" is not yet implemented). The log information file name specified when starting the virtual CD emulator is displayed in the center. If no log information file is specified, "No LogFile" is displayed. Below that is a bar that indicates where the information is displayed in the log window. This bar is normally purple, but turns yellow when you enter LogView mode.

●Bottom bar
In the right corner, the number of lines of log information currently displayed relative to the total number of log information is displayed.

●Log window
A window colored in blue and light blue in the center of the screen. There is a scroll bar on the right side that indicates the position of the currently displayed log information relative to the total number of log information.

●Mode window
This is the top window of the three on the right side of the screen. Displays the following three modes.

  • Virtual CD emulator modes
    Direct..........Direct DOS file access
    Realtime.....Real time emulation

  • Screen display mode
    Always.....Mode to display all log information
    Error..........Mode to display only error information (not implemented)
    Logview....Mode to view log information

  • CD speed
    Single......Standard
    Double........2x speed

●Jumper window
The window in the center of the three on the right side of the screen. Displays the jumper setting position.

●Buffer window
This is the bottom window of the three on the right side of the screen. Displays the number of buffers currently in use relative to those prepared in the program.
