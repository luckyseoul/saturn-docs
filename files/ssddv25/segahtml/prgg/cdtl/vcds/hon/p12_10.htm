5.2 TOC information file generation tool VCDMKTOC

5.2.1 Command specifications

command:
VCDMKTOC

Command name:
TOC information file generation for write-once CD

Format:
VCDMKTOC△File name body part

argument:
File name body part: Body part of the disk configuration information file name

function:
Extracts the TOC information required for write-once CD writing from the final disc configuration information file, converts it to the writing system's format, and outputs the file.

Input file = file name body part.RTI
Output file = file name body part.TOC

Note:
  • When using XBLD to create a disk image, there is no need to use this tool as XBLD automatically generates a TOC information file.
  • When using VCDBUILD to create a disk image, it is necessary to create a TOC information file using this tool.

Example of use:
VCDMKTOC△TSTGAME
