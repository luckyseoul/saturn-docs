Virtual CD System User's Manual/Chapter 5 CD Emulation Related Tools

5.4 Byte Swap Tool SWAP

5.4.1 Command specifications

command:
SWAP

Command name:
byte swap

Format:
SWAP△[ -v ]△Old file name△New file name

argument:
Old file name: DOS file name subject to byte swapping
New file name: DOS file name created as a result of byte swapping

option:
-v show usage

function:
Converts the byte order of the specified DOS file and creates a new DOS file.

5.4.2 About CDDA file format

CDDA data files accepted by the Virtual CD system must be in Intel little endian byte order.
If the CDDA data file has a Motorola big endian format byte order, use this tool to perform data conversion.
