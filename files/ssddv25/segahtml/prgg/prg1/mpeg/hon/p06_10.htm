MPEG library

6.Video effects

6.1 Border color

The area outside the display window is output in border color. Also, after instructing to start playback, border color is output until the video is actually output.

6.2 YC multiplier

You can set the image brightness and color difference magnification. Used for fade in and fade out. Setting the color difference magnification to 0 results in a monochrome image.

6.3 Mosaic

You can apply mosaic to the video. Mosaic specifications are set independently in the X and Y directions.

6.4 Blur

You can blur the image.

6.5 Luminescence ski effect

Adds a transparent bit to pixels below a certain brightness. This can be used when superimposing an image of only the movement of a person on the scroll screen.
