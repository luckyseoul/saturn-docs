転送関数
 
Data Name
MpgTrFunc
 
No
3.4

　書　式
void (*MpgTrFunc)(void *dst, void *src, Sint32 nbyte)
　入　力
dst
：転送先アドレス
src
：転送元アドレス
nbyte
：転送バイト数
　出　力
なし
　説　明
転送関数を表すデータ型です。転送関数を登録するには、MPG_WnSetTrFunc関数を使用します。
詳細は、「4.7　ユーザ転送関数の登録」を参照してください。
