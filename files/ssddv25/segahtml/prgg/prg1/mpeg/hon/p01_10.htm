MPEG library

1. Overview

This library is for controlling MPEG systems located on CD blocks. The MPEG system has the following functions.

  • Video playback function
  • Still image playback function (high definition also possible)
  • Window function
  • Capturing function
  • Visual effects function
  • Smooth branch playback function

The MPEG library controls CD blocks through the CD communication interface. The MPEG system reads and decodes MPEG streams from CD buffers within CD blocks. Decoded image data can be output in the following two ways.

  • How to output directly to a TV monitor via VDP2. (16 million colors)
  • How to output using VDP1 etc. after transferring to host area. (32000 colors)
