BOOT ROM User's Manual

Introduction

This manual describes BOOT ROM . Since the BOOT ROM is already built into the game console, it will operate automatically when the power is turned on or reset.

BOOT ROM is responsible for determining the operation of the main unit after turning on the power or pressing the reset button. Its main functions are displaying the SEGASATURN logo, launching games, providing service programs, and running multiplayer to play various CDs.

Before starting the game, it checks whether the GAME-CD is present and whether it is a genuine GAME-CD . For information on how to create a regular GAME-CD , please refer to the " DISC Format Standard Specifications " .
Also, please refer to the " System Program User's Manual " and " Backup Library User's Manual " for instructions on how to use the service program that can be used from the application after starting the game.
