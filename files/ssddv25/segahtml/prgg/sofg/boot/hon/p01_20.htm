BOOT ROM User's Manual

BOOT ROM processing flow

■Processing flow

If GAME-CD is recognized while the SEGASATURN logo is displayed, the game will automatically start. If not GAME-CD , run multiplayer .

Figure 1 BOOT ROM processing flow overview

■Notes

●If there is no CD inserted or if the CD door is open
In multiplayer , "CD not inserted" and "CD door open" are displayed respectively.

●If a game cartridge is installed
Game cartridges are preferred. To start GAME-CD , turn off the power and remove the cartridge.

■Differences between the product version and target box version

●SCSI device for debugging support
In addition to the retail version features, the Target Box version adds the ability to check SCSI devices and SIMM memory for debugging support and launch the game. It checks the SCSI device and SIMM memory, and if a file named [IP.BIN] exists, it will try to launch the game from it.
For details on how to use each, please refer to the " Simple CD Simulator User's Manual " .

●No system disk required
The Target Box version allows you to start the game from the Write Once CD without using a system disk .
