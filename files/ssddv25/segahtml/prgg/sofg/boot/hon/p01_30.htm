BOOT ROM User's Manual

BOOT ROM features

■SEGASATURN logo display

Check and initialize the hardware before displaying the logo. GAME-CD is checked while the logo is displayed.

If GAME-CD is installed, start the game, and if GAME-CD is not installed, start multiplayer .

After resetting the SMPC, go to the "Date and Time Settings" screen and then display the logo.

You can always skip the logo animation and go to multiplayer by holding the A button and resetting.

You can always skip the logo animation and go to the "Saved Data Management" screen by pressing and holding the L or R button while resetting.
Logo animation can be skipped by pressing Start, A, B, C, X, Y, Z, L, R buttons.

■Notes on the “Saved Data Management” screen

●Auto format
The main unit's backup RAM is automatically initialized when you use it for the first time, so use "Erase all (initialization)" when you want to erase all data or when you can no longer load data. .

●Backup RAM failure
If the following message appears, the main unit's backup RAM may be malfunctioning. For details, please contact our technical support .

  • When executing initialization: → " Failed to initialize "
  • When performing deletion: → " Failed to delete records from the device. "

●Precautions when turning off the power
Do not turn off the power during initialization, erasing, or copying. If you turn off the power, you may not be able to load data. If the data cannot be loaded, please initialize it.

●About the erase screen
How to view the erase screen (method described in the instruction manual)

  • NO. → Data number
  • Name → Name of data on backup RAM

The game abbreviation etc. will be automatically written.

This feature is not a BOOT ROM feature.
Please handle this in each application.

comment: Auxiliary display of the name of the data.
amount to use: Capacity of each data. The capacity used varies depending on the game.
Free space: Unused capacity of backup RAM. Data scrolls using the up and down direction buttons.

■Starting the game

In order to prevent the creation and sale of unauthorized game software, we check whether the GAME-CD contains boot code before starting the game.
Be sure to put the boot code in the specified location on GAME-CD . If the boot code is not recognized, the game will not launch.
For the contents of the boot code and how to create it, please refer to " DISC Format Standard Specifications " .

●Procedure for starting the game (method described in the instruction manual)
  1. Turn on the TV.
  2. Switch the TV screen to video input mode.
  3. Press the open button to open the CD door.
  4. Insert the Sega Saturn CD with the side printed with the game name facing up.
  5. Close the CD door.
  6. Press the power button and the game will start automatically.

●Procedure for ending the game (method described in the instruction manual)
  1. During a game or after a game over, hold down the A button and press the reset button.
    After a while, the multiplayer screen will appear after the Sega Saturn logo.
  2. Open the CD door with the open button and remove the CD.
  3. Turn off the power button on the main unit.
  4. Unplug the power cable from the outlet.

●When you want to return to the game title screen (method described in the instruction manual)
Pressing the A, B, C, and Start buttons simultaneously during a game will return you to the game's title screen.

This feature is not a BOOT ROM feature.
Please handle this in each application.

■About the service program

●System program
The following services are available. This service program must be used to access these resources.

  1. Registering and referencing interrupt handling routines
  2. SCU interrupt mask set, read, and change operations
  3. Simple semaphore operation
  4. System clock switching
  5. SCU interrupt routine priority change
  6. Start CD multiplayer
  7. Power-on clear memory operation

For details, please refer to the " System Program User's Manual " .

●Backup library
Provides read/write and search functions for backup storage devices. This service program must be used to access the internal backup RAM.
(Currently, this service program must be used when accessing external storage devices. SEGA plans to distribute a library in the future to access unsupported external storage devices.)
For details, refer to the " Backup Library User's Manual " .

■Multiplayer execution

When multiplayer starts, control buttons will appear on the screen. Multiplayer operation button selection and operation decisions are made using a dedicated control pad.

●How to operate the control pad
The functions of each button on the control pad are as follows. Basic operations can be performed directly on music CDs using the X, Y, Z, L, and R buttons.

Directional buttons: Select/Move
Start button: Game Start
A button: decision
B button: cancel
C button: decision
X button: 1 song repeat
Y button: Stop
Z button: Play/Pause
L button: * Song return (skip & search)
R button: *Song forwarding (skip & search)
*Press the L and R buttons briefly to skip one song at a time, and press and hold them for a long time to search.

● How to read the operation buttons (main buttons)

1.Multi-button
When a Sega Saturn CD is loaded, the S mark button will be displayed.

2. Saved data management button
Press this button to display the save data management screen for managing the game's save data.

3. Panel erase button
Press this button to clear the multiplayer screen and display the background screen (screen saver). (While CD+G is playing, the CD+G graphic will be displayed instead of the background screen)

4. Song return button (skip & search)
A short press will skip one song at a time, a long press will search.

5.Play/pause button

6. Song forward button (skip & search)
A short press will skip one song at a time, a long press will search.

7.Repeat button
Switch between repeat one song/repeat all songs/cancel.

8.Stop button

9.Function switching button
Switch between the main button and option button.

●How to read the operation buttons (option buttons)

1. Pitch & Voice Button

2.Program button

3.Surround button

4.Intro button
Once set, it will play 10 seconds from the beginning of each song and then move on to the next song.

5.Display switching button
Changes the time display on the multiplayer screen.

6.Shuffle button
If set, the songs on the CD will be played in random order.

7.All clear button
Cancels all functions set with each operation button.

8.AB repeat button

9.Function switching button

Note:
The program button and shuffle button, AB repeat button and intro button, surround button and pitch & voice button cannot be used at the same time. If one button is already set and you set the other button, the previously set button will be canceled.

About voice cancellation:
Voice cancellation is an effect that reduces the singer's voice by reducing the sound in the center of a stereo-recorded song, but does not erase the singer's voice. Also, voice cancellation is not recommended for songs recorded in monaural, as the entire song will become smaller. Even if the song is recorded in stereo, voice cancellation will be applied to Japanese songs such as folk songs and poetry, classical songs and songs with few instruments, duet songs, songs with strong chorus or echo, and songs where the singer's voice is not centered. may not be effective.

■To change settings

On the Sega Saturn, you can change the date and time of the built-in clock and the language displayed on the multiplayer screen.

●Date and time settings:
On the date and time setting screen, use the left and right direction buttons to select an item, and use the up and down buttons to change it. Select "OK" and press the C button to change the date and time and return to the user settings screen.

Applications can use the date and time set by the user, but must not change them. To change the date and time, you need to have the user set it on the date and time settings screen.

●Language settings:
You can select the display language for the multiplayer screen from the following six countries.
English, German, French, Spanish, Italian, Japanese

Multilingual applications should determine their default language from this user-preference language. Additionally, if there is a function for the user to change the supported language within the application, the setting must be changed using the prescribed method so that it is reflected in the multiplayer language setting.

●Other settings/help window:
You can select whether to display or not display the help window on the multiplayer screen.

Help window settings should not be referenced or changed from the application.

●Other settings/audio output:
You can switch between stereo and monaural audio output for music CDs, CD+G, and CD+EG.

Mono-enabled applications must determine their default audio output settings from this user-configured audio output setting. Additionally, if there is a function for the user to change the audio output settings within the application, the settings must be changed using the prescribed method so that they are reflected in the multiplayer audio output settings.

●Other settings/sound effects:
You can select ON/OFF for sound effects on the multiplayer screen.

Sound effect settings must not be referenced or changed from the application.
