troubleshooting

■If this message appears

"You cannot play with this SEGASATURN CD"
This will be displayed if a Sega Saturn CD that is not for use in Japan is included. In this case, please check the type of CD.
(If music data is included, you can only play the music data.)
This message will also be displayed if the recording side of the CD (the side on which the game name, etc. is not printed) is dirty. In this case, wipe the recording surface with a soft, dry cloth.

"This CD cannot be played"
This appears when a CD that contains no music data is inserted. In this case, please check the type of CD.

"No CD included"
This message appears if the CD is not inserted, if the CD is severely damaged, if the CD is inserted upside down, or if the CD is of a type that the Sega Saturn cannot recognize. In this case, check the condition and type of the CD.

"You cannot play with this SEGASATURN cartridge"
This will be displayed if a Sega Saturn cartridge other than for use in Japan is included. In this case, please check the type of Sega Saturn cartridge.

■If you think there is a problem

●Multiplayer screen does not start
Has the game cartridge been removed from the cartridge slot?

●Sega Saturn CD game does not start
Is the disc upside down ?
Is the disc dirty ?
Is the disc scratched ?

●CD, CD+G, CD+EG can be heard in monaural
Is the audio output set to monaural?
(If using Sega Saturn Stereo AV Cable or Sega Saturn S Terminal Cable)

●When I turn on the power, the date and time setting screen is displayed many times.
●Data saved in the main unit's backup RAM will be deleted.
Does it have a lithium battery? Or is the lithium battery dead?

●The lamp does not turn on immediately even if you press the power button.
It may take a second or two for the power lamp to light up, but this is not a malfunction.

In addition to this, if you experience strange operation or display during use, try pressing the reset button or turning the power button on and off. If that doesn't work, remove the battery cover and press the master reset switch. (However, if you perform these operations while the game data is being saved, the data may not be saved and may be deleted.)
  • The target box's POWER ON RESET switch is slightly different from the power ON/OFF switch.
  • If the POWER ON RESET switch does not work, turn the POWER button ON/OFF.
  • The target box's master reset switch is the SMPC RESET switch.

If the product does not work properly even after performing the above steps, unplug the power cable from the outlet and contact the store where you purchased it or our technical support center .

■Q&A

Q1:
GAME-CD does not start.

A1:
Be sure to put the boot code in the specified location on GAME-CD. If the boot code is not recognized, the game will not launch. For the contents of the boot code and how to create it, please refer to " DISC Format Standard Specifications " .

Q2:
The created GAME-CD starts on the target box, but it does not work on the commercial version.

A2: The following are possible.

  • Boot code suitable for the DISC format was not written.

  • The system disk is not in use.
    It will not start if the manufacturer ID is not written correctly. Be sure to check the manufacturer ID. For more information, please refer to " DISC Format Standard Specifications " .
