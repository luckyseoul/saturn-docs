BOOT ROMユーザーズマニュアル

BOOT ROMの機能

■SEGASATURNのロゴ表示

　ロゴ表示前にハードウェアのチェックとイニシャライズを行います。ロゴの表示中にGAME-CDのチェック等を行います。

　GAME-CDが入っている場合にはゲームを起動し、GAME-CDが入っていない場合にはマルチプレイヤーを実行します。

　SMPCのリセット後には、「日付、時刻の設定」画面に行ってからロゴ表示をします。

　Aボタンを押しながらリセットすると、いつでもロゴアニメーションをスキップしてマルチプレイヤーに行くことができます。

　Lボタン、または、Rボタンを押しながらリセットすると、いつでもロゴアニメーションをスキップして「保存データ管理」画面に行くことができます。
ロゴアニメーションは、スタート、A、B、C、X、Y、Z、L、Rボタンを押すとスキップできます。

■「保存データ管理」画面についての注意点

　●自動フォーマット
　本体のバックアップRAMは、初めて使うとき自動的に初期化されるようになっているので、「全部消す(初期化)」はデータをすべて消したいときまたはデータをロードできなくなったときに行ってください。

　●バックアップＲＡＭの故障
　下記メッセージが出たときは、本体のバックアップRAMが故障していることも考えられます。くわしくは弊社テクニカルサポートまでお問い合わせください。

  • 初期化実行時：　→　「初期化できませんでした」
  • 消去実行時：　→　「本体から記録を消せませんでした」

　●電源切断時の注意
　初期化、消去、コピーの途中では、電源を切らないでください。電源を切るとデータをロードできなくなることがあります。もしデータがロードできなくなったときは、初期化を行ってください。

　●消去画面について
　消去画面の見かた(取り扱い説明書に記載されている方法)

  • ＮＯ．　→　データの番号
  • 名前　→　バックアップRAM上でのデータの名前

　ゲームの略称などが自動的に書き込まれます。

この機能は、BOOT ROMの機能ではありません。
各アプリケーションで対応してください。

コメント:データの名前の補助表示。
使用量:各データの容量。ゲームによって使用する容量は異なります。
空き容量:バックアップRAMの未使用容量。方向ボタンの上下でデータがスクロールします。

■ゲームの起動

　無許可で不正なゲームソフトの作成販売を防止するために、GAME-CDにブートコードが入っているかどうかをゲームの起動前にチェックします。
　GAME-CDの指定の位置に必ずブートコードを入れてください。ブートコードを認識できない場合は、ゲームは起動されません。
　ブートコードの内容、および、作成方法は、 「DISCフォーマット規格仕様書」を参照してください。

　●ゲームの開始手順(取り扱い説明書に記載されている方法)
  1. テレビの電源を入れます。
  2. テレビ画面をビデオ入力モードに切り替えます。
  3. オープンボタンを押し、CDドアを開けます。
  4. ゲーム名などが印刷されている面を上にして、セガサターンCDを入れます。
  5. CDドアを閉めます。
  6. パワーボタンを押すと、自動的にゲームが始まります。

　●ゲームの終了手順(取り扱い説明書に記載されている方法)
  1. ゲーム中またはゲームオーバー後にAボタンを押しながらリセットボタンを押します。
    しばらくすると、セガサターンのロゴのあとにマルチプレイヤー画面が表示されます。
  2. オープンボタンでCDドアを開け、CDを取り出します。
  3. 本体のパワーボタンをOFFにします。
  4. 電源ケーブルをコンセントから抜きます。

　●ゲームのタイトル画面へ戻りたいとき(取り扱い説明書に記載されている方法)
　ゲーム中にA、B、C、および、スタートボタンを同時に押すと、ゲームのタイトル画面に戻ります。

この機能は、BOOT ROMの機能ではありません。
各アプリケーションで対応してください。

■サービスプログラムについて

　●システムプログラム
　下記サービスが利用できます。これらの資源にアクセスする場合には、必ずこのサービスプログラムを使用しなくてはなりません。

  1. 割り込み処理ルーチンの登録、参照操作
  2. SCU割り込みマスクのセット、参照、変更操作
  3. 簡易セマフォ操作
  4. システムクロック切り替え
  5. SCU割り込みルーチン優先度変更
  6. CDマルチプレイヤー起動実行
  7. パワーオンクリアメモリ操作

　詳細は「システムプログラムユーザーズマニュアル」を参照してください。

　●バックアップライブラリ
　バックアップ用記憶装置への読み書きと検索機能を提供します。内蔵バックアップRAMへのアクセスには、必ずこのサービスプログラムを使用しなくてはなりません。
(現在は外部記憶装置へのアクセス時にも、必ずこのサービスプログラムを使用しなくてはなりません。未対応の外部記憶装置へのアクセスには、将来SEGAからライブラリが配布される予定です。)
　詳細は「バックアップライブラリユーザーズマニュアル」を参照してください。

■マルチプレイヤーの実行

　マルチプレイヤーが起動すると、操作ボタンが画面に表示されます。マルチプレイヤーの操作ボタンの選択や操作の決定は、専用のコントロールパッドで操作します。

　●コントロールパッドの操作方法
　コントロールパッドの各ボタンの機能は次のとおりです。音楽CDに対しては、X、Y、Z、L、Rボタンを使って直接基本操作が行えます。

方向ボタン：選択／移動
スタートボタン：ゲームスタート
Ａボタン：決定
Ｂボタン：取り消し
Ｃボタン：決定
Ｘボタン：１曲リピート
Ｙボタン：停止
Ｚボタン：再生／一時停止
Ｌボタン：※曲戻し(スキップ＆サーチ)
Ｒボタン：※曲送り(スキップ＆サーチ)
※Ｌ、Ｒボタンは、短く押すと１曲毎にスキップし、長く押すとサーチを行います。

　●操作ボタン(メインボタン)の見方

　　1.マルチボタン
　セガサターンCDが入っているときはSマークボタンが表示されます。

　　2.保存データ管理ボタン
　このボタンを押すと、ゲームのセーブデータを管理するための保存データ管理画面を表示します。

　　3.パネル消去ボタン
　このボタンを押すと、マルチプレイヤー画面を消去し、背景画面(スクリーンセーバー)を表示します。（CD+G再生中は、背景画面のかわりにCD+Gのグラフィックを表示します）

　　4.曲戻しボタン(スキップ＆サーチ)
　短く押すと１曲毎にスキップし、長く押すとサーチを行います。

　　5.再生／一時停止ボタン

　　6.曲送りボタン(スキップ＆サーチ)
　短く押すと１曲毎にスキップし、長く押すとサーチを行います。

　　7.リピートボタン
　１曲リピート／全曲リピート／解除を切り替えます。

　　8.停止ボタン

　　9.機能切替ボタン
　操作ボタンのメインボタンとオプションボタンを切り替えます。

　●操作ボタン(オプションボタン)の見方

　　1.ピッチ＆ヴォイスボタン

　　2.プログラムボタン

　　3.サラウンドボタン

　　4.イントロボタン
　設定すると、各曲の最初から10秒間を再生して次の曲に進んで行きます。

　　5.表示切替ボタン
　マルチプレイヤー画面の時間表示を切り替えます。

　　6.シャッフルボタン
　設定すると、CDの曲を順不同で再生します。

　　7.オールクリアボタン
　各操作ボタンで設定されている機能をすべて解除します。

　　8.ABリピートボタン

　　9.機能切替ボタン

注意：
　プログラムボタンとシャッフルボタン、ABリピートボタンとイントロボタン、サラウンドボタンとピッチ＆ヴォイスボタンは、 それぞれ同時に使うことはできません。既にどちらかが設定されているときに、もう一方のボタンを設定すると、先に設定されていたボタンは解除されます。

ヴォイスキャンセルについて：
　ヴォイスキャンセルは、ステレオ録音された曲の中央に位置する音を小さくすることにより、歌手の声を小さくするもので、歌手の声を消す効果ではありません。またモノラル録音の曲は、曲全体が小さくなってしまうので、 ヴォイスキャンセルはお勧めしません。ステレオ録音された曲でも、民謡、詩吟など邦楽系の曲、クラシックや楽器の少ない曲、デュエットの曲、コーラスやエコーの強い曲、歌手の声が中央に位置していない曲などは、 ヴォイスキャンセルの効果の出ないことがあります。

■設定を変更するには

　セガサターンでは、内蔵時計の日付、時刻やマルチプレイヤーの画面の表示言語などを変更できます。

　●日付、時刻の設定：
　日付、時刻の設定画面で方向ボタンの左右で項目を選び、上下で変更してください。「決定」を選びCボタンを押すと、日付、時刻は変更され、ユーザー設定画面に戻ります。

アプリケーションでは、ユーザが設定した日付、時刻を利用することができますが、変更してはいけません。日付、時刻を変更するには、ユーザに日付、時刻の設定画面で設定してもらう必要があります。

　●言語の設定：
　以下の６ヶ国の中からマルチプレイヤー画面の表示言語を選択できます。
英語、ドイツ語、フランス語、スペイン語、イタリア語、日本語

多国語対応のアプリケーションは、デフォルトの言語をこのユーザ設定の言語から決める必要があります。また、アプリケーション内で対応言語をユーザが変更する機能がある場合には、マルチプレイヤーの言語の設定に 反映されるように所定の方法によって設定を変更する必要があります。

　●その他の設定／ヘルプウィンドウ：
　マルチプレイヤー画面でのヘルプウィンドウを「表示する／表示しない」が選択できます。

ヘルプウィンドウの設定は、アプリケーションから参照も変更もしてはいけません。

　●その他の設定／音声出力：
　音楽CD、CD+G、CD+EGの音声出力のステレオとモノラルの切り替えができます。

モノラル対応のアプリケーションは、デフォルトの音声出力設定をこのユーザ設定の音声出力設定から決める必要があります。また、アプリケーション内で音声出力設定をユーザが変更する機能がある場合には、 マルチプレイヤーの音声出力設定に反映されるように所定の方法によって設定を変更する必要があります。

　●その他の設定／効果音：
　マルチプレイヤー画面での効果音のON/OFFを選択できます。

効果音の設定は、アプリケーションから参照も変更もしてはいけません。
