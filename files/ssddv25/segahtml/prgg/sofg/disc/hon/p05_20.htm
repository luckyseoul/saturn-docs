DISC format standard specifications

Appendix B Volume Descriptor

VolumeIdentifier“SAMPLE_GAME_TITLE”; Required, changeable

Directory String Enter the game title within 32 characters. Please fill in the title so that you can identify it by looking at this character string. There are no other restrictions.

Note : Spaces are not part of the directory string and cannot be used.

VolumeSetIdentifier“SAMPLE_GAME_TITLE”; Required, changeable

Directory string Enter the game title within 128 characters. Normally, enter the same string as [VolumeIdentifier]. If you have more than 2 discs, you can also write the name of the set.

PublisherIdentifier“SEGA ENTERPRISES, LTD.”; Required, changeable

Enter the publisher (company) name using up to 128 ASCII characters. Please fill in the information so that the selling company can be identified by looking at this character string. If outsourcing, follow the example. If you are a licensee, please enter the company name.

DataPreparerIdentifier“SEGA ENTERPRISES, LTD.”; Required, changeable

Enter the data editor (company) name using up to 128 ASCII characters. Please fill in this string so that the production company can identify it. If outsourcing or licensee, please enter the company name.

CopyrightFileIdentifier“SMP_CPY.TXT”; Required, changeable

Enter the copyright file name using up to 8 characters of directory string + “.” + 3 characters. Always place the copyright file in the root directory. The copyright file contains all copyright notices related to the game. There are no rules about the contents of the file. In the case of outsourcing, the name shall be “Copyright(c) SEGA ENTERPRISES, LTD 1995”.

AbstractFileIdentifier“SMP_ABS.TXT”; Required, changeable

Enter the abstract file name using up to 8 characters of the directory string + “.” + 3 characters. The abstract file must be placed in the root directory. For books, the abstract file includes a preface and synopsis, but for games, it would be a good idea to include an overview of the game. There are no rules about the contents of the file.

BibliographicFileIdentifier“SMP_BIB.TXT”; Required, changeable

Enter the bibliographic file name using up to 8 characters of the directory string + “.” + 3 characters. Always place bibliographic files in the root directory. In the bibliographic file, for books, include the references used to write and produce the book, but for games, it is a good idea to include the name of the original work or the original game that was ported. There are no rules about the contents of the file.

VolumeCreationDate 22/11/1994 00:01:02:00:36; Selectable, changeable

Normally there is no need to specify it. If not specified, the date and time when the CD image file was created will be entered. Please use it together with [VolumeModificationDate] when you want to distinguish the modification date and time.

VolumeModificationDate 22/11/1994 00:01:02:00:36; Selectable, changeable

Normally there is no need to specify it. If not specified, the date and time when the CD image file was created will be entered. Please use this together with [VolumeCreationDate] when you want to distinguish the modification date and time.
