DISC format standard specifications

DISC format overview

■Features

The physical format of GAME-CD for this game console complies with the Semi CD-ROM XA standard.
Therefore, interleaved recording, which previously depended on applications, can now be realized as a system, making it easier to play back images and audio in parallel.

"Semi CD-ROM XA" : CD-ROM XA with Model 1 track

■Disc size and recording time

We can only produce 12cm CDs. 8cm GAME-CD cannot be produced. To avoid trouble, limit the start time of the readout area to the following range.

Time of first LSN(#0) 00:02:00
Time of last LSN (~#283499) ~63:01:74
Lead-out area start time ~63:04:00

Therefore, the maximum recording time is 63 minutes . Multi-session is not available.

■Linear speed and track pitch

The linear velocity and track pitch of GAME-CD are fixed to the following values in order to improve track jump accuracy and speed up seek speed.

  • Linear velocity → 1.25 m/sec
  • Track pitch → 1.6 μm

■Disk format

The disc format complies with the following standards.

  • physical format
    SONY and PHILIPS CD standards “RED BOOK”, “YELLOW BOOK”, “CD-ROM XA”

  • logical format
    ISO9660

  • MPEG format
    ISO11172

■Track layout

The inner side will be the CD-ROM area, and the outer side will be the CD-DA area.

■Sector structure

In addition to the traditional Mode1, the sector has Mode2 Form1 and Mode2 Form2 with subheaders. A variety of interleaved recordings are possible using file numbers and channel numbers.

■ISO9660 compliant

The ISO9660 standard does not specify the contents of logical sector numbers 0 to 15. CD producers can use it for boot programs and protection information for system startup.
By specifying this area in the disc format, GAME-CD can be started. No boot cartridge required. Logical sector numbers 16 and above comply with ISO9660.
