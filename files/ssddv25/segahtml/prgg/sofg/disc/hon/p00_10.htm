DISC format standard specifications

Introduction

This standard specification specifies how developed application software should be placed on a CD. CDs that do not comply with this standard specification will not be recognized as GAME-CD. All application software running on this game console must comply with this standard specification.
This standard specification only describes what programmers who develop application software should know. Rules regarding the basic physical format of the CD and protection settings to prevent copying must be complied with. Since this is done automatically during mass production, the details are not described in this standard specification. Therefore, if you use CD tools other than those specified by us, you may run into major problems . Please use our designated tools as much as possible. Please note that mass production outside of our designated factories is technically impossible.

Please be sure to use the CD tool specified by our company. If you wish to use a CD tool other than those specified by our company, please contact us as approval is required.
