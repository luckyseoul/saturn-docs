PCM/ADPCM playback library

4.Programming notes

The following are precautions when playing back using this library.

(1) Notes on creating applications

  • This library uses CPU DMA and timer. When operating this library, do not use the CPU's DMA and timer.

  • The frequency of calling PCM_Task should be at least the frequency of V blank interrupts (1 time/16ms).
    If the same sound occurs twice, it may be because PCM_Task is called infrequently.

  • PCM_Task You can set the upper limit of the amount to be processed in one call using the function PCM_Set1TaskSample . This allows you to stabilize the load on the PCM_Task function.

(2) Relationship with other libraries

  • This library uses the file system, stream system, DMA library, and ADPCM decompression library. Please link these libraries.

(3) How to take a buffer

  • Please ensure the following sizes.

     work buffer
     : Size of work structure.
     ring buffer

     :Minimum (sector size)*10 [byte]. An integer multiple of the sector size.
     For CD-ROM XA Audio playback, 1 sector = 2324 bytes.
     Otherwise, 1 sector = 2048 bytes.
     PCM buffer
     :4096*2 ~ 4096*4 [sample/1ch].
     Pose processing work
     :Minimum 4096 [sample]. The same size as the PCM buffer is optimal.

(4) Seamless branch

  • When seamless branching with PCM_EntryNext , the PCM volume and PAN will be the same as the previous handle.

  • When seamless branching with PCM_EntryNext , you can play continuously for up to 60 minutes. Continuous playback is not possible beyond this point.

  • When seamless branching, please pre-read files in the application program.

  • If you use a file system, you cannot use seamless branching.

  • Seamless branching can only be performed during single playback. Cannot be executed during multi playback.

(5)Multi playback

  • When playing multiple streams, set the PCM stream playback number to a different number.

  • When playing multiple files on a CD at the same time, use file interleaving or channel interleaving. In that case, use the stream system.

  • The same file cannot be played multiple times. Please specify a different file.

  • Multi playback can be performed on up to 4 at the same time.

  • Only one piece of ADPCM compressed data can be played.

(6) ADPCM compatible

  • Please link the ADPCM decompression library SEGA_ADP.LIB.

  • Call the ADPCM use declaration PCM_DeclareUseAdpcm after the initialization function.

◆Playback of specified ADPCM format

  • It can be played using exactly the same procedure (same program) as the AIFF format. However, please note that the CPU load will be higher than in the case of AIFF format.

◆CD-ROM XA Audio format playback

  • The library determines the playback frequency and number of channels (stereo/monaural) from the coding information in the subheader area. Please make sure it is written correctly.

  • Stream keys are set by the library user.

  • The ring buffer should be an integral multiple of the sector size of 2324 bytes.

  • Please set the playback information with PCM_SetInfo .

  • When playing CD_ROM XA Audio, only stream playback mode can be used.

  • Please refer to the sample program smppcm5.c.

(7) How to use functions

  • Be sure to call PCM_Init at the beginning of your program.

  • Be sure to call PCM_VblIn within the V blank IN interrupt.

  • PCM_Start can only be executed once for a handle.
    If you want to play the same file multiple times, generate a handle each time.

  • Call PCM_SetLoadNum and PCM_SetPcmStreamNo before starting playback.

  • For the handle created with PCM_CreateMemHandle , be sure to notify the amount of data supplied to the ring buffer using PCM_NotifyWriteSize .

  • When using the pose function, it is necessary to specify the work for pose processing using PCM_SetPauseWork in advance. This work does not need to be prepared for each handle.
    This work is a work area that is used temporarily during pause-on processing, so you can reserve the area immediately before pause-on processing and release the area immediately after.

  • Data transfer method from CD block to ring buffer By default, data is transferred using CPU DMA.
    PCM_SetTrModeCd allows you to specify program transfer, CPU DMA, or SCU DMA.
    Call PCM_SetTrModeCd after creating the handle and before calling the task function for the first time.

  • When playing CD-ROM XA Audio, be sure to set the playback information using PCM_SetInfo .

(8)About SaturnPCM format

(a) Data creation

  • Convert and create AIFF files using the conversion tool AIF2SAP.

[Format]
aif2sap aiffile [sapfile]
[input]
aiffile: AIFF file name
sapfile: SaturnPCM file name
[function]
Convert AIFF files to SaturnPCM files (SAP files).
If you do not enter a SaturnPCM file name, a SaturnPCM file will be created with the file name that is the base name of the AIFF file name with the extension " SAP " added.

(b) Data format

  • It is uncompressed PCM.

  • Adopts sector boundary structure.

  • The first 2048 bytes are the header area. Thereafter, PCM data is arranged in the order of L channel and R channel in units of 4096 samples.

(c) How to use

  • The SaturnPCM format has two playback modes: file playback mode (using file system) and stream playback mode (using stream system).

  • After the initialization function, you can use the SaturnPCM format by calling the function PCM_DeclareUseSapGfs , which declares the use of SaturnPCM in file playback mode, or the function PCM_DeclareUseSapStm in stream playback mode.

  • After declaring the use of SaturnPCM, it can be used in the same way as the AIFF format.

  • For specific usage, please refer to the sample programs smppcm41.c (file playback mode) and smppcm21.c (stream playback mode).

(d) Regarding resources used
  • The default setting is to transfer data from the CD buffer to the sound memory using SCU-DMA (channel 0). The data transfer method can be specified as program transfer, CPU-DMA, or SCU-DMA using the function PCM_SetTrModeCd .

(e) Work area

  • The SaturnPCM format does not require a ring buffer; instead, it requires an extended work buffer (the size of the extended work buffer is 2048 bytes).

(f) Restrictions

  • SaturnPCM format and AIFF / ADPCM / CD-ROM XA Audio format cannot be used at the same time. After declaring the use of SaturnPCM, all PCM files to be played will be in SaturnPCM format.
