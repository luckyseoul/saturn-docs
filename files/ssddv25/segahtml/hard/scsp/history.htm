MIEMP(R) ; Midi Input EMPty
	"1B" is set when the input FIFO is empty. The data in the MIDI-IN buffer is
	When there is no data in the MIDI-IN buffer, such as when all data has been read out by the above command, "MIEMP" becomes "1B", indicating that the buffer is empty.
	Figure 4.60 shows a diagram of MIDI-IN and the interrupt generation section. An interrupt occurs when "MIEMP" changes from "1B" to "0B" after receiving external data.
	The interrupt will be released when all the data in the MIDI-IN buffer is read and "MIEMP" becomes "1B".
