SCSP User's Manual/4.2 Sound source register

■LFO register

An LFO is a low frequency oscillator used to modulate audio signals.
One LFO is installed in each slot, and each slot has an output for amplitude modulation and an output for frequency modulation.
There are four types of LFO output waveforms: sawtooth wave, square wave, triangle wave, and noise (white noise), and you can choose any of these.
The block diagram of the LFO is shown in Figure 4.46. Sawtooth waves, square waves, and triangle waves, except for noise waveforms, can be reset and their frequencies can be changed. Additionally, the LFO waveform and modulation depth can be set independently for the amplitude modulation side and frequency modulation side.

Figure 4.46 LFO block diagram

LFORE(R/W) ; LFO REset
Specifies whether or not to reset the LFO. Setting this bit to "1B" resets the LFO. Also, by writing "0B", it starts operating.

LFOF[4:0](R/W); LFO Frequency
Specifies the oscillation frequency of the LFO.

 ALFOS[2:0](R/W) ; Amplitude-LFO Sensitivity
 Specifies the amount of amplitude modulation applied by the LFO. This amplitude modulation allows you to express a tremolo effect (a phenomenon caused by periodically varying the volume).
