SCSP User's Manual/4.2 Sound source register

■4.2 Sound source register

The structure of the sound source register is as shown below (Table 4.9).
The contents of each register will be explained according to this configuration. Regarding the symbols added after the register name,

  • (R) is read-only
  • (W) is for writing only
  • (R/W) can read and write

are expressed respectively.

Also, when reading data from a write-only register (bit), the value will be "0B". When writing data to a read-only register (bit), be sure to write "0B".

List 4.7 Sound source register allocation

● Loop control register :
KYONEX, KYONB, SBCTL, SSCTL, SA, LSA, LEA, PCM8B, LPCTL

● EG register :
EGHOLD, AR, D1R, D2R, RR, DL, KRS, LPSLNK

● FM modulation control register :
SOUS, MDL, MDXSL, MDYSL, STWINH
→ When using the FM sound source method

● Volume register :
TL, SDIR

● PITCH register :
OCT, FNS

● LFO register :
LFORE, LFOF, ALFOWS, ALFOS, PLFOWS, PLFOS

● MIXER register :
IMXL, ISEL, DISDL, DIPAN, EFSDL, EFPAN, MVOL, DAC18B

● Slot status register :
MSLC, CA

● Sound memory configuration register :
MEM4MB

● MIDI register :
MIBUF, MIOVF, MIFULL, MOFULL, MOEMP, MOBUF

● Timer register :
TACTL, TIMA, TBCTL, TIMB, TCCTL, TIMC

● Interrupt control register :
SCIPD, SCIEB, SCIRE, SCILV0, SCILV1, SCILV2, MCIPD, MCIEB, MCIRE

● DMA transfer register :
DGATE, DDI, DEXE, DMEA, DRGA, DTLG
