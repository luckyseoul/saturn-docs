SCSP User's Manual/4.2 Sound source register

■Sound memory configuration register

MEM4MB(W) ; MEMory 4MBit
Specify the amount of memory connected to SCSP.

Table 4.25 Memory capacity
MEM4MB Memory capacity
0 1Mbit DRAM used
1 4Mbit DRAM used

Note
 Be sure to set it to "1" in this system.
