MIEMP(R) ; Midi Input EMPty
	　入力FIFOが空の時、"1B"がセットされます。MIDI-INバッファ内のデータがCPU
	等によって全て読みだされている等、MIDI-INバッファにデータが何も無い時は
	"MIEMP"が"1B"となり、バッファが空であることを表します。
	　図4.60にMIDI-INと割り込み発生部の図を示します。割り込みは、"MIEMP"が
	"1B"の状態から、外部のデータを受信して"MIEMP"が"0B"となった時に発生し、
	MIDI-INバッファのデータが全て読み出されて、"MIEMP"が"1B"となった時に、割
	り込みが解除します。

	図4.60　MIDI IN部と割り込み発生部
