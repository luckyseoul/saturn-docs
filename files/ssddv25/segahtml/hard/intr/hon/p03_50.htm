■3.5 SCSP

SCSP is a custom sound LSI that combines a PCM (FM) sound source and a dedicated sound DSP.
The audio function is highly functional and has high sound quality, and a variety of interfaces are provided with future expandability in mind. The calculation section also has performance comparable to that of a synthesizer, allowing it to produce a large number of notes.
The DSP section can also reproduce various sound fields and create multiple sound fields such as special effects such as 3D sound localization.

●System configuration

The main CPU, sound CPU, sound memory, and D/A converter are connected to the SCSP. These can operate independently of the main processing in this sound system.
The main CPU transfers sound (CPU, DSP) programs and waveform data to the SCSP's sound memory via the SCU. The sound CPU transfers the waveform data to the SCSP's internal registers. SCSP loads waveform data from sound memory and delay data to create effects. These sounds are mixed by a mixer and output as sound via a D/A converter.

 ●Function
 The main features of SCSP are listed below.


    

  •  frequency control
  •  volume control
  •  FM calculation
  •  LFO (Low Frequency Oscillator) modulation function
  •  digital audio mixing
  •  Effects (reverb) by DSP




 ●Effect
 SCSP's DSP can create multiple sound fields, so you can make settings so that the sound field of the background music and the sound field of the game itself are different.

 For example, in a racing game, you can simultaneously apply reverb of a concert venue to the background music and reverb to create the atmosphere inside a tunnel for the game.
 Figure 3.26 Tunnel and BGM reverb




 Since the DSP receives not only the audio signal from the sound source but also the audio signal from the CD, it is possible to apply effects to the audio from the CD. In addition, the output level of the CD can be controlled via SCSP, so it is possible to balance the audio signal of the sound source section and the CD, so the sound of the sound source section will not be obscured by the sound of the CD and become inaudible. .




 ●Sound localization
 SCSP is equipped with a high-performance digital mixer, so you can control the localization of each sound in real time. Therefore, sound effects can be output in a localized position that matches the position of the character on the screen. This processing can also be done by DSP. In this case, you can make more detailed localization settings, so you can move the sound localization smoothly even when the character is moving slowly. By adding reverb to this localization, it is also possible to create a sense of depth (distance).
 Figure 3.27 Example of use in a tennis game




 In addition to this, depending on the type of reverb, it is possible to express the spaciousness of a space, whether indoors or outdoors. In addition, there are various types of reverb such as hall, stage, room, iron plate, etc., and it is possible to set all kinds of conditions.
