Sega Saturn Overview Manual

Chapter 1 Introduction to Sega Saturn

●Main CPU is a 32-bit RISC chip
・Equipped with SH-2 that supports arithmetic units similar to DSP
●Memory
・ 32M bits (4M bytes)
・ 4M bits (512K bytes) for CD-ROM
●Powerful graphic function
・ Up to 16,777,216 colors
・ 24 million color pixels/SEC(VDPI)
・ Sprite processor that can display polygons
・ High performance background processing processor
●Enhanced sound function
・ 32 channel PCM sound source
・ FM sound source
・ Equipped with audio-dedicated effect DSP
●Cutting-edge CD-ROM drive
・ Equipped with 32-bit RISC chip SH-1
・ MPEG (optional)
●Development language
・ C language, assembly language
