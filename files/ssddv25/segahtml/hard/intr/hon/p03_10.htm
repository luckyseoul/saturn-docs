Sega Saturn Overview Manual

Chapter 3 Functions

■3.1 CPU

The main CPU is equipped with a 32-bit RISC chip with built-in DSP function, and the sound block section is equipped with a 16-bit CPU MC68EC000. In addition, SH-1 is installed on the subsystem side.

Table 3.1 CPU specifications
SH-2
・RISC type instruction set
・ Internal, external 32-bit bus
・ Cache 4K bytes
・ Clock 28.6MHz Note 1
・ Built-in multiplier/divider
SH-1
・RISC type instruction set
・ Built-in A/D converter
・ Internal 32-bit bus, external 16-bit bus
・ Clock 20MHz
・ Cache 4K bytes
・ Built-in multiplier
MC68EC000
・Internal 16-bit bus, external 16-bit bus
・ CISC type instruction set
・ Clock 11.3MHz

note
