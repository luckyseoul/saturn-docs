■4.5 Forced drawing termination register

The drawing forced end register (ENDR, End register) forces the drawing to end. This is a 16-bit write-only register located at address 10000CH.

Forced end of drawing: draw end

  • Forcibly interrupts the drawing currently being processed.

  • Drawing of that frame will be forcibly terminated within approximately 30 clocks after writing data to the register.

  • Please specify 0000H for the write data.

  • It is not possible to continue drawing something that has already finished drawing.

  • If the amount of data to be drawn is large and the drawing does not finish within one frame, use pseudo-drawing continuation to divide it into two or more parts. Use this drawing forced termination function to forcefully terminate drawing in the middle of this pseudo-drawing continuation. For details, refer to " 4.8 Current Processing Table Address Register ".
