Chapter 8 Quick Reference

■8.1 System register

●TV mode selection register (TVMR, TV mode register)

V blank erase write enable bit: V blank erase/write enable (VBE), bit 3
TV mode select bits: TV mode select (TVM), bits 2 to 0

●Frame buffer switching mode register

Frame buffer change mode bit: frame buffer change mode (FCM), bit 1
Frame buffer change trigger bit: frame buffer change trigger (FCT), bit 0
Double interlace enable bit: double interlace enable (DIE), bit 3
Double interlace plot line: double interlace plot line (DIL), bit 2
Even/odd coordinate select bit: even/odd coordinate select bit(EOS), bit 4

●Plot trigger register

Plot trigger mode: plot trigger mode(PT), bits 1, 0

●Erase write data register

Erase write data: erase write data, bits 15 to 0

●Erase write upper left coordinate register

Erase write upper left coordinate X1: bits 14 to 9
Erase write upper left coordinate Y1: Bits 8 to 0

●Erase write lower right coordinate register

Erase write lower right coordinate X3: bits 15 to 9
Erase write lower right coordinate Y3: Bits 8 to 0

●Drawing forced termination register

●Transfer end status register

End-bit fetch status in the current frame: current end-bit fetch status(CEF), bit 1
Fetch status of end bit in previous frame: before end-bit fetch status(BEF), bit 0

●Processing interruption table address register

Processing interruption table address: bits 15 to 0

●Current processing table address register

Current processing table address: bits 15 to 0

●Mode status register

Version number: version number(VER), bits 15-12
Plot trigger mode upper: PTM1, bit 8
Even/odd coordinate selection bit: EOS, bit 7
Double-dense interlace enable bit: DIE, bit 6
Double-dense interlaced drawing line: DIL, bit 5
Frame buffer switching mode bit: FCM, bit 4
V blank erase write enable bit: VBE, bit 3
TV mode selection bits: TVM, bits 2-0

■8.3 Command table

●CMDCTRL (control word)

End bit: end bit(END), bit 15
Jump format: jump select(JP), bits 14 to 12
Zoom point bit: zoom point(ZP), bits 11 to 8
Character read direction bit: character read direction (Dir), bits 5 to 4
Command selection bits: command select(Comm), bits 3 to 0

●CMDLINK (LINK specification)

●CMDPMOD (drawing mode word)

High speed shrink: high speed shrink(HSS), bit 12
Preclipping disable: preclipping disable(Pclp), bit 11
Clipping mode bit: clipping mode bit(Cmod), bit 9
Mesh enable bit: mesh enable bit(Mesh), bit 8
End-code disable bit: end-code disable (ECD), bit 7
Transparent pixel disable bit: see-through pixel disable (SPD), bit 6
Color mode bit: color mode bit, bits 5 to 3
Color calculation bit: color calculation bit, bits 2 to 0
MSB on bit: MON(MSB on), bit 15
