■4.4 Erase write

Before starting drawing, the sprite IC clears the contents of the frame buffer. This erasure is called erase write, and it specifies the fill area to be erased and the fill data to be written to that area. There are three registers related to erase write: erase write data register , erase write upper left coordinate register , and erase write lower right coordinate register .

■Erase write data register

The erase write data register (EWDR) defines fill data during erase write. This is a 16-bit write-only register located at address 100006H. After turning on the power or resetting, the value becomes undefined, so be sure to set the fill data.

When drawing parts to the framebuffer, VDP1 automatically clears the framebuffer. During this erase (erase write), the frame buffer is filled with the 16-bit data set in the erase write data register.

When drawing to the frame buffer is 8bit/pixel (high resolution or rotation 8), erase/write will be done in 2pixel increments.
The area to be erased and written is set by the erase write upper left coordinate register and the erase write lower right coordinate register.

■Erase write upper left coordinate register

The erase write left coordinate register (EWLR) sets the upper left coordinate of the erase write area. This is a 16-bit write-only register located at address 100008H. After turning on the power or resetting, the values will be unstable, so be sure to set the coordinates. Set unused bits to 0.

  • Specifies the fill area of the frame buffer when writing an erase.

  • The X coordinate is set in 8 pixel units for 16 bit/pixel (normal, rotation 16, HDTV), and in 16 pixel units for 8 bit/pixel (high resolution, rotation 8). When the system register value is 1, it becomes 8 or 16.
    The actual lower right X coordinate is the value obtained by multiplying the register setting value by 8 or 16 and subtracting 1.

  • Set the Y coordinate in units of one line. When using double-dense interlacing, the value will be twice the Y coordinate register setting value, so please set it to 1/2 of the actual coordinate value. For example, when the setting value is 223, the coordinate value will be 447.

  • The actual X coordinate is expressed by the following formula.

Upper left coordinate X1 = register setting value x 8
Lower right coordinate X3 = register setting value x 8−1

8bit/pixel

Lower right coordinate X3 = register setting value × 16−1

  • X1≧X3, or Y1＞ If set to Y3,

    Normal, high resolution → 1 dot rotation/HDTV → 8 dots

    The erase write will be performed. In this case, the erase write is performed assuming that the area is set to (X1, Y1), (X3 = X1 + 1, Y3 = Y1).

  • In normal and high resolution mode, when VBE = 0, erase write is performed outside the frame buffer during the display period. If the X3 coordinate is set beyond the display screen, the erase write will continue at 4 pixels in normal mode and 8 pixels in high resolution after the last valid data (the falling edge of HTIM), and the erase write will continue outside the display screen. Not done.

  • If the erase write range is set within the display screen, no erase write will be performed outside the display range.

  • Erase writes are not affected by clipping.

  • When displaying HDTV, scaling or rotating the frame buffer, it is not possible to erase and write the frame buffer during display. In this case, the erase write is performed during the vertical retrace period (V_BLANK), so there is not enough time to erase the entire screen. If you want to erase write the entire screen, you need to fill in the unerased areas with polygons when you start drawing.
