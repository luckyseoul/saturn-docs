■4.2 Frame buffer switching mode register

The Frame Buffer Change Mode Register (FBCR) controls switching between drawing and displaying the frame buffer and drawing double-dense interlacing. This is a 16-bit write-only register located at address 100002H. After the power is turned on or reset, the value becomes undefined, so be sure to set the switching mode. Set unused bits to 0.

Frame buffer change mode bit: frame buffer change mode (FCM), bit1
Frame buffer change trigger bit: frame buffer change trigger (FCT), bit0

  • Typically, two frame buffers are used, one as the front and the other as the back. Leave the front side visible and draw on the back side. Then, after one frame switching time has passed, the front and back sides are toggled. The front side that was displayed becomes the back side that is drawn, and the back side that was drawn becomes the front side that is displayed.

  • Frame buffer access can only be made on the drawing side. This is not possible on the display side.

  • There is a limit to the number of characters that can be drawn in one frame, so if you want to draw many characters, set it to manual mode and control erase and change from the CPU.

  • When any data is written from the CPU to FBCR, the values of FCM and FCT are updated inside VDP1 when the field changes.

  • In manual mode, the FCT bit setting is valid only for the next frame. When a frame changes, the contents of FCT are updated internally.

  • Set FCM and FCT immediately after the V blank OUT interrupt. Access is prohibited from the first H blank IN interrupt after the V blank OUT interrupt until the next H blank IN interrupt.

1 cycle mode

  • This is normal mode.

  • One frame changes automatically every 1/60 seconds.

  • Set the VBE and FCT bit values to 0.

Erase (manual mode)

  • Control one frame erase write from CPU.

  • Specify manual erase write of the frame buffer by writing to the registers with VBE=0, FCM=1, and FCT=0. Erase writes to the display frame buffer on the next specified field, clearing the display frame buffer.

  • There is no switching between drawing and display framebuffers. When you erase, the display frame buffer is cleared, so if you want to display it, you must specify change in the field after specifying erase to switch between drawing and display.

  • Use this mode when one frame consists of two or more fields, such as double-dense interlacing. Also, when switching from manual mode to 1 cycle mode, use this erase in the field before switching.

  • Erase is used when you know that a frame change will occur in the next field. If the frame change is unknown up to the previous field, use Erase & Change.

Change (manual mode)

  • The switching of one frame is controlled from the CPU.

  • Specify switching by writing to the registers with VBE=0, FCM=1, and FCT=1. The next specified field will be toggled between drawing and display.

  • Since no erase write is performed, it is necessary to specify erase in the field immediately before specifying change and erase write the frame buffer.

  • You can draw characters on the back side until you instruct to switch.

  • Normally, this change is used when switching from 1 cycle mode to manual mode. Also, use this change when switching frame buffers in manual mode.

Erase & Change (Manual mode)

  • Setting VBE = 1 in the register specifies V blank erase, and setting FCM = 1 and FCT = 1 specifies frame buffer switching after V blank.

  • Use this when the frame change is unknown up to the previous V blank, such as when not switching frame buffers until CPU processing is finished.

  • Once VBE is set to 1, erase writing will be performed automatically on the next V blank, so after a frame change, set VBE to 0 before the next V blank.

  • Perform erase and change settings immediately after the V blank IN interrupt. If you set it to anything else, it may change without being able to be erased.

  • If you are using normal or high resolution, and you know the frame change timing in advance, such as with interlace, specify erase and change and perform an erase write during the display period. In this case, it is possible to erase/write the entire display screen.

●Sequence when using erase & change

  1. Set VBE=0, FCM=1, FCT=1.

  2. Wait for the CPU, etc. to finish processing without setting TV mode selection or FB switching mode.

  3. If CPU processing is completed by the H blank IN interrupt immediately before the V blank (224th line when 224 lines are displayed, 240th line when 240 lines are displayed), VBE = 1, FCM = 1, FCT = 1 ( Erase & Change). Perform erase and change settings immediately after the V blank IN interrupt.

  4. After the V blank IN interrupt ends, the V blank erase starts.

  5. At the end of the V blank, the erase write is interrupted and a frame change is performed.

  6. If the erase write is not completed, please erase the unerased area using polygons.

  7. Immediately after the V blank OUT interrupt, return VBE to 0 to stop V blank erase.

  8. Return to (2).

Even/odd coordinate select bit: even/odd coordinate select bit(EOS), bit4
    

  •  This bit is enabled when High Speed Shrink (HSS) is set to 1 for a rectangular sprite or a deformed sprite. If HSS=1 is specified, lines where the drawing magnification is <1 will be drawn by sampling only pixels at either even or odd coordinates of the original picture data. This bit specifies whether even or odd coordinates are to be sampled.
    

  •  When EOS=0, only pixels with even coordinates are sampled. When EOS=1, only pixels at odd coordinates are sampled.
    

  •  If HSS=0 is specified, this bit is not referenced.
    

  •  For more information, please refer to " High Speed Shrink " in " 6.3 Drawing Mode Words ".
