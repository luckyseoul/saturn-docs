■6.6 CMDSIZE (character size)

CMDSIZE specifies the size of the defined character pattern. CMDSIZE is valid for texture drawing commands. Specify in 16 bits at the start address of the command table +0AH. Set unused bits to 0.

  • Specify the size of the character pattern in multiples of 8 for width (X) and 1 pixel for height (Y).

  • The width is 5 bits, and you can specify a value from 1 to 63. Since the unit is 8 pixels, the actual size can be specified from 8 to 504 pixels. Do not specify 0.

  • The height is 8 bits, and you can specify a value from 1 to 255. Do not specify 0.
