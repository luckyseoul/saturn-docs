■7.9 Line drawing commands

Line drawing commands draw rectangles into the frame buffer. The inside of the rectangle is not filled.
When the end bit is 0B and the command selection bit is 0110B, it is a line drawing command.

Line drawing commands are defined as follows.

  • Setting the end bit to 0B and the command selection bit to 0110B makes it a polyline drawing command.

  • Specify the jump format. When the jump format is Assign or Call, divide the address of the next command table to be processed by 8H and set it to CMDLINK.

  • Set pre-clipping. Specify whether to enable or disable it, considering the clipping area and the drawing position of the part.

  • Specify the user clipping enable bit and clipping mode. Specifies whether user clipping is outside or inside in clipping mode.

  • Set mesh enable. When mesh is enabled, the entire line may not be drawn depending on the position and shape of the line.

  • Set MSB on for shade or window processing in VDP2.

  • Set the color mode to 000B. Set the color code to non-textured color (CMDCOLR) .

  • Specify color operation. Color calculation is valid when non-texture color is in RGB mode. If you do not want to perform color calculations, specify Replace. When performing Gouraud shading processing, divide the address of the Gouraud shading table by 8H and specify it. Gouraud shading processing is effective when the non-texture color is in RGB mode. Only the vertices (A) and vertices (B) of the Gouraud shading table are valid, and the vertices (C) and vertices (D) are ignored.

  • Define the vertices (A) of the line to be drawn to CMDXA, CMDYA, and the vertices (B) to CMDXB, CMDYB.

  • Note: If two vertices are set to the same coordinates, the line will be drawn with 1 pixel.
