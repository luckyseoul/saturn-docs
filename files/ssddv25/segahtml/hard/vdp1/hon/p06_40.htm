■6.4 CMDCOLR (color control word)

CMDCOLR specifies the color of the part. Functions vary depending on the part and color mode. Set a color bank, color lookup table address, or non-textured color. CMDCOLR is 16 bits located at the command table start address +06H.

■Color lookup table

  • Defines the address of the color lookup table.
  • When the color mode is lookup table mode, the 4bit data of the character pattern of the texture part is converted to 16bit pixel data by referring to the color lookup table and written to the frame buffer.
  • A color lookup table defines 16-bit 16-color color codes. Since the 16-bit data on the table is written to the frame buffer as is, there is no distinction between color bank code and RGB code as character patterns for texture parts.
    When read to VDP2, when the 16-bit MSB is 0, it is treated as a color bank code, and when it is 1, it is treated as an RGB code.
  • Color lookup table address defines the address of the color lookup table /8H. The color lookup table is defined with a 20HByte boundary, so the LSB2bit of the lookup table address is fixed to 00.

■Non-texture color

  • Non-texture color defines the color of non-texture parts.
  • For non-texture parts, the non-texture color is written as pixel data to the frame buffer.
  • Non-texture colors are unrelated to transparent color codes and end codes.
  • When the display mode is 8bit/pixel, the lower 8bits are valid. At this time, only the color bank code can be specified.
  • When performing color calculations (excluding shadows) on non-texture parts, be sure to set the RGB code for the non-texture color.
