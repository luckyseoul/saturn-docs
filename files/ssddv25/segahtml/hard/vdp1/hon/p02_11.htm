VDP1 User's Manual/Chapter 2 Address Map

●Frame buffer

  • It consists of two 2Mbit DRAMs and is divided into two sides: a display frame buffer and a drawing frame buffer.

  • The display frame buffer and drawing frame buffer functions are switched immediately before the screen display period (DISP). After power-on or reset, frame buffer 0 becomes the drawing frame buffer and frame buffer 1 becomes the display frame buffer.

  • Read/write access from the system controller (system controller IC) to the frame buffer is performed only to the drawing frame buffer. The display frame buffer is in the back bank and cannot be accessed.

  • Drawing is performed in synchronization with the CPU operating clock. The CPU operating clock is 28MHz, and one pixel of data is drawn in synchronization with this clock.

  • Read/write access from the system controller to the frame buffer and drawing access from VDP1 are prioritized.

  • Frame buffer access priority is always

    system controller＞ drawing

    This is the order.

  • If you access from the system controller while drawing, the drawing will be interrupted and the process will take a long time, so please avoid this as much as possible.

  • In order to prevent drawing and CPU access from occurring at the same time, use a method such as manual start of drawing to control it.

  • Word access is possible. Byte access is possible when the display is 8bit/pixel (high resolution or rotation 8). Do not perform byte access when using 16bit/pixel.

  • By reading the frame buffer diagonally, the entire frame buffer can be rotated and displayed. Additionally, the entire frame buffer plane can be expanded or contracted by skipping or repeating the read addresses. Rotation, enlargement, and reduction can be performed at the same time.

  • Rotation is instructed using VDP2. Please refer to the VDP2 manual for detailed rotation instructions.

frame buffer plane
The framebuffer plane coordinates are: The lower right coordinate value increases.

X: −1024≦X≦1023
Y: −1024≦Y≦1023

Operation is not guaranteed if you specify more than these values.

You can also place parts outside the display screen, as shown in the image above. However, nothing is written beyond the frame buffer plane.

Pixel data on frame buffer

The pixel data on the framebuffer is: There is 16bit and 8bit data. RGB data that does not go through VDP2's color RAM is only 16 bit. When all bits are 0, it is treated as a transparent dot by VDP2.
