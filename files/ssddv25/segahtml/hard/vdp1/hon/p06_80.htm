VDP1 User's Manual/Chapter 6 Command Table

■6.8 CMDGRDA (Gouraud shading table)

  • Specifies the address of the Gouraud shading table.

  • The Gouraud shading table address is valid when Gouraud shading processing is specified for color calculation, and is specified in 16 bits at the start address of the command table + 1CH.

    CMDGRADA
    +1CH    		 Gouraud shading table/8H

  • Divide the Gouraud shading table address by 8H and specify it in 16 bits.

  • The Gouraud shading table is a table for Gouraud shading processing, and is a table that defines the amount of change in the RGB brightness of each of the four vertices (two points in the case of a line). The table size is 8HByte (4word) and is defined with an 8HByte boundary.
