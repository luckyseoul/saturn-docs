■4.4　イレースライト

　描画を開始する前に、スプライトICはフレームバッファの内容を消去します。この消去をイレースライトと呼び、消去するフィル領域とその領域に書き込むフィルデータを指定します。 イレースライトに関連するレジスタには、イレースライトデータレジスタ、イレースライト左上座標レジスタ、イレースライト右下座標レジスタの3つがあります。

■イレースライトデータレジスタ

　イレースライトデータレジスタ(EWDR、Erase write data register)は、イレースライトのときのフィルデータを定義します。書き込み専用の16bitのレジスタで、100006H番地にあります。 電源投入後またはリセット後は、値が不定になりますので、必ずフィルデータを設定してください。

イレースライトデータ:　erase write data、bit15〜0
　フレームバッファにパーツを描画するとき、VDP1は自動的にフレームバッファを消去します。この消去(イレースライト)時にイレースライトデータレジスタに設定した16bitのデータがフレームバッファに満たされ(フィルされ)ます。

　フレームバッファへの描画が8bit/pixel(ハイレゾリューションまたは回転8)のときは2pixelずつイレースライトされることになります。
　イレースライトする領域はイレースライト左上座標レジスタ、イレースライト右下座標レジスタで設定されます。

■イレースライト左上座標レジスタ

　イレースライト左上座標レジスタ(EWLR、Erase write left coordinate　register)は、イレースライト領域の左上座標を設定します。書き込み専用の16bitのレジスタで、100008H番地にあります。 電源投入後またはリセット後は、値が不定になりますので、必ず座標を設定してください。未使用ビットは0に設定してください。

  • イレースライト時、フレームバッファのフィル領域を指定します。

  • X座標は、16bit/pixel(ノーマル、回転16、HDTV)のとき8pixel単位、8bit/pixel(ハイレゾリューション、回転8)のとき16pixel単位で設定します。システムレジスタの値が1のとき8または16となります。
    実際の右下のX座標は、レジスタ設定値を8、16倍して1を引いた値になります。

  • Y座標は1ライン単位で設定します。倍密インタレースのときY座標のレジスタ設定値の2倍になるので、実際の座標値の1/2を設定してください。例えば、設定値223のとき、座標値は447になります。

  • 実際のX座標はつぎの式で表されます。

16bit/pixel時
左上座標X1=レジスタ設定値×8
右下座標X3=レジスタ設定値×8−1

8bit/pixel時
左上座標X1=レジスタ設定値×16
右下座標X3=レジスタ設定値×16−1

  • イレースライトの座標のチェックは行いませんので、あらかじめCPUでX1＜X3、Y1≦Y3となるよう設定してください。

  • 各TVモードにおけるイレースライト範囲は、それぞれのメモリマップの範囲内を設定してください。

図4.2　イレースライト領域

  • X1≧X3、またはY1＞Y3に設定した場合は、

    ノーマル、ハイレゾリューション時　→　1ドット
    回転・ＨＤＴＶ時　→　8ドット

    　のイレースライトが行われます。この場合、領域は(X1, Y1)、（X3＝X1＋1, Y3＝Y1）、に設定されたと仮定してイレースライトを行います。

  • ノーマル、ハイレゾリューションで、VBE＝0のときのイレースライトは、表示期間中にフレームバッファーをはみ出してイレースライトを行います。X3座標を表示画面を超えて設定した場合は、有効データの最終(HTIMの立ち下がり)以降、 ノーマル時4pixel、ハイレゾリューション時8pixelイレースライトが継続され、それ以外の表示画面外ではイレースライトは行われません。

  • イレースライト範囲を表示画面内に設定した場合は、表示範囲外のイレースライトはまったく行われません。

  • イレースライトはクリッピングの影響を受けません。

  • HDTV、フレームバッファの拡大縮小、回転表示時には、表示中にフレームバッファのイレースライトを行うことができません。この場合イレースライトは垂直帰線期間(V＿BLANK)に行うため、時間が不足し、画面全体をイレースライトすることはできません。 全画面をイレースライトしたいときは、未消去部分を描画開始時にポリゴンで埋める必要があります。

  • Vブランクイレースに必要なピクセル数は

    (X3−X1＋1)×（Y3−Y1＋1）×8

    で表わされます。これがVブランクイレースに使用できるピクセル数以内なら、イレースライトが完了します。

  • Vブランクイレースに使用できるピクセル数は

    {(1ラスター中のピクセル数)−200 ｝×｛(1フィールド中のラスター数)−(表示ラスター数)｝

    となります。それぞれの値は次のとおりです。
