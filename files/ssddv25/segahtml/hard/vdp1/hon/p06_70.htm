■6.7 CMDXA~CMDYD (vertex coordinate data)

Specify coordinates such as clipping area coordinates and sprite drawing vertex coordinates in CMDXA to CMDYD. Up to 4 vertex coordinates (X coordinate, Y coordinate) can be specified. Define 16 bytes (8 words) from the start address +0CH to +1AH of the command table.

  • Specify the coordinates in CMDXA to CMDYD with 16 bits each. Specify negative numbers as two's complement numbers. The specifiable range is -1024 to 1023. The upper 5 bits are sign extended and write the same value as bit 10.

  • The meanings of CMDXA to CMDYD differ depending on each command. The correspondence between commands and CMDXA to CMDYD is as follows. See each command for details.
