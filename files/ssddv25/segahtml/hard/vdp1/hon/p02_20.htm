The size of VRAM is 4Mbit (512KByte), and addresses are assigned in byte units from 000000H to 07FFFFH. Table data cannot be written beyond address 07FFFFH. Make sure that each table fits within the size of VRAM.

●Command table

  • The command table is a table in which commands are defined on VRAM, and VDP1 reads the commands and performs the drawing and clipping processing of parts.

  • The command is:

    Drawing command:
    It is divided into texture drawing and non-texture drawing, and each has regular sprite, rectangular sprite, deformed sprite drawing commands, polygon, polyline, and line drawing commands to draw these parts.

    Command to set clipping coordinates:
    There are user clipping and system clipping coordinate setting commands to set the drawing area of parts.

    Command to set relative coordinates:
    Specify to define the drawing coordinates of parts using relative coordinates.

    Draw end command:
    Finish drawing.

  • The size of the command table is 1EH (30) Byte and the boundary is 20H (32) Byte.

  • Each command is read into VDP1 and processed individually. This operation is called fetching.

  • The command table is fetched from the start address of VRAM (000000H), and the next command table is fetched according to the jump format specification.

  • The color lookup table, Gouraud shading table, and character pattern table are referenced as specified in the command table.

●Color lookup table

  • This is a table that defines 16-bit 16-color color codes on VRAM.

  • When the color mode is used in the lookup table method with texture drawing commands, it is referenced as color data.

  • The pixel data of the character pattern is converted to a color code and written to the frame buffer.

  • The size is 20H (32) Bytes and the boundary is also 20H (32) Bytes.

  • Referenced in lookup table address instructions for texture drawing commands.

●Gouraud shading table

  • This is a table that defines four 16-bit RGB codes on VRAM.

  • It is referenced when Gouraud shading processing is specified in color calculation in a part drawing command.

  • The pixel data of the part is subjected to Gouraud shading processing and written to the frame buffer.

  • The size is 8HByte and the boundary is also 8HByte.

  • Referenced in Gouraud shading table address instructions for part drawing commands.

  • When applying glow shading, the pixel data of the part must be RGB code. Results are not guaranteed when using color bank codes.

●Character pattern table

  • This is a table that defines character pattern pixel data on VRAM.

  • Referenced in texture drawing commands.

  • Pixel data is defined as 4, 8, or 16 bit/pixel color data according to the color mode specification.

  • Character pattern pixel data is added to a color bank in color bank mode, converted using a color lookup table in color lookup table mode, and written to the frame buffer as is in RGB mode.

  • The size is determined by the character size and color mode. The boundary is 20H (32) Bytes.

  • Referenced in character address instructions for texture drawing commands.
