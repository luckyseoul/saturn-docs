VDP1 User's Manual/Chapter 6 Command Table

■6.5 CMDSRCA (character address)

  • CMDSRCA specifies the address that defines the character pattern.

  • CMDSRCA is valid for texture drawing commands. Specify in 16 bits at the start address +08H of the command table.

CMDSRCA
+08H		 Character address/8H 0 0

  • Specify the address that defines the character pattern to be drawn with the texture drawing command.

  • Specify the address in VRAM of the character pattern to be drawn, divided by 8H, in 16 bits.

  • Specify the start address where the pixel data of the defined character pattern is stored. The pixel data at the upper left corner of the character pattern becomes the start address. Specify the address of the upper left vertex of the defined character pattern, even if you want to rotate the character or flip it horizontally or vertically.

  • The content of character pattern pixel data is 4, 8, or 16 bit/pixel depending on the color mode.

  • Specify the table size with CMDSIZE (character size).

  • The character pattern table is defined with a 20HByte boundary, so LSB2bit is fixed to 00B.
