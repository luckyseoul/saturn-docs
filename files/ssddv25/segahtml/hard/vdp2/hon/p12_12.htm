VDP2 User's Manual/Chapter 12 Color Calculation

●Extended color calculation function

The extended color calculation function is a function that adds the second image and the third image at a certain ratio and uses the result as the second image data. By performing color calculations on this second image and the top image, it is possible to perform color calculations on three screens. When a line color screen is inserted, the result of color calculation at a certain ratio between the third image and the force image is used as third image data, and the third image and line color screen are

The result of adding at a fixed rate is used as the data for the second image, so color calculations can be performed on 4 screens. However, the extended color calculation function can only be used when the TV screen mode is normal mode, and cannot be used when the TV screen mode is high resolution or dedicated monitor mode.
When performing extended color calculation, whether to add the third image and force image depends on the color calculation enable bit of the screen of the third image, and whether to add the second image and third image depends on the color calculation of the screen of the second image. Follows enable bit.
When using the extended color calculation function, the extended color calculation ratio varies depending on the color RAM mode, insertion of line color screen, color calculation enable bit value and color format of the second and third images, and color format of the force image.

[note]
The extended color calculation function cannot be used when the TV screen mode is high resolution or dedicated monitor mode.
When inserting a line color screen, the color format of the second image will be in palette format.
The extended color calculation ratio is based on the value obtained by multiplying the RGB data by 1/4.
