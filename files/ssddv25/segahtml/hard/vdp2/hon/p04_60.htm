■4.6 Pattern name table (page)

A pattern name table (or page) stores pattern name data in VRAM, arranging it in the form of a table that describes how character patterns are laid out in a square with a size of 64 cells horizontally and 64 cells vertically. Pattern name data specifies the start address and other control information of the character pattern stored in VRAM for each character pattern.
The pattern name data on the pattern name table is 1 word or 2 words. If it is 1 word, auxiliary data of the lower 10 bits of the pattern name control register is added to fill in the missing bits.

●Data structure of pattern name table

The VRAM capacity required for a pattern name table of 64 cells horizontally x 64 cells vertically (one page) and the boundary stored in VRAM vary depending on the pattern name data size (number of words) and character size. The capacity of the pattern name table and the data structure of the table are shown in Table 4.4 and "Details".
