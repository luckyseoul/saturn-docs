●Rotating scroll screen map register

The rotation scroll screen map register specifies the start address of the pattern name table placed on each plane of the screen according to rotation parameters A and B. This is a 16-bit write-only register located at addresses 180050H to 18006EH. The value is cleared to 0 after power-on or reset, so be sure to set it.

Map bit (for rotational scrolling) : Map bit
(RAMPA5〜RAMPA0, RAMPB5〜RAMPB0, RAMPC5〜RAMPC0, RAMPD5〜RAMPD0, RAMPE5〜RAMPE0, RAMPF5〜RAMPF0, RAMPG5〜RAMPG0, RAMPH5〜RAMPH0, RAMPI5〜RAMPI0, RAMPJ5〜RAMPJ0, RAMPK5〜RAMPK0, RAMPL5〜RAMPL0, RAMPM5 ~RAMPM0, RAMPN5~RAMPN0, RAMPO5~RAMPO0, RAMPP5~RAMPP0, RBMPA5~RBMPA0, RBMPB5~RBMPB0, RBMPC5~RBMPC0, RBMPD5~RBMPD0, RBMPE5~RBMPE0, RBMPF5~RBMPF0, RBMPG5~RBMPG0, RBMPH5~RBMPH0, RAMPI5~RBMPI0 , RBMPJ5 to RBMPJ0, RBMPK5 to RBMPK0, RBMPL5 to RBMPL0, RBMPM5 to RBMPM0, RBMPN5 to RBMPN0, RBMPO5 to RBMPO0, RBMPP5 to RBMPP0)
When displaying a rotating scroll screen in cell format, specify the start address of the pattern name table placed in each plane.

RAMPA5～RAMPA0 180050H bits 5-0 For plane A of the screen with rotation parameter A
RAMPB5～RAMPB0 180050H bits 13-8 For plane B of the screen with rotation parameter A
RAMPC5~RAMPC0 180052H bits 5-0 For plane C of the screen with rotation parameter A
RAMPD5～RAMPD0 180052H bits 13-8 For screen plane D with rotation parameter A
RAMPE5～RAMPE0 180054H bits 5-0 For screen plane E with rotation parameter A
RAMPF5～RAMPF0 180054H bits 13-8 For screen plane F with rotation parameter A
RAMPG5~RAMPG0 180056H bits 5-0 For screen plane G with rotation parameter A
RAMPH5～RAMPH0 180056H bits 13-8 For screen plane H with rotation parameter A
RAMPI5～RAMPI0 180058H bits 5-0 For plane I of the screen with rotation parameter A
RAMPJ5～RAMPJ0 180058H bits 13-8 For screen plane J with rotation parameter A
RAMPK5~RAMPK0 18005AH bits 5-0 For screen plane K with rotation parameter A
RAMPL5~RAMPL0 18005AH bits 13-8 For screen plane L with rotation parameter A
RAMPM5～RAMPM0 18005CH bits 5-0 For screen plane M with rotation parameter A
RAMPN5～RAMPN0 18005CH bits 13-8 For screen plane N with rotation parameter A
RAMPO5～RAMPO0 18005EH bits 5-0 For screen plane O with rotation parameter A
RAMPP5～RAMPP0 18005EH bits 13-8 For screen plane P with rotation parameter A
RBMPA5~RBMPA0 180060H bits 5-0 For plane A of the screen with rotation parameter B
RBMPB5~RBMPB0 180060H bits 13-8 For plane B of the screen with rotation parameter B
RBMPC5 to RBMPC0 180062H bits 5-0 For plane C of the screen with rotation parameter B
RBMPD5～RBMPD0 180062H bits 13-8 For screen plane D with rotation parameter B
RBMPE5~RBMPE0 180064H bits 5-0 For plane E of the screen with rotation parameter B
RBMPF5~RBMPF0 180064H bits 13-8 For screen plane F with rotation parameter B
RBMPG5~RBMPG0 180066H bits 5-0 For screen plane G with rotation parameter B
RBMPH5~RBMPH0 180066H bits 13-8 For screen plane H with rotation parameter B
RBMPI5~RBMPI0 180068H bits 5-0 For plane I of the screen with rotation parameter B
RBMPJ5～RBMPJ0 180068H bits 13-8 For screen plane J with rotation parameter B
RBMPK5~RBMPK0 18006AH bits 5-0 For plane K of the screen with rotation parameter B
RBMPL5~RBMPL0 18006AH bits 13-8 For screen plane L with rotation parameter B
RBMPM5～RBMPM0 18006CH bits 5-0 For screen plane M with rotation parameter B
RBMPN5~RBMPN0 18006CH bits 13-8 For screen plane N with rotation parameter B
RBMPO5~RBMPO0 18006EH bits 5-0 For screen plane O with rotation parameter B
RBMPP5~RBMPP0 18006EH bits 13-8 For screen plane P with rotation parameter B
