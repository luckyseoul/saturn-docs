If only one rotating scroll screen is displayed, the normal scroll screen can also be displayed at the same time, but if two rotating scroll screens are displayed, the normal scroll screen cannot be displayed at all. At this time, the register for RBG1 is used for NBG0.
When the external input screen is displayed, NBG1 cannot be displayed. At this time, the register for NBG1 is used to set the external input screen.

●Line screen

The line color screen is a screen for performing color calculations with other screens. You can make the entire screen a solid color or specify a color for each line, but you cannot display characters.
The back screen is the screen that appears when all other screens are transparent. You can make the entire screen a solid color or specify a color for each line, but you cannot display characters.

●Window

For the normal window, you can choose between a normal rectangular window, which is specified by two screen coordinates at the top left and bottom right, and a normal line window, where the left and right screen coordinates are specified for each line. A sprite window is a window containing sprite characters.
Depending on the purpose of use, the window has a ``transparency processing window'' that specifies areas to be made transparent, a ``color calculation window'' that specifies areas that will not perform color calculations, and a ``rotation parameter window'' that allows you to switch screens using two rotation parameters.
