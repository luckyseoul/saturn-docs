VDP2 User's Manual/Chapter 4 Scroll screen

●Map size

The size of the map (the number of map planes) changes depending on whether the screen is a normal scroll screen or a rotating scroll screen. Each normal scroll screen has a map of 2 horizontal planes x 2 vertical planes.
The rotation scroll screen has a map of 4 horizontal planes x 4 vertical planes for each of rotation parameter A and rotation parameter B. Figure 4.15 shows the layout of planes by map size.

If the NBG0 and NBG1 1/4 reduction enable bits (N0ZMQT, N1ZMQT) are set to enable reduction to 1/4, the size of the NBG0 and NBG1 maps will be different from normal. In this case, the plane size of the screen that is set to be able to be reduced to 1/4 should not be 2 pages wide x 2 pages tall.
