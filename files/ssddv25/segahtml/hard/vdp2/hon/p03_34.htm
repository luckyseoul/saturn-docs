VDP2 User's Manual/Chapter 3 RAM/■3.3 How to access VRAM during the display period

●VRAM cycle pattern register specification procedure

The procedure for specifying the VRAM cycle pattern to the register is as follows.

  1. Determines the TV screen mode.

  2. Decide whether to divide VRAM into two.

  3. Determine the number of character colors and reduction settings for the scroll screen to be displayed.
    Also decide whether to use the vertical cell scrolling feature.

  4. Determine the VRAM bank to store the image data (pattern name data, character pattern data, bitmap pattern data) required for each scroll screen.
    When using the vertical cell scroll function, also determine the VRAM bank that will store the vertical cell scroll table data.

  5. Decide whether to perform read/write access by the CPU.

  6. Specify access commands in the VRAM cycle pattern register so as to adhere to the specified restrictions for each access timing.
