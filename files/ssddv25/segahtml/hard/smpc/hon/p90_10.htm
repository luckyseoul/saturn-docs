SMPC User's Manual

explanation of words

SMPC(System Management & Peripheral Control)
Controls the interface with peripheral devices such as reset management and control PAD of the Saturn system. It is also equipped with an RTC (Real Time Clock) function that can be backed up by a battery, allowing you to set and obtain a calendar clock.

SCSP(Saturn Custom Sound Processor)
A multifunctional game sound source LSI that combines a PCM sound source and sound DSP.

DSP (Digital Signal Processor)
This is a high-speed calculation dedicated circuit that mainly performs calculations (multiplication and addition) at high speed.

VDP1(Video Display Processor 1)
This is an LSI that controls the drawing of sprites and polygons. VRAM and frame buffer are connected to VDP1. These use drawing commands transferred from the CPU to VRAM and perform drawing to the frame buffer. Then, upon request from VDP2, the drawing data is transferred from the frame buffer to VDP2 and displayed on the display device.

VDP2(Video Display Processor 2)
Equipped with scroll surface control function and priority function.

PLL (Phase Locked Loop)
Various clocks for the Saturn system (Clock generators for CPU, system control, image drawing/display, sound, etc.).

SCU (System Control Unit)
Equipped with CPU I/F, A-Bus I/F, and B-Bus I/F controllers to smoothly transfer data between each bus. Furthermore, it is equipped with a DMA controller, an interrupt controller, and a DSP to realize DMA control, interrupt control, and high-speed arithmetic processing.

Main CPU
It is equipped with a 32bit RISC CPU SH-2 that controls the entire system.

MC68EC000
This is a sound control CPU centered on SCSP. It performs the control function of SCSP.

V-BLANK-IN
This is one of the three types of blanking interrupts. This interrupt indicates the end timing of screen display.

V-BLANK-OUT
This is one of the three types of blanking interrupts. This interrupt indicates the start timing of screen display.

H-BLANK-IN
This is one of the three types of blanking interrupts. This interrupt indicates the timing at which one line of display ends.

Peripheral
Peripherals connected to the Saturn, such as the control PAD, mouse, keyboard, etc.
