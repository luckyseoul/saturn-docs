SGL Manual

Words of supervision

SEGA 3D Game Library (SGL) is a C language function library created to support software development on Sega Saturn, and is suitable for developing software using 3D graphics. SGL deliberately selects the types of functions, so the total number of functions is not very large. However, it is possible to develop 3D games etc. by combining these functions, and based on the design philosophy that it is possible to develop high-speed and flexible software only by combining such simple modules, SGL was made.

I hope that SGL will open up the wonderful world of Sega Saturn.
