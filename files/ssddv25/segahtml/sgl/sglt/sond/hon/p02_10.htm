2. Make a song

This chapter explains the steps to create a song using the SEGA Sound Tool and precautions when using the tool.
We will not discuss creating sound effects here, but you can create sound effects using the exact same steps as creating songs.
There are a lot of terms and it may be confusing at first, but we only post basic editing methods, so feel free to try them out.

About songwriting tools

  1. Software for creating songs (such as a sequencer) is not provided with SEGA Sound Tool. Please use commercially available software.
  2. Step 1 can be done using commercially available tools. Please choose the one that is convenient for you.
  3. If you only use notation software, please use one that allows you to edit MIDI events (at least controllers and programs).
