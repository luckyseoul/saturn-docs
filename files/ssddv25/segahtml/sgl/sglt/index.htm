SGL TUTORIAL

Introduction

Purpose of this manual
This book was created as a manual for developers who use the Sega Graphic Library (SGL) to develop software for the Sega Saturn.
SGL is a function library with enhanced 3D graphics functions. This book is designed to serve as an introductory guide to 3D graphics, so even those who have no experience in developing software using 3D graphics can easily understand it.

Structure of this manual
This manual is a tutorial format where you can learn the knowledge necessary to develop software for Sega Saturn using SGL.
The contents are divided according to the developer's duties as follows.

"Development environment"
A manual for system administrators. The knowledge required for development equipment configuration and software development system configuration is written for each person in charge of business.

"Programmer's Tutorial"

Basic knowledge of 3D software programming and usage of SGL functions will be explained using sample programs. This chapter is closely related to SGL software packages.

Note) If you are a programmer who has learned the basics of SGL using this book, please refer to the separate volume " SGL Reference ".

"SOFTIMAGE SATURN MODULE TUTORIAL"

"Sound Tutorial"

You can learn the knowledge required by sound designers in developing sound for Sega Saturn.

"Data delivery"

Contains the information necessary for passing data between designers and programmers.
