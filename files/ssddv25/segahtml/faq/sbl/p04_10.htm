Will DMA_CpuResult() work properly if I call it before calling DMA_CpuMemCopy*()?

Q)
Will it work properly if I call DMA_CpuResult() before calling DMA_CpuMemCopy*()?

A)
DMA_CpuResult() obtains the status from the CPU-DMA hardware register, so it will work properly even if you call this function before calling DMA_CpuMemCopy*().
