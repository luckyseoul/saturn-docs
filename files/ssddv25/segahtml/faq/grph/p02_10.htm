Tools for Windows

3D Editor/Win cannot directly read SEGA3D files.

Q)
3D Editor/Win cannot directly read SEGA3D files.

A)
Unfortunately, currently (12/96) this is not possible. Please convert the DXF format file to SG3 format and read it. Please also refer to the SG3 format, which has been published publicly.
