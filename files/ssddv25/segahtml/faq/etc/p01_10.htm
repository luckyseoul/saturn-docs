Please tell me how to read the address error list.

Q)
I received an address error list, but I don't understand how to read it.

A)
For example, suppose you receive a list like this:

 f-no     addr        data  cs  bm   bs st  dsck sdram
00002+ 00000010/16     200 CS0 SH2M    WR
00001+ 00000012/16     200 CS0 SH2M    WR

addr is the address being accessed and its bit width,
data is the size of the data bus,
bm is the chip being accessed (e.g. SH2M, SH2S, SCU)
st is READ/WRITE.

So in this case,
This means that Master SH2 is accessing 0x00000010 for writing in words.

What is Simple Address Checker?

Q)
What is Simple Address Checker?

A)
The official name of the simple address checker is "SS Checker."

This SS checker can check the prohibited access areas (hatched areas in the figure) on the Saturn address map in Figures 1.3 and 1.5 , which are found in the SCU mapping section of the SCU User's Manual of "HARDWARE MANUAL". It's a part.

Therefore, not all address errors can be detected; for example,

"There is a write operation to a read-only register"

It is not possible to detect such types of address errors.

For strict checks, please use the conventional "Address Checker".
