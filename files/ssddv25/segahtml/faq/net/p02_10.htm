FAQ/Network/Modem

XBANDOther

Even though your XBAND settings are within the same station number, you may be playing against someone from a different station number.

Q)
Although the XBAND settings are within the same station number, there may be times when you play against someone from a different station number.

A)
We will never request a match with an opponent outside the station. However, if the other party has a nationwide designation, you can connect.

How many XBAND levels are there?

Q)
How many XBAND levels are there?

A)
The maximum number of levels that can be specified is 30.

When I moved the pad left and right on the level screen, levels from other games were displayed.

Q)
When I moved the pad left and right on the XBAND level screen, the levels of other games were displayed.

A)
The XBAND menu screen does not depend on the software, so as long as you have played that game at least once on XBAND, you can see the results of that game, even if it is a different game.

A message saying "Connection with XBAND is not working properly..." appears and I am unable to compete.

Q)
"Connection with XBAND is not going well..."

A message appears and I can't play.

A)
It seems the server is down. very sorry. Please wait until it returns.

The screen often freezes during the game?

Q)
The screen often freezes during the game?

A)
If the line is in bad condition, the game may stop momentarily to synchronize. In other words, it is a system specification.

Sometimes it takes a reset during the game.

Q)
Sometimes it takes a reset during the game.

A)
If the line is in poor condition, the game will be reset and you will be returned to the menu screen. In other words, it is a system specification.

About ISDN line.

Q)
I am testing using an ISDN line, but after entering the phone number in the phone settings,

"Are you sure you want to connect to XBAND to test if this phone setting is correct?"

If you select "Yes" in

"It looks like your phone number was entered incorrectly."

The following message will be returned.

A)
Try calling your phone number to determine if your phone settings are correct. However, in the case of an ISDN line, there are two regular telephone lines, so the other line is called, and the above error message is displayed because the other line is not busy.
If the phone number does not become busy after checking three times, the phone number will be registered correctly.

I heard that the debug version of XOS should not connect to the server.

Q)
I heard that the debug version of XOS should not connect to the server.

A)
We are in the process of applying a patch to the product version of XOS from the server. Therefore, the debug version may not work properly.

Billing system details.

Q)
Please tell me the details of the billing system.

A)
The billing system is as follows.

  • Basically, you will be charged for access.
  • Charges will be made for the last access.
  • 1 credit for last email access.
  • 3 credits if the last match was successful.
  • If no opponent was found last time, 0 credits.
  • If the previous match was determined to be unsuccessful, 0 credits.
  • 3 credits if you also send an email when connecting to a match.
  • If you hang up when selecting a character in a normal match, you will receive 3 credits if you successfully return to XOS.
    If it hangs as it is, 0 credits
  • If you forcibly end a designated match by opening the CD door, you will receive 1 credit.
  • If you forcibly end a normal match by opening the CD door, you will receive 0 credits.
