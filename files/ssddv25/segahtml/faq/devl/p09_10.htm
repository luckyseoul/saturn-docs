FAQ/Development environment

XBAND

It only boots in local mode.

Q)
It only boots in local mode. Why?

A)
There may be a poor connection between the development target and the modem. Please re-insert and check.

I'm developing with CartDev + DevSaturn, but it doesn't seem to recognize the modem.

Q)
I'm developing with CartDev + DevSaturn, but it doesn't seem to recognize the modem.

A)
Are you using a SIMM socket type cartridge adapter?
If it is a SIMM socket type, it will not work because the SIMM address space and the modem address space conflict.

I'm doing a server test with CartDev + DevSaturn, but it's not working properly.

Q)
I'm doing a server test with CartDev + DevSaturn, but it's not working properly.

A)
XOS+modem and CartDev+DevSaturn are not compatible, so testing under these conditions is not recommended.
