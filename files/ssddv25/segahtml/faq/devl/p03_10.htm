ICE/EVA board related

Even when IPI.EXE is started, "NO INTERFACE BOARD" is displayed and it cannot be used at all.

Q)
In order to connect Hitachi ICE (E7000/E7000PC) and EVA board, I inserted a PC interface board into the ISA bus and connected it, but even when IPI.EXE was started, "NO INTERFACE BOARD" was displayed and I could not use it at all. not. Could I ask the reason?

A)
Communication between the (E7000/E7000PC/EVA board) and the interface software is performed through 16K bytes of main memory space as shared memory.
In many IBM-PC/AT compatible machines, the factory settings prohibit the use of this area as shared memory.
From the BIOS setup, go to the menu named SHARED MEMORY, or SHADOW MEMORY, etc., and change the setting to Enable for the same area as the address set with the dip switch on the PC interface board. Be sure to also change the DOS environment variable E7000SYS on the host PC.
