CDDA

CDDAのデータってどうやって作るの？

Ｑ)
実際にコンピュータで扱えるデータにした後に どのようにしてCD-DAで組み込む形に変換するのでしょうか？

Ａ)
Macintoshを前提にすると、一般的には、

  • Digidesign社のSound Designer II(以下 SD II)を使用して、 HDレコーディングするか、既にあるAIFFファイル等をSD IIフォーマットに 変換する

  • SD IIファイルをDOSやUnixに転送する。

  • VCD付属のSWAP.EXE等を用いてエンディアン変換するで、VCD等で使用できるようになります。

VCD等に渡すCD-DAデータは、44.1KHz 16bit StereoのPCMデータが以下のように 並んでいれば何でもいいはずです。

  • 1フレームは2ワードから成ります。ワードは16bit、リトルエンデイアンです。

  • 最初のワードが左チャンネル、次のワードが右チャンネルです。

+0       +1       +2       +3       +4       +5       +6       +7 byte
 -------- -------- -------- -------- -------- -------- -------- --------
|<---------- frame 0 -------------->|<---------- frame 1 ---------------
|<------left----->|<----right------>|<------left----->|<----right-------
|<-low-->|<-high->|<-low-->|<-high->|<-low-->|<-high->|<-low-->|<-high--

その後CDをビルドするためのスクリプトに、各CD-DAファイルにそれぞれ 

 Track           CDDA
    Pause             150
    FileSource        ¥sample.da
    EndFileSource
 EndTrack

という様な記述をします。
上記記述中"Pause 150"の部分は絶対に変更しないで ください。
これは、一つのCD-DAデータに対して一つ必要です。
また、CD-DAトラックの直前のトラックのPostGapは必ず150にしてください。
