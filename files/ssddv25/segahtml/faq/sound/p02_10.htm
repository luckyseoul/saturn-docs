FAQ/Sound related

General tools

It crashes frequently when using MIDI etc. using sound tools.

Q)
Mac and DevSaturn frequently freeze while using sound tools.
There is no problem when opening and closing windows, but when I change some value it almost always stops.

A)
This is a problem related to Macintosh hardware, but if MIDI signals and SCSI signals occur at the same time, the application may hang.
To avoid this, turn off MIDI settings when setting values, etc., and when using MIDI, do not let it perform tasks that use SCSI, such as setting values.
