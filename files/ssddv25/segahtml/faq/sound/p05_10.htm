FAQ/Sound related

DSP linker

There are times when the effect is not applied.

Q)
When I use the linker to set an effect and play sound on the keyboard, sometimes the effect is applied and sometimes it is not.

A)
If the effect does not work, first examine the map in the sound simulator to determine whether the changed data has been transferred to the target by checking the cross in the map window.
Next, check whether you have correctly changed the effects and mixer on the simulator.
On the tone editor, check that the levels of ``Direct Level,'' ``Effect Send,'' and the mixer's ``Effect Level'' are raised properly.
If the effect is not applied when you reload the data you were working on previously, check to see if you have saved the tone file or map file to which you applied the effect as a binary file.
Data without effects may be transferred to the target when the sound simulator starts.

Reverb becomes distorted when Effect Send Level is maximized

Q)
It's hard to tell how much reverb is being applied, so when I set the Effect Send Level to the maximum, the sound becomes distorted.

A)
Specifications.
If distortion occurs, the only option is to lower the level.

The sound may stop producing noise.

Q)
Sometimes the sound stops and becomes noise.
If you change the Effect's PAN in the tone editor's mixer, move to SndSim, and try to play it. Files are not saved during automatic transmission.
If I restart the tool, there is no problem.

A)
This may occur if you frequently change tool parameters or move scroll bars etc. due to SCSI communication problems. Please be careful when changing parameters.
Also, there is no problem with the data itself, so restart it and continue working.

What are reverb module TYPEs 1 to 4?

Q)
Please tell me the difference between TYPE 1 to 4 in the reverb module parameters of the DSP linker.

A)
Think of it as a difference in the size of the hall (BOX).

Real-time parameter changes.

Q)
How can I change effect parameters in real time (while the song is playing)? Should I download it from the linker while playing it with SndSim?

A)
If you execute "Parameter change → Link → Download" with the DSP linker, you can check the effect in real time.

I get an error saying "not enough work rams".

Q)
When I try to download using the DSP linker, an error message appears stating that there is not enough work ram.

A)
The created effect algorithm will be linked by selecting [Link] from the [Process Menu] in [DSP Linker].
If the link is successful, the "Link Result Information" dialog will be displayed.
The value indicated by "Free Area Required" in this dialog will be the size of the DSP work area allocated by the map.
Also, when setting the DSP work ram with a sound simulator, the first address is separated by 2000H.
Even if you try to set an address smaller than that, it will automatically be moved back to a more clearly defined address.

"DSPRAM Size too small."

The above error message is a problem with memory mapping on the target.The RAM area secured in the memory map settings (on the development board) is smaller than the DSP work RAM size required for the DSP program you are trying to download. Therefore, the download has been canceled.
Please change the memory map settings or the DSP program algorithm.
