■プログラム文法

全てのニモニック、パラメータは、定められた区切り記号、すなわち、「空白文字」、「カンマ(,)」、「タブ」、「改行」のいずれか１つ以上によって区切られなければなりません。

　●外部メモリの読み出しおよびロード先MEMSの指定(LDI)

LDI MEMSxx, MR[AddressElement(s)/NF]

  • 外部メモリ読み出し用パラメータ「MR[...]」の記述中には区切り文字を入れてはなりません。

  • 「AddressElement(s) 」は、別途示す「アドレス記述要素」を記号「+」で連結したものを表します。

  • 「AddressElement(s) 」のアドレス記述要素の中に、必ず１個のアドレス定数シンボル(ユーザが定義したアドレス用シンボル名)が含まれていなければなりません。

　●YREGへのロード(LDY)

LDY INPUTS

　●ADREGへのロード(LDA)

LDA INPUTS

　●乗加算

@ pM * pC ± ( pM * pC ± ( ... ( pM * pC ± ( pM * pC + pA ) ) ... ) )

pM：被乗算数
pC：乗算係数
pA：披加算数

  • 左カッコ「(」と「)」の個数は一致していなければなりません。

  • 最も右側の「(」は、最も左側の「)」よりも左側になければなりません。

  • pMとpAの組み合わせには次表のような制限があります。

    　pM　
    　pA　
    INPUTS
    [PEG, TEMP00-TEMP7F]
    TEMP00-TEMP7F
    [REG,T]※

    pMで{TEMP00-TEMP7F}を指定し、なおかつpAにもTEMPを指定する場合には、同一の添字を持つTEMPしか使用できません。このためpAの方には“T”と指定します。

  • 乗算係数としてYREGの値を引数に使用する場合、{YREGH, YREGL｝のいずれかの表記とします。この２通りの表記による違いは次表を参照してください。

    　表　記　
    乗算機に渡されるデータ（13bits）
    YREGH
    YREG bit23-bit11
    YREGL
    0YREG bit15-bit4

　●ストア

opt
：ストアオプション。
　｛ S1 / S2 / S3 ｝の内のいずれか１つ、または省略。
Destination(s)
：ストア先の指定。
　以下に示す「a群〜d群」から合計１個以上を選択します。省略は不可。
