7.エラー/警告メッセージ

「Error : 」はエラー、「Warning : 」は警告であることを示します。エラーが１つでも発生した場合はアセンブルできません。警告が発生した場合、アセンブルは実行されますが、プログラムに潜在的な問題が含まれている可能性があります。

■ソースコードの構成に関するエラー/警告

　Error : Missing“#COEF”.
「#COEF」ラベルが見つからない。

　Error : Missing“#ADRS”.
「#ADRS」ラベルが見つからない。

　Error : Missing“#PROG”.
「#PROG」ラベルが見つからない。

　Error : Missing“#END”.
「#END」ラベルが見つからない。

　Error : Illeagal source text.
ソースコードに誤りがある。「#COEF」、「#ADRS」、「#PROG」、「#END」の各ラベルの位置関係の異常等が考えられる。

■係数/アドレス定数定義に関するエラー

　Error : Unknown error occurred in #COEF.
#COEF(係数定義)部分の記述中に何らかの誤りがある。

　Error : Unknown error occurred in #ADRS.
#ADRS(アドレス定義)部分の記述中に何らかの誤りがある。

　Error : Initial value for“symbol”is out of range.
“symbol”に与えられた初期値が許容範囲外。

　Error : Invalid mode for“symbol”.
“symbol”に与えられた初期値の表記モードが選択範囲外。

　Error : Too many COEF defines.
COEF定義数が許容量を超えている。

　Error : Too many ADRS defines.
ADRS定義数が許容量を超えている。

　Warning : symbol“symbol” never used.
定義されているが使用されていない係数／アドレス定数シンボルが存在することに対する警告。

　Warning : Multiple definition.
同一のシンボル名を使用した定義が複数存在することに対する警告。この場合、最後の定義が優先される。

■プログラムの記述に関するエラー

　Error : Undefined symbol“symbol”detected.
未定義シンボルが検出された。

　Error : Invalid parameter“parameter”detected.
無効なパラメータが検出された。

　Error : Invalid description“string”.
乗加算記述中の「string 」という文字列に問題がある。

　Error : Illegal parentheses.
乗加算記述中の「(」と「)」の位置関係に誤りがある。

　Error : Parentheses mismatch.
乗加算記述中の「(」と「)」の数が一致しない。

　Error : Missing“>”before this line.
直前の「@」に対応する「>」が存在しない。

　Error : Invalid“>”detected.
無効な「>」を検出した。

　Error : Invalid“(”detected.
無効な「(」を検出した。

　Error : Invalid“)”detected.
無効な「)」を検出した。

　Error : Missing“]".
外部メモリアクセス用パラメータの記述に「]」が見つからない。

　Error : Invalid elements [...] detected.
外部メモリアクセス用パラメータのアドレス記述要素の表現に誤りがある。

　Error : Undefined address element“string“ detected."
外部メモリアクセス用パラメータのアドレス記述要素中に未定義の文字列が検出された。

　Error : Missing base address.
外部メモリアクセス用パラメータ中のアドレス記述要素中に、アドレス定数が含まれていない。

　Error : Use“S3”to store to ADREG.
演算結果をADREGにストアするためには「S3」オプションが必要。

　Error : PROG code overflow ( steps )."
プログラムのステップ数が許容量を超えた。

　Warning : Multiple STR to EFREGxx.
EFREGの同一アドレスに対するストアが２回以上行われている事に対する警告。この場合、最後の１回のストアのみ有効とな/る。
