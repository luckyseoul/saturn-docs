作成パラメータ
 
Data Name
PcmCreatePara
 
No
3.2
ハンドルの作成情報を表します。PCM_Create〜への各種パラメータ値を構造体として設定します。 

typedef struct {
     PcmWork *work;          /* ワークの先頭アドレス　　　　　　　　　　　　      */
                             /* 本ライブラリが再生するときの作業領域　　　　      */
     Sint32     *ring_addr;  /* リングバッファアドレス　　　　　　　　　　　      */
                             /* メモリのデータを再生するときは、そのアドレス      */
     Sint32     ring_size;   /* リングバッファサイズ[byte]　　　　　　　　　　　　*/
                             /* メモリのデータを再生するときはファイルサイズ      */
     Sint32     *pcm_addr;   /* サウンドメモリのPCMバッファアドレス　　　　       */
     Sint32     pcm_size;    /* サウンドメモリのPCMバッファサイズ[sample/1ch］　　*/
} PcmCreatePara;

　PCMバッファに関する注意

  • PCMバッファは、サウンドメモリに確保してください。

  • PCMバッファサイズは4096の整数倍を指定してください。(最低4096×2)

  • PCMバッファサイズの指定をS[sample/1ch]とすると、再生条件に応じて、次のようなバイト数に解釈されます。

    再生条件
    PCMバッファサイズ（バイト数）
     8bit　モノラル
     　S［byte］
     8bit　ステレオ
    2×S［byte］
    16bit　モノラル
    2×S［byte］
    16bit　ステレオ
    4×S［byte］

  • スムーズ連続再生をする場合は、同じ領域(アドレス、サイズ)を指定してください。

  • マルチ再生をする場合は、別の領域を指定してください。
