3.6　インタリーブの定義

　インタリーブ定義の例を以下に示します。

                                                    ファイルソース
Extent                              　　　　　　┌────────────┐
    FileInterleave  3 1             ┌←ＡＳＲＣ│ＡＡＡＡＡＡＡＡＡＡＡＡ│
        File  AFILE                 │　　　　　└────────────┘
            FileSource ASRC         │　　　　　┌────────────┐　　　　 　　　　　　
            EndFileSource           ├←ＢＳＲＣ│ＢＢＢＢＢＢＢＢＢＢＢＢ│
        EndFile                     │　　　　　└────────────┘             　  
    EndFileInterleave               │
    FileInterleave  1 3             │　　│←−−− エクステント−−−→−−
       File  BFILE                  │　　┌────────────────         　  　　
           FileSource BSRC          └→　│ＡＡＡＢＡＡＡＢＡＡＡＢＡＡＡ
           EndFileSource            　　　└────────────────　　　　             
        EndFile               
    EndFileInterleave         
EndExtent
