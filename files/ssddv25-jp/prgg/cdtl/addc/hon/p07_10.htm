７．エラー

エラーが発生した場合、以下の形式でメッセージを出力します。

サブコマンドファイル名 (行番号) ：エラーメッセージ [エラーコード]

エラー一覧

  • ドライブが接続されていません
  • ドライブの準備ができません
  • ディスクに異常があります
  • サブコマンドに誤りがあります
  • ファイルがディスクに存在しません
  • ディレクトリがディスクに存在しません
  • ファイルがDOS上に存在しません
  • ファイルサイズが大きすぎます
  • ファイルはすでに編集対象に指定されています
  • 指定されたファイルはインタリーブされています
  • ファイルがすでにディスクに存在します
  • ディレクトリの更新はできません
  • 追記イメージファイルを作成できません
  • ディスクがいっぱいになりました
  • これ以上このディスクに書き込みはできません
  • 転送速度が遅すぎます
  • ギャップサイズが小さすぎます
  • TOCファイルに異常があります
  • ファイルにアクセスできません
  • サブディレクトリが多すぎます
  • DSKファイルに異常があります
  • ディスクの内容が不正です
  • メモリ不足です
  • リードエラーが発生しました
  • 通信エラーが発生しました
  • ハードウェアエラーが発生しました
  • ディスクが空です

▲一覧表

ドライブが接続されていません [fe02][fe82]
Drive is not connected

　原　因
SCSIにCD-Rドライブが接続されていません。
　対　策
接続及び、IDが重複していないことを確認してください。

▲一覧表

ドライブの準備ができません [fe04][fe28][fe50][fe5a][fea3][feb7]
Drive is not ready

　原　因
CD-Rドライブが状態にならない。
　対　策
ディスクが正しくセットされていることを確認してください。

▲一覧表

ディスクに異常があります [fd0b][fe31][fe33][fea9][feaf][feb2][feb3]
Something wrong with the disc

　原　因CD-Rディスクが異常です。
　対　策CD-Rディスクの規格を確認してください。

▲一覧表

サブコマンドに誤りがあります [fd12]
Bad Sub-command

　原　因
サポートしていないサブコマンドが指定された。
　対　策
サブコマンドを確認する。
▲一覧表

ファイルがディスクに存在しません [fd15]
File does not exist on the disc

　原　因
指定されたファイルがCD-Rディスクに存在しない。
　対　策
正しいファイル名をフルパスで指定する。
▲一覧表

ディレクトリがディスクに存在しません [fd14]
Directory does not exist on the disc

　原　因
指定されたディレクトリがCD-Rディスクに存在しない。
　対　策
正しいファイル名をフルパスで指定する。
▲一覧表

ファイルがDOS上に存在しません [fd07][fd13]
File does not exist on DOS

　原　因
指定されたファイルがDOS上に存在しない。
　対　策
ファイル名を確認してください。
▲一覧表

ファイルサイズが大きすぎます [fd1a]
File size is too huge

　原　因
システム領域に指定したファイルのサイズが大きすぎる。
　対　策
ファイルサイズを32768バイト以下にする。
▲一覧表

ファイルはすでに編集対象に指定されています [fd17]
File is specified already

　原　因
同じファイルに対してサブコマンドが２重に発行された。
　対　策
サブコマンドを確認してください。
▲一覧表

指定されたファイルはインタリーブされています [fd1c]
Specified file is interleaved

　原　因
インタリーブされているファイルに実行不可能なサブコマンドを発行した。
　対　策
ディスクビルドをやり直す。
▲一覧表

ファイルがすでにディスクに存在します [fd16]
Same file name exists on the disc already

　原　因
追加しようとしたファイルが、すでにCD-Rディスクに存在する。
　対　策
ファイル名を変更するか、置換する。
▲一覧表

ディレクトリの更新はできません [fd1b]
Can't renew the directory

　原　因
ディレクトリに対してサブコマンドが指定された。
　対　策
全面更新する。
▲一覧表

追記イメージファイルを作成できません [fd1d]
Can't create the image file for the additional description

　原　因
指定された作業ディレクトリにファイルを作成できない。
　対　策
作業ディレクトリを確認してください。ハードディスクの空き容量を確認してください。
▲一覧表

ディスクがいっぱいになりました [feaa][feb0][feb4]
Disc is full

　原　因
書き込み位置がディスクの終端に達した。
　対　策
新しいディスクを使用する。
▲一覧表

これ以上このディスクに書き込みはできません [fd18]
Can't write on this disc any more

　原　因
使用済みディスクに対してマスタモードで書き込もうとした。
または、以下のようなディスクに書き込もうとした。

  • 99トラック書かれているディスク

  • マスターモード（disc at once）で書かれたディスク

  • 最終セッションが確定されているディスク

  • セッションがクローズ（fixation）されてないディスク

　対　策
新しいディスクを使用する
▲一覧表

転送速度が遅すぎます [fead]
Forwarding Speed is too slow

　原　因
書き込み中にCD-Rドライブのデータバッファが空になった。
　対　策
書き込み速度を遅くする。
ディスクキャッシュを使用する。
デバイスドライバ等を減らしてコンベンショナルメモリを多く空ける。
▲一覧表

ギャップサイズが小さすぎます [fd02][fd03]
Gap size is too small

　原　因
トラック間のギャップが小さすぎる。
　対　策
Mode2トラックの前は225セクタ、他の場合は150セクタ以上にする。
▲一覧表

TOCファイルに異常があります [fd04][fd05][fd06][fd0a][fd10]
Something wrong with the TOC file

　原　因
TOCファイルに間違いがある。
　対　策
正しいTOCファイルを使用する。
▲一覧表

ファイルにアクセスできません [fd08]
Can't access to the file

　原　因
ファイルのアクセスに失敗した。
　対　策
ファイルやディレクトリに対して、正常にアクセスできるかをチェックする。
▲一覧表

サブディレクトリが多すぎます [fd0d]
Too many sub-directories

　原　因
サブディレクトリの数が多すぎる。
　対　策
サブディレクトリの総数を1024以下にする。

▲一覧表

DSKファイルに異常があります [fd0c][fd0e][fd0f]
Something wrong with the DSK file

　原　因
DSKファイルの内容がISO9660規格に準拠していない。
　対　策
正しいDSKファイルを使用する。

▲一覧表

ディスクの内容が不正です [fd19][fe21]
Illegal disc contents

　原　因
CD-Rディスクの内容がISO9660規格に準拠していない。
　対　策
全面更新する。

▲一覧表

メモリ不足です [fd11][fec1]
Not enough memory

　原　因
実行に必要なメモリ容量を確保できない。
　対　策
デバイスドライバ等を減らして、コンベンショナルメモリを多く空ける。

▲一覧表

リードエラーが発生しました [fe11][fe17][fe18][fe32][fe47][fe57][fea0][fea2]
Read Error Occurred [feab][feac][feae]

　原　因
ディスクの読み取りエラーが発生しました。
　対　策
CD-Rディスクを確認してください。

▲一覧表

通信エラーが発生しました [fd00][fe00]
Communication Error Occurred

　原　因
通信中にエラーが発生しました。
　対　策
接続やケーブルなどを確認してください。

▲一覧表

ハードウェアエラーが発生しました [fe08][fe09][fe15][fe29][fe40][fe42][fe44]
Hardware Error Occurred [fe53][fe83][fec0]

　原　因
CD-Rドライブに異常が発生しました。
　対　策
CD-Rドライブを確認してください。

▲一覧表

ディスクが空です [feb1]
Disc is empty

　原　因
空のディスクに差分追記を行おうとした。
　対　策
全面追記を行ったディスクに替えてください。
