CDのピックアップの移動
 
Function Name
GFS_CdMovePickup
 
No
6.1

　書　式
Sint32 GFS_CdMovePickup(GfsHn gfs)
　入　力
gfs：ファイルハンドル
　出　力
なし
　関数値
エラーコード。
　機　能
CDのピックアップをアクセスポインタの位置まで移動させます。
GFS_Fread関数、GFS_NwFread関数、またはGFS_NwCdRead関数によるCDからの読み込み時、ピックアップのシーク時間を短縮するために使用します。
