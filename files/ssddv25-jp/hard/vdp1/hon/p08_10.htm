第８章　クイックレファレンス

■8.1　システムレジスタ

　●TVモード選択レジスタ(TVMR、TV mode register)

Vブランクイレースライト許可ビット：V blank erase/write enable(VBE)、ビット3
TVモード選択ビット : TV mode select(TVM)、ビット2〜0

　●フレームバッファ切り替えモードレジスタ

フレームバッファ切り替えモードビット : frame buffer change mode(FCM)、ビット1
フレームバッファ切り替えトリガビット : frame buffer change trigger(FCT)、ビット0
倍密インタレース有効ビット : double interlace enable(DIE)、ビット3
倍密インタレース描画ライン : double interlace plot line(DIL)、ビット2
偶数/奇数座標選択ビット:even/odd coordinate select bit(EOS)、ビット4

　●プロットトリガレジスタ

プロットトリガモード : plot trigger mode(PT)、ビット1、0

　●イレースライトデータレジスタ

イレースライトデータ : erase write data、ビット15〜0

　●イレースライト左上座標レジスタ

イレースライト左上座標X1 : ビット14〜9
イレースライト左上座標Y1 : ビット8〜0

　●イレースライト右下座標レジスタ

イレースライト右下座標X3 : ビット15〜9
イレースライト右下座標Y3 : ビット8〜0

　●描画強制終了レジスタ

　●転送終了状態レジスタ

現フレームでの、エンドビットのフェッチ状態:current end-bit fetch status(CEF),ビット1
前フレームでの、エンドビットのフェッチ状態:before end-bit fetch status(BEF),ビット0

　●処理中断テーブルアドレスレジスタ

処理中断テーブルアドレス:ビット15〜0

　●現処理テーブルアドレスレジスタ

現処理テーブルアドレス:ビット15〜0

　●モード状態レジスタ

バージョン番号：version　number(VER)、ビット15〜12
プロットトリガモード上位：PTM1、ビット8
偶数／奇数座標選択ビット：EOS、ビット7
倍密インタレースイネーブルビット：DIE、ビット6
倍密インタレース描画ライン：DIL、ビット5
フレームバッファ切り替えモードビット：FCM、ビット4
Vブランクイレースライト許可ビット：VBE、ビット3
TVモード選択ビット：TVM、ビット2〜0

■8.3　コマンドテーブル

　●CMDCTRL(コントロールワード)

エンドビット:　end bit(END)、ビット15
ジャンプ形式:　jump select(JP)、ビット14〜12
ズームポイントビット:　zoom point(ZP)、ビット11〜8
キャラクタ読み出し方向ビット:　character read direction(Dir)、ビット5〜4
コマンド選択ビット:　command select(Comm)、ビット3〜0

　●CMDLINK(LINK指定)

　●CMDPMOD(描画モードワード)

ハイスピードシュリンク：　high speed shrink(HSS)、ビット12
プリクリッピング無効：　preclipping disable(Pclp)、ビット11
クリッピングモードビット:　clipping mode bit(Cmod)、ビット9
メッシュ有効ビット:　mesh enable bit(Mesh)、ビット8
エンドコード無効ビット:　end-code disable(ECD)、ビット7
透明ピクセル無効ビット:　see-through pixel disable(SPD)、ビット6
カラーモードビット:　color mode bit、ビット5〜3
色演算ビット:　color calculation bit、ビット2〜0
MSBオンビット:　MON(MSB on)、ビット15

　●CMDCOLR(カラー制御ワード)
