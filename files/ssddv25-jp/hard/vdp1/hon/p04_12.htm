■4.2　フレームバッファ切り替えモードレジスタ

　フレームバッファ切り替えモードレジスタ(FBCR、Frame buffer change　register)は、フレームバッファの描画と表示の切り替えと倍密インタレースの描画を制御します。書き込み専用の16ビットのレジスタで、100002H番地にあります。 電源投入後またはリセット後は、値は不定になりますので、必ず切り替えモードを設定してください。未使用ビットは0に設定してください。

フレームバッファ切り替えモードビット:frame buffer change mode(FCM)、bit1
フレームバッファ切り替えトリガビット:frame buffer change trigger(FCT)、bit0

  • 通常、2つのフレームバッファは、1つを表面、他を裏面として使います。表面を表示させておき、裏面に描画します。そして1フレーム切り替え時間経過後、表面と裏面をトグルさせます。 表示させていた表面が描画される裏面になり、描画されていた裏面が表示される表面になります。

  • フレームバッファのアクセスは、描画側にだけできます。表示側にはできません。

  • 1フレームに描画できるキャラクタの数には限りがあるので、多くのキャラクタを描画したいときは、マニュアルモードに設定し、イレースとチェンジをCPUから制御します。

  • CPUからFBCRに任意のデータが書き込まれると、FCM、FCTの値はVDP1の内部でフィールドチェンジ時に更新されます。

  • マニュアルモードのとき、FCTビットの設定は次のフレームに対してのみ有効です。フレームチェンジのときFCTの内容は内部で更新されます。

  • FCM、FCTの設定は、VブランクOUTインタラプトの直後に行ってください。VブランクOUTインタラプト後の最初のHブランクINインタラプトから、次のHブランクINインタラプトまでは、アクセスが禁止されます。

1サイクルモード

  • 通常のモードです。

  • 1フレームは1/60秒ごとに自動的に切り替わります。

  • VBE、FCTビットの値は0に設定してください。

イレース(マニュアルモード)

  • 1フレームのイレースライトを、CPUから制御します。

  • VBE=0、FCM=1、FCT=0のレジスタへの書き込み動作を行うことでフレームバッファのマニュアルイレースライトを指定します。指定した次のフィールドで表示フレームバッファにイレースライトが行われ、表示フレームバッファがクリアされます。

  • 描画と表示のフレームバッファの切り替えは行われません。イレースを行うと表示フレームバッファがクリアされてしまうので、表示を行う場合は、イレースを指定した次のフィールドでチェンジを指定して描画と表示の切り替えを行う必要があります。

  • 倍密インタレース等、2フィールド以上で1フレームになる場合に、このモードを使います。また、マニュアルモードから1サイクルモードに切り替える場合、切り替えの前のフィールドでこのイレースを使います。

  • イレースは、2つ先のフィールドでフレームチェンジを行うことが分かっている場合に使います。直前のフィールドまでフレームチェンジが不明の場合は、イレース＆チェンジを使ってください。

チェンジ(マニュアルモード)

  • 1フレームの切り替えを、CPUから制御します。

  • VBE=0、FCM=1、FCT=1のレジスタへの書き込み動作を行うことで切り替えを指定します。指定した次のフィールドで描画と表示の切り替えが行われます。

  • イレースライトは行われないので、チェンジを指定する直前のフィールドでイレースを指定して、フレームバッファをイレースライトする必要があります。

  • 切り替えを指示するまでは、裏面にキャラクタを描画することができます。

  • 通常、1サイクルモードからマニュアルモードに切り替える場合にこのチェンジを使います。また、マニュアルモードでフレームバッファを切り替える場合に、このチェンジを使います。

イレース＆チェンジ(マニュアルモード)

  • VBE＝1をレジスタに設定することで、Vブランクイレースを指定し、あわせてFCM＝1、FCT＝1を設定することで、Vブランク後のフレームバッファの切り替えを指定します。

  • CPUの処理が終了するまで、フレームバッファを切り替えない場合など、直前のVブランクまでフレームチェンジが不明の場合に使います。

  • 一度VBE＝1を設定すると、次のVブランクでも自動的にイレースライトが行われてしまうので、フレームチェンジ後は次のVブランクの前までに、VBE＝0に設定してください。

  • イレース＆チェンジの設定は、VブランクINインタラプトの直後に行ってください。それ以外に設定した場合、イレースできずにチェンジすることがあります。

  • ノーマル、ハイレゾで、かつ、インタレースのようにフレームチェンジのタイミングが前もって分かっている場合は、イレースとチェンジを指定して、表示期間中のイレースライトを行ってください。 この場合、表示画面全体のイレースライトが可能になります。

●イレース＆チェンジを使用する場合のシーケンス

  1. VBE＝0、FCM＝1、FCT＝1を設定します。

  2. TVモード選択、FB切り替えモードを設定せず、CPU等の処理の終了を待ちます。

  3. Vブランク直前のHブランクINインタラプト（224ライン表示時の224ライン目、240ライン表示時の240ライン目）までに、CPU の処理が終った場合、VBE＝1、FCM＝1、FCT＝1（イレース＆チェンジ）を設定します。 イレース＆チェンジの設定は、VブランクINインタラプトの直後に行ってください。

  4. VブランクINインタラプト終了後、Vブランクイレースが開始されます。

  5. Vブランク終了時点で、イレースライトが中断してフレームチェンジをします。

  6. イレースライトが完了していない場合、未消去部をポリゴンでイレースライトしてください。

  7. VブランクOUTインタラプト直後、VBEを0に戻し、Vブランクイレースを停止させておきます。

  8. (2)へ戻ります。

表4.3(b)　フレームバッファ切り替えモードの使用例(VBE使用)

倍密インタレース有効ビット:double interlace enable(DIE)、bit3
倍密インタレース描画ライン:double interlace plot line(DIL)、bit2

  • 単密インタレースでは、偶数フィールドと奇数フィールドで同じ絵を表示します。 一方、倍密インタレースでは、偶数フィールド/奇数フィールドで、異なった絵(それぞれ偶数、奇数ラインのみ描画)を表示することによって、縦の解像度を2倍に増やしています。

  • DIE=1で、倍密インタレースが有効になります。

  • DIEを変更した後の最初の表示画面の内容は保証されません。

  • 倍密インタレースでは、フィールドの切り替えを1/60秒ごとにするために、FCM=FCT=0(1サイクルモード)にします。

偶数／奇数座標選択ビット:even/odd coordinate select bit(EOS)、bit4

  • 矩形スプライト、または変形スプライトで、ハイスピードシュリンク(HSS)を１に指定したとき、このビットは有効になります。HSS=1を指定すると、描画が　倍率＜１　になるラインは、 元絵データの偶数または奇数座標のいずれかのピクセルのみを、サンプリングして描画します。偶数／奇数座標のどちらの座標をサンプリングするかをこのビットで指定します。

  • EOS=0のとき、偶数座標のピクセルのみをサンプリングします。EOS=1のとき、奇数座標のピクセルのみをサンプリングします。

  • HSS=0を指定した場合は、このビットは参照されません。

  • 詳しくは、「6.3　描画モードワード」の「ハイスピードシュリンク」を参照してください。
