3. Reset

Note that because the title sequence exists on both “Disc 1” and “Disc 2”, the jump destination of the reset will be partially changed.

1> Reset using the reset button on the main unit

In all cases, it is the same as normal power OFF → ON.

2> Reset by "A + B + C + Start button" on the pad

The destination is as follows. 
“Disc 1” title loop → as usual (“multiplayer screen”)
During “Disc 1” main game → As usual (“Disc 1” “title screen”)
“Disc 2” title (loop) → as usual (“multiplayer screen”)
During “Disc 2” main game → “Disc 2” “Title screen”

* During the disc replacement process (while the message for disc replacement is being displayed), it is considered to be in the main game and jumps to the title screen of each disc that is currently entered.

* In the case of this reset in the main game, be sure to retain the settings such as score and options.

3> Reset by opening the CD door

In all cases, it jumps to the “multiplayer screen” of the main unit BOOT ROM, as usual.
