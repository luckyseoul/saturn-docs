1. Basic design

1> Specifications

As a basic design, the conditions of the specifications imposed on the second and subsequent discs are summarized below.

  • Be sure to start the disc from the multiplayer screen
    (→ To ensure that CD check = security check is passed)
  • Be sure to use backup RAM to save data required between disks
    (→ Because there is no other way to transfer information to the second and subsequent sheets)

    * The method of continuing to the second and subsequent sheets using a “password” is permitted as a special case. In that case, there may be a specification that does not use the backup RAM.

  • There must be a "title screen" on each disc that is the destination of soft reset
    (→ To prevent frequent disk swapping)
  • "Sega logo" and "Title screen" must exist on each disc
    (→ Trademark / Copyright indication (or data) is preferably present on each disc)

    * Soft reset means reset by "A + B + C + Start button" on the pad.

From the backup system requirements

  • Has a function to select main body RAM / cartridge RAM
  • Has a function to select saved data (only for systems that handle multiple data)

2> Title sequence

Considering the specification conditions, at least the following title sequences are required for the title sequences of the second and subsequent discs.

  • CD check
  • "License Sega Logo" display
  • Pad check
  • Application “SEGA logo” display
    * However, skip immediately after the “License Sega Logo” is displayed.
  • "Title screen"
    * Title logo, “PRESS START BUTTON” display, (C) notation

It is not necessary to include the following items normally included in the sequence.

  • x Demonstration
  • x "Start / Option selection screen"
  • x "Option"

    * If the game is over, continue, or game is cleared, return to the application “SEGA Logo” on each disc.

    * If the demonstration is omitted, there is no need to “loop” the title.

    * “Options” are left to the judgment of each application. However, if there is a high possibility that the setting contents are frequently changed during the play of the disc 2, it should be included.

    * If you do not include "Option", there is a specification that does not have a "Start / Option selection screen"
