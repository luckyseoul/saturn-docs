Introduction

This standard specification defines how the developed application software should be placed on the CD. CDs that do not comply with this standard specification will not be recognized as GAME-CD. All application software running on this game console must comply with this standard specification.
This standard specification describes only the contents that programmers developing application software should know. The basic physical format of CDs and protection settings for copy protection must also be observed. However, these are only available at SEGA-designated disk builders, write-on-slitters, SEGA-designated factories, etc. Since this is done automatically during mass production, this specification does not provide details. Therefore, if you use CD tools other than those specified by SEGA, you may face major problems. Use SEGA's designated tools as much as possible. In addition, it is technically impossible to mass-produce outside the SEGA designated factory.

Please use the CD tool specified by SEGA.
If you want to use a CD tool other than those specified by SEGA, please contact us for approval.
