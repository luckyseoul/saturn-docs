4.8 IP creation method

  • SYS_ID.SRC
    Sample assembler source program for creating SYSTEM ID.
    Change it according to the application. (See "4.3 SYSTEM ID Explanation")
    Be sure to put it at the top of the program.

    Sample file name above: In the directory after installing the software library disk

      \ SATURN \ SEGASMP \ SYS \ SYS_ID.SRC

  • SYS_SEC.OBJ
    Security code object. (See “4.4 Security Code”)
    Link and install as is.

  • SYS_ARE? .OBJ
    Area code object. (See “4.5 Area Code”)
    Link and install as is.


    the above files

      SYS_ID.OBJ, SYS_SEC.OBJ, SYS_ARE? .OBJ・・

    Link SYS in this order to create SYS_IP.BIN.
    This file should be in the CD system area.

IP placement

IP size can be created with a minimum of 2 sectors and a maximum of 16 sectors.
If the required IP size is 8 sectors or less, it is possible to record multiple IPs for improved reliability. At this time, place each IP from the beginning of the sector.
∙ By doing this, it is possible to start up even if reading failure occurs in the first sector.
