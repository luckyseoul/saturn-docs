4.4 Security code

Place directly behind the SYSTEM ID. The code will be provided as object code from SEGA, so please use it without any changes. The contents are the program and data that display the license of SEGA. Applications that do not have the correct security code are not recognized as CDs for Sega Saturn, so the game cannot be started.
Security code file name: In the directory after installing the software library disk
    \ SATURN \ SEGALIB \ LIB \ SYS_SEC.OBJ

4.5 Area code

Place immediately after the security code. The code is provided as object code from SEGA, so please use it without any changes.
∗ There are four types of area codes for each hardware sales area, but it is necessary to enter the area code corresponding to the “corresponding area symbol” of the SYSTEM ID. When listing more than one, make sure that the order of entry for “corresponding area symbols” and “area codes” is the same.
Each area code has the same size, so it can be easily changed.
Also, it is possible to make a common disk by connecting multiple area codes. (See “Appendix A Sample List”)

Area code file name: In the directory after installing the software library disk 

     \ SATURN \ SEGALIB \ LIB \   SYS_ARE? .OBJ   ;? is the same character as the corresponding area
                       ; 4 types exist
