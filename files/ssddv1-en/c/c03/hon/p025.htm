4. Boot system

4.1 System area

The system area is the area that is placed at the beginning of the CD-ROM.
In the system area, system information for starting applications and initial programs are written.
These must be placed continuously in the system area as IP (Initial Program).
IP consists of boot code and application initial program (AIP). The boot code includes an ID such as a game name and a security code. AIP includes code for each initial program.
