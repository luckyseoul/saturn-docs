4.3 Explanation of SYSTEM ID

Principle

    Available characters
      All characters that can be used in the SYSTEM ID are alphanumeric characters in ASCII code. However, use of “. /-:” Is permitted for some items.
      Also, unless otherwise specified, all uppercase and lowercase letters can be used.

    Enter

    • All entries are left-justified unless otherwise specified. Do not put a space before.
    • Unless otherwise specified, all empty parts are filled with ASCII code 20H.

    Definition of expressions

      △ and space used in the description are ASCII code 20H.

    Other rules

      RESERVED area must be filled with 00H.

Description of each item

    Hardware identifier (start address: 00H) 
       definition Enter the unique ID for the hardware
Usable characters: Uppercase English characters only
Number of characters: 16 characters
Entry rules “SEGA △ SEGASATURN △” must be included.

    Manufacturer ID (Start address: 10H) 

       definition Enter the manufacturer ID specified by SEGA
Usable characters: alphanumeric characters only
Number of characters: 16 characters
Filling rules
For SEGA brand:
Fixed 16 characters “SEGA △ ENTERPRISES”
For third-party brands:
16 characters of “SEGA △ TP △ KAISHA-A”
In KAISHA-A, enter a unique company code given to each third party.
Example: SEGA △ TP △ T-999 △△△
Stipulation: The above underlined part should be left-justified and the remainder should be filled with spaces to make it 16 characters.

    Product number (starting address: 20H) 

       definition Enter the product number specified by SEGA.
Usable characters: alphanumeric characters only
Number of characters 10 characters
Filling rules Fill the empty space with a space.
Entry example SEGA brand title: GS-9099 △△△
Third party title: T-99901G △△
