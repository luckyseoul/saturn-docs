Appendix B Volume descriptor contents and system ID contents

    VolumeIdentifier “SAMPLE_GAME_TITLE”; Required, changeable
    Enter the game title within 32 characters.
    Enter the title so that the title can be identified.
    There are no other restrictions.
    Caution : Spaces cannot be used because they are not strings for directories.

    VolumeSetIdentifier “SAMPLE_GAME_TITLE”; Required, changeable
    Enter the game title within 128 characters for the directory.
    Enter the same string as [VolumeIdentifier] normally.
    In the case of two or more sets, you can also enter the name of the set.

    PublisherIdentifier “SEGA ENTERPRISES, LTD.”; Required, changeable
    Enter the publisher (company) name within 128 ASCII characters.
    Enter this information so that the sales company can identify it.
    Follow the example for subcontracting.
    If you are a 3rd party, please enter your company name.

    DataPreparerIdentifier “SEGA ENTERPRISES, LTD.”; Required, changeable
    Enter the name of the data editor (company) within 128 ASCII characters.
    Enter this information so that the production company can identify it.
    In the case of outsourcing or 3rd party, please enter the company name.

    CopyrightFileIdentifier “SMP_CPY.TXT”; Required, changeable
    Directory text string 8 characters + "." + Enter the copyright file name within 3 characters. Make sure to place the copyright file in the root directory.
    In the copyright file, put all the copyright notices related to the game.
    There are no rules about the contents of the file.
    In the case of subcontracting, “Copyright (c) SEGA ENTERPRISES, LTD 1995”.

    AbstractFileIdentifier “SMP_ABS.TXT”; Required, changeable
    Enter the abstract file name within 8 characters + "." + 3 characters for the
    directory. The abstract file must be placed in the root directory.
    The abstract file may be a foreword or a synopsis for books, but a game outline should be included for games.
    There are no rules about the contents of the file.

    BibliographicFileIdentifier “SMP_BIB.TXT”; Required, changeable
    Enter the bibliographic file name using
    directory character string 8 characters + "." + 3 characters. Make sure to place the bibliographic file in the root directory.
    In the bibliographic file, the bibliography file should contain the references used to write the book, but the game should include the original title and the original game name of the port.
    There are no rules about the contents of the file.
