1. DISC format overview

1.1 Features

The physical format of the GAME-CD for this game console conforms to the Semi CD-ROM XA standard.
 As a result, interleaved recording, which previously depended on applications, can now be implemented as a system, making it easier to play back images and audio in parallel.
"Semi CD-ROM XA": CD-ROM XA

with Model 1 track

1.2 Disc size and recording time

Only 12cm CD can be produced. 8cm GAME-CD cannot be produced.
∙ To avoid trouble, the start time of the lead-out area is limited to the following range.
    First LSN (# 0) time
    Last LSN (~ # 283499) time
    Leadout area start time     		00:02 : 00
    ~ 63: 01: 74
    ~ 63: 04: 00
Therefore, the maximum recording time is 63 minutes.
* Multi-session is not available.

1.3 Linear velocity and track pitch

GAME-CD's linear velocity and track pitch are fixed to the following values ​​in order to improve track jump accuracy and increase seek speed.
    Linear velocity
    Track pitch     		1.25 m / sec
    1.6 μm

1.4 Disc format

The disc format conforms to the following standards.
  • Physical format: Sony and PHILIPS CD standards "RED BOOK", "YELLOW BOOK", "CD-ROM XA"
  • Logical format: ISO9660
  • MPEG format: ISO11172

1.5 Track layout

The inner circumference side is the CD-ROM area and the outer circumference side is the CD-DA area.

1.6 Sector structure

The
sector has Mode2 Form1 and Mode2 Form2 with subheaders in addition to the existing Mode1. Various interleaved records using file numbers and channel numbers are possible.
