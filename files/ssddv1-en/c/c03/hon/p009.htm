2.3 Key to specify the position on the disk

In addition to absolute time (Atime) and logical sector number (LSN), frame address (FAD) is introduced to specify the position on the disk. 

     Logical sector number (LSN) ......... Absolute time 00:02:00 is set to 0 for each sector (frame).
.. Serial number assigned consecutively. 
    
Frame address (FAD) ......... Absolute time 00:00:00 is set to 0 in units of sectors (frames)
.. Serial number assigned consecutively. There is a one-to-one correspondence with absolute time.
.

The logical sector number and frame address have the following relationship.
Logical sector number = frame address-150
∙ Access to the CD block using the frame address as a key.
