6.9 3D sound

    This sound driver supports the following two types of 3D sound. The types of localization and number of channels that can be specified are as follows. Specify any panorama with the “3D control (11h)” or “Qsound control (12h)” command of the sound control command. The virtual sound source moves to the specified location.

    Since the movement of the virtual sound source is often random for both Q and YAMAHA3D sounds, the main system controls all of the panning movements. The sound driver simply moves the sound image to the specified location. However, if you need a simple linear movement, or if you want the sound driver to have a little more intelligent control, you can do it for each project as needed.

    As DSP expansion module of YAMAHA, 4 kinds of DSP programs of Q sound 4ch, Q sound 8ch, YAMAHA 3D sound 1ch, YAMAHA 3D sound 2ch are prepared, so when using 3D sound, the above 4 kinds of DSP Download the necessary DSP program from the programs using the “Effect Change (83h)” command.
