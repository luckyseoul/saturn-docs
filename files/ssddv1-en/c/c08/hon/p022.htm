    Tone data Bank number (0-15)
    If there are multiple tone banks (sound data storage area) in the current area map, specify the number of the tone bank from the beginning. One area map can have up to 16 tone banks, so it can be any value from 0 to 15. Always 0 if there is only one tone bank.

    Tone data mixer number (0-127)
    Since multiple mixer data can be stored in one timbre data, specify the number of mixer data from the beginning in the timbre data. A maximum of 128 mixers can be stored in one tone data, so any value from 0 to 127 is possible. Always 0 when there is only one mixer data.

    Effect output channel (0-15, 16-17)
    DSP 16ch Effect Out selection. DSP effect output has 16 channels, so specify 0-15. If you select CD-DA, specify 16 (Lch) or 17 (Rch) specially.
    Please refer to “Chapter 6 Supplementary explanation 6.7 DSP and mixer” for detailed explanation.

    Effect output level (0-7)
    Specify the level of the effect sound output from the effect output channel from 0 to 7.
    0 is the lowest level (= Off), and 7 is the maximum level.

    Effect output PAN (0-31)
    Specify the PAN of the effect sound output from the effect output channel from 0 to 31.
    For details, refer to “Chapter 7 Appendix 7.3 Details of SCSP PAN (32 levels)”.
