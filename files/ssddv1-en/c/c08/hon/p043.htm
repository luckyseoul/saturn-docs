6.7.1 What is a mixer?

The
    mixer is hardware that balances the volume (volume) of the SCSP sound source and the localization (distribution to the left and right). Although the sound source itself has only two types of sound generation slot and digital audio input, each can pass through DSP, so the mixer can be divided into the following four types of mixer blocks. 

     Slot Direct Mixer: Direct output level from sound generation slot (without DSP) and PAN
CD-DA Direct Mixer: Direct output level from CD-DA (without DSP) and PAN
Effect In Mixer: Input level to DSP
Effect Out Mixer: Effect level from DSP (through DSP) and PAN

    Of these, “Slot Direct Mixer” and “Effect In Mixer” are already set in the sound data, so there is no need to control them. As for the “CD-DA Direct Mixer”, there are dedicated “CD-DA Level (80h)” and “CD-DA Pan (81h)” commands, which you can control.

    Thus, in this manual, “mixer” means the “Effect Out mixer” above. The mixer in this manual refers to “16ch effect level and PAN settings output from DSP”.

6.7.2 DSP and mixer

The
    mixer is a setting for the sound output from the DSP. Therefore, even if the effect processing works properly and the effect is applied correctly, the effect sound will not be output unless the correct mixer is set. The mixer is data that sets the volume and panning for the 16 channels of the DSP output channel, and is created by the sound creator as part of the timbre data.

    In addition, since all the sounds of sequence playback, PCM stream playback, and CD-DA playback are input to the DSP, it is possible to correctly grasp which sound is input to which channel and which channel is output from which scene. You have to control it above. Before switching effects, check which mixer is compatible and what the mixer specifications are.
