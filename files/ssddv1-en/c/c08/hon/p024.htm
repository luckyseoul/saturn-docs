4.3.1 Sequence playback mode / status 

     +0 
     Sequence playback mode (0-4) 
     +1 
     Sequence restatus (0-FFh)

    While the sequence is playing, the current status is written to the mode / status area as needed. Please refer to the mode / status area to know the current state of sequence playback.

    The mode / status area corresponds to pronunciation management numbers 0 to 7 and has a total of 16 bytes of 2 bytes x 8 sequences. For details of the area address, refer to the section of host interface work in the system area. 

      [Sequence playback mode] [Sequence playback status] 
00h: Initial state 00h: Normal
01h: During playback 80h: Out of resolution range
02h: During fading 81h: No tempo data
03h: Pause during playback 82h: No event data
04h: Pause during fade 83h: Out of tempo data range
, FFh: Data error during data decompression

4.3.2 CD-DA input level

    Stores the digital audio input signal level. When the control command “Digital Audio In input level analysis start (0Ah)” is issued, detection of the input signal starts and this area is set. Values ​​are from 0 to 7FFFh, where 0 is no input signal and 7FFFh is the maximum input signal level. Also, this input signal level is an instantaneous value, so it always changes as the input signal level changes.
    Normally, only the total level Lch / Rch is stored, but a dedicated DSP program
    (DSP-3 Band Ana.EXB) can also be used to detect levels divided into high temperature range, mid range and low temperature range. However, since the level of the input signal can be detected here, the signal level set in this area does not change even if the output volume is changed with the “CD-DA level (80h)” control command. 

      Note: This processing is a load on the sound driver, so if level detection is no longer required
 Execute the “Digital Audio In input level analysis end (0Bh)” command to detect the level.
