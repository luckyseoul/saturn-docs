6.10 Sound initial command

    Sound Initial (10h) The value of P1 to P5 of the command is executed when 01H, otherwise it is ignored. This command is mainly intended to be set immediately before issuing a MAP change.

P1 to P5 details
    • By executing the P1 execution instruction (01h), stop all sequences that are currently sounding. This has no effect on other sounds (PCM stream playback, CD-DA playback).

    • P2 execution instruction (01h) will stop all PCM stream playbacks that are currently sounding. This has no effect on other sounds (sequence playback, CD-DA playback).

    • In response to the P3 execution instruction (01h), set the direct components [EFSDL] and [EFPAN] to "00H" for the CD-DA input components [EXTS0] and [EXTS1] to output them. Is turned off. Therefore, if the CD-DA input is processed and output by an effect, the volume will not be turned off. This has no effect on other sounds (sequence playback, PCM stream playback). 

          Sound address 100217H.b <--- 00H
                  100237H.b <--- 00H

    • P4 execution instruction (01h) initializes the DSP unit with a built-in sound source. In practice, the following data is set in the DSP register to turn off the effect component output and prohibit the DSP from accessing (R / W) the D-RAM. At this time, initialization of the mixer is also executed, but it is restored. This has no effect on other sounds (sequence playback, CD-DA playback, PCM stream direct components). 

          [IMXL] <--- 00H
    [EFSDL],[EFPAN] <--- 00H
    [MPRO] <--- 00000000H
    [COEF] <--- 000H
    [TEMP] <--- 000000H

    • P5 execution instruction (01h) writes [EFSDL] = [EFPAN] = 0 to all the [EFREG] in the mixer section, and does not output the effect component. This has no effect on other sounds (sequence playback, CD-DA playback, PCM stream direct components).
