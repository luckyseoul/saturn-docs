6.6 Fade in and fade out

6.6.1 Fade-in method

Before issuing the
    sequence start command, issue a sequence volume command with a fade rate specified (if the fade rate is not specified, the current sequence volume will simply change). The next sequence start command will start from the current sequence volume and fade in until it reaches the specified sequence volume. You can also control the fade-in curve by using the sequence volume command multiple times.

6.6.2 Fade-out method

Issue the sequence volume command with
    Volume = 0 specified. Start from the current sequence volume and fade out according to the fade rate until Volume = 0 is reached. You can also control the fade-out curve by using the sequence volume command multiple times.
