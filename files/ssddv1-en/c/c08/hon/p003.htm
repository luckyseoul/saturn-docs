Introduction

    This manual is for game programmers to incorporate sound drivers into games. Explains how to start the sound system, the types of sounds and how to play them.

    In addition, this manual contains detailed explanations for those who program all of the sound control by themselves, but it is easy to use the Sound Interface Library, a program library provided by SEGA. There is also a way to incorporate it. Please use it if necessary. For details and usage, refer to the user's manual for the sound interface library.
