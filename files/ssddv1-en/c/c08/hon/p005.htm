Chapter 1 System Overview

1.1 Hardware overview

    The sound system is centered around the sound source LSI, and is connected to a sound CPU, 512KB sound memory, main system and CD interface. The main system can access the sound memory and all SCSP IO space via the SCU, and can control the stop (reset) and restart (reset release) of the sound CPU via the SMPC.
    The most important of these is the sound memory, which controls all aspects of the sound system, including sound driver execution, data management, sound source data storage, and communication between systems.

1.2 Sound driver

The
    sound driver is a sound control program for producing songs and sound effects. The program is stored in sound memory and operates independently of the main system. Therefore, songs and sound effects can be played from the main system simply by issuing commands.
    Both the sound driver and sound data are stored in the sound memory, so once you turn off the power, all of them will disappear. Therefore, the main system must start the sound driver every time the power is turned on. Since the sound CPU is stopped by the reset signal when the power is turned on, first transfer the sound driver to the sound memory, and then release the reset signal. This will launch the sound driver and allow you to play songs and sound effects.
