Chapter 6 Supplementary explanation

6.1 How to issue a command

There are two methods for issuing
    commands: “timing flag handshake” and “command code handshake”. However, since the command code handshake is for compatibility with the sound driver Ver1.00 to Ver1.29, use the timing flag handshake for the sound driver Ver1.30 or later.
    Either selection is possible, but command code handshake is selected if nothing is specified for upward compatibility. Therefore, when selecting timing flag handshake, the command sequence control word (4E1h ) ”Should be set to the timing flag handshake side. Refer to “Chapter 5 System area 5.1.3 System interface work” for the setting contents.

6.1.1 Timing flag handshake

This is a command issuance method that uses the
    timing flag to ensure that the order of commands written by the main system is reproduced. Use the following method to issue commands using timing flags. “Timing Flag (4E0h)” is in the system interface work. Refer to “Chapter 5 System Area 5.1.3 System Interface Work”.

    Main system processing (command issuance)

    1. If the timing flag is "0", write as many commands as you want in the command block.
      (Up to 8 commands, command blocks may be used with a gap between them.)
    2. Set the timing flag to “1”.

    Sound driver processing (command collection and execution)
    1. If the timing flag is “1”, command execution is started in order from the command block 1.
      (The command blocks are executed in order from 1 to 8, and the block with the command code "00h" goes to the next block without doing anything)
    2. The command block that has finished executing the command returns the command code to “00h”.
    3. When all processing up to command block 8 is completed, the timing flag is returned to “0”.
