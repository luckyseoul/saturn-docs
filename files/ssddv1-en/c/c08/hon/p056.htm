 Map change 
-No sound 
-Operation becomes strange 
 Have you stopped all pronunciation before? 
 The sound driver performs internal processing according to the map even if there is no sound 
. Before the map change, issue the “Sound Initial (10h)” command to stop the entire pronunciation process. 
 
 □ Has the address of the DSP workram changed? 
 The DSP workram is always rewritten by DSP internal processing. If the map is switched without stopping the DSP 
, the data transferred to the 
 portion of the previous map corresponding to the DSP workram will be destroyed. 
 
 □ Has the effect changed? 
 The DSP is stopped before the map change. After the map change, issue the effect change command again if necessary. 
 
 □ Have you changed the mixer? 
 The mixer may have been initialized before the map change. After changing the map 
, be sure to issue the mixer change command again.

 -No sound 
 -Bad sound balance 
 □ Sequence data bank Is there a change at the top? 
 When creating a standard MIDI file, there is a sequencer that changes the order of control changes for the same delta time. Make sure to change the bank first, for example, by shifting the clock. If there is a program change or MIDI volume before the bank 
 change, there will be no sound 
 and the balance will be poor. 
 Abnormal operation occurs 
 □ Is the correct command issued in the correct order? 
 Please check whether the correct commands are issued in the correct order 
 in the process where the order of commands is determined. The history of the sound control command is stored in the reserved area of ​​the system area. 
 (The latest 16 bytes x 128 commands are stored in 2048 bytes from 800h to FFFh. See also the next section.)
