6.4.6 Notes

    Caution for continuous transfer
    When transferring waveform data, avoid the long-term continuous transfer so that the sound CPU can operate. Note that this is given priority while the main system is accessing the sound memory, and the sound CPU cannot operate. If continuous transfer is required, divide it into transfer of about 1msec at the maximum. The sound CPU becomes operable by leaving a gap.

    Notes on using DSP
    When using DSP (effect) for PCM stream playback, mixer settings are required. When using DSP, prepare the necessary mixer data and issue the mixer setting command. Even if there is no sequence playback, the tone data for mixer settings is required.
