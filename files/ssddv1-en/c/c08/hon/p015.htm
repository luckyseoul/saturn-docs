4.2 Command details

The
    sound control command has the following four types depending on the type of sound to be played. Which playback is associated with each command is described in the command name column with (S P C). 

     S: Command for sequence playback or commands related to sequence playback
P: Command for PCM stream playback or related to PCM stream playback
The command
C: Command for CD-DA playback or commands related to CD-DA playback
S / P / C: Commands related to all (or some) of the above, etc.

    Also, refer to “4.2.1 Explanation of each parameter” for details of each parameter.
