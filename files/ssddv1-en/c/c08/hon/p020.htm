    PAN Control ON / OFF (Bit7: 0/1)
    This bit indicates whether the sequence PAN is controlled or not.
    1 controls the sequence PAN. If 0, no control is performed.

    3D distance (0-127)
    The distance from the listening point of the YAMAHA3D sound to the virtual sound source.
    The value is 0, the distance is 0, and the distance increases as the value increases.

    3D orientation (0-127)
    The horizontal orientation of the virtual sound source viewed from the listening point of YAMAHA3D sound.
    The value is 0 for front, 32 for right 90 degrees, 64 for true back, 96 for left 90 degrees.

    3D height (0-127)
    The vertical orientation of the virtual sound source viewed from the listening point of YAMAHA3D sound.
    A value of 0 is directly above, 32 is front, 64 is directly below, and 96 is directly behind.

    Q channel number (0-7)
    The number of the channel that controls the Q sound.
    Specify 0 to 7 because there are a maximum of 8 channels.

    Q PAN Position (0-30)
    Specifies the PAN position of the Q sound. 0 is 90 degrees left, 15 is center, and 30 is right 90 degrees.

    CD-DA Level (00h-E0h)
    This is the CD-DA output level setting. There are 8 levels: 00h for minimum volume (= Off) and E0h for maximum volume. 

     Off <---------------------> Max 
     00h, 20h, 40h, 60h, 80h, A0h ,C0h,E0h

    CD-DA PAN (0-31)
    This is the CD-DA output PAN setting.
    For details, refer to “Chapter 7 Appendix 7.2 Details of SCSP PAN (32 levels)”.

    Total volume (0-15)
    SCSP total volume (overall volume for all playback) settings.
    0 is the lowest volume (= Off), and 15 is the maximum volume.

    Effect bank number (0-15)
    If there are multiple DSP banks (DSP microprogram storage area) in the current area map, specify the number of the DSP bank from the beginning. Since one area map can have up to 16 DSP banks, it can be any value from 0 to 15. Always 0 when there is only one DSP bank.
