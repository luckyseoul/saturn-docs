2.1.2 Necessary data file

    Basically, all you need to start the sound driver is the sound driver program itself. The sound area map is also transferred here because the sound area map is transferred once and does not need to be transferred thereafter. All the area maps in the game are stored in the sound area map area here. Prepare the following two data files when starting the sound driver using this procedure. 

     1. Sound driver (SDDRVS.TSK)
The sound driver program itself is an executable binary data file.
Supplied as a sound tool. 
    
2. Sound area map (name is arbitrary)
Binary data file that combines all area maps in the game. Game
Since it differs depending on the type, ask the sound creator to create it.
For details of the sound area map, see “Chapter 6 Supplementary explanation 6.8 Sound area map”.
It is in the section of “P”.
