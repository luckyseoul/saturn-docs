 No effect is applied 
 □ Has the DSP program been transferred? 
 In order to apply effects, the DSP program must be correctly transferred to the sound memory. 
 
 □ Is the transferred bit set? 
 After transferring a DSP program, the effect change cannot be made unless the "L" bit (transferred) of the sound area map CRNT work is set. 
 
 □ Has the effect changed? 
 When applying effects, the DSP program in the sound memory must be downloaded onto the actual DSP. Please issue the effect change command that corresponds to the effect to be used. 
 
 □ Have you changed the mixer? 
 In order to output the effect sound, you must set the correct mixer 
. Please issue the mixer change command corresponding to the effect to be used. 
 
 □ Are you sending to the DSP with a tone? 
 Each tone in the tone data has a setting for which effect to connect (send the sound 
). If this is different, no effect will be applied. Please check with the sound creator.

 The sound has disappeared due to version upgrade 
 □ Bank change in sequence data Is it in? 
 Sequence data must include bank changes and program changes. Although it will sound even if there is no bank change on the development tool for consistency with the tool, it is always necessary in the actual machine. 
 
 □ Is the sequence compression format different? 
 The sequence compression format is different between the old version (1.1x) and the new version (1.2x) of the sound driver. Please check if it is the correct version 
. 
 
 □ Isn't processing dependent on the data size? 
 The size of the driver changes as the sound driver is upgraded. Have you handled this with past constants?
