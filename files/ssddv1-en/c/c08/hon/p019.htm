4.2.1 Explanation of each parameter

    Pronunciation management number (0-7)
    Sequence playback can play up to 8 sequences at the same time, so specify a pronunciation management number from 0 to 7 at the start of the sequence. After this, sequence playback will be ended, paused, resumed, etc. using this pronunciation management number.

    Sequence data bank number (0-15)
    When there are multiple sequence banks (sequence data storage area) in the current area map, specify the number of the sequence bank from the beginning. Since one area map can have up to 16 sequence banks, it can be any value from 0 to 15. Always 0 when there is only one sequence bank.

    Song number in sequence data (0-127)
    Since multiple song data can be stored in one sequence data, specify the number of song data in the sequence data. Since up to 128 songs can be stored in one sequence data, it can be any value from 0 to 127. Always 0 when there is only one song data.

    Priority level (0-31)
    The correspondence is undecided.

    Sequence volume (0-127)
    Specify the sequence volume from 0 to 127. 0 is the lowest volume, 127 is the highest volume
    (= Original sound). The time to reach the specified volume can be specified with a fade rate. The final volume after the fade is retained as the current sequence volume. If there is no need for normal fade, set only the sequence volume with the fade rate (P3) = 0.

    Fade rate (0-255)
    Specify the time (0 to 255) to reach the specified sequence volume from the current sequence volume. The larger the value, the slower the change, 255 being the longest and 1 being the shortest. (If it is 0, only the sequence volume is set without fading.) Fading is performed from the current sequence volume toward the specified sequence volume. Whether the specified sequence volume is larger or smaller than the current sequence volume determines whether it fades in or out.

    Tempo value (+32767-> -32768)
    Relative tempo value relative to the standard tempo value (0000h). The tempo is doubled every 1000h (4096). In other words, it can be controlled with 4096 levels of accuracy until the tempo is doubled (or half). Since 0 is the standard tempo, you can always return to the original tempo by specifying 0000h.

    Area map number (0-255)
    A sequential area map number that specifies the number of the area map from the beginning in the sound area map.
