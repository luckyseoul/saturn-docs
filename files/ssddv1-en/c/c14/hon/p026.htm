MPEG stream notes for building

There are the following notes when building an MPEG stream.


When building an MPEG stream with the disk builder, dummy data (empty sectors) will be included for the difference between the sector rate and bit rate. As a result, the following problems occur:

    (a) File size becomes large.
    (b) The effect of prefetching to the CD buffer is lost.

To remove empty sectors, specify the sector rate as small as possible within the range that satisfies the following relationship. That is, the sector rate value that exceeds the total of all bit rates and is closest to it.

      Sector rate ≧ Total of all bit rates

To calculate the sector rate, please refer to the following part of “Virtual CD System Supplement Manual”.

    "2.6 Relationship between sector rate and bit rate"

Note that this manual only describes the calculation formula (CD rate) in bit units. To obtain a value that can be specified directly as the sector rate (value in units of sectors), use the following formula: Please use.

      Sector rate ≧ [BR (NV) / 2296 + BR (NA) / 2279 + BR (F1) / 2048 + BR (F2) / 2324] / 8
