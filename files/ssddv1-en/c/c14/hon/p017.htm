3. Supplementary explanation of the partial update tool VCDUTL.EXE

3.1 Overview

This software modifies (updates) a portion of a CD image once created in DOS file units.
To correct a part of the CD image once created, it is sufficient to rebuild the CD image again with the disk builder software. However, this takes time and effort, and is not efficient. The purpose of this software is to modify a CD image in a short time without returning to the disk builder process.
