(2). Partial update execution

  • The DOS file (pat_7.dat) in the ISO file (ISOF1.DAT; 1) that makes up the disk image (test1.dsk) of the project file name test1 To replace the file (pat_1.dat) and update the disk image, enter the following: Note that the ISO file name to be specified must be entered in uppercase letters. 

       Correct: VCDUTL test1 ISOF1_1.DAT; 1 pat_7.dat pat_1.dat
Incorrect: VCDUTL test1 TEST1.PVD pat_7.dat pat_1.dat 
      
* VCDUTL.EXE does not directly update the volume descriptor set (test1.pvd).

    As a result, if the file size of pat_1.dat is the same or smaller than pat_7.dat, the pat_7.dat part of the disk image will be replaced with pat_1.dat.
    To continue emulation

      VCDEMU test1
    Enter to perform real-time mode emulation.

  • If the -f option is specified, an update information file is created without updating the disk image.
      VCDUTL test1 ISOF1_1.DAT;1 pat_7.dat pat_1.dat -f test1.pat

    As a result, an update information file (test1.pat) is created.
    To execute emulation continuously, start the VCD emulator with the -u option.

      VCDEMU test1 -u test1.pat
    Enter to perform direct DOS access mode emulation.
    Simply
    VCDEMU test1
    Note that if you enter, real-time mode emulation using the created disk image test1.dsk will be executed.
