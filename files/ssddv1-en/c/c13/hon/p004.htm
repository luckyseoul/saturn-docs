Installation

Hardware installation

    Connect the CD-R recorder YAMAHA CDE / CDR100 (CDE100 is the model name with the CDR100 housing) to the host machine via SCSI. For details on the connection method, refer to the CDR100 manual.

    If the SCSIID of CDR100 is set to 5, it is not necessary to set the SCSI ID in the argument of the command segacdw each time.

Software installation

Copy the executable file segacdw from the distribution media of the
    floppy disk to the hard disk of the host. Set the path if necessary.
