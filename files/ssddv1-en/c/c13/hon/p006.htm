TOC file generator command

    Command name
      gentoc

    Syntax
      gentoc [-v] image_prefix

    Description
      This command generates a TOC file from a CD image file generated by C-Trac Builder for MEGA-CD / SEGA-CD. Start this command from the system prompt.

    Argument

      image_prefix For image_prefix, specify the name of the CD image file. The name of the CD image file is the prefix part of the file with the extension .emu.

    Options

      -v Displays information such as the contents of the cue sheet.

    Example
    To generate the TOC file test.toc from
      test.emu, specify as follows.

        C> gentoc test
