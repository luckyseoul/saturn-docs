Troubleshooting

    This section describes measures to take when an error message is displayed.

Error concerning image file

    If the error message introduced in this section is displayed, there is a problem with the CD image. Make sure that the .dsk file or .emu file and the .toc file exist in the same directory and that they were created correctly on the virtual CD system. If the error still occurs, create a CD image again.

Error regarding image file format

    The following error message means that the CD image you are trying to record is malformed.

    □Bad data form
    □unknown data form in line
    □Error Data Length

    The following error message is a CD image with a format that is not supported by segacdw or the mode of the CD-ROM to be created is invalid.

    □Unknown data mode

ISRC length error

There is a problem with the ISRC length stored in the
    CD image. Examine the original data and regenerate the image.

    □ISRC length error in line

Cue sheet error

    If the following error message is displayed, there is a problem with the cue sheet. Create the .dsk and .toc files again on the virtual CD system.

    □Cue Sheet intermidiate conversion failed
    □Cue Sheet parsing failed
    □Cue Sheet conversion failed
    □Cue sheet size error
    □Cue sheet too large
    □Empty cue sheet
    □No track definitions in cue sheet
    □Can't find lead-out in cue sheet
    □Nocore for cue sheet

    In addition, the following error indicates that the cue sheet has not been generated or that there is no file containing the cue sheet in the same directory as the image file.

    □No cue sheet
