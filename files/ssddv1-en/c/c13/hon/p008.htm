Error caused by relationship between host machine and CD-R recorder

Error when transferring CD image

    The following error message means that the I / O speed of the host hard disk is not in time for the writing speed of the CD-R writer. Use command options to adjust the CD-R writing speed.

    □Buffer Under Run

CD-R recording device setting error

    The following error message occurs when an invalid value is specified for the writing speed. Use option -s to specify the correct writing speed.

    □Error:Bad speed value

    The following error message appears when the CDR100 firmware version is out of date and the SEGA Saturn CD cannot be created. Update the CDR100 firmware to the correct version.

    □Firmware upgrade of CD recorder is needed to use this software.
