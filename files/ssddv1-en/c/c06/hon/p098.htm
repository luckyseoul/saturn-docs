          ・ Calculation of luminance of vertex for Goo display (optional)

 gourVertCount Number of vertex entries for vertex luminance calculation
When 0, vertex brightness calculation is not performed
VertNormal vertex normal table for vertex luminance calculation
Matrix conversion matrix to viewpoint coordinate system
LightVector Light source vector in the viewpoint coordinate system
 vertBright Vertex brightness calculation result table
0x00 = darkest
0x1f = brightest
