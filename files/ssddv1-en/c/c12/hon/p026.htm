    file name consists of a body part and an extension. The body part and extension are separated by a period. The body part and extension must be alphanumeric (Kanji can be used for the secondary volume descriptor), and the number of characters must be within 8 characters for the body part and 3 characters for the extension. It does not matter if there is no body part or extension, but you cannot specify a file name (only a period) without both.

    The version number is a value in the range 1 to 32767. If the version number is omitted, the version number is 1.
