2.3 When updating part of a disk image

    This chapter describes the operation procedure of “Partial Update CD Image”.
    If you have already performed "Real-time emulation", you can use it.
    Pre-processing for "Real-time emulation" must be performed and a file with the extension "DSK" must be generated. Perform steps 1 to 4 in the previous section.
[Procedure 5]
    Start the pre-processing program (VCDUTL.EXE) with the "-f" option.
    By entering the command as shown in the example, the preprocessing program (VCDUTL.EXE) is started and the files required for emulation are created.
    If this preprocessing is performed without the "-f" option, only the "real-time emulation" file is generated (modified). In this case, perform “real-time emulation” according to step 5 and after in the previous section. 

     [Example 5] C: ¥>   VCDUTL △ TSTGAME.SCR △ ISOFILE.DDD △ DOSAUDIO.D01  
  DOSAUDIO.D02 △ -f △ DOSAUDIO.PAT [ENTER]  
This example configures an ISO9660 file called ISOFILE.DDD in the CD image generated by TSTGAME.SCR.
The DOS file named DOSAUDIO.D01 in the data file to be replaced with the DOS file named DOSAUDIO.D02
Indicates that it will be replaced with. 
    
[Result 5] Update information file: DOSAUDIO.PAT is generated.

    There are no rules for file names of update information files.

[Step 6]
    English environment. (See previous paragraph)
[Step 7]
    Start the virtual CD emulator (VCDEMU.EXE) with the "-u" option.
    By entering the command as shown in the example, the virtual CD emulator is started and the "CD image partial update" operation is performed.

    [Example 7] C: \> VCDEMU △ TSTGAME △ -u △ DOSAUDIO.PAT [ENTER]
    [Result 7] The initial screen of the virtual CD emulator is displayed.
    The virtual CD emulator is activated.

[Step 8]
