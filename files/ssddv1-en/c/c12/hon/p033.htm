MPEG file definition

    MPEG file is defined between and .
    This definition adds a system layer to multiple MPEG-compressed MPEG data (audio, video, data), multiplexes, and generates an ISO11172 stream. The generated ISO11172 stream is placed on the disk as an ISO9660 file.
    Specify the MS-DOS file to which the generated ISO11172 stream is output as the parameter of the MpegMultiplex line. Do not specify this parameter if you do not need to create an MS-DOS file.

    The individual MPEG data that make up an MPEG file is defined between and . In the MpegStream line parameter, specify the data file that stores the MPEG compressed data and the data type.
    The type of data stored in the specified file specifies one of the following three types of parameters.
    ●AUDIO
    Indicates audio data.
    ●VIDEO
    Indicates video data.
    ●DATA
    Indicates data.

    Specify the following command line between and .
    ●BitRate
    ∙ Specify the data bit rate in bps.
    The following commands can be used as MPEG file definitions.
    ●BeginTimeF
    ∙ Specify the start position in the ISO9660 file as a relative position from the beginning of the file.
    If the parameter is specified with a "+" sign instead of a relative position, it indicates that it will continue after the previously defined file source.
    ●EndTimeF
    ∙ Specify the end position in the ISO9660 file relative to the beginning of the file.
    Specifying a "-" symbol for the parameter instead of a relative position indicates that it will continue before the previously defined file source.
    ●AutoEOR
    ∙ Indicates that EOR (End Of Record) is recorded in the sub-header of the sector that stores the last byte of the file source. This is valid only for MODE2 type tracks.
    ●RealTime
    Indicates that this file source is a real-time file.
