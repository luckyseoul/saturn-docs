    Example usage:
      VCDUTL△TSTGAME△ISO1FILE.DDD△DOSAUDIO.D01△DOSAUDIO.D02
      △ [-f △ DOSAUDIO PAT] [ENTER]

      VCDUTL Executable file name
      TSTGAME Name of the project that created the CD image to be changed
      ISO1FILE.DDD ISO file name including the DOS file to be modified
      DOSAUDIO.D01 DOS file name to be changed
      DOSAUDIO.D02 DOS file name to replace


    "-F" option
      DOSAUDIO.PAT Update information file name for DOS file replacement (optional).
      If this option is specified, the CD image itself is not updated. It is played based on the update information file during emulation.
      If this option is not specified, the update information file is not output and the CD image is rewritten and updated.

      If you want to change multiple DOS files for the data of one CD image, there are the following two methods.

      1. Execute the command multiple times without the "-f" option.
      2. Execute the command multiple times without changing the update information file name with the "-f" option.
    Note that the CD image remains as it is in the method of 2.


If the
    "-f" option is specified and the ISO file containing the specified DOS file to be changed is configured with channel interleave, the command will not be executed and an error will occur.
    If there is no "-f" option and the DOS file size is not appropriate, an error will occur.

VCDUTL error message
    Cannot open CD image file.
    ∙ The CD image file to be updated does not exist or the file could not be opened.
    Confirm the existence of the CD image file to be updated.

    Cannot found iso file [ test ].
    The ISO file "test" was not found in the CD image file. Enter the name of an existing ISO file by referring to the script file.

    Cannot found dos file [ test ].
    ．The file “test” to be updated could not be found in the RTI file. Enter the name of an existing DOS file by referring to the script file.

    Cannot found Project file [ test ].
    The project file “test” does not exist or the file could not be opened. Specify the correct project name.

    Cannot found RTI file [ test ].
    RTI file "test" does not exist or file open failed. Check the existence of the RTI file described in the project file.
