    DOS file [ test ] is channel interleaved.
    The file "test" is channel interleaved when creating an update information file with the [-f] option. This file cannot be specified because channel interleaved files cannot be emulated in direct DOS mode.

    New DOS file [ test ] open error.
    ∙ The DOS file to be replaced does not exist or the file could not be opened. Specify an existing DOS file.

    New DOS file size [ a byte ] is larger than old DOS [ b byte ].
    The size of the DOS file to be replaced is larger than the size of the DOS file to be replaced. Specify a DOS file whose size is the same as or smaller than the size of the DOS file to be replaced.

VCDMKTOC.EXE

    Command:
      VCDMKTOC
    Command name:
      Generate TOC information file for write-once CD
    Function:
      Extract TOC information necessary for write-once CD writing from the final RTI file, convert it to the format of the writing system, and output the file.
    Format:
      VCDMKTOC RTI file name body part
    Description:
      Input file = File name body part.RTI
      Output file = file name body part.TOC
    Example usage:
      VCDMKTOC△TSTGAME
