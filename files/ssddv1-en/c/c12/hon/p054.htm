5.2 Release Program

■VCDEMU.EXE

    Command:
      VCDEMU
    Command name:
      Virtual CD emulator
    Function:
      Performs pseudo playback of CD.
      An error can be forcibly generated during pseudo playback.
    Format:
      VCDEMU file name body part [-f RTI file name] [-l log file name]
       [-j jumper setting position] [-u update information file]
    Description:
    If all
      options are omitted, the file with the extension ".scr" in the specified body part is a script file, the file with the extension ".dsk" is a disk image file, and the extension ".rti" The file with is used as the default disk configuration information file. The log information file is not created.

      If option "-f" is specified, the disk configuration information file name will be the specified file name.
