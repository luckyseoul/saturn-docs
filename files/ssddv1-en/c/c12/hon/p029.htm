    VolumeModificationDate (PVD, SVD)
    ∙ Specify the last modification date of the volume.
    If you do not specify this command line, the current date and time will be used.

    ●VolumeExpirationDate(PVD,SVD)
    Specify the expiration date of the volume.
    If you do not specify this command line, a special date of “no expiration date” is set.

    ●VolumeEffectiveDate(PVD,SVD)
    Specify the effective date of the volume. If you do not specify this command line, the information in the volume takes effect immediately.

    ApplicationUse (PVD, SVD)
    Specified application use field on this command line.
    ∙ Specify the data file that stores the contents of the application use field in the parameter. If the size of the file is shorter than the field, 0 is embedded. If it is too long, an error will occur.

    BootSystemIdentifier (BRT)
    ∙ Specify the boot system identifier of the boot record as a character string with a parameter.

    ●BootIdentifier(BRT)
    ∙ Specify the boot identifier of the boot record as a character string with a parameter.

■ Track definition

    tracks are defined between and .
    One set from to represents one track.
    Specify the track type in the parameter of the Track line. The following track types are available. 

     ● CDDA: For audio tracks
● MODE0: Mode 0 data track
● MODE1: Mode 1 data track
● MODE2: Mode 2 data track

    In the track definition, specify the following:
    ●Pause
    Specify the number of blocks to pause at the beginning of the track. If there is no command line, playback will begin immediately without pausing.
    Normally, this pause time is about 2 seconds. The number of blocks is 150.

    ●Empty
    ∙ Null blocks (blocks filled with 0x00) of the number of blocks specified by the parameter are generated at the position of this command line.
    This is used when defining lead-in and lead-out.

    ●Preemphasis
    This is a command line to indicate whether the pre-emphasis bit of the Q subcode channel should be turned on.
    ⿟ Turns on when the parameter value is TRUE, and turns off when the parameter value is FALSE.
    If you do not specify this command line, the pre-emphasis bit will be OFF as the default value.
