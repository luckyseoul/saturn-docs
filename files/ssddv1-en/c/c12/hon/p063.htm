VCDUTL.EXE

    Command:
      VCDUTL
    Command name:
      Update CD image part
    Function:
      A tool to update files in a CD image generated by VCDBUILD.
      1. Replaces a part of the ISO image of the CD image with the specified DOS file and updates the CD image. ISO files can be file interleaved or channel interleaved. You can emulate in less time than regenerating the entire disk.
      2. Replace a part of the ISO image of the CD image with the specified DOS file, and create the modified information with the CD image as it is. ISO files may be file interleaved, but channel interleaving is not subject to change. Emulate only the updated part with direct DOS file access.

    Caution
    For
      1., The replacement DOS file must be the same size or smaller than the size of the DOS file to be replaced. If the new file is larger than the old file, an error is displayed and the image is not updated.
      Currently, the DOS file to be changed is a file other than MPEG or CD-DA. It is le.
      In the case of 2., there are no particular restrictions.
