    EscapeSequence (SVD)
    Indicates the set of characters described in the secondary volume descriptor and the characters described in the directory record and path table. Only SHIFT-JIS is valid.

    LPath (PVD, SVD)
    ∙ It specifies that LPath descriptor is written out. Only one LPath is allowed per volume descriptor.

    MPath (PVD, SVD)
    ∙ Specifies that the MPath descriptor is to be written out. Only one MPath is allowed per volume descriptor.

    OptionalMPath (PVD, SVD)
    Specified when attaching an optional L path table.

    OptionalMPath (PVD, SVD)
    Specified when attaching an optional M path table.

    ●VolumeSetIdentifier(PVD,SVD)
    Specify the volume set identifier with a parameter.

    ●PublisherIdentifier(PVD,SVD)
    Publisher identifier is specified as a string as a parameter. You can also specify the contents of the publisher identifier as a file on disk. In this case, write a script to place the file containing the publisher identifier in the root directory (file definition described later), and specify the file name with an underscore at the beginning of the file name.

    DataPreparerIdentifier (PVD, SVD)
    Specify the data editor identifier as a character string in the parameter. In addition, the contents of the data editor identifier can be specified as a file on the disc. In this case, write a script to place the file containing the data editor identifier in the root directory (file definition described later), and specify the file name with an underscore at the beginning of the file name.

    ApplicationIdentifier (PVD, SVD)
    ∙ Specify the application identifier as a character string with a parameter. You can also specify the contents of the application identifier as a file on the disk. In this case, write a script to place the file containing the application identifier in the root directory (file definition described later), and specify the file name with an underscore at the beginning of the file name.

    CopyrightFileIdentifier (PVD, SVD)
    Specify the copyright message as a file on the disc.
    The file must exist in the root directory.
    Specify the file name as a parameter.

    AbstractFileIdentifier (PVD, SVD)
    Specified abstract information as a file on the disc.
    The file must exist in the root directory.
    Specify the file name as a parameter.

    ●BibliographicFileIdentifier(PVD,SVD)
    Specified bibliography information as a file on disk.
    The file must exist in the root directory.
    Specify the file name as a parameter.

    ●VolumeCreationDate(PVD,SVD)
    Specify the volume creation date.
    If you do not specify this command line, the current date and time will be used.
