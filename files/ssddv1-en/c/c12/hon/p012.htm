6. Switching between virtual CD and CD drive

    In order to switch between the virtual CD and CD drive, there is a selector switch as shown in Fig. 1 between the CD block and the CD drive. When operating this switch, both the virtual CD and CD drive CD trays must be open. To open the virtual CD, use the menu selection of the VCD emulator.
    Press the 
     / [SPACE] key.
• Check that “MENU” on the top bar is highlighted in white, and press [ENTER] or
・ Press the SOLKEY [DOWN] to display the menu contents.
・ Select [Open CD Tray] with [DOWN] and press [ENTER] or [SPACE]
The virtual CD will be open.

    If the changeover switch is operated without performing this operation, inconsistency will occur between the track information stored on the target machine and the CD drive (VCD).
