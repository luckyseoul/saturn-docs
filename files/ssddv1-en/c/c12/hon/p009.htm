    Enter the following MS-DOS command.

[Procedure 2]

    C: \> SET △ VCDIO = 020000 [ENTER]

    If the consistency with the VCD I / F board is not achieved, the virtual CD emulator will not operate properly. Also, please note that the PC compatible machine may hang up in some cases.

    If the jumper setting is set to a value other than the default due to the convenience of a PC compatible machine, the environment variable value will be different.
    For example, if the interrupt number is 01, the channel number for DMA transfer is 02, and the VCD I / F board I / O address is 03, set the environment variables as follows.

    C: \> SET △ VCDIO = 010203 [ENTER]
