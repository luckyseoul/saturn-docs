3. Jumper pin settings

[Important]
    VCD I / F board has
      (1) ISA-IRQ setting (J3)
      (2) ISA-DMA setting (J4)
      (3) I / O address setting (J5)
      (4) Diag setting (J6)
    There are four jumper pins.

    If the three function settings (1), (2), and (3) overlap with those already set on your PC compatible computer, the virtual CD will not start or the PC compatible computer will hang up. Doing so may cause trouble.

    Know the settings of each PC compatible machine, and change the following settings only when the VCD I / F board settings must be changed from the default state, such as when overlapping with the DMA channel of the SCSI board. to hold. In this case, you must also change the value of the environment variable. When installing with the factory default settings, it is not necessary to set environment variables after starting up the PC compatible machine. For the procedure, refer to section 5.1 Preparation for startup.

(1) ISA-IRQ settings (J3)
The interrupt request number for the PC is selected by shorting with the
    jumper. The default is set to IRQ10 . 
       1-2 pin IRQ4 (00)
3-4 pin IRQ3 (01)
5-6 pin IRQ10 (02)
7-8 pin IRQ11 (03)
9-10 pin IRQ12 (04)
11-12 pin IRQ15 (05)
(2) ISA-DMA setting (J4)
Select the DREQ and DACK signal numbers for DMA transfer with the PC by shorting with the
    jumper. The default is set to DREQ5 / DACK5 . 
     1-2 pin & 3-4 pin DREQ5 / DACK5 (00)
5-6 pin & 7-8 pin DREQ6 / DACK6 (01)
9-10 pin & 11-12 pin DREQ7 / DACK7 (02)
(3) I / O address setting (J5)
Select the I / O address of the I / F board as seen from the PC compatible machine by shorting with the
    jumper. The default is set to 340H . 
       1-2 pin & 3-4 pin & 5-6 pin 340H (00)
3-4 pin & 5-6 pin 350H (01)
1-2 pin & 5-6 pin 3E0H (02)
5-6 pin 300H (03)
1-2 pin & 3-4 pin 310H (04)
3-4 pin 320H (05)
1-2 pin 330H (06)
Open 370H (07)
    The Diag setting function of (J6) is used when the board is manufactured. You can leave it open.
