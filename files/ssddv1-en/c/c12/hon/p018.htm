(6) Start virtual CD emulator

    After completing step (4) or (5) in the previous section, start the virtual CD emulator.
    Whether (4) or (5) is started can be determined by the existence of the created file, which mode of emulation is performed.
    After starting VCD emulation, the operation on the target box side is the focus. With a virtual CD emulator, just check the playback status or message.

(7) Correction work
If the material or program needs to be modified as a result of
    emulation, use the respective creation tools.
    As a result of modification, if the size of the material / program file has changed from before modification, it is necessary to modify the CD configuration using VCDPRE.EXE or VCDBUILD.EXE.
    Even if the size does not change, if you want to perform "real-time emulation", you must correct the CD configuration, but if you want to check with "Direct DOS file access" before that, start the virtual CD emulator Just emulate it.
(8) Partial update
Run the program
    VCDUTL.EXE.
    In this case, select "Update CD image part" and "Real-time emulation" depending on the execution option.
