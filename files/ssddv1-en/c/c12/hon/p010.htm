5.2 Start and end

    Start the virtual CD emulator. Enter the command as follows:

[Procedure 4]

    C: MYDIR

    The virtual CD emulator starts and the screen is displayed.
    The name of the specified disk image file, CD configuration information file, script file, and log information file is displayed on the screen.
    If no log information file is specified, "No Log File" is displayed.

    The virtual CD emulator is waiting for key input to confirm the message. If pressed, continue.

[Procedure 5]

Press

    [ENTER] or [ESC].
    The program starts loading the files necessary for execution.

    If it loads correctly,
    [Result]
    =========== Open New File = ****. Dat ===============
    =========== All Data has been Read ================
    =========== PAUSE2 ================================
    Is displayed.

    The operation mode displayed in the dialog box in the upper right of the screen should be Direct. The operation mode is "Direct DOS file access".
    After this state, operations from the target box are the focus.
