5. Execution with sample data
    Check the operation of the virtual CD emulator that has been set up.
    In the following explanation, [ENTER] on the command line to input means pressing the carriage return key. △ means that it is separated by a space. Others enclosed in [] indicate keys on the keyboard.

[Procedure 0-a]
    Install the VCD I / F board on the PC. At this time, check the value of the next jumper number and make a note of it.
    ● Jumper number to select interrupt number (J3)
    Jumper number (J4)
    for selecting the channel number for DMA transfer Jumper number (J5)

    for selecting the I / O address of the VCD I / F board If the VCD I / F board has already been installed, perform [Procedure 0-b]. At this time, you may not need to set up the environment [Step 1]. Read the description of [Procedure 1].

[Procedure 0-b]
    Next, turn on the PC compatible computer and wait for MS-DOS to start up.
    [Result] When MS-DOS starts up, the MS-DOS prompt appears.

    When MS-DOS starts up, proceed to the next step.

5.1 Preparations for starting up

    Does not work in Japanese mode, so set DOS to English mode. Enter the command as follows:

[Procedure 1]
    C: \> CHEV △ US [ENTER]

    If you are in Japanese mode, the screen will flash and you will be prompted at the top of the screen.

    Next, set the environment variable VCDIO.
    However, if you are already using a virtual CD emulator on that PC compatible machine, this setting may be set automatically when MS-DOS starts up, check with the person who used it until then please do.
    If it is set again, skip this step and start from “Step 3”.

    The value of the environment variable VCDIO must reflect the setting of the VCD I / F board as described in 3. Jumper pin setting.
    In the example, the default value of the VCD I / F board is set.
