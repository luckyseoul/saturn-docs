4. Installation and connection to a PC compatible machine

    (1) What you need
      Virtual PC compatible PC: 1 unit
        Recommended specs
          486 / 33MHz or higher, memory: 8MB or higher, expansion slot: ISA bus 3 slots or higher, video memory: 512KB or higher, FDD: 3.5 "x 1, SCSI board: Adaptec AHA-154xCF, HDD (1.2GB or higher) : Dec DSP3210 / DSP3107L etc.

      NOTE XMS memory must be used to process a large number of files.
      Be sure to specify HIMEM.SYS in CONFIG.SYS.

      VCD I / F card (RT-V1A)
      VCD I / F cable
      SEGASATURN programming BOX
      SH-2 ICE

    (2) Setup
      Unpack the VCD I / F card (RT-V1A) and insert it securely into the expansion slot of your PC compatible machine.

      Use the supplied virtual CD I / F cable to connect the VCD I / F board connector to the virtual CD I / F connector of the SEGASATURN programming BOX. Set up the programming box and ICE according to the instructions in each manual.
