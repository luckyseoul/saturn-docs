About this manual

    This manual consists of two parts: a description of virtual CD system setup and a description of CD emulation software.

    The setup section describes how to install on a PC compatible machine. In addition, the procedures necessary for performing emulation work are described in the CD emulation software edition.

    Installation of the VCD I / F board to a PC compatible machine requires a basic knowledge of the PC compatible machine. In addition, knowledge of MS-DOS program execution and rudimentary knowledge of the CD-ROM standard are required to run CD emulation software.
