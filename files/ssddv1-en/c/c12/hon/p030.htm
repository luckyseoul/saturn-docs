    Channels
    This is a command line to indicate whether a track has 2 or 4 channels.
    Enabled only when the track type is CDDA.
    This instruction is reflected in the Q subcode information.
    If you do not specify this command line, the default value is 2.

    ●Copy
    This is a command line for instructing the copy protection status of audio data of a certain track.
    If the parameter value is TRUE, digital copying is permitted.
    If you do not specify this for a track that needs to be specified, the default value is FALSE.

    ● Directory definition
    ∙ CD-DA track is defined as the last track.
    ∙ Tracks for data can have a hierarchical structure with directories.

Directory definition

    directory is defined between and .
    One set from to represents one directory.
    Define a directory hierarchy by placing a pair of to between and .
    Specify the directory name in the parameter of the Directory line.
    There are files in each directory, and files can be divided into two types as follows.

    ● File interleaving
    ● File not interleaved

    Files that are not file interleaved are further divided into the following three types.
    ● Simple file
    ● Channel interleaved file
    MPEG file

    Files that are file interleaved are represented using files that are not file interleaved.

    The command line that indicates the characteristics of the directory itself is:
    ●Attributes
    Specified directory attributes with parameters.
    Specified as HIDDEN or NOHIDDEN for the attribute type.
    * If this command line is not specified, the NOHIDDEN attribute is taken as an abbreviation.
    ●MinLength
    Specify the minimum number of bytes for the directory.
    ●RecordingDate
    Specify the recording date of the directory.
    If you do not specify this command line, the date the disk image was created will be used.
