Chapter 2 Operation procedure details

    In this chapter, the operation procedure is divided into the following three types of emulation models.
    The operation procedure is almost the same, but the files required to execute emulation are different. These files are generated by the emulation preprocessing program. A pre-processing program is prepared for each emulation model.

    ● "Direct DOS file access"
    A collection of data files before CD image and a CD configuration information file are required. A pre-processing program that creates this CD configuration information file from a script file is provided. Described in Section 2.1.

    ● "Real-time emulation"
    Prepare a file with the CD image intact. A preprocessing program that creates a CD image file from a script file is provided. Described in Section 2.2.

    ● "Update CD Image"
    A CD image file, a modified MS-DOS file, and an update information file are required. A preprocessing program for creating an update information file is provided. The parameters for emulation execution are also different. Described in Section 2.3.
