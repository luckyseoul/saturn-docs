CD emulation software

    Describes how to use CD emulation software, which is application software that runs on PC compatible machines. It briefly describes the CD emulation system and describes the role of CD emulation software.

    Chapter 1 “Overview” explains the general flow of emulation.
    Detailed usage is described in Chapter 2 for each model assuming three types of emulation models.

    In order to perform emulation, it is necessary to specify in advance how data will be arranged on the CD.

    The contents displayed on the virtual CD emulator are described in Chapter 4 "Displaying the VCD emulator".
