      format  MpgMv MPG_MvCreate (StmHn vstm, StmHn astm)
 Input  vstm: Video stream handle
  astm: Audio stream handle
 Output  None
 Function value  MPEG video handle
 Function  Generates an MPEG video handle for playing MPEG streams. Video data
Specify the stream handle for  and  and the stream handle for audio data.
:  NULL can be specified for either one and audio and video can be played independently.
  If both are specified at the same time, playback will be synchronized.
:  If MPEG video handle generation fails, NULL is returned.
