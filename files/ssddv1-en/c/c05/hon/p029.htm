7.3 Data type 

  Title  
 Data specifications 
  Data  
 File handle 
  Data Name  
 GfsHn 
No
3.1

        Stores information for each file regarding file access. Generated by GFS_Open. Most functions that access files reference this data. 

  Title  
 Data specifications 
  Data  
 Directory Information Management 
  Data Name  
 GfsDirTbl 
No
3.2

        Directory information management structure can manage directory information without file name or directory information with file name. Use the following constants to specify which is to be managed. 

         constant name 
         description 
         GFS_DIR_ID 
         No file name information 
         GFS_DIR_NAME 
         Has file name information

        Data type for managing directory information. Holds the type, size, and substance of the directory information table.

        GfsDirTbl * dirtbl 
         access macro 
         type 
         Description 
         GFS_DIRTBL_TYPE (dirtbl) 
         Sint32 
         Directory information table Type 
         GFS_DIRTBL_NDIR (dirtbl) 
         Sint32 
         Directory information table 
         Prime number 
         GFS_DIRTBL_DIRID (dirtbl) 
         GfsDirId * 
         No file name Directory information 
         Pointer to table 
         GFS_DIR_NAME (dirtbl) 
         GfsDirName * 
         with file name Directory information 
         Pointer to table 

         (a) When using directory information without file name
GfsDirTbl dirtbl;
GfsDirId dir_id[MAX_DIR_ID]
        
GFS_DIRTBL_TYPE (& dirtbl) = GFS_DIR_ID; / * Directory information specification without file name * /
GFS_DIRTBL_NDIR (& dirtbl) = MAX_DIR_ID; / * Maximum number of elements * /
GFS_DIRTBL_DIRID (& dirtbl) = dir_id; / * Directory information table without file name * / 
        
(b) When using directory information with file names
GfsDirTbl dirtbl;
GfsDirName dir_name[MAX_DIR_NAME];
        
GFS_DIRTBL_TYPE (& dirtbl) = GFS_DIR_NAME; / * Specify directory information with file name * /
GFS_DIRTBL_NDIR (& dirtbl) = MAX_DIR_NAME; / * Maximum number of elements * /
GFS_DIRTBL_DIRNAME (& dirtbl) = dir_name; / * Directory information table with file name * /
