 GFS_Seek

2.3
 

     Format  Sint32 GFS_Seek (GfsHngfs, Sint32 off, Sint32 org)
 Input  gfs: File handle
:  off: Amount of access pointer movement (in sectors)
  org: Standard of movement (seek mode: GFS_SEEK_ ~)
 Output  None
 Function value  Position of the access pointer after movement. Negative error code if there was an error.
 Function  Moves the access pointer to a position off sector from org.
:  If movement to a position beyond the end of the file is specified, the file will be moved to that position.
