3.3 Image data output method

An output window can be created in the image data area in the output frame bank to output the data. There are the following two methods for outputting data.

(A) VDP2 direct output method
(B) Host transfer method

∙ Multiple output windows can be created when transferring to the host area, and only one output window can be created when outputting directly to VDP2.
Also, various video effects can be given to these windows.

Figure 3.4 Output window

Image effects

  • Trimming (Crop image)
  • Enlarge / reduce
  • Fade
  • Mosaic / Blur
  • Luminescence key
