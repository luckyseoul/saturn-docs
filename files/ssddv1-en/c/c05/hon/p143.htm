 Output  None
 Function value  Error code
 Function  Outputs a still image. If another MPEG still image handle or MPEG movie handle is being output
  fails and no still image is output.

.  If direct output to VDP2 is specified, it is connected to the specified bank.

  The image in the buffer area of ​​the host transfer window connected to the specified bank.

 Remarks  (a) mpgsp must be in the host output mode and the operating state must be playing.
  Otherwise, still image output will fail.
