1.3 Module configuration

Figure 1.1 shows the positioning of this library with respect to hardware and other software. The dotted line is the module included in the debug library.

Figure 1.1 Module configuration diagram 

 To use this library, the following libraries must be linked at the same time.
     ・ SHCNPIC.LIB SH7600 position independent code not supported library
     ・ SEGA_CDC.LIB CD communication interface library
     ・ SEGA_DMA.LIB DMA library
     ・ SEGA_CSH.LIB cache library
