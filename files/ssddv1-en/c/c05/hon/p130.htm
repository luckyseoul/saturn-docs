  Title

  Function  
 Set video end condition 
  Function Name  
 MPG_MvSetTermCond 
No
2.3
 

      format  void MPG_MvSetTermCond (MpgMv mpgmv, Sint32 vcnd, Sint32 acnd)
 Input  mpgmv: MPEG video handle
  vcnd: MPEG video stream end condition
:  acnd: MPEG audio stream end condition
 Output  None
 Function value  None
 Function  Sets transfer termination conditions for each stream. The following values ​​can be logically ORed
 .

       
         (1) MPEG stream end condition (common to video / audio)

           
        •  MPG_TCND_EOR: When a sector with the EOR bit set is transferred

        •  MPG_TCND_SEC: When system end code appears in the stream

        •  MPG_TCND_NONE: Do not set termination condition 
         
       
     

  Title

  Function  
 Set video output destination 
  Function Name  
 MPG_MvSetVideoDest 
No
2.4
 

      format  void MPG_MvSetVideoDest (MpgMv mpgmv, Sint32 dst)
 Input  mpgmv: MPEG video handle
:  dst: Output destination
 Output  None
 Function value  None
 Function  Set the video output destination.

       
         (1) Output destination

           
        •  MPG_OUTDST_DRCT: VDP2 direct output

        •  MPG_OUTDST_HOST: Host transfer output 
         
       
    
 Remarks  (a) This function setting is valid by calling the MPG_MvStart function. 

  Title  
 Function specifications 
  Function  
 Decode timing setting 
  Function Name  
 MPG_MvSetDecTim 
No
2.5
 

      format  void MPG_MvSetDecTim (MpgMv mpgmv, Sint32 tmg)
 Input  mpgmv: MPEG video handle
.  tmg: Decoding timing
 Output  None
 Function value  None
 Function  Sets the MPEG video decoding timing.

       
         (1) Decoding timing

           
        •  MPG_DECTMG_VSYNC: Decodes one picture with two VSYNC signals

        •  MPG_DECTMG_HOST: Decodes by calling the MPG_MvDecNext function

             
           
        
 Remarks  (a) This function setting is valid by calling the MPG_MvStart function.
