  Function  
 Transfer mode setting 
  Function Name  
 STM_SetTrMode 
No
4.7
 

      format  void STM_SetTrMode (StmHn stm, Sint32 tmode)
 Input  stm: Stream handle
 t  tmode: Transfer mode
 Output  None
 Function value  None
 Function  Sets the transfer method from the CD buffer section to the transfer area.

        (1) Transfer mode 
         Constant name 
         Transfer method 
         CPU load 
         STM_TR_SCU 
         SCU DMA 
         Transfer destination is B bus Above, the CPU is completely 
         independent operation 
         STM_TR_SDMA0 
         CPU DMA channel 0 
         CPU processing Ability drops 
         STM_TR_SDMA1 
         CPU DMA channel 1 
         CPU processing Ability drops 
         STM_TR_CPU 
         software 
         CPU is occupied Interrupt handling 
         is possible 

      Remarks  The default is STM_TR_CPU.
