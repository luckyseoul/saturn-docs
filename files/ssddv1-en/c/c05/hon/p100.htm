2. Basics

2.1 Terminology

Table 2.1 shows definitions of terms used.

Table 2.1 Definition of terms 
 Terminology 
 Significance 
 MPEG buffer 
 Memory area managed by MPEG / Video LSI. 
 Frame buffer 
 A region where decoded image data is stored. It consists of multiple frame banks. Normally 
 4 banks in resolution and 1 bank in high resolution 
. 
 Frame bank 
 Image for one picture of MPEG video stream 
 A region where data is expanded. 
 VBV buffer 
 A region used to decode an MPEG video stream. It is secured in the MPEG buffer. 
 Display window 
 A rectangular area on a TV monitor where MPEG video is output. 
 The frame buffer window data is output 
. 
 Frame buffer window 
 A rectangular area set for the frame buffer. 
 This area is the output target. 
 Bright spot 
 Minimum display unit on the display. 
 Pixels 
 Composed of 2 × 2 bright spots at normal resolution and 1 × 1 bright spot 
 at high resolution Display unit to be displayed. 
 Image data  
 Decoded color data. It is transferred to the host area as 16  color data. 
 MPEG window 
 Object for controlling the display window and the frame buffer window. 
 MPEG video handle 
 Object for controlling MPEG video. 
 MPEG still image handle 
 Object for controlling MPEG still image. 
 MPEG handle 
 A generic term for MPEG video handles and MPEG still image handles. 
 MPEG report 
 Data representing the state of the MPEG system. 
 Please refer to the CD communication interface manual for details.
