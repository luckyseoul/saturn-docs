  Function  
 Start still image playback 
  Function Name  
 MPG_SpStart 
No
3.7
 

      format  Sint32 MPG_SpStart (MpgSp mpgsp)
 Input  mpgsp: MPEG still image handle
 Output  None
 Function value  Error code
 Function  Starts playback of still images.
 Remarks  (a) Calling this function while playing another stream returns MPG_ERR_PLAYING.
  (b) If the MPEG decoder connection fails, MPG_ERR_MCON is returned.
