6. Video effects

6.1 Border Color

Border color is output in the area outside the display window. After instructing the start of playback, the border color is output until the actual video is output.

6.2 YC magnification

You can set the image brightness and color difference magnification. Used for fade-in and fade-out. When the color difference magnification is set to 0, the image will be monochrome.

6.3 Mosaic

Mosaic can be applied to the video. Specify the mosaic independently in the X and Y directions.

6.4 Blur

Video can be blurred.

6.5 Luminescence key effect

Adds a transparent bit to pixels below a certain luminance. You can use it when you want to superimpose images of human movements on the scroll surface.
