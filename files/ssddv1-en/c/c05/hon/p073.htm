  Title

  Data  
 Stream playback range 
  Data Name  
 StmFrange 
No
3.3

        Used to specify and obtain the playback range of a stream.

        (1) Stream playback range
        StmFrange *frange
         access macro 
         type 
         Description 
         STM_FRANGE_SFAD (frange) 
         Sint32 
         Start playback FAD 
         STM_FRANGE_FASNUM (frange) 
         Sint32 
         Number of playback sectors

        (2) Stream playback range constant 

         constant name 
         description 
         STM_FAD_CDTOP 
         Indicates the top of the disc (specifies the playback start FAD) 
         STM_FAD_CDEND 
         Indicates the number of sectors to the end of the disk 
         (Specify the number of playback sectors)
