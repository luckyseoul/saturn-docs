No

      format  Sint32 MPG_MvGetAudioStat (MpgMv mpgmv)
 Input  mpgmv: MPEG video handle
 Output  None
 Function value  Current audio operating status
 Function  Acquires the current operating status as follows.

        •  MPG_ASTAT_PREP: Preparing

        •  MPG_ASTAT_PLAY: Now playing
