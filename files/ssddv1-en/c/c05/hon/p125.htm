12. Function details

12.1 MPEG system control 

  Title  
 Function specifications 
  Function  
 MPEG system initialization 
  Function Name  
 MPG_Init 
No
1.1
 

      format  Sint32 MPG_Init (Sint32 dscn)
 Input  dscn: Display scanning method
 Output  None
 Function value  Error code
 Function  Initializes the MPEG system. MPEG audio is always replayed when this initialization is performed.
  will be live.
  When using the MPEG library, this function must be called only once at the beginning.
 Not . 
    

       
         (1) Display scanning method

           
        •  MPG_DSCN_NITL: NTSC non-interlace mode

        •  MPG_DSCN_ITL: NTSC interlace mode

        •  MPG_DSCN_PLNITL: PAL non-interlace mode

        •  MPG_DSCN_PLITL: PAL interlace mode 
         
       
     
    
 Remarks  (a) Execute the following procedure within this function and return an error code.
        Use the 
         Procedure 
         Error code 
         1 
         Perform a soft reset of the CD block (CDC_CdInit function). 
         If an error occurs, return 
         MPG_ERR_CDINIT 
         2 
         CDC_GetHwInfo function to check if the MPEG cartridge is installed. 
         If not installed, return 
         MPG_ERR_NOMC. 
         3 
         If MPEG cannot be used, 
         MPEG check (SYS_CHKMPEG) of the service routine in BOOT ROM is executed. 
         If the check fails, return 
         MPG_ERR_MPNG. 
         4 
         MPEG decoder initialization (CDC_MpInit function) is executed. 
         If an error occurs, return 
         MPG_ERR_MPINIT. 
         5 
         MPEG interrupt mask setting (CDC_MpSetIntMsk function) is executed, and 
         picture start detection and sequence end detection interrupts are enabled. 
         If an error occurs, return 
         MPG_ERR_NG. 
         6 
         If a constant for PAL is specified for the display scan method, 
         CDC_MpSetWinDofs function is used to set the display window offset 
         to (150, Set to 45). 
         If an error occurs, return 
         MPG_ERR_NG.

    (b) Call the GFS_Init function and STM_Init function after executing this function.
