 Specify loop start stream 
  Function Name  
 STM_SetLoop 
No
7.5
 

      format  Bool STM_SetLoop (StmGrpHn grp, StmHn loopstm, Sint32 loopmax)
 Input  grp: Stream group handle
:  loopstm: Loop start stream
:  (NULL if not looping; STM_LOOP_DFL for the first stream)
:  loopmax: Number of loops (STM_LOOP_ENDLESS if infinite)
 Output  None
 Function value  TRUE: When set correctly
  FALSE: Resident stream
 Function  Specify the loop start stream and loop count of the stream group.
 Remarks  (a) The default loop start stream is the most forward stream. Loop times
  Infinite times.
:  (b) When the loop start stream is closed, the first stream is the loop open.
  Start stream.
  (c) Loop counter is initialized.
  (d) A resident stream cannot be specified as a loop start stream.
