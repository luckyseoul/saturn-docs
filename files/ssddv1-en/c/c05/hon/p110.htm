5. MPEG window

5.1 MPEG window control

Opens a window for outputting to the area in the frame buffer. The control interface of this window makes visual effects easy.

(1) Display window

Sets the display window as a rectangular area that is actually displayed on the TV monitor.
For VDP2 direct output method, specify the position and size with respect to the TV monitor. In the case of the host transfer method, only the size is specified because it is not directly displayed on the TV monitor.

(2) Frame buffer window

The display window outputs data in an arbitrary rectangular area in the frame buffer. This rectangular area in the frame buffer is called the frame buffer window. The frame buffer window can be opened within the area of ​​one frame bank.

(3) Window control parameters

The control parameters of the display window and frame buffer window are as follows.

(a) Display window

  • Display reference position (DZX, DZY): Display reference position on the TV monitor
  • Display relative position (DLX, DLY): Relative coordinates from display reference position
  • Display size (DSX, DSY): Size on TV monitor

(b) Frame buffer window

  • Zoom point (FZX, FZY): Reference position in the frame buffer
  • Magnification (FRX, FRY): X and Y magnifications
