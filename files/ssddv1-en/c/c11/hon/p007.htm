How to start and stop

MFCAT startup and shutdown 
      Startup  
    
 1  Start [mfcat.exe] from the DOS prompt.
 
    
The following display will appear.
 
    
 Exit  
    
It will end automatically.
Starting and exiting CDSIM 
      Startup  
    
 1  Start [cdsim.exe] from the DOS prompt.
 
    
The following display will appear.
SUN startup example (when PORT-A / SCSI ID 2 is used)
CDSIM -i / dev / ttya -o / dev / rsd2a (CR) 
    
HP startup example (when using PORT-0 / SCSI ID 5)
CDSIM i / dev / tty00 -o / dev / dsk / c201d5s0 (CR) 
    
 
    
 Exit  
    
Ending with error automatically.
If it does not end automatically, press the [ESC] key.
In case of SUN or HP, press [CTRL] + [C] to exit.

● Confirm installation

    To confirm that the installation was successful, make the necessary settings, start the software, check the copyright display, and exit.
