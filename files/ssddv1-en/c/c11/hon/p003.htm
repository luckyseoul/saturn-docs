Introduction

■ Introduction

    "Simple CD simulator" has "SIMM system" that uses RAM on target and "SCSI system" that can read DOS file on SCSI hard disk. This debug support function can be used from "Software Library / CD Library / File System Library".

● Notation used in this document

    Gothic represents the name. Example: CD Tool
    [xxxx] represents a file name, DOS command name, or key name. Example: [cdsim.exe]
    Underline represents user input. Example: MFCAT [RET]
    [RET] indicates the input of the return key.
    [\ N] represents a line feed code.
