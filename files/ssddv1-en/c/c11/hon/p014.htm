■CDSIM

● CD simulator CDSIM

Format
    CDSIM [-f]
    CDSIM -i -o [-f ]
Options
    -f CD file name and DOS file name definition file name
Function
    After starting, poll the target box SCSI driver for CD-ROM data requests.
    If there is a request, response processing for that request is executed.
How to exit
To terminate
    , press the [ESC] key.
    For the workstation version, press [CTRL] + [C].
Examples
Start
    [CDSIM.DAT] as a definition file.
      C: \> CDSIM -fCDSIM.DAT [RET]

    Example of SUN startup (when PORT-A / SCSI ID 2 is used)
      CD SIM -i/dev/ttya -o/dev/rsd2a [RET]
    HP startup example (when using PORT-0 / SCSI ID 5)
      CD SIM -i/dev/tty00 -o/dev/dsk/d201d5s0 [RET]
