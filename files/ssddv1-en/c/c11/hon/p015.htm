Definition file format for CD file names and DOS file names

Format
    [; ] [\ n]
    [; ] [\ n]

    A definition file is a text file that describes one correspondence between a CD file name and a DOS file name on one line. File names are separated by spaces or tabs, and comments after the semicolon are comments.
    File identifiers 0,1,2 ... are assigned from the beginning.

Remarks
    Limit number of characters 
       CD file name: 12 characters or less
DOS file name: 64 characters or less (including path name)
Maximum number of digits per line: 128 characters or less
    * File name should be 8 characters + '.' + 3 characters MS-DOS format.

Reference examples
    Definition of n files 
       CD file name DOS file name; File identifier 0 [\ n]
CD file name DOS file name; File identifier 1 [\ n]
CD file name DOS file name [\ n]
・ ・
・ ・
・ ・
CD file name DOS file name; File identifier n-1 [\ n]
[EOF]
