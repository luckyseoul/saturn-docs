Troubleshooting

Q & A 

     Q: Cannot access memory file (SIMM system) 
    
A: Check the following.
· Is the content of data loaded to SIMM broken?
Is the start address of SIMM set in [_GFMC_base] 
    
Q: The PC does not recognize the target (SCSI system)
(The message "SEGA SATURN XXXX" is not output) 
    
A: Check the dip switch settings. Other SCSI devices and IDs
Please be careful not to collide. 
    
Q: [CDSIM.EXE] has output an error message 
    
A: Error message such as Illegal Request, Saturn Not Found, Saturn GetReq Error
If, is output, start again from BOOT ROM startup. 
    
Q: My PC calendar time is out of sync 
    
A: While performing [CDSIM], such as breaking the target ICE,
 The PC calendar time may be delayed.
In such cases, reset the calendar time.
