If any other behavior or display is wrong during use, press the reset button. Or try turning the power button ON / OFF once. If that does not work, remove the battery cover and press the master reset switch. (However, if you perform these operations while saving game data, the data may be lost without being saved.)
* The POWER ON RESET switch on the target box is slightly different from the power ON / OFF.
If the POWER ON RESET switch does not work, turn the POWER button ON / OFF.
* The master reset switch of the target box is the SMPC RESET switch.

If the above does not work correctly, unplug the power cable from the outlet, Please contact your dealer or our technical support center.

Q & A 

Q1: GAME-CD does not start.
A1: Be sure to put the boot code at the specified position on the GAME-CD. If the boot code is not recognized, the game will start
   It will not be. For the contents of the boot code and how to create it, refer to  "DISC Format Standard Specification" . 

Q2: The created GAME-CD starts in the target box, but it does not work with the commercial version.
A2: The following can be considered.
1) The boot code conforming to the DISC format is not described.
2) The system disk is not used.
It will not start if the manufacturer ID is not described correctly. Be sure to check the manufacturer ID.
Please refer to  “DISC Format Standard Specification”  for details.
