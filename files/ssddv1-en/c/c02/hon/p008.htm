■ About service program

System program

The following services are available. You must use this service program to access these resources.
    (1) Register and refer to interrupt processing routines
    (2) SCU interrupt mask set, reference and change operations
    (3) Simple semaphore operation
    (4) System clock switching
    (5) SCU interrupt routine priority change
    (6) CD multiplayer activation execution
    (7) Power-on clear memory operation
For details, please refer to “System Program User's Manual” in “System Library User's Guide” .

● Backup library

Provides read / write and search functions for backup storage devices. This service program must be used to access the internal backup RAM. (Currently, this service program must be used when accessing external storage devices. SEGA will be distributed in the future to access unsupported external storage devices.)
For details, please refer to "Backup Library User's Manual" in "System Library User's Guide" .

Multiplayer execution

When
Multiplayer is started, the operation buttons are displayed on the screen. Use the dedicated control pad to select Multiplayer operation buttons and determine the operation.

● Control pad operation

The function of each button on the control pad is as follows. For music CDs, basic operations can be performed directly using the X, Y, Z, L, and R buttons. 
     direction buttons: Select / Move
Start button: Start game
A button: Determine
B button: Cancel
C button: Determine
X button: 1 song repeat
Y button: Stop
Z button: Play / Pause
L button: Song return (skip & search)
R button: Song advance (skip & search)

* If you press the L and R buttons briefly, each song will be skipped, and if you press it long, the search will be performed.
