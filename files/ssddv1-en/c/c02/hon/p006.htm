BOOT ROM function

■ SEGASATURN logo display

Check and initialize hardware before displaying the logo. Check GAME-CD while displaying the logo. If GAME-CD is installed, start the game. If GAME-CD is not installed, run Multiplayer To do.
⿟ After resetting SMPC, go to "Date and time settings" screen and display the logo. You can always skip the logo animation and go to Multiplayer by holding down the A button and resetting. You can skip the logo animation and go to the "Save Data Management" screen at any time by resetting while holding down the L or R button. Logo animation can be skipped by pressing the Start, A, B, C, X, Y, Z, L, R buttons.
