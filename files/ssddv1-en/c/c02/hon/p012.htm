Troubleshooting

If you see this message

I can't play with this SEGASATURN CD
    Displayed when a SEGA Saturn CD other than for Japan is used. In such a case, check the CD type. (If music data is included, only music data can be played.)
    This message is also displayed when the CD recording surface (the surface on which no game name is printed) is dirty. In such a case, wipe off the recording surface with a soft, dry cloth.

This CD cannot be played

    Displayed when a CD that does not contain any music data is loaded. In such a case, check the CD type.

No CD

    This message is displayed when there is no CD, when the CD is severely damaged, when the CD is inserted upside down, or when a CD of a type that cannot be recognized by Sega Saturn. In such a case, check the CD status and type.

You cannot play with this SEGASATURN cartridge.

    Displayed when a non-Japan Sega Saturn cartridge is installed. In such a case, check the type of Sega Saturn cartridge.

■ If you suspect a malfunction

Multiplayer screen doesn't start
    Has the game cartridge been removed from the cartridge slot?

Sega Saturn CD game doesn't start

    Is the disc turned upside down?
    Is the disc dirty?
    。 Is the disc scratched?

CD, CD + G, CD + EG sounds in mono

    Is the audio output mono? (When using Sega Saturn Stereo AV Cable or Sega Saturn S Terminal Cable)

When the power is turned on, the date and time setting screen is displayed many times / Data saved in the backup RAM of the main unit disappears

    Is a lithium battery installed? Or is the lithium battery dead?

The lamp does not light immediately after pressing the power button

    It may take 1 or 2 seconds to turn on the power lamp, but this is not a malfunction.
