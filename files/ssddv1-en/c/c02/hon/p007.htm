■ Launch game

Check to see if the boot code is included in GAME-CD before launching the game to prevent unauthorized unauthorized creation and sale of game software. Be sure to put boot code at the specified position on GAME-CD . If boot code is not recognized, the game will not start. For the contents of Boot Code and how to create it, refer to "DISC Format Standard Specification" .

● How to start the game (the method described in the instruction manual) 

 
  1  Turn on the TV. 

 2  Switch the TV screen to video input mode. 

 3  Press the open button to open the CD door. 

 4  Insert the Sega Saturn CD with the game name printed on top. 

 5  Close the CD door. 

 6  Pressing the power button will automatically start the game.

● How to finish the game (method described in the instruction manual) 

 
  1  Press the reset button while holding down the A button during or after the game.
After a while, the multiplayer screen will appear after the Sega Saturn logo. 

 2  Use the open button to open the CD door and remove the CD. 

 3  Turn off the power button on the main unit. 

 4  Unplug the power cable from the outlet.

● When you want to return to the game title screen (method described in the instruction manual)

If you press A, B, C, and Start button at the same time during the game, you will return to the game title screen. 

  This feature is not a BOOT ROM feature. Please support for each application.
