How to read the operation buttons (option buttons)


  1. Pitch & Voice button

  2. Program button

  3. Surround button

  4. Intro button
    If set, it will play 10 seconds from the beginning of each song and go to the next song.

  5. Display switch button
    Switches the time display on the multiplayer screen.

  6. Shuffle button
    If set, CD tracks are played in random order.

  7. All clear button
    Cancels all functions set with each operation button.

  8. AB repeat button

  9. Function switch button

Caution
The program button and shuffle button, AB repeat button and intro button, surround button and pitch & voice button cannot be used simultaneously. If one of the buttons is already set and the other button is set, the previously set button is canceled.

About voice cancellation:
Voice canceling reduces the singer's voice by reducing the sound located in the center of the song recorded in stereo, and does not eliminate the singer's voice. For monaural recordings, voice cancellation is not recommended as the entire song will be smaller. Even if the song was recorded in stereo, Japanese music such as folk songs, poetry, songs with few classical and musical instruments, duet songs, songs with strong chorus and echoes, songs where the voice of the singer is not centered, etc. May not be effective.
