Introduction

This manual describes BOOT ROM . BOOT ROM is already built into the game console itself, so it automatically operates when the power is turned on or reset. BOOT ROM determines the operation of the main unit after turning on the power or pressing the reset button. The main functions are SEGASATURN logo display, game launch, service program provision, and multiplayer playback of various CDs.
∙ Before starting the game, check whether there is GAME-CD and whether it is a regular GAME-CD . Please refer to "DISC format standard specification" for the production method of regular GAME-CD .
Also, how to use the service program that can be used from the application after starting the game is described in “System Library User's Guide” “System Program User's Manual” and “Backup Library User's Guide” See "Manual" .
