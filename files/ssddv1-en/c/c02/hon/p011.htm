Changing the settings

With Sega Saturn, you can change the date and time of the built-in clock and the display language of the multiplayer screen.

Date and time settings:
Select an item with the left and right direction buttons on the date / time setting screen, and change it with the up and down buttons. Select "OK" and press C to change the date and time and return to the user setting screen.

In the application, the date and time set by the user can be used. Don't be. To change the date and time, the user must set the date and time on the setting screen.

Language settings:
The display language of the multiplayer screen can be selected from the following six countries.
English, German, French, Spanish, Italian, Japanese

Multilingual applications must determine the default language from this user-configured language. In addition, if the user has the ability to change the supported language in the application, it is necessary to change the setting by a predetermined method so that it will be reflected in the multiplayer language setting.

Other settings / Help window:
You can select “Show / Hide” for the help window on the multiplayer screen.

Help window settings should not be referenced or changed by the application.

Other settings / Audio output:
Audio CD, CD + G, CD + EG audio output can be switched between stereo and monaural.

Mono-enabled applications need to determine the default audio output setting from this user-configured audio output setting there is. In addition, if there is a function that allows the user to change the audio output setting in the application, it is necessary to change the setting by a predetermined method so that it is reflected in the audio output setting of the multiplayer.

Other settings / sound effects:
You can select ON / OFF of sound effects on the multiplayer screen.

Sound effect settings must not be referenced or changed by the application.
