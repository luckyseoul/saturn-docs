Installation

Hardware setup

〈PC version〉
Start up the PC and set the PC version floppy disk in the floppy drive.
Be sure to read [README.DOC] in the root directory of the FD first. Describes how to install.

〈SUN version〉
Prepare the tape device.

〈HP version〉
Prepare for DAT.

■ Media

Release 2 is provided on the following media.
------------------------------------
PCVersion FD
SUN Version 8mm Tape
HP Version DAT
-------------------------------- ----

Installation method

〈PC version〉
The PC version can be installed for each library and tool.

Insert a floppy disk into the software library floppy drive and execute the [INSTALL] command. Install in the current directory. Install all libraries in a directory called [SATURN] in the current directory. If there is no [SATURN] directory, create it.
If the floppy drive is A drive and the installation destination is C drive, it will be as follows.

A directory called [C: \ USR \ SATURN \ ....] is created.
