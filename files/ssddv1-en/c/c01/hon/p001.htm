Introduction

Purpose of this binder

This document provides information necessary for developing application software, such as how to use tools, how to boot up, how to use libraries, how to create programs, and how to create CDs.

■ Target for this binder

This manual is intended for programmers who produce application software.
Release 1 basically only supported SATURN TARGET BIGBOX, but release 2 only supported SATURN TARGET MODEL M. Since there are some differences from the final product, please be sure to replace it with Release 3 (final release) when commercializing.

■ Other

In order to notify you of the latest accurate information as soon as possible, corrections to the manual contents and more detailed information will always be supplied with the software provided. Be sure to read the additional manual for the provided media. Additional manuals are in the directory [\ SATURN \ xxxxx \ MAN \].

In this guide, we try to collect, organize, and deliver the information needed by programmers with easy-to-use information. We would like to hear the voices of those who are using it as soon as possible, so please let us know what you think.
