      Indicates the creation information of the handle. Set various parameter values ​​to PCM_Create ~ as a structure. 

      typedef struct {
     PcmWork * work; / * Work start address * /
                             / * Work area when this library is played back * /
     Sint32 * ring_addr; / * Ring buffer address * /
                             / * When playing back data in memory, its address * /
     Sint32 ring_size; / * Ring buffer size [byte] * /
                             / * File size to play memory data * /
     Sint32 * pcm_addr; / * PCM buffer address of the sound memory * /
     Sint32 pcm_size; / * PCM buffer size of sound memory [sample / 1ch] * /
} PcmCreatePara;

      Note on PCM buffer

      • Reserve the PCM buffer in sound memory.
      • Specify an integer multiple of 4096 for the PCM buffer size. (Minimum 4096 x 2)
        If the
      • PCM buffer size is set to S [sample / 1ch], the number of bytes is interpreted as follows according to the playback conditions. 

         Playback conditions 
         PCM buffer size (bytes) 
         8bit monaural 
         S [byte] 
         8bit stereo 
         2 × S [byte] 
         16bit monaural 
         2 × S [byte] 
         16bit stereo 
         4 × S [byte]

      • Specify the same area (address, size) for smooth continuous playback.
      • Please specify another area for multi playback.
