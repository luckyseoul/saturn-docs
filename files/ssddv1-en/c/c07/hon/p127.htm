 Start playback 
  Function Name  
 PCM_Start 
No
3.1
 

  format  void PCM_Start (PcmHn pcm)
 Input  pcm: Handle
 Output  None
 Function value  None
 Function  Playback starts.
 Remarks  Playback can be performed only once for the generated handle.
  If you want to play the same file over and over again, generate a handle each time.
