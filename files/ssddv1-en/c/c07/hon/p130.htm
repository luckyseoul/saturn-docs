 Set playback volume 
  Function Name  
 PCM_SetVolume 
No
4.3
 

  format  void PCM_SetVolume (PcmHn pcm, Sint32 volume)
 Input  pcm: Handle
  volume: Volume (0-7)
 Output  None
 Function value  None
 Function  Specify the volume. (No output at 0, 7 at maximum volume)
 Default  is 7.
