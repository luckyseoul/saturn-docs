Debug support library

1. Guide

1.1 Purpose

By incorporating this library into the system under development, you can display character strings on the screen, enter data using the software keyboard, and read and write memory contents.

1.2 Description

  • This library uses the VDP2 graphic library to build a simple debug environment on top of NBG0 on the normal scroll screen. This library cannot be used without using the VDP2 graphic library.
  • This library supports only dedicated pads. This library cannot be used without using the peripheral library.

1.3 Program description example

An example of an actual program in C language is shown below. 

#include          "sega_scl.h"
#include          "sega_dbg.h"



void   err(Uint8 *mess);
Uint16 PadData;

main()
{
          SCL_Vdp2Init();
          DBG_Initial(&PadData,RGB16_COLOR(31,31,31),0);

          .......... / * Program * / 

          if(......)     
                    err ("An error occurred in the ~ function of main ()");
          .......... / * Program * / 



}

void err(Uint8 *mess)
{
          DBG_Printf ("% s \ n", mess); / * Display message * /
          DBG_Monitor (); / * Use simple debugging environment * / 

}
