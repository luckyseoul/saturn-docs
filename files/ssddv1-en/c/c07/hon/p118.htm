 Force switchability check value 
  Data Name  
 PCM_CHANGE_ ~ 
No
2.4

        Indicates the possibility of forced switching. 

         Constant Name 
         Description 
         PCM_CHANGE_OK_AT_ONCE 
         Can be forcibly switched immediately. 
         PCM_CHANGE_NO_DATA 
         Data supply is insufficient. When performing forced switching 
         (PCM_Change), continuous playback is not performed smoothly. 
         PCM_CHANGE_NO_ENTRY 
         PCM_EntryNext does not register the next handle. Forced switching (PCM_Change) cannot be performed.
