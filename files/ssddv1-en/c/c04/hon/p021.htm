● Intback command issue function

Get system data (excluding time)
  • There are no restrictions other than the common (above).

Peripheral data acquisition, time data acquisition

  • Do not issue a command from the issue of the backback command until the next V-BLANK IN.
  • Issue the intback command 14ms before the specified V-BLANK IN.
  • The peripheral data collection process in SMPC is performed during one vertical display period.
  • Data that could not be acquired before issuing V-BLANK IN after issuing the intback command (timeout) cannot be acquired thereafter.
  • If timeouts occur frequently, the peripheral is treated as not connected.
  • SMPC starts the peripheral acquisition so that it is 1ms before V-BLANK IN which specified the end of peripheral acquisition.
  • V-BLANK IN skip count
    The
      V-BLANK IN skip count indicates the execution timing of the peripheral data collection processing in the SMPC after issuing the intback command.
      It is prepared for games that change the frame in two frames or more.
      Peripheral data collection processing in SMPC is executed during V-DISP before V-BLANK IN for the first time (V-BLANK IN skip count + 1) after issuing the intback command.
      Set to 0 when executing to V-BLANK IN immediately after issuing the Intback command.
