7.2.5 Status and report 

  Title  
 Data specifications 
  Data  
 Status and reports ( 1/2) 
  Data Name  
 Status & CD Report 
  No 
5.0

(1) Response format

        The response consists of a status and a report. Whether to return a CD report as a report depends on the command. The periodic response always returns a CD report.
        The status and CD report are collectively called CD status information.

(2) Status

        When the status is FFH, it indicates REJECT (command invalid). The status code is always valid except during REJECT. Also, bit5 to bit7 are exclusive and cannot be 1 at the same time.
