(5) Decode subcodes R to W

(a) Start and end of decoding
    Decode ON / OFF is set with the CD block initialization command.
    To start decoding, set the decoding ON and then execute CD-DA playback.

(B) Decoding start timing
Decoding starts at
    〈PLAY〉.
    Actually, data acquisition starts from 2 frames before entering the 〈PLAY〉 state.

(C) Pack buffer clear timing
    Cleared when decoding starts.
    The contents of the pack buffer are retained even if you pause or seek.

(D) Decoding condition
Decoded only during
    CD-DA playback.
    It is not decoded in other cases (scan playback or CD-ROM playback). 

  Note Pack pack buffer is not cleared only by setting decode ON. Therefore, enter the 〈PLAY〉 state
If you issue an acquisition command before becoming, the pack data of the previous song may remain.
Please make sure to enter 〈PLAY〉 state before issuing the acquisition command.

(6) Subcode R to W error

(a) Overrun error
If the
    pack is not received in time, the pack buffer is overwritten and an overrun error occurs. After the data transfer is completed (when 23 packs are actually acquired without acquiring pack data), the acquisition pointer advances to a pack with no overrun error.

(B) Pack data error
The

    CD block performs a CRC check on the P series and Q series of packed data, and corrects the data if an error is detected.
    If correction is impossible, a pack data error will occur.
