SMPC I / F User's Manual

1. Purpose

This library is a library that uses SMPC (System Management & Peripheral Control) functions.

2. Features

  • The burden on the main CPU can be greatly reduced.
  • The interface between the main CPU and SMPC is a software handshake method using SMPC registers.
