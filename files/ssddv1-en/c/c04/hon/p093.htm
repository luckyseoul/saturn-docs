(4) Frame address exception

        Depending on the conditions, the frame address is interpreted as follows. 
         Condition 
         Start position, seek position 
         end position 
         FAD  
         FAD = start of disc (150) 
         FAD = top of disk -1 
         (the number of FAD sectors is 0) 
         FAD> End of disc 
         FAD = End of disc + 1 
         (equal to readout) 
         FAD = disc end 

         Relationship between start position and end position 
         Start FAD <150 
        : End FAD = Start FAD + Number of FAD sectors-1 
        : End FAD = 150 + number of FAD sectors-1
        The contents of the playback range that are retained are the start FAD and end FAD.

(5) Track / index exceptions

        Depending on the conditions, the track / index is interpreted as follows. 

         Condition 
         Start position, seek position 
         end position 
         TNO = 0 (the default value of the track) 
         TNO = the first track on the disc 
         TNO = last disc track 
         X = 0 (index default value) 
         X = 1 
         X = 99 (63H) 
         TNO  
         TNO = first disc track 
         X = 1 (same as X = 0) 
         TNO = first track on the disc 
         X = 99 (same as X = 0) 
         TNO> final disc track 
         TNO = final disc track 
         X = 1 (same as X = 0) 
         TNO = last disc track 
         X = 99 (same as X = 0) 
         X does not exist 
         (from the next track) 
         (Until the end of the track)
        TNO: Track number, X: Index number

        X = 0 means that only the track is specified. (Track start / end index)
        TNO = X = 0 is the default value for the position parameter.
        (Start position: start of disk, end position: end of disk, seek position: home position)

(6) Exceptions to playback range

        If the end position is less than the start position, the playback range is retained, but the CD is not played.
        (For both frame address specification and track / index specification)

(7) Meaning of special specification 

         
      •  Specifying the default value for the seek position: Used as a stop command.
.. (Seek to home position)

      •  Seek position unchanged: Used as a pause command.

      •  Play range unchanged specification: Used for pause release (resume CD playback).
