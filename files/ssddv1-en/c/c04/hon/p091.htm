6.1

        The status of the CD block and the CD report are collectively called CD status information.

(1) CD status information …… CDC_GetCurStat, CDC_GetLastStat, CDC_GetPeriStat function

        CdcStat * stat 
         Access macro 
         type 
         Description 
         CDC_STAT_STATUS (stat) 
         Uint8 
         Status (status code Etc.) 
         CDC_STAT_FLGREP (stat) 
         Uint8 
         CD report CD Flag and repeat count 
         CDC_STAT_CTLADR (stat) 
         Uint8 
         CD report CONTROL / ADR byte 
         CDC_STAT_TNO (stat) 
         Uint8 
         CD report track Number (binary value) 
         CDC_STAT_IDX (stat) 
         Uint8 
         CD report index Number (binary value) 
         CDC_STAT_FAD (stat) 
         Uint32 
         CD report frame Address

(2) Related macros 

         macro name 
         description 
         CDC_GET_STC (stat) 
         Get status code from CD status information 
         CDC_GET_REPEAT (stat) 
         Get repeat count from CD status information
