    (3) Standby time

    Specify the time from 〈PAUSE〉 to 〈STANDBY〉 transition.
    Transition to 〈STANDBY〉 state when standby time elapses in 〈PAUSE〉 state. 

     setting value 
     description 
     0000H 
     180 seconds (3 minutes) …… Initial value 
     003CH-0384H 
     (60-900) 
     Transition time (in seconds) …… 60-900 seconds ( 1 to 15 minutes) 
     (Minimum value: CDC_STNBY_MIN, Maximum value: CDC_STNBY_MAX) 
     FFFFH 
     Do not change settings (CDC_PARA_NOCHG)

    (4) ECC count

    ∙ Specify the number of ECC processing (PQ correction once) for CD-ROM decoding. 

     setting value 
     description 
     00H 
     ECC is processed only once in real time …… Initial value 
     01H to 05H 
     Maximum number of repetitions when there is an error after ECC processing (total 2 to 6 times) 
     80H 
     No ECC processing 
     FFH 
     Do not change settings

    (A) Applies to Mode1 or Form1 sectors.
    (B) When bit2 = 1 of initialization flag (Mode2 subheader is not recognized), Mode2 ECC processing is not performed.
