  Title  
 Function specifications 
  Function  
 Operate power-on-clear memory 
Function Name
SYS_PCLRMEM
 
No
7.1
 

 Format  Uint8 * SYS_PCLRMEM
 Input  Perform normal memory access.
 Output  〃
 No function value 
 Function  This is an 8-byte memory address managed by the BOOT ROM. This memory is initially set to 0 only at power-on startup
  is initialized, but the contents are retained with the reset button (NMI).
 Remarks  The range is not checked. Be careful not to access outside the range.
