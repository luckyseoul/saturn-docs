5.3.3 Connector

(1) Connection from buffer section to aperture (copy / move sector data)

The sector data can be copied / moved by connecting the partition output connector to the aperture input connector and flowing the sector data. The connection / inflow / outflow process is executed by issuing a single command.

Figure 5.6 Copy / move sector data

(2) Selector connection by OR condition (many-to-one connection)

Multiple aperture true output connectors can be connected to the same compartment input connector. This allows you to store sectors that meet any of several conditions. (OR condition: OR condition)
