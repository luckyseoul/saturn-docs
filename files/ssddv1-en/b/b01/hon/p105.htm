■ 6.7 CMDXA to CMDYD (vertex coordinate data)

Specify coordinates such as clipping area coordinates and sprite drawing vertex coordinates in CMDXA to CMDYD. Up to 4 vertex coordinates (X coordinate, Y coordinate) can be specified. Define the command table start address + 16 bytes (8 words) from 0CH to + 1AH.

  • The coordinates are 16bit each and are specified in CMDXA to CMDYD Negative numbers are specified in 2's complement. The range that can be specified is -1024 to 1023. The upper 5 bits are the same as bit 10 for sign extension.
  • The meaning of CMDXA to CMDYD varies depending on each command. The correspondence between commands and CMDXA to CMDYD is as follows. Refer to each command for details.
