Chapter 3 Process Flow

Drawing process flow

The flow of drawing procedure using VDP1 is as follows. 

Procedure 1. Turn on the system.
Step 2. Set the required value in the system register of VDP1.
Step 3. Write the necessary character pattern table to VRAM.
Step 4. Write the necessary color lookup table to VRAM.
Step 5. Write the required Gouraud shading table to VRAM.
Step 6. Write the necessary command table to VRAM.
Step 7. Simultaneously with the frame change, drawing automatically starts in the frame buffer.
Displayed at the next frame change.
Step 8. Repeat steps 3 to 6 as necessary.
