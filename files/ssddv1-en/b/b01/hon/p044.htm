Even / odd coordinate select bit: even / odd coordinate select bit (EOS), bit 4
  • This bit is valid when high-speed shrink (HSS) is set to 1 for rectangular sprites or deformed sprites. If HSS = 1 is specified, the line with the drawing magnification <1 is drawn by sampling only the pixels of the even or odd coordinates of the original picture data. This bit specifies whether to sample even or odd coordinates.
  • When EOS = 0, only pixels with even coordinates are sampled. When EOS = 1, only pixels with odd coordinates are sampled.
  • If HSS = 0 is specified, this bit is not referenced.
  • For details, see “High-speed shrink” in “6.3 Drawing Mode Word”. 

     EOS 
     Even / odd coordinate selection bit 
     0 
     sample even pixels only 
     1 
     sample only odd-coordinate pixels
