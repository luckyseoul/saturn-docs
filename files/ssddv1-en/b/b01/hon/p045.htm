4.3 Plot trigger register

The plot trigger register (PTMR, Plot trigger mode register) controls the start of drawing. This is a write-only 16-bit register at address 100004H. The value is reset to 00B after the power is turned on or reset. Fix unused bits to 0.

Plot trigger mode: Plot trigger mode (PT), bit 1, 0
  • Controls drawing start.
  • When plot trigger mode is 10B, drawing starts automatically as soon as the frame starts.
  • When plot trigger mode is set to 01B, drawing starts when it is written to the register. If 01B is written to the plot trigger mode during drawing, drawing starts from the top of the command table at that point.
  • When plot trigger mode is 00B, drawing will not start even if the frame starts. It will be idling.
  • After power-on or reset, the value is reset to 00B.

  • When plot trigger mode is rewritten from 01B to 00B or 10B, it becomes effective from the next frame buffer switching timing. However, when the plot trigger mode is changed from 00B or 10B to 01B, it becomes effective at that point, and drawing starts even after automatic drawing by 10B.
  • If the table is not rewritten, the same drawing will be performed, so the result of the translucent color operation will change. If you want to change only the drawing start mode without drawing, do as follows. 
     (1) Change the plot trigger mode from 10B to 00B.
(2) At the next frame, change the plot trigger mode from 00B to 01B.
