When the system register setting value changes
The timing when the system register setting value becomes valid is as follows.

  • Change immediately
      Plot trigger mode (when PTM, 01B is written)
      TV mode selection (TVM)

  • Changes every field (1/60 second)
      Frame buffer switching mode (FCM)
      Frame buffer switching trigger (FCT)

  • Things switched by frame buffer switching
      Plot trigger mode (when PTM, 00B or 10B is written)
      Even / odd coordinate selection bit (EOS)
      Double dense interlace enabled (DIE)
      Double dense interlace drawing line (DIL)
      Erase light data
      Erase light coordinates (upper left, lower right)

  • Change after one line display after V blank IN interrupt
      V Blank Erase Write Permission (VBE)
