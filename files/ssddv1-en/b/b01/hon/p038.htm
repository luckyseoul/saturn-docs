4.2 Frame buffer switching mode register

Frame buffer switching mode register (FBCR, Frame buffer change register) controls frame buffer drawing, display switching, and double-dense interlace drawing. This is a write-only 16-bit register at address 10002H. Since the value is undefined after the power is turned on or reset, be sure to set the switching mode. Set unused bits to 0.

Frame buffer change mode bit: frame buffer change mode (FCM), bit 1

Frame buffer change trigger bit: frame buffer change trigger (FCT), bit 0

  • Normally, two frame buffers use one for the front and the other for the back. Display the front side and draw on the back side. After one frame switching time has elapsed, the front and back sides are toggled. The front side that was being displayed becomes the back side to be drawn, and the back side that was being drawn becomes the front side to be displayed.
  • The frame buffer can be accessed only on the drawing side. It cannot be displayed.
  • There is a limit to the number of characters that can be drawn in one frame, so if you want to draw many characters, set to manual mode and control erase and change from the CPU.
  • When any data is written from the CPU to the FBCR, the values ​​of FCM and FCT are updated inside VDP1 at the time of field change.
  • In manual mode, the FCT bit setting is valid only for the next frame. The contents of FCT are updated internally when a frame change occurs.
  • Set FCM and FCT immediately after the V blank OUT interrupt. Access is prohibited from the first H blank IN interrupt after the V blank OUT interrupt to the next H blank IN interrupt.
