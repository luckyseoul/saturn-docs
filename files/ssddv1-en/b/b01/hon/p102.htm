■ Non-textured color

  • Non-textured color defines the color of non-textured parts.
  • For non-textured parts, the non-textured color is written to the frame buffer as pixel data.
  • Non-texture color is not related to transparent color code and end code.
  • When the display mode is 8bit / pixel, the lower 8bit is valid. In this case, only the color bank code can be specified.
  • When performing color operations (excluding shadows) on non-texture parts, be sure to set the RGB code for the non-texture color.
