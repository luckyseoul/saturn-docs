6.6 CMDSIZE (character size)

CMDSIZE specifies the size of the defined character pattern. CMDSIZE is valid for texture drawing commands. Specify 16 bits in the command table start address + 0AH. Set unused bits to 0.

  • Specify the character pattern size in multiples of 8 for horizontal (X) and 1 pixel for vertical (Y).
  • Besides 5 bits, you can specify a value between 1 and 63. Since it is in 8 pixel units, the actual size can be 8 to 504 pixels. Do not specify 0.
  • Vertical is 8 bits and a value between 1 and 255 can be specified. Do not specify 0.
