  • Returns within the command main routine (return, jump return, skip return) are prohibited.
  • Zoom point values ​​are only 0H, 5H, 6H, 7H, 9H, AH (10), BH (11), DH (13), EH (14), and FH (15). Any other setting is prohibited.
  • When HSS = 1, the end code of the original picture is ignored regardless of whether the sprite is enlarged or reduced.
  • Set the lower 2 bits of CMDLINK to 00.
  • Set the lower 2 bits of the lookup table to 00.
  • When setting the color bank, set 0000 to the lower 4 bits of the color bank data.
  • Set to ECD = 1, SPD = 1, and color mode = 0 when non-texture.
  • When performing color calculation with non-texture, set RGB data (8000H or higher) for non-texture color.
  • If you set to RGB mode and use 7FFFH data for the original picture, set ECD = 0.
  • When using RGB mode and using 0000H data for the original picture, set SPD = 0.
  • When the RGB mode is set, setting the frame buffer to 8 bits / pixel is prohibited. The only color modes that allow 8 bits / pixel are modes 0, 1, 2, 3, and 4.
  • When the frame buffer is set to 8 bits / pixel, set the color calculation mode to 0. Only replacement is possible. Other color operations are prohibited.
  • When the frame buffer is set to 8 bits / pixel, the upper 8 bits of the non-texture color are ignored. At this time, the use of RGB data is prohibited.
  • Do not set the MSB on bit (MON) to 1 when the frame buffer is set to 8 bits / pixel.
  • When the MSB on bit (MON) is set to 1, set the color calculation mode to 0.
  • Store the command table at 000000H address of VRAM.
