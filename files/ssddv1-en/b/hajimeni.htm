Hardware Manual Vol.2


Introduction


Purpose of this binder

    This manual is a manual for understanding the hardware configuration and overview of this system, and for learning about various hardware functions and how to use them.


■ Target for this binder

    This document is intended for programmers who develop programs on this system.


■ Composition of this binder

    This document consists of the following two manuals.

    1. "VDP1 User's Manual"

      VDP1 is an IC that controls sprites. This manual describes the system configuration and various functions of VDP1.

    2. "VDP2 User's Manual"

      VDP2 is an IC that controls the scroll screen and the display priority. This manual describes the system configuration and various functions of VDP2.
