Shadow function

The shadow function is a function to add a sprite character shadow on each screen.
There are two types of sprites that can be used as shadows: normal shadow and MSB shadow. Normal shadows can only be added to the scroll screen. MSB shadows can add shadows to sprites as well as scroll screens.
