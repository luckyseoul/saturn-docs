■ Bitmap palette number register

Bitmap palette number register specifies the palette number and special function bits when the scroll screen is displayed in bitmap format. This is a write-only 16-bit register located at addresses 18002CH to 18002EH. The value is cleared to 0 after power-on or reset, so be sure to set it.

Special priority bit (for bitmap) : Bit map special priority bit

(N0BMPR, N1BMPR, R0BMPR)
Specified special priority bit when scroll screen is displayed in bitmap format.

N0BMPR 18002CH bit 5 NBG0
N1BMPR 18002CH Bit 13 For NBG1
R0BMPR 18002EH bit 5 For RBG0

Please refer to “ 11.2 Special priority function ” for the usage of this bit.

Special color calculation bit (for bitmap) : Bit map special color calculation bit
(N0BMCC, N1BMCC, R0BMCC)
Specified special color calculation bit when scroll screen is displayed in bitmap format.

N0BMCC 18002CH Bit 4 NBG0
N1BMCC 18002CH Bit 12 For NBG1
R0BMCC 18002EH Bit 4 For RBG0

Please refer to “ 12.2 Special Color Arithmetic Function ” for how to use this bit.
