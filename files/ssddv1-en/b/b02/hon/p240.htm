Color control control register

Color calculation control register controls color calculation. This is a write-only 16-bit register located at address 1800ECH. The value is cleared to 0 after power-on or reset, so be sure to set it.

Bokeh operation enable bit : Gradation enable bit (BOKEN), bit 15

Specify whether to use the blur calculation function.

BOKEN Process
0 Do not use the blur calculation function
1 Use the blur calculation function

∙ When this bit is set to 1, the extended color calculation function cannot be used.
The blur calculation function can be used only when the TV screen mode is normal mode and the color RAM mode is mode 0.

Bokeh screen number bit : Gradation number bit (BOKN2 to BOKN0), bits 14 to 12
Specify the screen that uses the blur calculation function.

BOKN2 BOKN1 BOKN0 Calculation function use screen
0 0 0 Sprite
001RBG0
0 1 0 NBG0 or RBG1
0 1 1 Setting prohibited
1 0 0 NBG1 or EXBG
101NBG2
110NBG3
1 1 1 Setting prohibited

Extended color calculation enable bit : Extended color calculation enable bit (EXCCEN), bit 10
Specify whether to use the extended color calculation function.
