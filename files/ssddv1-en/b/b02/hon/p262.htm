Chapter 15 How to use VDP2

15.1 Operation flow

An example of the procedure for defining and setting VDP2 data is as follows.

Procedure 1. Set the TV screen mode.

    • Select normal graphics, high resolution graphics, or dedicated monitor
    • Interlace mode setting
    • Set vertical resolution and horizontal resolution
Step 2. Select the scroll screen to be used.
    • Normal scroll screen (NBG0, NBG1, NBG2, NBG3)
    • Rotary scroll screen (RBG0, RBG1)
    • External input screen (EXBG)
    • Line color screen (LNCL)
    • Back screen (BACK)
Step 3. Select the function of each screen.
    • Select cell format or bitmap format.
    (1) In cell format
    • Character color depth
    • Character size
    • Pattern name data size
    • Plane size
    • Scaling function
    • Line scroll function
    • Vertical cell scroll function
    • Mosaic processing function
    (2) In bitmap format
    • Bitmap color depth
    • Bitmap size
    • Scaling function
    • Rotation function
    • Mosaic processing function
Step 4. Select color RAM mode.
Step 5. Select the window to use.
    When using a normal line window, the line window table is stored in VRAM.
