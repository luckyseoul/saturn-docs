4.2 scroll screen configuration

The scroll screen has two screen formats: cell format and bitmap format.

■ Cell format

Scroll screen in cell format is “cell” which is a picture pattern of horizontal 8 dots x vertical 8 dots, “character pattern” where cells are arranged in horizontal 1 × vertical 1 or horizontal 2 × vertical 2 `` Page '' in which the pattern is arranged in 32 x 32 or 64 x 64 in the horizontal direction, `` Plain '' in which the page is arranged in horizontal 1 x vertical 1, horizontal 2 x vertical 1, or horizontal 2 x vertical 2 It consists of a “map” arranged in 2 x vertical 2 (for normal scroll screen) or horizontal 4 x vertical 4 (for rotating scroll screen). Figure 4.1 shows the configuration of the cell-type scroll screen.

Figure 4.1 Cell format scroll screen configuration

The cell data is the dot color data stored in VRAM as a character pattern table. Color data is 4, 8, 16, or 32 bits depending on the number of character colors. Character pattern data consists of 1 or 4 cell data. Page data is the character pattern name data (character pattern data address) stored as a pattern name table. One, two, or four page data are arranged as a plane. The map specifies the start address of the pattern name table in the map register and map offset register.
