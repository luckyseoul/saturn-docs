xxSDEN Process
0 Do not use shadow function (do not add shadow)
1 Use shadow function (add shadow)

Transparent shadow select bit : Transparent shadow select bit (TPSDSL), bit 8
Specify whether or not to enable sprites for transparent shadows.

TPSDSL Process
0 Disable transparent shadow sprites
1 Enable transparent shadow sprite

If you disable the transparent shadow sprite, you will not be able to add shadows to the transparent shadow sprite on any screen.
