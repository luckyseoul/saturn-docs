EXCCEN Process
0 Do not use extended color calculation function
1 Use extended color calculation function

∙ It cannot be used at the same time as the blur calculation function. When the BOKEN bit is 1, this bit is ignored.
∙ The extended color calculation function can be used only when the TV screen mode is the normal mode and cannot be used when the high resolution or dedicated monitor mode is used.

Color calculation ratio mode bit : Color calculation ratio mode bit (CCRTMD), bit 9
Specify the color calculation ratio mode.

CCRTMD Mode Processing
0 0 Specify the color calculation ratio on the top image
1 1 Specify the color calculation ratio on the second image side

∙ Whether to perform normal color calculation is always specified on the top image side.

Color calculation mode bit : Color calculation mode bit (CCMD), bit 8
Specify the color calculation mode.

CCMD Mode Processing
0 0 Add according to the value of the color calculation ratio register
1 1 Add as it is

When in mode 1, the value of the color calculation ratio register on each screen is ignored.
