Map offset bit : Map offset bit
(N0MP8 to N0MP6, N1MP8 to N1MP6, N2MP8 to N2MP6, N3MP8 to N3MP6, RAMP8 to RAMP6, RBMP8 to RBMP6)
∙ When the display format of the scroll screen is cell format, specify the 3-bit map offset value to be added to the upper part of the 6-bit map register. For bitmap format, specify the bitmap pattern boundary.

N0MP8 to N0MP6 18003CH Bits 2 to 0 NBG0 For
N1MP8 to N1MP6 18003CH Bits 6 to 4 For NBG1
N2MP8 to N2MP6 18003CH Bits 10 to 8 For NBG2
N3MP8 to N3MP6 18003CH Bits 14 to 12 For NBG3
RAMP8 to RAMP6 18003EH Bits 2 to 0 For rotation parameter A
RBMP8 to RBMP6 18003EH Bits 6 to 4 For rotation parameter B

The boundary address of the bitmap pattern is as follows.
(Bitmap pattern boundary address value) = (Map offset register value 3 bits) x 20000H
