The actual top VRAM address is calculated using the following formula. If the VRAM capacity is 4M bits, the most significant bit of the address is ignored. 

 (Back screen table start address) = (Back screen table address register value 19 bits) × 2H

When the back screen color mode bit is set to “monochrome”, the color data specified by the back screen table address bit is used for the entire screen.
