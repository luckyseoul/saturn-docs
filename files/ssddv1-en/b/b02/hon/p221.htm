Special function code select register

Special function code select register specifies the special function code to be enabled for each scroll screen. This is a write-only 16-bit register located at 180024H. The value is cleared to 0 after power-on or reset, so be sure to set it.

Special function code select bit : Special function code select bit (N0SFCS, N1SFCS, N2SFCS, N3SFCS, R0SFCS)

Specify the special function code to be enabled for each scroll screen.

N0SFCS 180024H Bit 0 For NBG0 (or RBG1 For use)
N1SFCS 180024H Bit 1 For NBG1
N2SFCS 180024H Bit 2 For NBG2
N3SFCS 180024H Bit 3 For NBG3
R0SFCS 180024H Bit 4 For RBG0

xxSFCS Process
0 Enable special function code A
1 Enable special function code B
[Note] N0, N1, N2, N3, or R0 is entered in the bit name xx.
