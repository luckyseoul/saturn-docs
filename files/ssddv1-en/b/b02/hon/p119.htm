Mosaic enable bit : Mosaic enable bit (N0MZE, N1MZE, N2MZE, N3MZE, R0MZE)
Specify the screen for mosaic processing.

N0MZE 180022H Bit 0 For NBG0 (or RBG1)
N1MZE 180022H Bit 1 For NBG1
N2MZE 180022H Bit 2 For NBG2
N3MZE 180022H Bit 3 For NBG3
R0MZE 180022H Bit 4 For RBG0

xxMZE Process
0 Do not perform mosaic processing
1 Mosaic processing
[Note] N0, N1, N2, N3, or R0 is entered in the bit name xx.

* When mosaic processing is performed on the rotating scroll surface, only horizontal mosaic processing is performed.
When performing mosaic processing in double dense interlace mode, the screen is forcibly displayed in single dense interlace mode.
If you perform mosaic processing on NBG0 or NBG1, the vertical cell scroll function cannot be used on the mosaic processed screen. Therefore, the display screen at that time is the one that has been subjected to mosaic processing on the screen when vertical cell scrolling is not performed.
