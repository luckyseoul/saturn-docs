■ Screen over processing

When displaying the
rotation scroll screen, if the display coordinate value of the calculation result exceeds the specified display area, select one of the following four and set it in the register. Screen over processing is not set for RBG0 and RBG1, but for scroll screens using rotation parameter A and scroll screens using rotation parameter B. 
 (1) The image set in the display area is repeated outside the display area.
(2) Outside the display area, the character pattern specified in the screen over pattern name register is repeated.
(Only when the rotary scroll screen is in cell format).
(3) Make everything outside the display area transparent.
(4) The display area is forcibly set to 0 ≦ X <512, 0 ≦ Y <512 regardless of the plane size or bitmap size.

Screen over pattern name

The pattern name data when the specified character pattern is repeated in the screen over processing setting is specified in the 16-bit screen over pattern name register. The screen over pattern name data specified in the register is handled in the same way as when the data size of the pattern name table on the scroll surface is 1 word, and there are insufficient bits using the lower 10 bits of auxiliary data in the pattern name control register. To make the screen over pattern name data of a total of 26 bits. The bit structure of the screen over pattern name register is when the pattern name data size is 1 word as shown in “ Pattern name data ” of “ 4.6 Pattern name table ” It changes according to the character size, the number of character colors, and the character number assist mode. The size of the repeated character pattern depends on the character size setting.
The 16-bit screen over pattern name data is specified for the scroll screen with the rotation parameter A and the scroll screen with the rotation parameter B, but the 10-bit auxiliary data specified in the pattern name control register is for RBG0 and RBG1. Please note that Also, the screen over pattern name data cannot be used when displaying the rotary scroll screen in bitmap format.
