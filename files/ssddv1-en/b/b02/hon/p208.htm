Sprite window enable bit : Sprite window enable bit (SPWINEN), bit 4
Please refer to “ 8.1 Window Area ”.

Sprite type bit : Sprite type bit (STYPE3 ~ STYPE0), bit 3 ~ 0
Specify the sprite type.

STYPE3STYPE2STYPE1 STYPE0 Sprite data type
0 0 0 0 Type 0
0 0 0 1 Type 1
0 0 1 0 Type 2
0 0 1 1 Type 3
0 1 0 0 Type 4
0 1 0 1 Type 5
0 1 1 0 Type 6
0 1 1 1 Type 7
1000 Type 8
1 0 0 1 Type 9
1 0 1 0 Type A
1 0 1 1 Type B
1100 Type C
1 1 0 1 Type D
1110 Type E
1 1 1 1 Type F

Specify type 0 to 7 when sprite data is 16 bits per dot, and type 8 to F when it is 8 bits.
