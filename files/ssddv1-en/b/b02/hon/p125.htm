The screen scroll value register value is valid up to a range that does not exceed the display area of ​​each screen. When the display area is exceeded, the display area screen is displayed repeatedly.
Please specify a positive value for all screen scroll values.
Scroll value can be changed from the middle of the screen by changing the value during the horizontal blanking period.
