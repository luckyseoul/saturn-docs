Window position bit (for horizontal coordinates) : Window start / end X bit
(W0SX9 to W0SX0, W0EX9 to W0EX0, W1SX9 to W1SX0, W1EX9 to W1EX0)
∙ Specify the horizontal start and end coordinates. The specified coordinate value is the coordinate value (H counter value) on the TV screen.

W0SX9 to W0SX0 1800C0H Bits 9 to 0 W0 For start point coordinates
W0EX9 to W0EX0 1800C4H Bits 9 to 0 For W0 end point coordinates
W1SX9 to W1SX0 1800C8H Bits 9 to 0 For W1 start point coordinates
W1EX9 to W1EX0 1800CCH Bits 9 to 0 For W1 end point coordinates

The register bit configuration varies depending on the graphic mode setting. For normal graphics, the least significant bit is invalid data. In the case of dedicated normal graphics, the most significant bit becomes invalid data. In the case of dedicated high-resolution graphics, the most significant bit is invalid data, and since there is no bit for H0, the value is in units of 2 pixels.

Window position bit (for vertical coordinates) : Window start / end Y bit
(W0SY8 to W0SY0, W0EY8 to W0EY0, W1SY8 to W1SY0, W1EY8 to W1EY0)
∙ Specify the start and end coordinates in the vertical direction. The coordinate value to be specified is the coordinate value (V counter value) on the TV screen.

W0SY8 ~ W0SY0 1800C2H bits 8-0 For W0 start point coordinates
W0EY8 to W0EY0 1800C6H bits 8 to 0 For W0 end point coordinates
W1SY8 to W1SY0 1800CAH bits 8 to 0 For W1 start point coordinates
W1EY8 to W1EY0 1800CEH bits 8 to 0 For W1 end point coordinates
