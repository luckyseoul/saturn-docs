External latch flag : External latch flag (EXLTFG), bit 9
Indicates whether the HV counter value is latched in the HV counter register by an external signal. When the screen status register is read, it is cleared to 0. 

 EXLTFG 
 HV counter value status 
 0 
 Not yet latched in register 
 1 
 latched in register

External synchronization flag : External SYNC flag (EXSYFG), bit 8
Indicates whether the internal circuit is synchronized by an external synchronization signal. When the screen status register is read, it is cleared to 0. 

 EXSYFG 
 External synchronization state 
 0 
 not sync 
 1 
 Internal circuit synchronized

V blank flag : Vertical blank flag (VBLANK), bit 3
Indicates the vertical scanning status of the TV screen. 

 VBLANK 
 Vertical scanning state 
 0 
 Scanning is in the vertical display period 
 1 
 Scan during vertical blanking (VBLANK)

H blank flag : Horizontal blank flag (HBLANK), bit 2
Indicates the horizontal scanning status of the TV screen. 

 HBLANK 
 Horizontal scan state 
 0 
 Scan is in horizontal display 
 1 
 Scan during horizontal retrace (HBLANK)
