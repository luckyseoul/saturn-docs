N0W1E 1800D0H Bit 3 Transparency processing For window NBG0 (or RBG1)
N1W1E 1800D0H Bit 11 For NBG1 (or EXBG)
N2W1E 1800D2H Bit 3 Transparency processing window for NBG2
N3W1E 1800D2H Bit 11 Transparency processing window for NBG3
R0W1E 1800D4H Bit 3 Transparency processing window for RBG0
SPW1E 1800D4H Bit 11 For sprites in transparency window
RPW1E 1800D6H Bit 3 For rotation parameter window
CCW1E 1800D6H Bit 11 For color operation window

xxW1E Process
0 Do not use W1 window
1 Use W1 window
[Note] The bit name xx is N0, N1, N2, N3, R0, SP, RP, or CC.

Window enable bit (for SW) : SW enable bit
(N0SWE, N1SW, N2SWE, N3SWE, R0SWE, SPSWE, CCSWE)
∙ Specify whether to use the sprite window SW for each screen.

N0SWE 1800D0H bit 5 NBG0 in transparency window (Or RBG1)
N1SWE 1800D0H Bit 13 For NBG1 (or EXBG) in the transparency window
N2SWE 1800D2H Bit 5 Transparency processing window for NBG2
N3SWE 1800D2H Bit 13 Transparency processing window for NBG3
R0SWE 1800D4H Bit 5 Transparency window for RBG0
SPSWE 1800D4H Bit 13 For transparency window sprites
CCSWE 1800D6H Bit 13 For color operation window

xxSWE Process
0 Do not use SW window
1 Use SW window
[Note] N0, N1, N2, N3, R0, SP, or CC is entered in the bit name xx.

When using the sprite window, set the sprite window enable bit (SPWINEN) in the sprite control register to 1.

Window area bit (for W0) : W0 area bit
(N0W0A, N1W0A, N2W0A, N3W0A, R0W0A, SPW0A, RPW0A, CCW0A)
∙ Specify which of the effective areas of the normal window W0 to be used for each screen.
