● Inversion function bit

The inversion function bit is 2-bit data and specifies whether to use the inversion function for the character pattern displayed at that position. The inversion function bit has the up / down inversion 064 left / right inversion bit that inverts the character pattern up and down. Table 4.7 shows the inversion function bits, and Figure 4.12 shows an example of character pattern inversion display.

Table 4.7 Inversion function bit 
 Vertical flip bit 
 Vertical flip bit
Processing

0 1

1 0

1 1
