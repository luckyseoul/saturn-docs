 DASEL 
 Processing 
 0 
 Display images only in the settings display area 
 1 
 Display image in all standard display areas

When displaying in all standard display areas, images from external screen data will be displayed correctly in all. However, images outside the other setting display areas (sprites, scroll screens, etc.) cannot be displayed correctly. Therefore, use the windows to force other images to become transparent except in the setting display area.

External screen enable bit : EXBG enable bit (EXBGEN), bit 0
Controls input of external screen data. 

 EXBGEN 
 Processing 
 0 
 Do not enter external screen data  
 1 
 Enter external screen data

When inputting external screen data, the data will be NBG1 screen data, so the external screen settings for NBG1 will be used.
