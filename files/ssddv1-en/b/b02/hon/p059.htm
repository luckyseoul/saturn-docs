4.4 Character pattern

The character pattern is a square pattern consisting of 1 or 4 cells, and its size is specified in each register.

■ Character size and cell placement

When the character pattern consists of 4 cells, the cell data used for the same character pattern must be stored continuously in the character pattern table.
