Line scroll enable bit (for horizontal screen scroll value) : Line scroll X enable bit
(N1LSCX, N0LSCX)
Specified whether to scroll in line units in the horizontal direction.

N0LSCX 18009AH Bit 1 For NBG0
N1LSCX 18009AH Bit 9 NBG1

NxLSCX Process
0 Do not scroll horizontally in line units
1 Scroll horizontally by line
[Note] 0 or 1 is entered in x of the bit name.

When using this function, be sure to store the horizontal screen scroll value in the VRAM line scroll table.

Vertical cell scroll enable bit : Vertical cell scroll enable bit
(N1VCSC, N0VCSC)
Specified whether to perform vertical cell scrolling.

N0VCSC 18009AH Bit 0 For NBG0
N1VCSC 18009AH Bit 8 For NBG1

NxVCSC Process
0 No vertical cell scrolling
1 Use vertical cell scrolling
[Note] 0 or 1 is entered in x of the bit name.

When using the vertical cell scroll function, be sure to specify the vertical cell scroll table data read access command in the VRAM cycle pattern register. Be sure to store the vertical cell scroll data in VRAM.
The vertical cell scroll function cannot be used at the same time as the mosaic function, and the mosaic function has priority.
