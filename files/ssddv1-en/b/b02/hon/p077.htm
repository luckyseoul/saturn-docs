xxPNB Pattern name data size
0 2 words

[Note] N0, N1, N2, N3, or R0 is entered in the bit name xx.

Character number supplement mode bit : Character number supplement bit
(N0CNSM, N1CNSM, N2CNSM, N3CNSM, R0CNSM)
Specified character number auxiliary mode when the pattern name data size on the pattern name table is 1 word.

N0CNSM 180030H Bit 14 For NBG0 (or RBG1)
N1CNSM 180032H Bit 14 For NBG1
N2CNSM 180034H Bit 14 For NBG2
N3CNSM 180036H Bit 14 For NBG3
R0CNSM 180038H Bit 14 For RBG0

xxCNSM Character number
Auxiliary mode 		Processing
0 0 The character number in the pattern name data is 10 bits.
Invert function can be specified for each character
1 1 The character number in the pattern name data is 12 bits.
Invert function cannot be used
[Note] N0, N1, N2, N3, or R0 is entered in the bit name xx.

Special priority bit (for pattern name auxiliary data) : Supplementary special priority bit
(N0SPR, N1SPR, N2SPR, N3SPR, R0SPR)
Specified special priority bit as pattern name auxiliary data when pattern name data size is 1 word.

N0SPR 180030H Bit 9 For NBG0 (or RBG1)
N1SPR 180032H Bit 9 For NBG1
N2SPR 180034H Bit 9 For NBG2
N3SPR 180036H Bit 9 For NBG3
R0SPR 180038H Bit 9 For RBG0

Please refer to “ 11.2 Special priority function ” for the usage of this bit.
