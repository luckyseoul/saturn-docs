Color calculation ratio register

Color calculation ratio register specifies the color calculation ratio. This is a write-only 16-bit register located at addresses 180108H to 18010EH. The value is cleared to 0 after power-on or reset, so be sure to set it.

Color calculation ratio bit (for scroll screen) : Color calculation ratio bit

(N0CCRT4 to N0CCRT0, N1CCRT4 to N1CCRT0, N2CCRT4 to N2CCRT0, N3CCRT4 to N3CCRT0, R0CCRT4 to R0CCRT0, LCCCRT4 to LCCCRT0, BKCCRT4 to BKCCRT0)
Specify the color calculation ratio for each scroll screen. The color calculation ratio is for 1/32 times the RGB color data.

N0CCRT4 to N0CCRT0 180108H bits 4 to 0 NBG0 (Or RBG1)
N1CCRT4 to N1CCRT0 180108H bits 12 to 8 For NBG1 (or EXBG)
N2CCRT4 to N2CCRT0 18010AH Bits 4 to 0 For NBG2
N3CCRT4 to N3CCRT0 18010AH Bits 12 to 8 For NBG3
R0CCRT4 to R0CCRT0 18010CH Bits 4 to 0 For RBG0
LCCCRT4 ~ LCCCRT0 18010EH bits 4-0 For LNCL
BKCCRT4 to BKCCRT0 18010EH Bits 12 to 8 For BACK
