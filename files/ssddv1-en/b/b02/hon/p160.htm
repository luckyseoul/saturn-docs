■ Rotation parameter switching

RBG0 can specify which of the two sets of rotation parameter tables to use, and can partially switch rotation parameters on one display screen. The rotation parameter can be used from the following four rotation parameter modes. 
 mode 0: Use rotation parameter A
Mode 1: Use rotation parameter B
Mode 2: The image is switched according to the coefficient data read from the coefficient table of the rotation parameter A
Mode 3: Switch by rotation parameter window

* In modes 0 and 1, images obtained by one set of rotation parameter tables are displayed. In modes 2 and 3, the image obtained with rotation parameter A and the image obtained with rotation parameter B are displayed on one screen.
In mode 2, set the RAKTE bit in the coefficient table control register to 1 to use the coefficient table for rotation parameter A. When the value of the most significant bit of the coefficient data read from the coefficient table is 0, the image obtained with the rotation parameter A is displayed, and when it is 1, the image obtained with the rotation parameter B is displayed as the RBG0 image. If the coefficient data for the rotation parameter A is set to be read for each dot, the two images can be switched for each dot, but the coefficient data for the rotation parameter B can be read for each dot. lose.
In mode 3, the two images are switched by the rotation parameter window bit in the rotation window control register. When the window is used as a transparency processing window, the image obtained by the rotation parameter B is displayed in the portion that is cut out and made transparent, and the image obtained by the rotation parameter A is displayed in the other portion of the RBG0.
