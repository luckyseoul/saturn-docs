■ Pattern name control register

Pattern name control register specifies pattern name data size, character number auxiliary mode, and pattern name auxiliary data. This is a write-only 16-bit register located at addresses 180030H to 180038H. The value is cleared to 0 after power-on or reset, so be sure to set it.

Pattern name data size bit : Pattern name data size bit (N0PNB, N1PNB, N2PNB, N3PNB, R0PNB)

Specify the pattern name data size when displaying in cell format.

N0PNB 180030H Bit 15 For NBG0 (or RBG1)
N1PNB 180032H Bit 15 For NBG1
N2PNB 180034H Bit 15 For NBG2
N3PNB 180036H Bit 15 For NBG3
R0PNB 180038H Bit 15 For RBG0
