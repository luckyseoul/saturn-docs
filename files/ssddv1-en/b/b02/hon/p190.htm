8.2 Window processing

There are the following three window processes.

(1) Transparency processing window
(2) Rotation parameter window
(3) Color calculation window

The transparency window is a window that forces the specified window valid area to be transparent and can be used for each screen.
The rotation parameter window is a window that specifies whether to display the image obtained with the rotation parameter A or the image obtained with the rotation parameter B when displaying the RBG0 screen. The image obtained by the rotation parameter B is displayed in the specified window effective area, and the image obtained by the rotation parameter A is displayed outside the window effective area.
The color calculation window is a window that does not perform color calculation in the specified window valid area, and is valid for screens that use the color calculation function.
