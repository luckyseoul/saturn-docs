When only one scroll scroll screen is displayed, the normal scroll screen can be displayed at the same time. However, when two scroll scroll screens are displayed, the normal scroll screen cannot be displayed at all. At this time, the NBG0 register is used to set RBG1.
∙ NBG1 cannot be displayed when the external input screen is displayed. At this time, the NBG1 register is used to set the external input screen.

● Line screen

Line color screen is a screen for performing color operations with other screens. You can set the entire screen to a single color or specify a color for each line, but you cannot display characters.
The back screen is displayed when all other screens are transparent. You can set the entire screen to a single color or specify a color for each line, but you cannot display characters.

● Window

For the normal window, you can select a normal rectangular window that specifies two screen coordinate values ​​at the upper left and lower right, and a normal line window that specifies the left and right screen coordinate values ​​for each line. A sprite window is a window with sprite characters.
Depending on the purpose of use, “transparent processing window” that specifies the area to be transparent for the window, “color calculation window” that specifies the area that does not perform color calculation, and “rotation parameter window” that switches between two rotation parameters There are three types.
∙ The windows used for each screen and how to overlap them can be specified for each screen.
