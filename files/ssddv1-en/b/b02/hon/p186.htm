■ Line window table address register

Line window table address register specifies whether the normal window is a line window and the top address of the table. This is a write-only 16-bit register located at addresses 1800D8H to 1800DEH. The value is cleared to 0 after power-on or reset, so be sure to set it.

Line window enable bit : Line window enable bit (W0LWE, W1LWE)

Specify whether the normal window is a line window.

W0LWE 1800D8H Bit 15 For W0
W1LWE 1800DCH Bit 15 For W1

WxLWE Process
0 Do not change normal window to line window
1 Make the normal window a line window
[Note] 0 or 1 is entered in x of the bit name.

When this bit is 1, be sure to store the line window table in VRAM.
