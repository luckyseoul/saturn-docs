Special color calculation bit (for pattern name auxiliary data) : Supplementary special color calculation bit
(N0SCC, N1SCC, N2SCC, N3SCC, R0SCC)
Specified special color operation bit as pattern name auxiliary data when the pattern name data size is 1 word.

N0SCC 180030H bit 8 For NBG0 (or RBG1)
N1SCC 180032H Bit 8 For NBG1
N2SCC 180034H Bit 8 For NBG2
N3SCC 180036H Bit 8 For NBG3
R0SCC 180038H Bit 8 For RBG0

Please refer to “ 12.2 Special Color Arithmetic Function ” for how to use this bit.

Supplementary palette number bit
(N0SPLT6 to N0SPLT4, N1SPLT6 to N1SPLT4, N2SPLT6 to N2SPLT4, N3SPLT6 to N3SPLT4, R0SPLT6 to R0SPLT4)
Specified palette number bit as pattern name auxiliary data when the pattern name data size is 1 word. The auxiliary palette number bit is added to the palette number bit of the pattern name data by 3 bits.

N0SPLT6 to N0SPLT4 180030H bits 7 to 5 For NBG0 (or RBG1)
N1SPLT6 to N1SPLT4 180032H Bits 7 to 5 For NBG1
N2SPLT6 to N2SPLT4 180034H Bits 7 to 5 For NBG2
N3SPLT6 to N3SPLT4 180036H Bits 7 to 5 For NBG3
R0SPLT6 to R0SPLT4 180038H Bits 7 to 5 For RBG0

Supplementary character number bit
(N0SCN4 ~ N0SCN0, N1SCN4 ~ N1SCN0, N2SCN4 ~ N2SCN0, N3SCN4 ~ N3SCN0, R0SCN4 ~ R0SCN0)
∙ Specify the character number bit as the pattern name auxiliary data when the pattern name data size is 1 word. The auxiliary character number bit is added to the character number bit of the pattern name data by 5 bits.

N0SCN4 to N0SCN0 180030H bits 4 to 0 For NBG0 (or RBG1)
N1SCN4 to N1SCN0 180032H Bits 4 to 0 For NBG1
N2SCN4 to N2SCN0 180034H Bits 4 to 0 For NBG2
N3SCN4 to N3SCN0 180036H Bits 4 to 0 For NBG3
R0SCN4 to R0SCN0 180038H Bits 4 to 0 For RBG0
