N0W0A 1800D0H Bit 0 Transparency processing For window NBG0 (or RBG1)
N1W0A 1800D0H Bit 8 For NBG1 (or EXBG)
N2W0A 1800D2H Bit 0 Transparency processing window for NBG2
N3W0A 1800D2H Bit 8 Transparency processing window for NBG3
R0W0A 1800D4H Bit 0 Transparency processing window for RBG0
SPW0A 1800D4H Bit 8 For transparency window sprites
RPW0A 1800D6H Bit 0 For rotation parameter window
CCW0A 1800D6H Bit 8 For color operation window

xxW0A Process
0 Enable inside W0 window
1 Enable outside W0 window
[Note] The bit name xx is N0, N1, N2, N3, R0, SP, RP, or CC.

Window area bit (for W1) : W1 area bit
(N0W1A, N1W1A, N2W1A, N3W1A, R0W1A, SPW1A, RPW1A, CCW1A)
∙ Specify which of the effective areas of the normal window W1 to use for each screen.

N0W1A 1800D0H Bit 2 NBG0 in transparency window (Or RBG1)
N1W1A 1800D0H Bit 10 For NBG1 (or EXBG)
N2W1A 1800D2H Bit 2 Transparency processing window for NBG2
N3W1A 1800D2H Bit 10 Transparency processing window for NBG3
R0W1A 1800D4H Bit 2 Transparency processing window for RBG0
SPW1A 1800D4H Bit 10 For transparent processing window sprites
RPW1A 1800D6H Bit 2 For rotation parameter window
CCW1A 1800D6H Bit 10 For color operation window

xxW1A Process
0 Enable inside W1 window
1 Enable outside W1 window
[Note] The bit name xx is N0, N1, N2, N3, R0, SP, RP, or CC.

Window area bit (for SW) : SW area bit
(N0SWA, N1SWA, N2SWA, N3SWA, R0SWA, SPSWA, CCSWA)
∙ Specify which of the effective areas of the sprite window SW to be used for each screen.
