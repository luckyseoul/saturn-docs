Priority number bit (for scroll screen) : Priority number bit
(N0PRIN2 to N0PRIN0, N1PRIN2 to N1PRIN0, N2PRIN2 to N2PRIN0, N3PRIN2 to N3PRIN0, R0PRIN2 to R0PRIN0)
Specify the priority number of each scroll screen.

N0PRIN2 to N0PRIN0 1800F8H Bits 2 to 0 NBG0 (Or RBG1)
N1PRIN2 to N1PRIN0 1800F8H Bits 10 to 8 For NBG1 (or EXBG)
N2PRIN2 to N2PRIN0 1800FAH Bits 2 to 0 For NBG2
N3PRIN2 to N3PRIN0 1800FAH Bits 10 to 8 For NBG3
R0PRIN2 to R0PRIN0 1800FCH Bits 2 to 0 For RBG0

¡The higher the priority number, the higher the display priority. When the priority number is 0, it is considered transparent and is not displayed.
For the priority number register of sprite, please refer to “ Priority number register ” in “ 9.2 Priority and color calculation ”.
