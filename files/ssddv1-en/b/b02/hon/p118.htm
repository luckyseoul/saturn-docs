Mosaic control register

The mosaic control register specifies whether to perform mosaic processing. This is a write-only 16-bit register located at 180022H. The value is cleared to 0 after power-on or reset, so be sure to set it.

Mosaic size bit : Mosaic size bit (MZSZV3 to MZSZV0, MZSZH3 to MZSZH0)

Specify the horizontal and vertical mosaic size.
MZSZV3 to MZSZV0 180022H bits 15 to 12 For vertical mosaic size
MZSZH3 to MZSZH0 180022H Bits 11 to 8 For horizontal mosaic size
