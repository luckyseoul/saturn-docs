Coefficient data mode bit : Coefficient mode bit (RAKMD1, RAKMD0, RBKMD1, RBKMD0)
Specify what parameter to use coefficient data.

RAKMD1, RAKMD0 1800B4H bit 3,2 rotation For parameter A
RBKMD1, RBKMD0 1800B4H bit 11,10 For rotation parameter B

Note that this bit is always valid, so be careful when rewriting.

RxKMD1 RxKMD0 Mode Function of Coefficient Data
0 0 0 Use scaling factor kx, ky
0 1 1 Use as scaling factor kx
1 0 2 Use as scaling factor ky
1 1 3 As the viewpoint coordinate Xp after rotation conversion Use
[Note] A or B is entered in the bit name x.

Coefficient data size bit : Coefficient data size bit (RAKDBS, RBKDBS)
Specify the size of coefficient data.

RAKDBS 1800B4H Bit 1 For rotation parameter A
RBKDBS 1800B4H Bit 9 For rotation parameter B

∙ This bit is valid only when the corresponding coefficient table is used.

RxKDBS Coefficient data size
0 2 words
1 1 word
[Note] A or B is entered in the bit name x.

Coefficient table enable bit : Coefficient table enable bit (RAKTE, RBKTE)
Specify whether to use the coefficient table.

RAKTE 1800B4H Bit 0 For rotation parameter A
RBKTE 1800B4H Bit 8 For rotation parameter B

RxKTE Process
0 Do not use coefficient table
1 Use coefficient table
[Note] A or B is entered in the bit name x.
