● Coefficient table start address

The start address of the coefficient table is obtained from the coefficient table start address (KAst integer part 16 bits) read from the coefficient table address offset register and the rotation parameter table. The coefficient table vertical address increment (DKAst integer part 9 bits) and coefficient table horizontal address increment (DKAx integer part 9 bits) are also read from the rotation parameter table. These address offsets, start addresses, and address increments vary depending on the data size of the coefficient table.
