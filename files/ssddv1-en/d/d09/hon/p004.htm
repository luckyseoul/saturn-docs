2. Setup

■ Operating environment

The environment required for
execution is as follows.
  • Apple Macintosh computer (model with SCSI interface) and MacOS Talk7 or System7 or later
  • Saturn Development System (Can operate with sound board only)

SSBug distinguishes the Japanese environment such as Kanji Talk7 (exactly the environment where the Japanese script is running), and displays Japanese when Japanese is available, and displays English when it is not. So the English system works well.

Setup

Refer to the sound development manual for the connection with Macintosh. If you are only using SSBug, you can just connect SCSI. In addition, SSBug automatically detects the SCSI ID of the sound board, so there is no need to configure SSBug SCSI settings.

Installation

SSBug is provided by the following four files.

The contents of each file are as follows.

  • SSBug-Macintosh side debugger program itself.
  • SSBug Target Code-This is the debugger program for the sound board.
  • SSBug Startup-Sample startup file described below.
  • SSBug / ReadMe-The latest information about SSBug.

Install as follows:

  1. Drag and copy the file SSBug Target Code to the system folder on the startup disk.

  2. Drag the remaining files to the desired location.
    This completes the installation. There is no need to restart your Macintosh.
