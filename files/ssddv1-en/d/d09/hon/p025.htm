ECHO


      format  ECHO [arg] 
    
 Description  ECHO ON
                  Input lines from the current input destination (macro, console, batch) are exported to the console
                  Coback Local settings for each nested macro, console, or batch
                  It becomes constant.
              ECHO OFF
                  Does not echo back.
              ECHO Other character string
                  Echoes the specified string back to the console.
