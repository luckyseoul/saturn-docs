Bus trace

The
bus trace records bus cycles using external hardware. The sound board can record up to 8192 bus cycles. The recorded signals are as follows.

    Address bus
    Data bus
    FC
    R/W
    MCCS (B-BUS select signal) 

BH


      format  BH expr 
    
 Description  Displays the bus history for the past expr since the last stop.
              Because of MC68000 instruction prefetch, the disassembly display of this command is not always accurate.
              Not. In particular, the instruction after the conditional branch is likely to be displayed incorrectly.
              Also, due to the hardware specifications, debugger operations may be recorded. 
    
              In the following example, the SCSI communication status of the debugger is recorded. 
    
              
    
              After accepting SCSI interrupt at count # 294, stop bus trace at # 276.
              The contents at are recorded.
