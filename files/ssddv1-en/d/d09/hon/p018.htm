HBC


      format  HBC bpnum 
    
 Description  Releases the hardware break for channel bpnum.
              If the character '*' is specified for bpnum, all channels are canceled. 


HBE


      format  HBE bpnum 
    
 Description  Enables hardware break for channel bpnum.
              If the character '*' is specified for bpnum, all channels are enabled. 
    
              ● The HBE command enables breaks without knowing the settings.
              ● The pass count of the hardware break is initialized every time user execution is resumed.

Access break

The
access break is used to set whether or not reading / writing or reading can be performed on the entire CPU space every 4 Kbytes, and to detect a bus cycle that violates this setting by monitoring external hardware.
As with hardware breaks, note that the bus cycle ends when a break occurs. 

MAP


      format  MAP 
    
 Description  Displays a list of access break settings. 


MAP


      format  MAP range, acc 
    
 Description  Set the access break condition acc in the address range range.
              acc is one of the following strings: 
    
              RW read / write
              RO Read only, break on write access
              NO Read / write disabled, break occurs at any access 
    
              If range is not on a 4K byte boundary, it will be rounded. 
    
              ● In normal use, in addition to the areas used in the user program, the following areas are also RW
                Please set. 
    
                $ 600000- $ 67FFFF (ROM mounting area)
                $ 800000- $ 82BFFF (Emulator part mounting area)
                $ A00000- $ A00FFF (MB89352A mounting area)
                $ E00000- $ E07FFF (debugger area)
                $ F00000- $ FFFFFF (Sound tool use area, but only when coexisting with sound tool)

              Please.
