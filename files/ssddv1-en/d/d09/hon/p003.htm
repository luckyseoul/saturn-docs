1. Introduction

SSBug is a symbolic remote debugger dedicated to the sound CPU (MC68EC000) of the Saturn development board, hosted by an Apple Macintosh computer.
It supports both a traditional character terminal-oriented interface and a standard Macintosh user interface, allowing you to debug using either or both interfaces.

SSBug can also be used as a sound board alone, but if it coexists with the main CPU board, a synchronous break with the main CPU is also supported.
