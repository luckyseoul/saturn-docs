3. Files handled by the linker

Link information file (YLI)

File that is the target of “Open” or “Save” in the File menu. This file contains information about the link, such as which modules are linked and how.

■ Link information result file (LRI)

Contains information on hardware resource usage, memory allocation information, etc. when the executable file is transferred to SCSP.

■ Executable file (EXL)

A file in which the file name, ring buffer size, number of coefficient tables, and coefficient table data are added to the DSP microprogram body. Output when the link information file is saved.

■ Binary Executable File (EXB)

This is a binary file formatted to output an executable file to the spare program area on the target board.
