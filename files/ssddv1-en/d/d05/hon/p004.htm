The following hardware is required at a minimum.
  • Personal computer system set for Macintosh or Windows machine (Windows machine requires a separate SCSI I / F board)
  • SCSP software development board
  • SCSI cable for connecting the two points

Installation

Copy from the master disk to an appropriate location on the hard disk.

QuickStart

This section outlines the operations from the start to the end of SCSP / DSP / Linker.

Step 1: Start the linker application

Double-click the Linker icon on the finder to start the application.

Step 2: Open a new algorithm

Select “New” from the
File menu, enter the file name and press the Return key to open the New Algorithm Edit window. The extension “.YLI” is automatically added to the file name.

● Step 3: Check SCSI ID

SCSP / DSP / Linker automatically sets the SCSI ID for communication with the development board at startup. Select “SCSI ID” from the Option menu, and check that the displayed ID matches the SCSI ID setting of the hardware switch on the development board. 

  Warning  At this time, change the SCSI ID by setting the ID and clicking “OK”
You can also  . However, if the SCSI ID is set incorrectly,
  The contents of the storage device (hard disk, etc.) may be destroyed.
  Please note.

● Step 4: Build the effect algorithm

Step 4-1: Place DSP I / O modules
Selecting “I / O Modules” from the Window menu opens the “I / O Module” window.
Double-click the “Input (DSP)” module and “Output (DSP)” module in the “I / O Module” window, or click to select them, then click the “Select” button . The module is placed at the last clicked position in the algorithm edit window. 

  Reference  Drag the “I / O Module” window to edit the algorithm
  You can always see the “I / O Module” window by moving it to a position where it does not overlap
  This is useful for placing modules in succession.
