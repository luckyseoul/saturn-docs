Edit menu

    Undo
    The previous edit is canceled.

    Cut
    The selected module or connection is deleted. When the module is deleted, the connected connection is also deleted. Deleted modules and their information are stored in the Paste buffer.

    Copy
    The selected module is stored in the Paste buffer with that information.

    Paste
    Modules stored in the Paste buffer by Cut or Copy are displayed on the algorithm edit screen. The position displayed is the last clicked position in the algorithm edit screen.

    SelectAll
    All modules and connections are selected.


Window menu

    EffectModules
    The Effect module selection screen opens. If it is already open and behind another screen, it will be displayed in the foreground.
    Refer to “Module Arrangement” in “4. Algorithm Editing” for the module arrangement method.

    I/OModules
    The I / O module selection screen opens. If it is already open and behind another screen, it will be displayed in the foreground.
    Refer to “Module Arrangement” in “4. Algorithm Editing” for the module arrangement method.

    Parameters
    The parameter edit window for the selected module opens. You can double-click the module selection field instead of selecting this item.

    SizeToFit
    Reduce the contents of the algorithm edit screen so that the entire algorithm is visible. The algorithm cannot be edited in the reduced display. Also, if everything is displayed from the beginning, it will not be reduced. To return to the original size, select this item again. A check mark is displayed to the left of this item during thumbnail display.
