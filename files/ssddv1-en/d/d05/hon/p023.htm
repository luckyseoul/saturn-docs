● Problems related to development environment

SATURN SOUND BOARD not connected.
Development board is not connected (only when starting the Linker application).

● Problems with memory mapping on target

DSPRAM Size too small.
Download is stopped because the DSP external RAM area (on the development board) reserved in the memory map setting is smaller than the DSP external RAM size required by the DSP program to be downloaded. did. Change the memory map setting or the DSP program algorithm.

ModElementSize too small.
Because the SoftwareEG / LFO element data area (on the development board) reserved in the memory map setting is smaller than the size of the SoftwareEG / LFO element data linked to the DSP program you are trying to download, Download stopped. Change the memory map setting or reduce the number of SoftwareEG / LFO elements.

DSP SpareProgramArea too small.
The download was canceled because the spare DSP program memory area (on the development board) reserved in the memory map setting is smaller than the size of the DSP program to be downloaded to the spare area. Change the memory map setting or reduce the number of coefficient tables and SoftwareEG / LFO elements linked to the DSP program.
