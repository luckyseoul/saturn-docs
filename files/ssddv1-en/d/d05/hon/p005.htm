Step 4-2: Place the effect module
Selecting “Effect Modules” from the Window menu opens the “Effect Module” window.
Place the effect module in the same way as the DSP I / O module.

Step 4-3: Connect between modules
Connects modules placed in the algorithm edit window.
Click the output port of the module from which you want to extract output sound data, and then click the input port of the module to which you want to input the sound data. The module is connected. This connection determines the flow of sound data between modules.

● Step 5: Link The created effect algorithm is linked by selecting “Link” from the
Process menu. If the link is successful, the “Link Result Information” dialog box is displayed. This dialog displays information about the usage status of DSP-related hardware resources.

● Step 6: Download By selecting “DownLoad” from the
Process menu, the linked effect algorithm is downloaded to the target (development board) hardware. At this stage, it will operate according to the effect algorithm created by the DSP.

● Step 7: Edit effect parameters
Double-click the blank area (the part where no characters are displayed) in each module placed in the algorithm edit window, or select it and select “Prameters” from the Window menu. The edit window will open.
If you operate the scroll bar in this window with the mouse or enter the value directly in the text box and confirm with the return key, the parameter change result is reflected in the effect in real time.

If editing is performed to change the path of the sound data, the parameter real-time editing will not take effect from that point on (“DownLoad” in the Process menu will be grayed out). In this case, you can link and download again to enable real-time parameter editing.

● Step 8: Save as a file
Up to this point, information about links and downloaded effect algorithms exists only in the memory on the host machine, not as a file. When the effect algorithm is complete, save it by selecting “Save” from the File menu.

● Step 9: Quit the linker application By selecting “Quit” from the
File menu, the linker application is terminated.
