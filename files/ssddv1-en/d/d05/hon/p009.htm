Process menu

    Link
    In the current algorithm configuration, the number of program steps and internal memory usage are checked to see if they exceed the hardware limit, and the results are displayed.

    Download
    The data created by the menu item “Link” is transferred to the SCSP in the form of an executable.

Option menu

    RingBuffer
    A dialog box for specifying the size of the ring buffer used by the current algorithm is displayed.

    SCSI ID
    SCSP / DSP / Linker uses SCSI to transfer data to SCSP. Normally, the SCSI ID is automatically set when the linker is started, but when this item is selected, a dialog for determining the ID is displayed and the ID can be set again.

SoftwareEG / LFO menu

    This menu is used to set parameters for generating EG / LFO waveforms (SoftwareEG / LFO) on the sound CPU. SoftwareEG / LFO is a software that virtually implements up to 32 EG / LFO elements, depending on the load of the sound CPU.

    NumberOfElements
    Selecting this item opens the "NumberOfElements" dialog (described later).

    MasterSwitch
    Selecting this item opens the "MasterSwitch" dialog (described later).

    # 0 ~ # 31
    Selecting one of these items will open the “SoftwareEG / LFO Element” window (described later) corresponding to that number. If it is already open, it becomes active.

Dialog / Window

NumberOfElements dialog

This dialog sets the maximum number of SoftwareEG / LFO elements that can be used. If the setting value is N in this dialog, N elements from Element # 0 to Element # (N-1) are enabled.
