4. Edit algorithm

Specify the module to be linked in the algorithm edit window and specify the module wiring to create link information.

Module placement

Place the
module as follows.

  1. To place I / O modules, select “I / OModules” from the Window menu.
    To place effect modules, select “EffectModules” from the Window menu.
    The module selection window will open.

  2. Click the module you want to place in the module selection window and click the “Select” button, or double-click the module.
    The module is placed at the last clicked position in the algorithm edit window. If you have never clicked in the algorithm edit window, it will be placed in the upper right corner.

  3. Drag the placed module to the appropriate position.
