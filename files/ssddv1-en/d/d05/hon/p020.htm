■ Specify input buffer for modulator

Some module symbols have an “M” button. In such a module, the link cannot be executed without setting the modulator input buffer number (DSP input buffer number). The following numbers can be specified.
● SoundSlotEG / LFO drive module: 0 ~ 15
● SoundSlotEG / LFO drive module: 0 to 31

  1. Click “M” in the module.
    The input buffer setting dialog for the modulator is displayed.

  2. Specify the buffer number and click “OK”.
    The buffer number is set.

    ● About the modulator input buffer

    The
    modulator input buffer is a buffer for importing the waveform created by the SCSP sound generator (SoundSlotEG / LFO) or sound CPU (SoftwareEG / LFO) into the DSP as LFO or EG. In hardware, a part of DSP input buffer for music (SoundSlotEG / LFO) or a part of DSP DRAM area (SoftwareEG / LFO) is reserved for this purpose. See the diagram below for details.
