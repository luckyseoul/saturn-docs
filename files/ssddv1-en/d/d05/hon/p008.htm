    Opens the "Coefficient Table Allocator" for handling coefficient table data on the linker. If a coefficient table file is registered with "Coefficient table allocator", the coefficient table data is linked to the executable file and the Effect module that requires the coefficient table can be used.

GlobalCoef menu

    DefineGlobal
    The global coefficient definition screen opens. If this screen is already open and behind another screen, it will be displayed in the foreground.

    AlterToGlobal
    The global factor usage screen opens. This item can be selected only when a coefficient that can be globalized in the parameter edit window is selected. As a general rule, parameters whose units are displayed in [%] can be globalized.

    RevertToLocal
    The globally specified coefficient selected in the parameter edit window is returned locally. This item can be selected only when the parameter edit window is active.
