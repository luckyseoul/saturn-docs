SizeToFit function

The module display on the algorithm edit screen may not fit within the frame, and you may not be able to see everything at once.
In such a case, select “SizeToFit” from the Window menu, and the algorithm will be reduced on the algorithm edit screen so that you can see all of the algorithm at once.
A check is displayed to the left of the menu item while it is displayed in SizeToFit. During this time, you cannot edit the algorithm. Please note that this feature consumes a lot of personal computer memory.
