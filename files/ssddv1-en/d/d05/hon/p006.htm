2. Menu

File menu

    New
    A new algorithm edit screen opens. The name of the algorithm (link information file name) must be entered immediately after selecting this item. The extension “.YLI” is automatically added to this file name.

    Open
    Open the algorithm stored in the link information file (YLI). Immediately after selecting this item, select the link information file in the standard file open dialog. The algorithm edit screen opens and the specified file is read and the algorithm is displayed.

    Save
    The algorithm currently being edited is saved in the link information file (YLI). The save file name is the name of the current algorithm. An extended executable file (EXL) and binary executable file (EXB) are also output at this time.

    SaveAs...
    Saves the currently edited algorithm to a link information file (YLI). Immediately after selecting this item, specify the save file name in the standard save dialog. An extended executable file (EXL) and binary executable file (EXB) are also output at this time.

    Close
    The algorithm edit screen currently being edited is closed.

    Quit The linker will exit.
