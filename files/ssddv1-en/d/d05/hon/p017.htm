■ Reassign module ID

links are done in order of module ID. However, because module IDs are assigned in the order of connection, they may not be in the desired order. In such a case, you need to reassign the module ID.

  1. Double-click the ID of the module to be reassigned.
    The “Renumber” dialog box appears.

  2. Enter the value to be changed and click “OK”.
    The module ID is changed.
    If the changed IDs are duplicated or discontinuous, the IDs of other modules are automatically adjusted so that the IDs are continuous.

    Parameter editing

    1. Double-click the module selection field.
      The parameter edit window is displayed.

    2. Change the value by moving the scroll bar with the mouse or clicking in the value display frame and entering the value directly.
