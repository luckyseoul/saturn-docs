■ Menu structure

File menu

New
    Opens a new source file.

Open...

    Select (input) the file name from the standard file dialog and open the microprogram source file.

Save

    Saves the currently edited file with the same file name.

Save As...

    Saves the file currently being edited as a separate file. Specify the file name in the standard file dialog.

Revert To Saved

    Returns the source file currently being edited to the state before editing.

Close

    Closes the currently loaded source file. A warning is issued if there is a change history and it has not been saved.

Quit

    Terminates the assembler. 

 Caution  In dAsms, the attributes of related files are managed by the file name extension (considering the Windows version)
 . For this reason, the extension ".USC" must be added to the source code.
 No . For source files without this extension, the "Assemble ..." command
  (described later) will be invalid.

Edit menu

Undo, Cut, Copy, Paste, SelectAll
    Make the above standard edits to the source text.
