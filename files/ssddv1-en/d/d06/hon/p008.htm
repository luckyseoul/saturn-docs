● About reserved symbols

    Since the coefficient symbol “ZERO” has already been defined, the user must not define a new symbol name. The initial value given to this symbol is "0" and its data is placed at the beginning of the coefficient data part of the executable program. Therefore, user-defined coefficient symbols are placed in the order of definition after the second coefficient data part. The

    This reserved symbol “ZERO” can be used in the program part of the source code created by the user without being defined in the coefficient definition part, but its value (on the executable program or on the DSP hardware on which it is loaded) Do not change (in any case, such as above).
