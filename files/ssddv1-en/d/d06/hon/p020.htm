2.Defining address constant symbols (#ADRS)

2-1 Definition of write and read addresses for ring buffer for delay

In the

    signal flow diagram, the rectangle at the center of each part of Lch / Rch represents delay. The delay is created by a ring buffer, and the delay time is proportional to the difference between the write address and the read address. One address corresponds to one sample delay.

    as an address constant 

         waL/R
     raL/R

    Define For these address constant symbols, the address on the ring buffer can be given as an initial value in hexadecimal or decimal integer, but dAsms can use the notation converted to time (ms). Considering an appropriate delay time, the definition description on the dAsms source code is as follows. 

    ----------------------------------------------------------------
     waL=ms0.0
     raL=ms149.9
     waR=ms150.0
     raR=ms249.9
----------------------------------------------------------------
