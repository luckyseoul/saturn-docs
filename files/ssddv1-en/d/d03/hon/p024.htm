Wave Edit screen
This window is opened each time you open and displays as much as memory allows.
Wave data obtained from SCSP from the New screen and wave data opened from the Open screen are displayed in this window.
  • LoopStart and LoopEnd points can be set by moving the mouse cursor within the screen range.
  • Drag the waveform to highlight the entire selection. If you try to move beyond the selected range, the display contents will scroll automatically. The selected point will automatically move to the inner zero cross point after the drag ends.
    When the
  • zoom box is clicked, the window and the waveform display in the window are enlarged.
    If you drag the
  • size box to enlarge it, the window and waveform display will expand in the direction of mouse movement. If you drag the size box to reduce the size, only the window will be reduced in the horizontal direction regardless of the waveform display size. For the vertical direction, the waveform display size and window are also reduced.
    When the
  • loop point is moved, the Loop Edit screen and the header display screen are also changed.

Loop Edit screen
    • The left side is the loop end point and the right side is the start point.
      When the
    • loop point is moved, the Wave Edit screen and the header display screen are also changed.

    Header display screen
    The meaning of each item on the header display screen is as follows.

    Sample Size
    Set the number of data sampling.

    Sampling rate
    Displays the sampling frequency.

    Loop Mode
    Specify the loop mode when leveling with SCSP or Macintosh.

    Forward Loop
    Play back to normal.

    Reverse Loop
    Reads waveform data from the reverse and plays it back.

    Alternate Loop
    Repeatedly reads the loop part in the forward / reverse direction.
    Valid only when SCSP is selected in Option. If Macintosh is selected, playback will be a Forward Loop even if Alternate Loop is selected.
