1. Overview

Waveform Editor is software for capturing waveform data using SCSP connected to the SCSI interface of Macintosh, and displaying and editing waveform data in AIFF and SD2 format formats.
The waveform editor has the following functions.

● File operation

File management and comparison such as input / output and saving of files, editing such as mixing.

Edit

Redo the work and edit the waveform such as cut and paste. You can also change the waveform display size and dump display during work.

● Effect processing

Performs effect processing on the edited waveform.

● SCSP processing

Performs sound input / output processing for SCSP. The sampled sound is saved on the hard disk.

● TMP treatment

Plays or restores the wave sound that is in the temporary area.

Preference display

Displays SCSID.

SCSI setting

Performs SCSI processing on the Mac side when inputting / outputting waveform data from SCSP to Macintosh via SCSI.
