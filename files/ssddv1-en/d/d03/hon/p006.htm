Sound capture

There is no waveform to edit yet. Let's take in the sound from the SCSP board.

  1. Make sure that the source device is connected to the digital input of the SCSP board.

  2. Select Option ... from the SCSP menu.
    The screen for setting the output and input destination devices appears.

    Select

  3. SCSP.
    8-bit and 16-bit radio buttons are displayed.

  4. Set the output to either 8bit or 16bit.

  5. Press the OK button.
    The device settings are complete.
