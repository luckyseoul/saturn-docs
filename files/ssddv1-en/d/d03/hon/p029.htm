●Pitch Shift

Pitch shift the currently edited waveform. The following window is displayed.

The parameters set in this window are as follows:

Now
Displays the current frequency (MIDI code).

New
Set a new frequency (MIDI code).
You can set a value between 0 and 127.

OK
Rewrite temporary memory data of AIFF file.
