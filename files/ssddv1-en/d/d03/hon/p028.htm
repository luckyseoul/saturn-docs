Effect menu

This section explains each item in the Effect menu.

●Resample

Resamples the waveform currently being edited. The following window is displayed.

The parameters set in this window are as follows:

Now
Displays the current sampling frequency.

New
Set a new sampling frequency.
You can set a value from 1 to 65535.

OK
Rewrite temporary memory data of AIFF file.
