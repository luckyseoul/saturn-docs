●Size Shift

Changes the sample size of the waveform currently being edited. The following window is displayed.

The parameters set in this window are as follows:

Now
Displays the current sample size.

New
Set a new sample size.
You can set a value between 0 and 4294967295.

OK
Rewrite temporary memory data of AIFF file.
