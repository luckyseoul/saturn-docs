Save FunctionKey As...
Saves the settings made with the function key setup with a different name. Function keys are saved in the map file. Use these menus if you want to use key settings in another map file.

Startup System
When
Startup System is selected, the sound system is started based on the data of the sound driver etc. that have been transferred in advance.

Make Current
When
Make Current is selected, the currently selected map is switched. After this, the sound driver will operate this map as the current map (currently valid map). At this time, if automatic transmission is set in the file information of the map, the file data is automatically transferred.

Down Load System
Used when the target board becomes unusable for some reason and needs to be reset. This saves you the trouble of restarting SoundSimulator by sending the system and so on.
If you want to send a customized driver, place the driver file with the file name "SDDRV.TSK" in the same folder as the sound simulator and execute this menu.

Down Load
Transfers the currently selected file data to the target. When you click on the file you want to transfer, it is highlighted in black, indicating that it has been selected. To specify multiple files at the same time, click the next file while holding down the shift key. Click the selected file again to deselect it and return to the normal white display.

Effect Change
Switches DSP programs when there are multiple DSP programs on the current map. Click on the DSP program you want to switch to, and it will be highlighted in black, indicating that it has been selected. Do not specify multiple files at the same time.

Quit
Exits the sound simulator and closes the window.
