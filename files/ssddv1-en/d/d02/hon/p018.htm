Various parameters

16Bit, 8Bit
Select whether PCM data to play is 16it or 8bit.

Mono, Stereo
Select whether the PCM data to be played is Stereo or Monoral. Note that these parameters are not automatically detected when an AIFF file is read.

R Channel, L Channel
You can specify the channel to be output when playing a stereo file. However, it is not valid during playback. This parameter is ignored even if you follow the ParamChange button.

Direct Level
Set the playback volume. The setting value is from 0 to> 8.

Direct Pan
Set the Pan for playback. The setting value is from 0 to> 31. Ignored during stereo.

Start Address
This is the start address where the PCM data to be played is stored. From 0 to> 0xffff0, the setting value at the 1's place is ignored.

Buffer Size
Set the PCM data buffer to play. Set the value from 0-> 0xf000 in units of 0x1000. This value indicates the number of samples.

Play Pitch
Set the playback pitch. The setting value is 0-> 0xffff.

Eff Select
Select the effect for each channel. The setting value is from 0 to> 15.

Eff Send Level
Set Effect Send Level. The setting value is from 0 to> 7. In the case of monaural, these effect relationships are set with the right channel.

PCMStreamOffset
Set the playback position in the buffer. The setting value is 0-> 0xffff.
