Mixer window


You can change the name of the mixer. You can also double-click on the left side of the name to edit the Mixer Window opens.

Mixer edit window


Change the mixer parameters.
The parameters set in this window are as follows:

Effect Level
Sets the effect send / return.
You can set a value between 0 and 7.

Effect PAN
Sets the pan of the effected output.
Values ​​from R16 to C to L16 can be set.
