2. Glossary

SCSP format

This file contains all the information necessary to display on the Macintosh.

● SCSPBIN format

A file with the minimum information necessary to play a sound with SCSP. In fact, this data is downloaded to SCSP.

●VOICE

Tone. The number attached to this window is the same as the MIDI program change number.

●LAYER

Sound data. Many of these gather together to form a VOICE. In FM, each module and each carrier is treated the same as a layer.

●WAVE

A type of sound data, which is PCM data of actual sound.
