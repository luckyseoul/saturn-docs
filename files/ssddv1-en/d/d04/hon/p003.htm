1. Overview

This system is software for displaying and editing the tone parameters using SCSP connected to the SCSI interface of Macintosh.
The tone editor has the following functions.

● File operation

Manages files such as input / output and storage of files.

Edit

Redo work and edit data such as cut and paste and insert.

Nember treatment

Increase the number of Voice, Layer, Mixer, Velocity, PEG, PLFO.

● Window operation

Opens / closes the Mixer, Velocity, PEG, PLFO, FM, and MONITOR screens.

FM treatment

Updates with the same start note and end note as the selected layer.

Preference processing

SCSIID display, SCSPBIN format download, and Voice information display.

SCSI processing

Performs SCSI processing on the Mac side when inputting / outputting sound data from SCSP to Macintosh via SCSI.
