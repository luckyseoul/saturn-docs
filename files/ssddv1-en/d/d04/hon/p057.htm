● VL conversion 

 Approximate value: Approximate value table number used for velocity. This value is velocity point 0 ~ 3,
It is obtained by calculating the value of velocity levels 0-3.

How to ask


The relationship between velocity points and velocity levels is shown in the figure. Draw a curve with a level as shown in the figure for velocities 0-127. Find the value of D6D3 corresponding to the value closest to the slope value of these four curves from the table on the next page and put it in the approximate value table. The method for obtaining the slope is as follows.
