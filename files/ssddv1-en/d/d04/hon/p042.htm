The following data changes depending on the parameters set in this window.
The graph changes as soon as the parameter is changed.

DELAY TIME(msec)
Sets the delay time until PEG starts.

OFFSET LEVEL(cent)
Set the offset level from the key-on note until PEG starts.

ATTACK LEVEL(cent)
The size of the attack level.

ATTACK TIME(msec)
Time to reach PEG attack.

DECAY LEVEL(cent)
The size of the decay level.

DECAY TIME(msec)
Time to reach PEG decay.

SUSTAIN LEVEL(cent)
Sustain level.

SUSTAIN TIME(msec)
Time to reach the sustain level.

RELEASE LEVEL (cent)
The size of the release level.

RELEASE TIME(msec)
Time to reach the release level.

ATTACK, DECAY, SUSTAIN, and RELEASE each have two sliders. The upper row shows the level (ATTACK LEVEL if ATTACK), and the level increases in the positive direction as the slider is moved to the right. However, this is when the lower slope is not "0" (the slider is at the left end). When the slope is "0", the segment time increases as the slider is moved to the right. The lower row shows the slope, and the slope becomes steeper as the slider is moved to the right. In other words, changing the upper level will change the segment time.
