4. Files to use

The files used in the
tone editor are as follows.

SCSP data file

A file on the Macintosh that contains detailed information. Refer to the appendix for details.

SCSPBIN data file

This is a file that contains only the data that actually enters the memory on the 68000 and the header necessary to become a Macintosh file. Refer to the appendix for details.

● Wave Edit data file

AIFF format file created by Save processing.

● Alchemy file

AIFF format file created by Alchemy.

Sound Designer File

AIFF format file created by Sound Designer.
