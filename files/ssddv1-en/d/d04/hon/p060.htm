DR:
This is the level of change per unit time.
=DECAYLEVEL/DT
DT:
The table number of the timetable for the time to reach the decay level. The timetable contains the number of counts per unit time. The count number is calculated from the time (DECAY TIME) entered in the editor, the count number of the time table closest to the count number in absolute difference is searched, and the table number is set here.
Count = DECAY TIME (msec)
SR:
This is the level of change per unit time.
=SUSTAIN LEVEL/ST
ST:
The table number of the timetable for reaching the sustain level. The timetable contains the number of counts per unit time. The number of counts is calculated from the time entered in the editor (SASTAIN TIME), the count number of the time table closest to the count number in absolute difference is searched, and the table number is set here.
Count = SUSTAIN TIME (msec)

Count = RELEARSE TIME (msec)
Delay:
PLFO delay time table number. The timetable contains the count number per unit time. The count number is calculated from the time entered in the editor (PLFO DELAY TIME). Set the table number here.
Count value = PLFO DELAY TIME (msec. Unit time)
FRQ:
Increase / decrease width of PLFO triangle wave per unit time.
= DEPTH LEVEL / FRQ TIME (msec. Unit time)
FDR: The change width of the fade-in amplitude per unit time.
= DEPTH LEVEL / FADETIME * 2 (msec. Unit time)
