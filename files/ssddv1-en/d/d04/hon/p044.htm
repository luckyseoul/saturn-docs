The following data changes depending on the parameters set in this window.
The graph changes as soon as the parameter is changed.

PLFO DELAY TIME(msec)
Time until PLFO starts.

PLFO FREQUENCY(Hz)
The frequency of the PLFO waveform.

PLFO AMPLITUDE(cent)
This is the amplitude value in the steady state of the PLFO waveform.

PLFO FADE TIME(msec)
Time from the start of PLFO to the transition to steady state.
