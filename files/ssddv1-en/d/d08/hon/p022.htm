Load

Reads an existing project. A file selection dialog is displayed, in which you specify the file to open.

The file name displayed here is limited to the file type 'PROJ'.

Save

Saves the open project. You can continue the operation without closing the project window.

Front

This command activates the project window.
Used when hidden in another window such as a text window.

Assemble (shortcut: Command-K)

This command assembles the sources registered in the project in order.
However, it is not assembled in the following cases. 

-When an object has already been created and the source has not changed
・ When there is an error in the previously assembled file

If an error occurs, subsequent sources are not assembled.
At this time, the source object file where the error occurred is deleted.
