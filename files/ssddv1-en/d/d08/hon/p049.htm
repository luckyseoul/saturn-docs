IFE to ENDIF 

  format  IFE  

 Description  If the value of  is 0, it will assemble to ELSE or ENDIF. 

 [Example]  bbb equ 1
  ife bbb-1
:  move.w d0, d1 ----------------- assembled
  endif

IF to ENDIF, IFNE to ENDIF 

  format  IF  or IFNE  

 Description  If the value of  is other than 0, it will assemble to ELSE or ENDIF.
  Has the reverse function of IFE to ENDIF. 

 [Example]  bbb equ 1
 if bb-1
