Expression attributes

Symbols in the
expression must belong to one of the following:

    Absolute (value is determined)
    Relative (value is segment relative)
    External reference (EXTERN declared symbol)

An expression containing such a symbol must obey the following rules:

  • For operations other than addition and subtraction, all symbols used in it must be absolute.

  • Addition
    • One of the elements must be absolute.
    ・ Relative + Absolute becomes relative.
    • In an expression containing an external reference symbol, all of its elements must be absolute.

  • For subtraction
    • Relative-Absolute becomes relative.
    ・ Subtraction between relatives in the same segment is absolute.
    • All other elements in expressions containing external reference symbols must be absolute.
