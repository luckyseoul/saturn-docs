4. Assembler overview

■ About assembler statements

One line of
assembled source can be described in the following format. 

 [Label] 〈Instruction〉 〈Operand〉 [Comment]

[] Can be omitted, but <> cannot be omitted if either one is specified.
The delimiter for each element is a space or tab.

Label
The
label is the name given to the description line. Referenced when jumping from another line.
It can be up to 32 characters long and must start in the first column.
Acceptable characters are
a to z, A to Z, 0 to 9,?, @, _ (under bar)
is. Also, the first character cannot be a number.

* As a special function, “:” is attached to the end of the label, “PUBLIC”, and “#” is attached, “EXTERN”.

Comments
comments are explanations that make the program easier to understand.
It begins with; (semicolon) and ends with a line feed.
Any characters between them are treated as comments.
