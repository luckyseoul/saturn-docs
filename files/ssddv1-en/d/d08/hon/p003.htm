This product is integrated environment software that supports microcomputer software development, equipped with a text editor, assembler, and object linker that run on an Apple computer. Using the excellent interface of Macintosh, two types of software development, Z80 and MC68000, which are typical CPUs, can be performed consistently from source code creation to object module creation.
