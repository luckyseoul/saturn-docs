 REPT to ENDM 


  format   REPT 
 
  ENDM 

 Description  REPT expands the portion from REPT to ENDM as many times as the absolute expression indicated by . 

 [Example] 
   


 
 IRP ~ ENDM 


 
  format   IRP , 
 
  ENDM 

 Description  IRP expands until the argument list is completely replaced with a dummy.
  The argument list must be enclosed in “<” and “>”. 

 [Example] 
   


 
 IRPC ~ ENDM 


  format   IRPC , 
 
  ENDM 

 Description  IRPC has a character string as an argument, and the character string up to ENDM is one character at a time.
  Replace with dummy and expand.
  The argument list must be enclosed in “<” and “>”.
