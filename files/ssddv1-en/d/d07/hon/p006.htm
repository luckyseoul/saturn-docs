How to use pEdit

Change target data The data to be edited by
    pEdit is the contents of the coefficient (COEF) RAM and address constant (ADRS) RAM on the SCSP / DSP hardware.

Usage instructions

  1. Load an executable DSP program
      FileMenu-Open ... selects the executable file to be edited. This downloads the DSP program to SCSP / DSP, and opens two types of parameter edit windows (page 7) on the screen: a Coefficient window for editing coefficients and an Address window for editing address constants. The

  2. Edit parameters
      There are the following two ways to edit parameters in the parameter edit window (page 7).

      a) Enter a number directly in the text box where the parameter value is displayed
      b) Operate the scroll bar with the mouse

  3. Save executable DSP program
    If you want to save the result of editing the
      parameter, you can save it as an executable file (extension “.EXC”) by executing FileMenu-Save / SaveAs ....
