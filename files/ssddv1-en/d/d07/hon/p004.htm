pEdit functions

pEdit has a function to rewrite the coefficient data and address constant data included in the DSP program downloaded onto the SCSP / DSP hardware.

In the SCSP / DSP assembler “dAsms”, several notation modes such as integers and decimals can be specified in the coefficient / address constant definition part of the source code. Since it is read from the executable file, the coefficient / address constant data can be displayed / input in the same notation mode as the dAsms source code.
