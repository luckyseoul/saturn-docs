Developer's Documentation

Sound Tool Guide


Introduction


Purpose of this binder

    This document is a tool guide for sound developers on this system. By reading this manual, you can understand the environment for sound development and how to use each sound tool.


■ Target for this binder

    This manual is written for those who develop application software on this system and those who develop sound.


■ Composition of this binder

    This document consists of the following nine manuals.

    1. "Sound Development Manual"

      Explains the overall flow of sound development. Read this manual first to get an overview of sound development.

    2. "Sound Simulator User's Manual"

    The
      sound simulator is a simulator that allows sound data created with the sound tool to sound in the same state as when it was incorporated into the game.
      This manual describes the functions and usage of the sound simulator.

    3. “Waveform Editor User's Manual”

      Waveform Editor is a tool for importing waveform data and displaying and editing AIFF data. This manual describes the functions and usage of the waveform editor.

    4. "Tone Editor User's Manual"

    The
      tone editor is a tool for displaying and editing tone parameters. This manual describes the functions and usage of the sound editor.

    5. "DSP Linker User's Manual"

    The
      DSP linker is a tool for creating effects. This manual describes the functions and usage of the SCSP / DSP / Linker.

    6. "DSP Assembler User's Manual"

      This manual explains how to use the SCSP / DSP assembler (dAsms) and assembler syntax.

    7. “Parameter Editor User's Manual”

    The
      parameter editor (pEdit) has a function to rewrite the coefficient data and address constant data included in the DSP program downloaded onto the SCSP / DSP hardware. This manual describes the features and usage of pEdit.

    8. “Sound Programming Tool User's Manual”

      This manual describes the text editor, assembler, and linker. These tools are for those who want to develop sound programs on the Macintosh and are not necessary for normal sound development.

    9. "Sound Programming Debugger User's Manual"

      This manual describes the sound program debugger.

    10. “Saturn sound production precautions”

      Other precautions not described in the manual.
