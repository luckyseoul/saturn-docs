∙ The DSP EFFECT module with more memory accesses has a higher load on the sound driver. Specifically, the sound will stop, and the sound will stop if several SEs sound at the same time.
In that case,
1. Thin out the song sequence data.
2. If there is an FM (especially chord) tone, stop it.
3. Change to an effect with fewer memory accesses.
  In addition, since the operation of the driver has become lighter since version 2.00 of the sound driver, there should be fewer cases where the song is staggered than the 1.xx units.
The number of voices used will be reduced by the number of voices used from the maximum 32 sounds of TONEEditor.
  Also, when using multiple effects at the same time, these numbers are added.
