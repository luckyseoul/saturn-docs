▲ DSP operation of SCSP
The SCSP DSP always processes 128-step instructions. In the initial state, NOP (No OPeration) is written for all 128 steps, so the DSP effect is idle without any sound. By patching the effect module with DSPLinker and executing Link on the Process menu, the instruction code (file with the extension of .EXB) to be written to the DSP on MACINTOSH is created. Then, the instruction code is written to the DSP at Download in the Process menu, and the DSP starts executing the instruction that operates the patched module (REVERB if REVERB). This Download operation is the Effect Change on the actual machine.

▲ DSP EFFECT module use steps 

INPUT              2
OUTPUT             2

REVER             30
EARLY REFLACTION  54
DELAY             20
PITCH SHIFT       24
CHORUS            24

SURROUND          38

PHASER            18

FILTER             8
DYNAMIC FILTER    20
PARAMETRIC EQ      8
MIXER2             4
MIXER3             4
MIXER4             6
MIXER6             8
MIXER8            10

You can freely patch effects as long as these totals do not exceed 128 steps. As a precaution for connection, IN must be present, but it does not need to be OUT (but no sound).

****** Reference ********
AUTOPAN can be used as a gate. If you don't want to expand it to the left or right, try changing the AUTOPAN VOICE pitch or tweaking the MIXER pan.
