This creation standard is established in order to realize a user-friendly environment through all software by unifying basic functions and terms related to backup.
This creation standard is limited to applications that use backups.

1> Unification of terms (Glossary of backup-related standard terms)

Regarding terms related to backup in SEGA Saturn, the following terms shall be used for screen display and instruction manuals in the software. Also, terms written in the prohibition column (those with erasing lines) are not suitable for use in the game. Do not use these words. Also, do not use product names such as “Power Memory”.

Note) The following prohibited phrases are prohibited

  1. Sega Saturn

    * This brand name is generally used
    Prohibition) x Saturn

  2. "Backup RAM" "Backup"

    * General name that combines main unit RAM and cartridge RAM
    Prohibition) x RAM, x RAM cartridge

  3. "Main body RAM" "Internal backup RAM"

    Prohibition) x internal RAM

  4. "Cartridge RAM"

    Prohibition phrase) x external backup RAM, x power memory, x backup RAM cartridge

  5. "Extended memory"

    * The storage device connected to the Sega Saturn expansion port is called in the main unit BOOT ROM as follows:
    Prohibition phrase) x hard disk

Note) The following prohibited phrases are prohibited

  1. "Multiplayer screen"

    * Basic operation screen in BOOT ROM
    Prohibition) x control screen, x control panel

  2. "Saved data management screen"

    * Backup operation screen in BOOT ROM
    Prohibition phrase) x Backup RAM tool

  3. "Record" "Data" "Save Data"

    Prohibition phrase) x file

  4. "(Record) name" "Data name"

    Prohibition phrase) x file name

  5. "Capacity", "Used amount", "Free space", "Remaining capacity"

    Prohibition phrase) x area, x free area

  6. Block

    * It is a unit of capacity, but it is preferable to not attach as much as possible (no unit)
    Forbidden phrases) x bytes, x bits
