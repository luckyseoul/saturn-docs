separate volume 2: "Standard for creating software supporting input peripherals" (Sega Saturn version)

This paper is a standard for creating software that supports each input peripheral (peripheral device) for SEGASATURN. The basic specifications are based on the “SEGASATURN Software Creation Standard”, and the terms and other terms shall also conform to the “SEGASATURN Software Creation Standard”.

* Please refer to the sections such as [Game Sequence], [Pad Check], [Main Game> Pad Settings] in [SEGASATURN Software Creation Criteria] .

What is shown in this preparation standard is only a minimum guideline, and covers all the situations that can be caused by the player, or provisions for all applications with various game characteristics etc. No, it is not the responsibility of this article. The production side should make a detailed decision after careful consideration.
But don't forget that be as user friendly as possible , which is the basis of all the rules. At least in any scene of any application Do not runaway during gameplay is the main principle .
