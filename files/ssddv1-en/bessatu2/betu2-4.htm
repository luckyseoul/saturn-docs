4. Racing controller

All racing controller software must be able to be operated with CONTROL PAD.

1) Specifications

  • “Racing Controller” is a peripheral that allows analog input only in the left-right direction by turning the steering wheel.
  • Up / down input is performed by "Butterfly Shift" on the back of the steering wheel.
    ("Up" on the pad shifts to the right and "Down" shifts to the left)
  • A, B, C buttons are in the position to operate with the right hand, and X, Y, Z buttons are in the position to operate with the left hand.
  • There is no equivalent to the “LR button” of the CONTROL PAD.

2) Button settings

(a) Racing controller button setting principle

In addition to 〈button setting principles〉 in “Software creation standards”, the following principles must be observed (see Software creation standards “8. Main game 2> Pad settings / button settings”).

・ Operations that can be done with the CONTROL PAD can be done with the racing controller as much as possible . Consider in advance that there is no “LR button” on the racing controller.

・ On the menu screen, etc., the upper and lower inputs are performed by “butterfly shift” .
(Right shift is “up” and left shift is “bottom”)

 

(b) Default settings << Recommended specifications >>

The allocation of the operation to the buttons of the racing controller defaults to the following specifications with the accelerator and brake operations concentrated on the right hand. 

Handle Handle operation
Shift gear change, special operation (center of gravity movement, etc.)
A button Brake, special operation (weapon firing, etc.)
B button Accelerator
C button Brake, special operation (weapon firing, etc.)
X, Y, Z buttons

(4. Racing controller, finished)
