Introduction

This manual explains the functions and usage of the system controller. The system controller performs data transfer at high speed and smoothly mainly by bus control.

■ Explanation of words

The words used in this manual are explained below.

SCU
Abbreviation for System Control Unit. Equipped with CPU I / F, A-Bus I / F, and B-Bus I / F, data transfer between each I / F and multiple processors connected via a bus is executed smoothly. In addition, a DMA controller, interrupt controller, and DSP are installed inside to realize DMA control, interrupt control, and high-speed arithmetic processing.

Main CPU
Uses a RISC type CPU SH-2 that controls the entire system. SH-2 has a 32-bit internal bus and an external bus.

VDP1
Abbreviation for Video Display Processor 1. It has functions such as character and line drawing, color specification, glow shading color calculation, screen output coordinate specification, and frame buffer display control.

VDP2
Abbreviation for Video Display Processor 2. It has a scroll function that moves the screen up and down, left and right, and a rotation function, and a priority function that determines the priority of many display screens and controls image processing such as color calculation and color offset.

SCSP
Abbreviation for Saturn Custom Sound Processor. This is a multi-function game tone generator LSI that combines a PCM tone generator and a sound DSP.
