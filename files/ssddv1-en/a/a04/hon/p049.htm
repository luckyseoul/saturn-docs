Level-1 DMA suspended flag (4 [bit 17] in Figure 3.13)
D1BK (R) DMA level 1 BacK ground flag
Indicates that level 1 DMA transfer is suspended due to high level DMA. When it is 1, it means that it is currently suspended. When it is 0, it means that level 1 DMA is not suspended.

Level-0 DMA suspended flag (5 [bit 16] in Figure 3.13)
D0BK (R) DMA level 0 BacK ground flag
Indicates that the level 0 DMA transfer is suspended due to the high level DMA. When it is 1, it means that it is currently suspended. When it is 0, it means that level 0 DMA is not suspended.

Level-2 DMA waiting flag (6 [bit 13] in Figure 3.13)
D2WT (R) DMA level 2 WaiT flag
Indicates that level 2 DMA transfer is currently waiting. When it is 1, it indicates that it is currently waiting. When it is 0, it means that level 2 DMA is not waiting.

Level-2 DMA operation flag (7 [bit 12] in Figure 3.13)
D2MV (R) DMA level 2 MoVe flag
Indicates that level 2 DMA transfer is currently being executed. When it is 1, it indicates that it is currently operating. When it is 0, it indicates that level 2 DMA is not operating. When D2WT and D2MV are both 0, it indicates that level 2 DMA is stopped.

Level-1 DMA waiting flag (8 [bit 9] in Figure 3.13)
D1WT (R) DMA level 1 WaiT flag
Indicates that level 1 DMA transfer is currently waiting. When it is 1, it indicates that it is currently waiting. When it is 0, it means that level 1 DMA is not waiting.

Level-1 DMA operating flag (9 [bit 8] in Figure 3.13)
D1MV (R) DMA level 1 MoVe flag
Indicates that level 1 DMA transfer is currently in progress. When it is 1, it indicates that it is currently operating. When it is 0, it indicates that level 1 DMA is not operating. Also, when D1WT, D1MV, and D1BK are all 0, it indicates that level 1 DMA is stopped.

Level-0 DMA waiting flag (10 [bit 5] in Figure 3.13)
D0WT (R) DMA level 0 WaiT flag
Indicates that level 0 DMA transfer is currently waiting. When it is 1, it indicates that it is currently waiting. When it is 0, it means that level 0 DMA is not waiting.
