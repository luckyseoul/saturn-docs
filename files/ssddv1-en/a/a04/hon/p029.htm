Blanking interrupt

There are three types of blanking interrupts: V-blank-IN, V-blank-OUT, and H-blank-IN. Figure 2.11 shows the details of the blanking interrupt. The blanking interrupt synchronizes with the display and notifies the start and end of the display.

Figure 2.11 Blanking interrupt details

V-Blank-IN

Indicates the end of display. From now on, any attempt to display data on the screen will not appear on the screen.

V-Blank-OUT

Indicates the start of display. However, even if the start of the display is notified, it takes time (interval) until it is actually displayed. Also, timer 0 data is cleared.
