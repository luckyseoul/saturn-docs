Hardware Manual Vol.1


Introduction


Purpose of this binder

    This manual is a manual for understanding the hardware configuration and overview of this system, and for learning the various functions of the hardware and how to use them.


■ Target for this binder

    This manual is written for programmers who develop programs on this system.


■ Composition of this binder

    This manual is composed of the following four manuals.

    1. "System Overview"

      This manual provides an overview of the system hardware.

    2. "SCSP User's Manual"

      SCSP (Saturn Custom Sound Processor) is a Saturn sound generator LSI that combines a PCM sound source and a sound DSP. This manual describes the functions and usage of SCSP.

    3. "SCU User's Manual"

      SCU (System Control Unit) is a Saturn system controller, which includes a DMA controller, interrupt controller, and DSP. This manual describes the functions and usage of the SCU.

    4. "SMPC User's Manual"

      SMPC (System Management & Peripheral Control) is equipped with the clock management function with the Saturn system reset management, peripheral control, and battery backup function. This manual describes the functions and usage of SMPC.
