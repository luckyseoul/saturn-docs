■ Subsystem side

CPU
Performs mechanical control, error collection (C3), CD file management, etc.

RAM/ROM
RAM is used for CD buffer RAM, MPEG work RAM, CD error correction data cache, etc. The ROM contains programs such as the CPU CD BIOS.

CD-ROM drive
Double-speed CD-ROM drive is used.

MPEG Note)
Full Screen, Full Color, Full Motion, and CD Quality Audio can be played under this standard. Up to 72 minutes (30 frames per second) of video and sound can be stored in one CD. In addition to this, there are various application functions that use MPEG functions such as not only outputting the decompressed video but also importing it into the main system and processing it.

Note) MPEG is optional.
