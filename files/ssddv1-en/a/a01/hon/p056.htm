MPEG(Motion Picture ( image coding ) Expert Group)
An international standard for compression of color moving images (including audio) such as TV and video. Full Screen, Full Color, Full Motion, and CD Quality Audio can be played under this standard. In addition to conforming to international standards, there are original special functions.

Parts
Draws with the drawing command and can be divided into texture parts and non-texture parts.

Perth
In order to give a sense of perspective in computer graphics, this is a technique that expresses the distance in the distance and the distance in front.

Sprite
An image pattern that can be moved and redrawn at high speed. By preparing several sprite patterns and redrawing them while moving the specified coordinates, you can create animation effects such as game characters moving around.

High res
Abbreviation for high resolution. Both normal TVs and dedicated monitors can display high-resolution images, but the dedicated monitor provides even higher resolution.

Texture mapping
A computer graphics technique that applies a pattern to an object.

PCM(Pulse Code Modulation)
This method divides the sound (waveform) along the time axis and replaces each peak value with digital data. Data obtained by this method is called PCM data.
