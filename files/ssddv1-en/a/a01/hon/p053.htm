Introduction

This manual outlines the hardware of the Sega / home-use game console Saturn that supports 32-bit RISC (Reduced instruction set computer) processors and supports multimedia. This manual explains the features and functional overview of Saturn for game software developers.

Manual structure

This manual consists of the following chapters, appendices and indexes.

Chapter 1 Introduction to Saturn

    Explains the features of Saturn.

Chapter 2 Structure

    Describes Saturn's internal configuration and hardware specifications.

Chapter 3 Functions

    Describes the main functions of Saturn.

    (1) CPU
      Explains the main CPU, sound CPU, and I / O controller.

    (2) SCU

      Describes control of each bus (A-bus, B-bus, CPU-bus), DMA transfer, and matrix operation (DSP).

    (3) VDP1

      Explains how to define drawing data and control drawing.

    (4) VDP2

      Explains scroll screen control and display control.

    (5) SCSP

      Explains PCM / FM tone generator sound control.

    (6) CD-ROM

      Explains the outline of CD and MPEG.

    (7) Other

      Explains SMPC, etc.
