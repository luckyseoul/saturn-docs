MPEG function

MPEG plays video with audio.
* Because the image data before playback is compressed to about 1/50 and the audio data is compressed to about 1/10, it can be recorded on a CD for 74 minutes. In addition, since playback is performed using a dedicated LSI, the CPU is not burdened at all, and you can play games while playing high-quality video.

MPEG / Video function

Saturn's MPEG / Video has various special functions customized for Saturn.

● Window function
As shown in Figure 3.31, this is a function to cut out a part of the played image and display it on the TV screen in any size. By using this function, you can perform "MPEG playback image display position and display size change", "Select and display one of multiple screens", "Zoom in, zoom out", etc.
