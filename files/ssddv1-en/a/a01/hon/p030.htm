Scale function
The entire screen can be scaled horizontally and vertically. There are restrictions such as reducing the number of faces when zoomed out horizontally.

Line scrolling function
Scrolls up / down / left / right for each line and expands / contracts in the horizontal direction.

Vertical scroll function
A function that allows you to scroll up and down in units of cells in the horizontal direction. For example, you can add depth to a vertical scroll game.

Mosaic function
Each scroll screen is divided into the specified horizontal and vertical directions, and the color of the upper left dot in each area is displayed on all dots in that area.
