MPEG / Audio function

Audio data played back with MPEG / Audio is sent to SCSP via the same route as CD-DA (music CD), and various effects can be applied.

● Variable compression rate
The compression rate can be selected according to the application, and compression from 1 / 3.5 to 1/21 can be selected. With 1/21 compression, you can record 50 hours of audio on a CD. All lines and narration can be performed by voice even with long RPG and ADV.

● On-memory playback function
MPEG / Audio can be compressed from 1 / 3.5 to 1/21, but for example, if half of the 4M bits of CD buffer memory is used for MPEG / Audio using 1/21 compression, You can play 64 seconds of audio without accessing the CD. Therefore, audio playback without waiting time is possible. You can also connect short lines to make long conversations.
