2.3 Description of each part

Below is an explanation of the block diagram in Figure 2.1.

■ Main system side

SH-2 (x 2)
The entire system is controlled by the main CPU. RISC-type high-speed CPU, which has much higher processing power than conventional systems. Since it has the same arithmetic unit as the DSP inside, the computing ability is dramatically improved.

MC68EC000
A 16-bit CPU is installed for sound. The processing speed is faster than the conventional system.

RAM/ROM
RAM is 32M bits in total, 16M bits are allocated to the main CPU, 4M bits are allocated to the sound CPU, and the remaining 12M bits are allocated to video. The ROM contains the hardware initial program and the cartridge and CD IPL programs. In addition to this, a library for CDs will also be included.

SMPC(System Manager & Peripheral Control)
Controls the reset management of the entire system and the interface with external devices such as the control pad. In addition, since it has RTC (Real Time Clock) inside, you can know the calendar and time. When the power is turned off, the RTC is backed up by a battery.

SCU(System Control Unit)
Controls each bus (A-bus, B-bus, CPU-bus) and co-processor of main CPU. Since the DMA controller is built in, character data can be transferred to V-RAM during main CPU operation.
