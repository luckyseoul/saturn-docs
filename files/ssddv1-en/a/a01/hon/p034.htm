Priority function

Display priority of sprites and scroll screens is determined by a 3-bit priority number. You can set up to 8 sprite priority numbers, one of which is specified in character units.

● Priority determination
The priority number of the scroll screen is normally specified in units of planes. (When using the special priority function, it can be changed in character units or dot units.)

Figure 3.20 Priority function

  • Special priority function
    Priority numbers corresponding to each scroll screen can be changed in character units or dot units. By using this function and changing the priority of only a certain part of the scroll screen, you can make one scroll screen appear to have multiple screens.
