Chapter 3 Functions

3.1 CPU

A 32-bit RISC chip with a built-in DSP function is installed in the main CPU, and a MC68EC000 16-bit CPU is installed in the sound block. In addition, SH-1 is installed on the subsystem side.
Table 3.1 shows the specifications of each CPU.

Table 3.1 CPU specifications 
 SH-2 
-RISC type instruction set 
-Internal and external 32 bits Bus 
, cache 4 Kbyte 
, clock 28.6 MHz 
, built-in multiplier / divider 
 SH-1 
-RISC type instruction set 
-Built-in A / D converter 
-Internal 32-bit bus, external 16-bit bus 
, clock 20 MHz 
, cache 4 Kbyte 
, built-in multiplier 
 MC68EC000 
 ・ Internal 16-bit bus, external 16-bit bus 
 ・ CISC type instruction set 
 ・Clock 11.3MHz
