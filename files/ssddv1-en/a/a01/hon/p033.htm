● Window
Windows are classified into three types according to the area specification (coordinate specification) method.

  • Normal rectangular window
    Specified by the coordinates of the start point and end point

  • Normal line window
    Specified by the coordinates of the start point and end point line

  • Sprite window
    Specified by sprite character pattern
