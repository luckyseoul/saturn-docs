■ Function

The main functions of VDP1 are as follows.
Drawing
  • parts (character lines)
  • Color mode specification
  • Color calculation
  • Mesh processing
  • Specifying clipping and relative coordinates
  • Frame buffer display control
Parts, color mode, and coordinates are controlled by the command table on VRAM, and display of the frame buffer is controlled by system registers.
