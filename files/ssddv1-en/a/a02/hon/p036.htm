Table 4.11 SBCTL function
Bit Function
SBCTL0 Invert the sign other than the sign bit of the source waveform data
SBCTL1 Specify the sign bit of the source waveform data inversion

SSCTL[1:0](R/W) ; Sound Source ConTroL
Specify the data to be used as sound input data. Write "0B" to generate sound using waveform data on the sound memory. When this register is set to "1B", noise is output from the slot (LFO attached to each slot) where the setting is made.
