4.3 DSP memory control register

RBL [1: 0] (W); Ring Buffer Length
Specify the length of the ring buffer.

Table 4.41 RBL and ring buffer length
bits buffer length

RBP [19:13] (W) Ring Buffer (header) Pointer
Specify the top address of the ring buffer. This specification is specified on a 4Kword boundary.

The basic process for DSP effect processing is delay processing. Delay is realized by storing input data in memory and reading it with a time lag. This storage area is called a ring buffer.
∙ The ring buffer area can be set using the "RBL" and "RBP" registers according to the number of effect programs used at the same time and the effect delay time.
