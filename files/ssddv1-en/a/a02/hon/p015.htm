Memory controller
This block controls the sound memory by outputting the address generated by the address pointer to the memory and reading the data.

INTERPOLATOR
This block performs interpolation calculation of waveform data.

Envelope Generator
This is a function operation block that controls the audio output level in time.

Level calculator
This block calculates the waveform output level based on the level coefficient generated by EG, TL (Total Level), and ALFO.

DSP
An audio DSP that handles SCSP sound special effects.

Output mixer
This is the final block with various localization operations and level adjustment functions to combine each audio output into a stereo output.
