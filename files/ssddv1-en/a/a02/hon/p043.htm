RR [4: 0] (R / W); Release Rate
Specify the amount of EG change in the released state.
When "RR" = "00H", change (level attenuation) is minimum (0)
When "RR" = "1FH", change (level attenuation) maximum (MAX)

DL [4: 0] (R / W); Decay Level
Specify the upper 5 bits of attenuation level (EG) for transition from decay 1 state to decay 2 state. When the upper 5 bits of the attenuation level are equal to the DL value in the decay 1 state, the state transitions to decay 2.

KRS [3: 0] (R / W) Key Rate Scaling
Specify the degree of key rate scaling of EG.
00H represents the minimum scaling and 0EH represents the maximum scaling. When 0FH, specify scaling OFF.

LPSLNK (R / W); LooP Start LiNK
The “LPSLNK” (loop start link) function synchronizes the transition from the start of the loop and the attack state of the EG to the decay 1 state.
”When" LPSLNK "=" 0B ", the transition of the EG state and the position of the loop start point are irrelevant.

When "LPSLNK" = "1B", the following two changes can be seen.

  • When the EG reaches "000H" in the attack state, the waveform read address is earlier than the loop start point ("SA" + "LSA") (Figure 4.15)

In this case, EG reaches MAX level first (P.1). However, since the transition to the next segment (decay 1 state) cannot be made until the waveform readout address reaches the loop start point, the EG continues to hold the MAX level. Next, when the waveform readout address reaches the loop start point (P.2), the EG will transition to the decay 1 state.
