FM modulation control register

SOUS [15: 0] (R / W); SOUnd Stack
Data buffer for slot output. A 64-word ring buffer can hold two generations of sampling data. This is used for modulation and addition between slots.

MDL [3: 0] (R / W); MoDuLation level
Specify the influence (modulation degree) on the modulation of the modulation input source.

MDXSL [5: 0] (R / W); MoDulation input-X SeLect
Specify the source to be used as modulation input X. Specify the source slot of modulation input X as a 2's complement relative number from the current slot. When this value is within the range of "1CH" to "3BH", it indicates the latest generation, and when it is out of the range, it indicates that the source is one sample past the latest generation (see Table 4.16).

MDYSL [5: 0] (R / W); MoDulation input-Y SeLect
Specify the source to be used as modulation input Y. Specify the source slot of modulation input Y relative to the current slot in 2's complement. When this value is within the range of "1CH" to "3BH", it indicates the latest generation, and when it is out of the range, it indicates that the source is one sample past the latest generation (see Table 4.16).

STWINH (R / W); STack Write INHibit
When this bit is “1B”, writing slot output to the sound stack (SOUS) is prohibited. Normally "0B" is acceptable.
