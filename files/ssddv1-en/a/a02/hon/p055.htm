Level multiplication section
Multiplies the waveform read from the waveform memory by the level coefficient generated by ALFO, TL (Total Level), and EG. In addition, the actual waveform output level is adjusted.

Waveform RAM
RAM for sound.

Waveform address pointer
This block generates or stores the actual waveform memory address by adding or subtracting the SA (start address) value set in each slot and the waveform phase value output from the phase adder.

Waveform data buffer
Memory for temporarily storing the waveform read from the waveform memory.

PG(Phase Generator)
Manages the reading speed of the sound frequency waveform. (In fact, the waveform is skipped.)

EG(Envelope Generator)
A block that creates a temporal change in value (envelope curve) according to each rate and level setting. Since the value generated here is sent to the level calculator and then multiplied with the waveform data, the waveform output level will change over time.
