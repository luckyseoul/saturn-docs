(b) When KEY_OFF is performed during Decay 1 segment transition (Figure 4.13)

Figure 4.13 KEY-OFF during decay state transition

When entering the Decay 1 state, the value decays toward DL (Decay Level) according to the D1R (Decay 1 Rate) setting. If KEY_OFF is executed in the middle of this, it will be attenuated according to the set value of RR (release rate) from the level (KEY_OFF-LEVEL) at the time of KEY_OFF.

AR [4: 0] (R / W); Attack Rate
Specify the amount of EG change in the attack state.
When "AR" = "00H", change (level increase) minimum (0)
When "AR" = "1FH", change (level increase) maximum (MAX)

EGHOLD (R / W) EG HOLD mode
Specify whether to keep or change the value in the attack. As shown in Figure 4.12, when this bit is "1B", the attack value is "000H". When the bit is "0B", it changes according to the value specified in the AR register. When in hold mode, the time that EG holds “000H” (time until moving to segment 2) is determined by the value of “AR”.
