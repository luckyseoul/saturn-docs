ISEL [3: 0] (R / W); Input SELect
Specify the mix stack number for each slot when inputting sound slot output data to the DSP's mix stack register ("MIXS").

The mix stack ("MIXS") calculates the sum of the input for all slots and uses it as the DSP input. Since the mix stack has no overflow protection function, set the sum of all slots so that it does not exceed "0 [dB]".
