The following points should be noted when interfacing with the main CPU.
  1. Read / write in 16-bit units. It cannot be accessed in 8-bit units from the main CPU.
  2. When there is a read / write request, the address and data are taken into the SCSP buffer. As a result, "1" is output to the ready signal (MCRDYN) to the main CPU and a wait occurs. Since this wait continues until the internal processing of the LSI is completed, do not use continuous writing that causes frequent waits unless the power is turned on.
  3. When the power is turned on, the time required to initialize the sound memory by continuous writing is about 100msec with 4Mbit DRAM.
