Next, the SCSP chip block diagram shown in Figure 2.1 is explained.

Sound CPU interface
Interface to connect MC68EC000.

Main CPU interface
This interface connects the system controller (SCU).

DMA transfer interface
Data transfer between SCSP and sound memory is possible with DMA controller with built-in SCSP.

MIDI interface
Serial interface compatible with the MIDI standard. However, some external circuitry is required to support MIDI connectors.

External input (external digital audio input interface)
An interface that receives digital audio signals from external devices (external devices).

LFO (Low Frequency Oscillator)
A function generator that generates a waveform with a frequency lower than the range that can be heard by the human ear, and is used as a waveform for various modulations.

Phase Generator
This block calculates and calculates frequency information according to the sound frequency setting of PCM data.

Address pointer
Generates a waveform address value based on phase information from the phase generator.
