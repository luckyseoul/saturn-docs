■ Saturn 6P multi-tap (tentative name)

Saturn 6P tap is a 3-wire handshake peripheral.
∙ Peripherals that can be connected are Mega Drive 3 Button PAD, Mega Drive 6 Button PAD, Sega Mouse, Saturn Standard PAD, Saturn Analog Joystick, Saturn Keyboard. The maximum size of each Saturn 6P multi-tap is 15 bytes. When a peripheral of 16 bytes or more is connected, data of up to 15 bytes is collected. From the Saturn 6P multi-tap, the aforementioned data is output in SMPC control mode. All supported peripheral data is output with the Saturn peripheral ID as a header.
∙ Start when TH is set to 0B, and end when both TH and TR are set to 1B.
The first data is the Mega Drive ID acquisition phase. Data can be obtained by changing TH from 1B to 0B. Read R, L, D, U after 2μS after TH change.
