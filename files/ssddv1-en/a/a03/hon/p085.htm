■ Saturn 6P multi-tap (tentative name)

In SMPC control mode, the port status shown in Table 3.21 is output. The Saturn 6P multi-tap can be connected to a Megadrive 3 button PAD, a Megadrive 6 button PAD, a Saturn standard PAD (tentative name), a Saturn analog joystick (tentative name), a Saturn mouse (tentative name), and a Saturn keyboard (tentative name). For the data of each peripheral, refer to the data format of each peripheral.
The maximum data size for each Saturn 6P multi-tap is 15 bytes. Use port mode in 15-byte mode.
