● Keyboard device

A device typified by a full keyboard used in a personal computer.
Peripheral type is 3H and data size is 4 bytes.
As a feature of the format, 1st Data has a configuration equivalent to a Mega Drive 3-button PAD. Compatibility can be secured by building an application so that the application can be controlled with just 1st Data. Table 3.13 shows the standard format of the Saturn keyboard device.
