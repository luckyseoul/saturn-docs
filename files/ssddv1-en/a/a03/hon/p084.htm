 KBTYPE2 ~ 0 000: Saturn keyboard
001-110: SEGA RESERVED
111: UNKNOWN

The KBTYPE shown here is used for the IBM keyboard conversion adapter format. 000 is displayed when an IBM keyboard 101,102,106 keyboard is connected to the conversion adapter. If a keyboard that does not correspond to the conversion adapter or a device that cannot be recognized as a keyboard is connected, 111 is output. If the keyboard will be integrated in the future, it will be configured to output 000.
Caps Lock is 1: Caps Lock is locked (Caps Lock LED is lit)
Num Lock is 1: Num Lock is locked (Num Lock LED is lit)
Scroll Lock 1: Scroll Lock is locked (Scroll Lock LED is lit)
