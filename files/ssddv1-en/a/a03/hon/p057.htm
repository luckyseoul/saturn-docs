● Notes on optimizing peripheral data collection time

Peripheral data collection timing varies depending on the type and number of connected peripherals. When optimizing the peripheral data collection time, clarify the type, number, and combination of the corresponding peripherals and evaluate them sufficiently to prevent the occurrence of time-over.
Also, when there is a continuation, the continuation request wait time is also measured as the peripheral data collection time. Therefore, be careful to keep the time from SMPC interrupt generation to the continuation request as short as possible and to execute it in a certain time.
