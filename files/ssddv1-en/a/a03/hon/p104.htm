Introduction

■ Explanation of words

The words used in this manual are explained below.

SMPC(System Management & Peripheral Control)
Controls the interface with peripheral devices such as Saturn system reset management and control PAD.
In addition, the RTC (Real Time Clock) function that can back up the battery is installed, and the calendar clock can be set and acquired.

SCSP(Saturn Custom Sound Processor)
This is a multi-function game tone generator LSI that combines a PCM tone generator and a DSP for sound.

DSP(Digital Signal Processor)
This is a dedicated high-speed arithmetic circuit that mainly performs high-speed operations (multiplication / addition).

VDP1(Video Display Processor 1)
LSI that controls drawing of sprites and polygons. VDP1 is connected to VRAM and frame buffer. These use the drawing commands transferred from the CPU to the VRAM and execute drawing to the frame buffer. After that, the drawing data is transferred from the frame buffer to VDP2 according to the request from VDP2 and displayed on the display device.

VDP2(Video Display Processor 2)
Equipped with scroll surface control function and priority function.

PLL(Phase Locked Loop)
Various clocks for the Saturn system (clock generator for CPU, system control, image drawing / display, sound, etc.).
