Megadrive 3 button PAD

The Megadrive 3-button PAD is a TH-controlled peripheral. The access protocol outputs 1st data and 2nd data alternately by repeating the inversion of the TH bit. Megadrive peripheral ID is DH. Table 3.25 shows the access protocol and data format of the Megadrive 3-button PAD in SH-2 direct mode.
Please read TR, TL, R, L, D, U after 2μS after TH change.

Megadrive 6 button PAD

Mega Drive 6 Button PAD is a TH control type peripheral. The access protocol repeatedly outputs 1st Data to 8th Data by repeatedly inverting the TH bit. Megadrive 6 button PADs have the same Megadrive peripheral ID for compatibility with Megadrive 3 button PADs. With the 6-button PAD, the ID changes from DH to CH when ID discrimination continues until 6th Data. Table 3.26 shows the Megadrive 6 button PAD data format in SH-2 direct mode.
Please read TR, TL, R, L, D, U after 2μS after TH change.
