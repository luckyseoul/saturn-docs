■ Command parameter of INTBACK command when acquiring peripheral data
The command parameters for acquiring peripheral data using the INTBACK command are described below.

●IREG0

There are two types of IREG0 settings: INTBACK command issuance, continue, and break request.

When issuing an INTBACK command

IREG0 is used for the SMPC status acquisition switch.

Figure 3.6 IREG0 (when INTBACK command is issued)

Continue, break request

IREG0 is used for continue request and break request to SMPC.
* SMPC starts collecting the remaining peripheral data when there is a request to continue. When there is a break request, the peripheral data collection is terminated and the INTBACK command is terminated.
