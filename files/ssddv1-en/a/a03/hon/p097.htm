■ Saturn standard PAD (tentative name)

Saturn standard PAD is a TH and TR control type peripheral.
∙ Data is output by repeating the TH and TR bits with the specified bit pattern. After changing TH and TR, read R, L, D and U after 2μS.

■ Saturn Analog Joystick (tentative name)

Saturn Analog Joystick is a 3-wire handshake peripheral. It starts when TH is set to 0B, and ends when both TH and TR are set to 1B.
The first data is the Mega Drive ID acquisition phase. Data can be obtained by changing TH from 1B to 0B. Read R, L, D, U after 2μS after TH change.
