■ Saturn Peripheral ID

● Saturn Peripheral ID Configuration

Saturn peripheral ID consists of peripheral type and data size. With the Saturn peripheral ID, you can recognize the configuration and contents of the peripheral data. The configuration of the Saturn peripheral ID is shown in Figure 3.15.

Figure 3.15 Saturn Peripheral ID Configuration

Saturn peripheral type
Saturn peripheral type indicates the type of peripheral. Therefore, it can be used to recognize how the peripheral data is arranged. Saturn currently defines four types of peripherals and presents them as standard formats. For details, please refer to the section of Saturn Peripheral Standard Format.

Data size
The data size indicates how many bytes of peripheral data are output after the Saturn peripheral ID. Therefore, by using the data size, it is possible to recognize how many bytes of the peripheral data table are configured.
You can also recognize where the head of the next peripheral data table is.
