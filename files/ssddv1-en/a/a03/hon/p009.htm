EXLE2 (W): EXternal Latch Enable 2
This bit sets whether to use bit 6 of peripheral port 2 (P2) as an input to the PAD interrupt or VDP2 external latch. Writing "0" disables it, and bit 6 of peripheral port 2 is set as a normal I / O port. When "1" is written, bit 6 of peripheral port 2 can be used as a PAD interrupt input or VDP2 external latch input. Byte access from SH-2.

EXLE is multiplexed to bit 6 of the I / O port. Therefore, when using EXLE, it is necessary to set bit 6 of DDR1 / DDR2 to input. (Refer to VDP2 external latch function and SCU PAD interrupt.)
