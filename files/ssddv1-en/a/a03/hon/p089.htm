■ SH-2 Direct Mode Access Procedure for Peripherals with 5H Mega Drive Peripheral ID

The following shows the access procedure in the SH2 direct mode for a peripheral with a 5H mega drive peripheral ID.

  1. Get Mega Drive Peripheral ID.
  2. Saturn peripheral ID is acquired by executing the protocol according to the Megadrive peripheral ID.

    ∙ Protocol can be determined by D and U that make up Megadrive Peripheral ID. The other combination is SEGA RESERVED.

    3-wire handshake peripheral 

     D, U = 0, 1 (TH = 1)
 D, U = 0, 1 (TH = 0)

  3. Obtain the Saturn peripheral ID, access the number of times according to the data size, and receive all peripheral data.
