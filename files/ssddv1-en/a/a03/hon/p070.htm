● Saturn Peripheral ID Details

When a peripheral is connected directly to a peripheral port

Saturn peripheral defines data size up to 255 bytes.
Saturn peripherals include peripherals of 15 bytes or less and peripherals of 16 bytes or more and 255 bytes or less. Port mode has 15 byte mode and 255 byte mode. Therefore, there are four possible combinations of peripheral data size and port mode as shown in Table 3.8. The configuration of the Saturn peripheral ID and peripheral data is as shown in Figures 3.16 to 3.18.
