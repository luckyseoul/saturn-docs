6. Start / Option selection

* "Option" belongs to "After the game starts". On this start / option selection screen After the game start is selected, the “main game” is assumed.

    1) Differentiating from the title screen (game start screen)

      The start / option selection screen should not be the “game start screen”. (After pressing the “Start button” on the title screen, select Start / Option again.

      You can use anything other than the “menu”.

    2) Menu selection restrictions

      Control pad connection status and start status from title screen Select items that cannot be played in that situation.

        Example) “2 PLAY when CONTROL PAD is connected to“ Terminal 1 ”only START "etc.

      For restricted items, the menu itself is not displayed, and menus that cannot be selected are displayed. Make sure that the cursor is not on the screen. (It is possible to visually distinguish that it cannot be selected. Change the shape and color of the text)

    3) Progress to the next screen

      Select with “Direction button”, decide with “Start button”, Or proceed to options.
