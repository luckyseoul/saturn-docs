8. Main game

1> Screen display

    1) Restriction of display range of important items

      Game screen within 2 cells left and right, within 1 cell above and below (equivalent to 40 × 28 cell mode) Does not display important information such as the score or the number of remaining aircraft. (Difference in display area size between monitors Limit)

    The

    2) Unified terminology / notation

    • English katakana notation is unified. 

      PLAY → Play (Play is not used)
PLAYER → Player (player is not used)
SCORE → Score (Score-is not used), etc.
    • Score / High score are standardized as follows.
      ○ (recommended notation) × (prohibited)
      Score at 1PLAYER ONLY SCORE POINT
      2PLAYER score PLAYER1 (1P) / PLAYER2 (2P) 1PU / 2UP
      High score HI SCORE (TOP)

      Table 8-1 Recommended notation of score / high score

    • The number of remaining aircraft does not count the aircraft that the player is currently operating.

        Example: If the number of remaining aircraft is displayed as 2, the aircraft that the player is currently operating Recognize that there are two remaining machines.
        Therefore, if the game is over if one more machine is lost, the remaining machine display number is set to zero.

        Example) It is not good that “Tournament” is one of the items of “Tournament mode”.

    • Kanji level used is constant.

        Example) “Equipment” is kanji, but “speaking” learned in lower grades is hiragana. In this case, both kanji or both hiragana.

    3) Score

      The initial score is set to “0”.

    4) High Score

      The high score is not initialized even if it is reset.
      The high score and the score of the previous play can be confirmed during the demo game

3> Pause

* As for poses, they are poses due to the nature of games such as role playing games and adventures. Items that are not required or that use the “start button” for other purposes are excluded.

    1) Pause on / off

      Pause on / off is always done with the "Start button".
      In the case of two players playing at the same time, both CONTROL PADs can be paused / released. In this case, operations on the “terminal 1” and “terminal 2” sides are independent (pause on the “terminal 1” side). It is desirable that it can be released only on the “terminal 1” side.

    2) Screen display

      Displays [PAUSE] on the screen during pause. (Bug hangs and

      when the pause operation on the "Terminal 1" and "Terminal 2" sides is made independent during two-player play It is desirable to distinguish between [PLAYER1 PAUSE] and [PLAYER2 PAUSE].

    The

    3) Pause prohibited status

      Developer logo, title screen, demonstration screen, and nothing on screen At the time of pose, do not apply the pose.

    The

    4) Paused sound

      Make sure the sound is turned off during pause. If BGM is interrupted by pause, Continue from where it left off.

4> Reset

* Sega Saturn has a hardware reset and a CONTROL PAD button that you can use with the “Reset button on the main unit” There is a software reset that can be done with a combination of "A + B + C + start button" Both are defined in the program. The former hardware reset means power off / on It is necessary to define the same result, but the latter soft reset is Define it to be user-friendly by adding processing such as changes and data retention. The reset specified in this preparation standard is the combination of the latter CONTROL PAD buttons. ("A + B + C + Start button") is a software reset.

    1) Reset

      Make sure that "Reset" is applied on any screen.
      In this case, High score and optional settings are not cleared.
      (Reset only within the main game)

      * Excludes special processing timing such as disk access.

    The

    2) How to reset

      If "A + B + C button" and "Start button" of CONTROL PAD are pressed at the same time (In terms of processing, if the "A + B + C button" is pressed at the same time and the "Start button" is pressed) Reset takes place, and depending on the state at that time, it jumps to the following screen respectively.

    • In the main game (after starting the game) → "Title screen" (game start screen)

    • In the title loop (before the game starts) → "Multiplayer screen" (in the main unit BOOT ROM)

      The

      * When resetting from within the title loop (when moving to the “Multiplayer screen” on the console) The high score option settings may be initialized.

    The
    Reference) Reset omnibus application
    For omnibus-style software that allows you to play multiple titles, In the main game (after each game start) reset, each "title screen" From each title loop, “Main title (integrated title) screen and main title loop It is desirable to perform a gradual reset that returns to the "Multiplayer screen (in the main unit BOOT ROM)".
    • In the main game of each game → "Title screen" of each game
    • In each game title loop → "Main title (integrated title) screen"
    • In the main title loop → "Multiplayer screen" (in the main unit BOOT ROM)

5> Game Over / Continue

    1) Continue

      In principle, set the continue function. There is no specific number of times to continue, The system shall be based on the following.

      • [YES or NO] Basic selection method
      • Determine with "Start button", do not use other buttons
      • Perform a “countdown” to return to the “Company Name Logo” after a certain time
        (Do not speed up the countdown by pressing a button)
    The

    2) Progress to the next screen

      If no continue selection is made, it will be the first application in a certain time Return to "Company Name Logo".

6> Ending / Staff Roll

    1) No cancellation

      Ending / staff roll should not be canceled (skip).

    The

    2) Progress to the next screen

      After ending / staff roll, use timer or any button input Return to the beginning of the application ("Sega Logo").
