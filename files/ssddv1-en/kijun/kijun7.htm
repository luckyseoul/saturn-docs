7. Options

    1) Options

      Optional if possible, unless it impairs gameplay or is not ported to the original game Insert.

    The

    2) Optional items

      The following items are standard. 

      LEVEL difficulty setting
PLAYER Number of players setting
CONTROL Control settings
(RAPID blaze setting)
AUDIO Audio output setting
SOUND TEST Sound test
Exit from the EXIT option

      * Make audio output settings (switch between stereo and monaural) as much as possible.
      (Please refer to 9. Supplement 3> About audio output settings)

      * Supports the internal clock adjustment function (time adjustment, etc.) in the main unit BOOT ROM. Therefore, it is prohibited in principle to put it in the application.

      * The CONTROL setting is preferably of a type that can be set for each button.

    The

    3) How to operate

      Select the item to be changed with “Up / Down Direction Button” and change the item contents with “Direction Button Right / Left”. The operation to perform the update is standard.
