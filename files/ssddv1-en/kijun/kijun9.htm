      During the game, the “open button” on the main unit is pressed to open the CD door. If done, "Multiplayer screen" in the BOOT ROM as well as "Reset" in the title loop To fly. In this case, as with “Reset” in the title loop, The high score option settings may be initialized.
      (Limited to single-CD applications)

    3> Audio output settings

      For audio output setting (switching between stereo and monaural), the audio terminal has only one pin. Considering the case of playing on a monaural TV, the application side as much as possible Correspond with. Observe the following rules when responding.

      • The default setting matches the BOOT ROM setting
      • Change the settings on the BOOT ROM to match the settings on the application. Do not change ( Do not rewrite the settings in the BOOT ROM of the main unit )

      This setting item is also supported by the BOOT ROM of the main unit. Simple specifications are also accepted. In this case, the settings of the BOOT ROM of the main unit are changed for each play. Refer to and match the contents.

      * In applications where all sounds in the game are monaural, the BOOT ROM May not match the settings. In that case, write a proviso to that effect on the package or instruction manual, Call attention not to mislead.

    The

    4> About language settings for multi-compatible applications

      Language settings for displaying messages in multi-compatible (multi-language) applications Refer to the setting contents of the BOOT ROM of the main unit and adjust it accordingly.
      If the BOOT ROM is set to a language that is not supported by the application, The display message is determined according to the following rules.

      • If "English" is supported, give it the highest priority and use "English"
      • In other cases, the language is determined in the following priority order
        German> French> Spanish> Italian> Japanese

      * In this case as well, the settings on the BOOT ROM side of the main unit are not changed in accordance with the setting changes on the application side.

    5> Hidden command rules

    The hidden commands shown below are supported as much as possible.

    1. Pause character deletion

      Possible to erase pause characters, mainly for screen shots.
      The commands are standardized as follows. (Processing after erasure is free)

      command → X + Y + Z during pause (X, Y, Z button pressed simultaneously) ~ Common command

      * For applications that have movements on the screen even during a pause, use this command. It is desirable to delete the pause characters and stop all movements in the screen.

    6> Regulations for DA track

    1. Minimum track configuration

      If your application uses a CD-ROM, you must insert at least one DA. (In addition to the first track (DATA track) where the program is written, at least one more track) (AUDIO track, minimum 4 seconds) required) Therefore, at least 2 tracks are configured.

    2. Handling caution announcements

      When you listen to the Sega Saturn CD with a regular CD player, the first track is available depending on the model. (DATA tracks, sounds like noise) may be heard as is. To prevent this, It is recommended to include audio data of “Caution announcement”.
      (This audio data is provided in the library)

      Caution announcement "This CD is for Sega Saturn only ..."

      Pattern 1) Insert as DATA at the beginning of the first track (DATA track) <

      Pattern 2) If you don't use any DA song in your application, this “Caution announcement” Audio data as the only DA (AUDIO track).
