4. Title screen

* This title screen is defined as the “game start screen”. "Start button" on this screen It is assumed that “after the game is started” after “” is pressed, and “before the game is started” before that.

    1) Screen display

      Display at least the following three items.

    • Title logo
    • [PRESS START BUTTON] (Do not use "PUSH")
    • Copyright

    2) Title logo notice

      (Please refer to the SEGA display example)

      Like the Sega logo, the title logo should be displayed in the final form for about 2 seconds.

    3) Copyright notice

      Copyright is always displayed at the bottom of the game start screen (ie title screen).

      [(C) △ SEGA △ ENTERPRISES, △ LTD. △ 1996】

      △ = Space symbol

      * [(C) △ [official company name] △ [first issue year]]. There are no special rules for fonts and colors. First issue year Is the first release year.

    4) Progress to the next screen

      Here, press Start button on the CONTROL PAD to select the start / option. Proceed to the selection screen. Since this screen is the “game start” boundary, other than the start button Do not react. (except for mouse operations)
