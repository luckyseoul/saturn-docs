2.6 Add sound

Use MoviePlayer to add sound after creating a Cinepak movie with only
video. Open a sound file in AIFF format with MoviePlayer (the movie has no video). Similarly, open a movie-only Cinepak movie and paste a movie-only movie. Be sure to hold down the Option key when pasting.

Operation

  1. Cinepak movie with only video and open sound file with MoviePlayer
  2. Copying a movie with only sound after Select All
  3. Paste while holding down Option key after selecting Cinepak movie with video only
  4. Save after playback confirmation

2.7 Conversion to Saturn format

Use
MovieToSaturn_J to convert the edited Cinepak compressed file into a Saturn format movie file.

Operation

  1. Copy MovieToSaturn_J to an appropriate folder on Macintosh.
    Start
  2. MovieToSaturn_J, select the file you want to convert, and click the "Open" button (Figure 2.7).
  3. A save dialog opens. Enter the file name for saving (Figure 2.8). By default, ".CPK" is added to the end of the conversion source file name.
  4. Click the “Save” button to start conversion.
  5. Automatically ends when conversion is complete.
