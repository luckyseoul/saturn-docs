5. Film analysis utility FA (Film Analyzer)

“Film Analyzer FA” is a utility program for analyzing the Saturn Cinepak movie converted by MovieToSaturn_J.

5.1 Function

Displays the contents of the Cinepak movie for
Saturn.
Calculate and display data rate, compression rate, and key frame rate.
Calculate and display the ring buffer size required for movie playback.

5.2 Operating environment

IBM PC / AT compatible machine
MS-DOS Ver.5.0 or later

5.3 Operation method

From the MS-DOS command prompt

C> FA filename

Will display the analysis result as shown in Figure 5.1.
