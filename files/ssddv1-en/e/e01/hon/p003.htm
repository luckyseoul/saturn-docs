1. Overview

Cinepak for Saturn is software for easily incorporating Macintosh QuickTime movies into SEGA-SATURN. With Cinepak for Saturn, you can drastically improve the quality of the video embedded in your game, significantly reducing the production time of movies for SEGA-SATURN.
To create a Saturn Cinepak movie and use it in a game application, you generally need to:

  • Digitize video material and convert to QuickTime movie
  • Edit movies using the QuickTime editing tool
  • Cinepak compression of edited QuickTime movie
  • Using MovieToSaturn_J provided by SEGA, convert Cinepak-compressed QuickTime movie to Saturn format Cinepak movie
  • Create an application and play a Cinepak movie using the Cinepak library provided by SEGA

1.1 Features

The characteristics of
Cinepak for Saturn are as follows.
  • Continuous playback and branch playback can be performed seamlessly for both sound and video.
  • Multiple movies can be played simultaneously.
    The
  • chroma key function allows you to combine only a specific part of a movie onto another movie or still image.
  • The specified frame expansion function allows movie frames to be used as still images.
  • CD-ROM XA format (Mode2Form1) is supported, so multiple movies, movies and data (collision data, etc.) can be interleaved.
