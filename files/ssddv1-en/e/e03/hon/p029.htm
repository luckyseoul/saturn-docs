3. Author converter

3.1 Overview

This section describes the functions and operation methods of the Saturn Author conversion part (hereinafter referred to as the author converter).
The author converter converts the file output by the author editor for the author player.
For the data file used by the author converter, refer to “5. Data Format”.

3.2 System configuration

Function overview

An overview of the functions of this system is shown below.
  • Make movie file and collision file interleaved. Actual interleaving is performed by a virtual CD. The author converter creates an interleave definition file.
  • Outputs a script file for creating a CD-ROM image. The virtual CD creates a CD-ROM image based on this script file.
