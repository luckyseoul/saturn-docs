    Load Object
    “Load Object” is used to load object data into the object window. The object data is an already edited QuiukTime movie or PICT file with a file extension of "MOV" or "PCT".
    When the object window is active and “Load Object” is selected, a dialog box appears, displaying a list of object data that can be opened (Figure 2.9). When you select and open the necessary object data, object images are set in order from the 10th in the object window (Figure 2.10).
