[6] Save the file
All operations from [1] to [5] are scenario data. If a new scenario is created, select “Save As” from the File menu and save the created scenario with a file name. The file name of the scenario is assumed to have an extension of “ASC” in accordance with the file name rules of “5. Data format”. If you do not need to change the file name, select “Save” to save. When saving a scenario, the collision file, layout file, and environment file are saved at the same time.

[7] Check the scenario
Check the saved scenario with the simulator. Select “Start” from the Simulation menu to play the saved scenario on the screen window. Saturn PAD supports Macintosh mouse and keyboard.
