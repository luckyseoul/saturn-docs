This section explains the format of the data file output by Saturn Author.

Output data file

Table 5.1 lists the data files output by Saturn Author.

 Name 
 Description 
 Scenario file

. Text format.

 Describes collision information, branch destinations, and display coordinate data for moving images and still images. Text format or binary

 Describes information for dividing a movie 
 file to continuously play the movie file in real time. Text type

A text data file consists of a command token followed by zero or more settings. If there are multiple settings, specify them separated by spaces or tabs. Leading spaces and tabs are ignored.
