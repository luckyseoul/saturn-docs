Edit menu

The
    Edit menu contains commands for editing object data and collision frames. When you edit the collision frame, the action set for it is also edited. Only “Clear” can be used to edit object data.

    Table 2.3 Edit menu 
     Edit menu 
     Description 
     Undo 
     Undoes the previous edit to the collision frame. If you do 
     again, it will return to the original state with the cancellation. 
     Cut 
     Deletes the selected collision frame and saves it to the paste buffer 
    . The cut object can be pasted 
     elsewhere. 
     Copy 
     Saves the selected collision frame to the paste buffer. 
     Paste 
     Outputs the contents of the paste buffer saved with “Cut” and “Copy”. 
     Clear 
     
     Delete the selected object data or collision frame. The deleted contents are not saved in the paste buffer.
