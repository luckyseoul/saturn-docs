    Display Objects are automatically deleted after a specified time. Saturn sprite special functions (deformation, etc.) and scroll surface control (rotation, scrolling, etc.) are not possible.
    Up to 32 objects can be displayed on the TV screen at the same time. However, the number of displays is limited by Saturn's VRAM.

    Priority
    The display priority is as follows.

    Scroll surface Collision You can set collisions for pictures, animations, and movies.
    Collision is used to determine the hit with the cursor, and you can set the processing to be performed when the pad, top / bottom / left / right, A, B, C, or START button is pressed. For example, you can specify that if the A button is pressed, it will branch to another video.

    Below is a brief description of each object.

Picture The
    picture displays a single still image for a specified time.
    Display destination: Sprite surface, scroll image
    Display size: Horizontal: 8-320 (multiple of 8)
    , Vertical: 1-224
    Number of display colors: 32000 colors (RGB solid)

Movie
    Movie plays MPEG and Cinepak. You cannot play multiple movies at the same time.

    MPEG video
    Display destination: Direct surface, sprite surface, scroll surface
    Display size: Horizontal: 16-352 (multiple of 16)
    Vertical: 16-240 (multiple of 16)
    Number of display colors: 16 million colors (direct surface)
    32,000 colors (for sprite and scroll surfaces)

    Cinepak video
    There are no restrictions.
