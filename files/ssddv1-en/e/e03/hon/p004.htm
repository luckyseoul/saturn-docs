Event
Factors that cause collisions to be selected. Events include pad operation and time.

Action
What to process when a collision is selected. Branching, object display, etc.

Tag
The name given to the scenario time. Become a branch destination.

Branch
Move to the specified tag.

Interleaved file
A file that interleaves movie files and collision files.

Interleave definition file
Definition file for creating an interleave file output by the author converter. Build this file into a script file and create an interleaved file with a virtual CD.

Virtual CD
Saturn CD-ROM emulator.

Script file
A text file that defines how to create a CD-ROM image. The virtual CD interprets this file and creates a CD-ROM image.
