Preload

    Preload is a function that reads a specified object (picture) from a file into memory when the author player is started. If you want to display objects on the screen instantly in response to user operations, preload them.
    Otherwise, there will be a time lag when reading files from the CD-ROM. Therefore, preload objects other than videos so that they can be displayed on the screen instantly.
    The number of objects that can be preloaded is limited to Saturn's RAM. It is roughly the following degree.
    Display size: 80 × 80
    Display number: 32
    Display color number: 32000 colors (RGB solid)
