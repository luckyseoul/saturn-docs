1.5 About installation

Saturn Author provides the following files. There is no special installation program, so copy the necessary files to an appropriate folder or directory.

  • Author Editor

File name AT_EDIT

Copy AT_EDIT to a suitable directory on your Macintosh hard disk.

  • Author converter

File name AT_CNV.EXE

Copy AT_CNV.EXE to an appropriate directory on the PC / AT hard disk and set the path.

  • Author player

File name AT_PLAY.ABS

Used when creating a CD-ROM image with a virtual CD.

1.6 Terms used in this document

The terms used in this manual are explained below.

Object
Unit processed by Saturn Author. There are movie, picture, cursor and so on.

Collision frame
A rectangular area that is determined to have collided.

Movie

QuickTime movie. Cinepak and MPEG can be used.

Picture
Still image. PICT files can be used.

Cursor
What the user is operating. It's like a mouse cursor on a computer. You can make a picture a cursor.

Scenario
Specifies the display timing of the object.
