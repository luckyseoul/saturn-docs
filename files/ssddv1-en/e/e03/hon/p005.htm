2. Author Editor

2.1 Overview

This section explains the functions and operation methods of the author editor.
The author editor is an editing program that integrates multiple pieces of material data (QuickTime movie and PICT) edited individually to create scenarios, that is, to create applications using movies. You can add a collision frame to a movie or picture, and branch the movie by collision detection by collision pad and Saturn PAD operation. The scenario edited here can be simulated on Macintosh, converted by the author converter (to be described later), and then run on the author player as an embedded application.
Data edited with the author editor can be used not only as an author player but also for programs created by game application developers.
For the data file output by the author editor, see “Data Format” in Chapter 5.
