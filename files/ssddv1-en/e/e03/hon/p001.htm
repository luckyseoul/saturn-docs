1. Introduction Guide

1.1 About Saturn Author

Saturn Author is an authoring software that allows you to easily create interactive movies for Saturn by integrating multiple material data (QuickTime movies and PICT) that have been edited by other tools (movie editing tools and graphic tools). . With Saturn Author, you can significantly reduce the production time of applications using movies.
Saturn Author consists of the following programs:

Author Editor

Create a scenario by integrating multiple material data. Works with Macintosh.

Author Converter

Converts the data created by the author editor for the author player and outputs a virtual CD script file for creating a CD-ROM image. Works with IBM PC / AT.

Author player

Plays the movie based on the scenario created with the author editor. Works with Saturn.

1.2 Features

The characteristics of Saturn Author are as follows.
    • You can add collision frames and branch information to movies and still images.
    • Multiple material data can be integrated to create a scenario.
    • Simulations created on Macintosh can be simulated.
    • You can create interactive movies without a program.
    • Data output by the author editor can be used for game applications.
    • Cinepak movie and MPEG movie are supported.
