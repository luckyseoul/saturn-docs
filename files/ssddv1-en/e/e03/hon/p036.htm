Function configuration

    The configuration of this system is shown in Figure 4.2.


    Figure 4.2 Function configuration list

    The author converter consists of the following two modules.

Video playback
    Plays MPEG and Cinepac movies. Collision data acquisition and hit determination are performed.

Picture display

    Displays one still image (picture file). The collision selection registered in the picture file is selected.

4.3 Usage

How to create

    Prepare the following files and create a CD-ROM image with a virtual CD.
    For details, refer to “3. Author Converter”.

    -Author player (file name: AT_PLAY.ABS)
    ・ Scenario file (file name: AT_PLAY.ASC)
    ・ Script file
    ・ Interleave definition file
    ・ Video file (MPEG or Cinepak)
    ・ Picture file (1 still image)
    ・ Collision file 

      Caution  AT_PLAY.ABS is loaded with the CD-ROM boot module.
  The scenario file name should be AT_PLAY.ASC.
