Cursor The
    cursor is an object that moves on the screen in response to pad operations, and only one cursor can be displayed on the screen.

    Operation
    Table 4.3 shows the basic pad operations of the author player.

    Table 4.3 Pad operation 
     button 
     content 
     Up / Down / Left / Right 
     The cursor moves in the selected direction like a mouse cursor. 
     A, B, C, START button 
     Executes the process 
     registered in the cursor coordinate collision.

    View
    The cursor displays the user-created picture on the sprite surface.
    If not specified, the cursor is not displayed.
