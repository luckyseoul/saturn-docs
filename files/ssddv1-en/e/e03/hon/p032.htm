3.3 Usage

Operation procedure

The procedure for creating a CD-ROM image using the
author converter and virtual CD is shown below. (For directory, see Table 3.1)
  1. Copy the following file created with the author editor to IBM PC-AT. (For directory, see Table 3.1)
    ・ Scenario file
    Collision file
    ・ Layout file

  2. Copy Cinepak or MPEG video files to IBM PC-AT.
    Make sure that the extension of Cinepak movie files is “.CPK” and that of MPEG movie files is “.MPG”. If the extension is different, rename it.

  3. Executes the author converter. (See `` Startup method '' on page 33.)
    The author converter performs the following conversion processing based on the movie file name and collision file name described in the layout file.
    -Output interleave definition file.
    ・ Output script file.

  4. When using with a game app, the user creates a separate script file.
    It is necessary to include the interleave definition file output by the author converter in the script file.

  5. Create a CD-ROM image with a virtual CD. 

      Caution  Save the files used by the author converter in the following directory.
