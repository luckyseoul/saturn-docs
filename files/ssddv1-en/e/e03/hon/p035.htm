4. Author player

4.1 Overview

This section describes the functions of the Saturn Author player part. In this document, the player part of Saturn Author will be referred to as “Author Player”.
The author player is a tool for playing interactive movies on Saturn based on files created with the author editor.

4.2 System configuration

Function overview

The functions of this system are as follows.
  • Play an interactive movie based on a scenario file and a collision file created by the author editor.
  • When a collision pasted on a still image or movie is selected, another still image or movie is played.
