Authoring Tool Guide


Introduction


Purpose of this binder

    This document is a tool guide for creating authoring data on this system.
    By reading this manual, you can understand the environment for creating data and how to use each authoring tool.


■ Target for this binder

    This document is written for those who create authoring data on this system and those who develop application software.


■ Composition of this binder

    This manual consists of the following three manuals.

    1. “Authoring Environment Guide”

      Describes how to use the authoring tool and the development environment.

    2. "Saturn Author User's Manual"

      Saturn Author is authoring software that allows you to create interactive movies for Saturn by integrating data edited with other tools.
      This manual describes the features of Saturn Author and the author editor, author converter, and author player that compose Saturn Author.

    3. “Cinepak for Saturn User's Manual”

      Cinepak for Saturn explains the functions and usage.
