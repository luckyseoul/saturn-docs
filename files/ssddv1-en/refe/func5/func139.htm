Peripheral control function

slGetOptimize

Acquire peripheral acquisition time optimization mode

Format

Uint8 slGetOptimize()

Parameter

None

Function

Acquires the peripheral acquisition time optimization mode.

Return value

Peripheral acquisition time optimization mode

Remarks

The following values ​​are returned.
SMPC_OPT_ENA ... Acquisition time optimization permission (initial value)
SMPC_OPT_DIS ... Acquisition time optimization prohibited

Reference: HARDWARE MANUAL vol.1 (SMPC)
