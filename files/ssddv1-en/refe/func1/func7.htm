Scroll function

sl1MapRB

RBG map set (using rotation parameter B)

Format

void sl1MapRB(b)
void *b ;

Parameter 

 b Start address on VRAM of pattern name data table for rotation parameter B

Function

Set the map for rotating scroll. (Use rotation parameter B)
For the parameter, substitute the top address on the VRAM of the pattern name data table to be registered in the map register and map offset register.
The data table is used for one page from the specified address.

Return value

None

Remarks

Reference: Chapter 8 Scroll
