sl1MapRA

RBG map set (use rotation parameter A)

Format

void sl1MapRA(a)
void *a ;

Parameter 

 a Start address on VRAM of pattern name data table for rotation parameter A

Function

Set the rotation scroll map (use rotation parameter A).
For the parameter, substitute the top address on the VRAM of the pattern name data table to be registered in the map register and map offset register.
The data table is used for one page from the specified address.

Return root

None
