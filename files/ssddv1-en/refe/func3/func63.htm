Scroll function

slZoomR

RBG scaling

Format

void slZoomR(x , y)
FIXED x ;
FIXED y ;

Parameter 

x Reciprocal of enlargement / reduction ratio with respect to X axis direction of rotary scroll
y Reciprocal of enlargement / reduction ratio with respect to Y-axis direction of rotary scroll

Function

Sets the scaling ratio of the rotating scroll and saves the current state in the current rotation parameter.
Substitute the reciprocal of the scale value in the X and Y axis directions for the parameter.
For example, if you want to enlarge the X-axis direction by a factor of 2.0, substitute 1/2 for parameter “x”.

Return value

None

Remarks

Unlike normal scrolling, rotary scrolling can always be scaled at any magnification.

Reference: Chapter 8 Scroll
