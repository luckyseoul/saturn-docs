Sprite function

slSpriteType

Specify sprite data type

Format

void slSpriteType(type)
Uint16 type ;

Parameter

type Sprite type (0 to 15)

Function

Specify the type of sprite data.

Return value

None

Remarks

0-7 are for low resolution (320 or 352), 8-15 are for high resolution (640, 704), and the data width is 16bit and 8bit respectively.

Reference: HARDWEAR MANUAL vol.2 (VDP)
