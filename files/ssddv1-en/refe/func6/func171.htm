Sint8
Sound function

slSndPCMNum

Return free PCM channel number

Format

Sint8 slSndPCMNum(Mode)
Uint8 Mode ;

Parameter 

Mode PCM playback mode

Function

Returns an available PCM channel number.

Return value

In case of normal termination, the function returns 0-7.
If the PCM channel is full, the function returns -1.

Remarks

Parameter "Mode" includes "_Stereo" or "_Mono" and "_16Bit" or Specify logical OR with "_8Bit".
PCM can play up to 8 tones, but for stereo playback, 2 tones It may be necessary to have 8 sounds even if only 4 Please be careful.
