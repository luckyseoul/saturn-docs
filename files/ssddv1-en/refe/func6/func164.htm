Sound function

slSequenceReset

Initialization of specified sound effect parameters

Format

Bool slSequenceReset(Seqnm)
Uint8 Seqnm ;

Parameter 

Seqnm pronunciation control number

Function

Initializes the volume, tempo, and pan of the specified sound effect.
Volume is maximum, tempo is normal, and panning is uncontrolled.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 1 to 7 for the parameter "Seqnm".
