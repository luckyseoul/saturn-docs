Sound function

slSequenceCont

Resume sound effect during pause

Format

Bool slSequenceCont(Seqnm)
Uint8 Seqnm ;

Parameter 

Seqnm pronunciation control number

Function

Resumes the generation of the specified pause sound effect.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 1 to 7 for the parameter "Seqnm".
