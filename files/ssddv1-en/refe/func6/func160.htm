Sound function

slSequenceOff

Stop generating the specified sound effect

Format

Bool slSequenceOff(Seqnm)
Uint8 Seqnm ;

Parameter

Seqnm pronunciation control number

Function

Stops generating the specified sound effect.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 1 to 7 for the parameter "Seqnm".

Reference: Chapter 14 Sound Library
