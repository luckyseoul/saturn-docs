slPCMParmChange

Change the parameters for PCM playback

Format

Bool slPCMParmChange(Pdat)
PCM *Pdat ;

Parameter 

Pdat PCM structure data

Function

Change the value of each parameter for PCM playback.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

For details on the PCM type structure, refer to the separate "Structure Reference".
