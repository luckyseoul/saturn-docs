Sound function

slSequenceStat

Check while playing the specified sound effect

Format

Bool slSequenceStat(Seqnm)
Uint8 Seqnm ;

Parameter 

Seqnm pronunciation control number

Function

Checks whether the specified sound effect is playing.

Return value

Returns 1 when playing (pause) and 0 when stopped.
