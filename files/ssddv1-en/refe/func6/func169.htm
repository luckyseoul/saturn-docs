Sound function

slSndMixChange

Switching the mixer corresponding to the tone bank

Format

Bool slSndMixChange(Tbank , Mixno)
Uint8 Tbank ;
Uint8 Mixno ;

Parameter 

Tbank Tone bank number
Mixno Mixer number

Function

Switches the mixer corresponding to the tone bank.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 0 to 15 for the parameter "Tbank".
Specify a range from 0 to 127 for the parameter "Mixno".

Reference: Chapter 14 Sound Library
