Sound function

slSndVolume

Whole volume set

Format

Bool slSndVolume(Volume)
Uint8 Volume ;

Parameter 

Volume Volume value

Function

Sets the overall volume.

Return value

If the command buffer is full, the function returns FALSE.

   

Remarks

 

Specify a range from 0 to 127 for the parameter "volume".
(However, the lower 3 bits are ignored.)
