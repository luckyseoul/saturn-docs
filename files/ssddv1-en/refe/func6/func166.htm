Bool
Sound function

slSequenceTempo

Change speed of specified sound effect

Format

Bool slSequenceTempo(Seqnm , Tempo)
Uint8 Seqnm ;
Sint16 Tempo ;

Parameter 

Seqnm pronunciation control number
Tempo Tempo value

Function

Changes the speed of the specified sound effect.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 1 to 7 for the parameter "Seqnm". Specify the range from -32768 to 32767 for the parameter "Tempo". "Tempo" is a relative tempo value relative to the standard tempo of 0, doubles at 4096 (1000h), and halves at -4096.

Reference: Chapter 14 Sound Library
