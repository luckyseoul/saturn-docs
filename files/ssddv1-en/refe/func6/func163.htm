Sound function

slSequencePause

Pause the specified sound effect

Format

Bool slSequencePause(Seqnm)
Uint8 Seqnm ;

Parameter 

Seqnm pronunciation control number

Function

Pauses the specified sound effect.

Return value

If the command buffer is full, the function returns FALSE.

Remarks

Specify a range of 1 to 7 for the parameter "Seqnm".
