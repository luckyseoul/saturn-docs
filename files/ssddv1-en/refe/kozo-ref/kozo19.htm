Variable type

FIXED

Fixed-point variable type

Structure 

typedef   Sint32 FIXED ;

Description 

Refers to fixed-point data.
FIXED type numbers are expressed as follows.
      Upper 16 bits: Integer part
      Lower 16 bits: Decimal part
          Example) 16.5 → 0x00108000
