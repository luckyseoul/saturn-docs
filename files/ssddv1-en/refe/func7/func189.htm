slSetTrayCheck

CD tray open check

Format

void slSetTrayCheck(flag)
Uint8 flag

Parameter 

flag ON or OFF

Function

Specify whether to check to switch to the multiplayer screen when the CD tray is opened.
Specify ON or OFF for flag.
Note that the status is cleared when the function is called, so if the tray is open when it is turned on, it will not be checked until it is opened again.

Return value

None
