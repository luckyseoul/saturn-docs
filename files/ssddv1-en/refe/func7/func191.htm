slDMAStatus

DMA transfer check

Format

void slDMAStatus()

Parameter

None

Function

The slDMACopy () and slDMAXCopy () functions check whether the started D.M.A. transfer is in progress and return a flag.
Returns ON if transfer is in progress and OFF if it is completed.
