Arithmetic functions

slAng2FX

ANGLE angle value converted to FIXED value

Format

FIXED slAng2FX(ang)
ANGLE ang ;

Parameter 

ang ANGLE type angular value

Function

Converts an ANGLE-type angle value to a FIXED-type numeric value.

Return value

Angle data converted to FIXED type.

Remarks 

Example)
    ang = 0x4000 → 0x005A0000 (90.0)
    ang = 0x1000 → 0x00168000 (22.5)
