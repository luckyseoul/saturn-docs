slAng2Hex

ANGLE angle value converted to hexadecimal number

Format

Uint16 slAng2Hex(ang)
ANGLE ang ;

Parameter 

ang ANGLE type angular value

Function

Converts an ANGLE-type angle value to hexadecimal.

Return value

Angle data converted to hexadecimal.

Remarks 

Example)
    ang = 0x4000   →   0x005A
    ang = 0x1000   →   0x0016
