slDivFX

Division (B / A)

Format

FIXED slDivFX(a , b)
FIXED a ;
FIXED b ;

Parameter 

a in (B / A): divisor
b in (B / A): dividend

Function

Divide between fixed points (B / A).

Return value

The function returns the division result (B / A).

Remarks

This function does not check for overflow.
