slAng2Dec

ANGLE angle value converted to BCD value

Format

Uint16 slAng2Dec(ang)
ANGLE ang ;

Parameter 

ang ANGLE type angular value

Function

Converts an ANGLE-type angle value to a BCD-type numeric value.

Return value

Angle data converted to BCD type numerical value.

Remarks 

Example)
    ang = 0x4000   →   0x0090
    ang = 0x1000   →   0x0022
