slSquartFX

Return unsigned fixed-point square root

Format

FIXED slSquartFX(sqrtfx)
FIXED sqrtfx ;

Parameter 

sqrtfx unsigned fixed-point number

Function

Calculates the square root of an unsigned fixed-point number.

Return value

The function returns the square root of an unsigned fixed-point number.

Remarks

Since the operation is performed as an integer, the precision of the result is an 8-bit integer and an 8-bit decimal point.
