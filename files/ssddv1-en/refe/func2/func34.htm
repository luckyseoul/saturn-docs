slMapNbg0,1,2,3

NBG map set

Format

void slMapNbg0(a , b , c , d)
void slMapNbg1(a , b , c , d)
void slMapNbg2(a , b , c , d)
void slMapNbg3(a , b , c , d)
void *a , *b , *c , *c ;

Parameter 

a Start address on the VRAM of the pattern name data table for plane A
b Top address on VRAM of plane B pattern name data table
c Top address on VRAM of plane C pattern name data table
d Start address on VRAM of plane D pattern name data table

Function

Set the map for normal scrolling.
For the parameter, substitute the top address on the VRAM of the pattern name data table to be registered in the map register and map offset register.

Return value

None
