slScrMosSize

Specify the size of mosaic processing in H and V

Format

void slScrMosSize(Hsize , Vsize)
Uint16 Hsize ;
Uint16 Vsize ;

Parameter 

Hsize Horizontal size of mosaic processing (assigned value: 1 to 16 dots)
Vsize Vertical size of mosaic processing (assigned value: 1 to 16 dots)

Function

Specify the horizontal and vertical sizes for mosaic processing in dot units.
In non-interlace mode, specify 1 to 16 dots in both vertical and horizontal directions. In interlace mode, specify 2 to 32 dots (multiple of 2) in the vertical direction and 1 to 16 dots in the horizontal direction.
When mosaicking a rotating scroll, only horizontal mosaicing is performed.

Return value

None

Reference: HARDWEAR MANUAL vol.2 (VDP2)
