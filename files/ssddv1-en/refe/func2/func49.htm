slScrLineWindow0

Set line window table 0

Format

void slScrLineWindow0(adr)
void *adr ;

Parameter 

adr Data address on the line window VRAM

Function

Set the VRAM address of line window data table 0.

Return value

None

Remarks

Set the most significant bit to 1 to enable the window.
Pass NULL to disable the window. 

Example) Address = 0x25e3f000 (when constant is specified)
Use window: slLineWindow0 ((void *) (0x25e3f000 | 0x80000000));
不 Window not used: slLineWindow0 ((void *) NULL);
Address = 0x25e3f000 (when address is specified)
Window use: Sint16 * lptr;
Lptr = (Sint16 *) 0x25e3f000);
SllineWindow0 ((void *) (lptr + 0x40000000));
Since lptr is a pointer of Sint16 (2-byte variable)
不 Window not used: slLineWindow0 ((void *) NULL);
