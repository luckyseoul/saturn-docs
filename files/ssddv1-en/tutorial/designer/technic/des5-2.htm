Magnet function

As you can see, the Magnet function is a function that attaches the picked point to a certain point. However, please note that this function works only in the set window.

“On Point” and “On Tag”:
While “On Point” picks the point you picked, it sticks to another point, while “On Tag” sticks to the TAG point.
“Unselected Objects” and “All visible Objects”:
