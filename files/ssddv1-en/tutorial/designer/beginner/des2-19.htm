Freeze of scale

Here, when you look at the [ScaleY] menu, the value of Y is 0.9000, but once the size of the object is determined, it is easier to understand based on that size,
[Effect] → [Freeze] → [Scaling] To set the current size as the standard (1.0000).

Now you have a TV monitor model.

Save model

First, you need to name your model.
[Info] → [Selection]
In the dialog box to name the model, change the temporary name “Cube” in “Name” to your favorite name (eg SATURN_TV_SET) and click “OK”.

To save the model,
[Save] → [Select Models] Then click “Save” to save.
