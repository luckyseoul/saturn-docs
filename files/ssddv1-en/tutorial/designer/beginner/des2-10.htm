Operation mode switching

TAG cannot be operated unless the operation mode is set to “TAG”.
Conversely, the entire object cannot be manipulated unless it is set to “OBJ”.
Since operation mode switching is frequently used, the following shortcut keys are provided.

shortcut key
“F8” key: Select OBJ mode
“F9” key: Select TAG mode
