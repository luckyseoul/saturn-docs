6-2. Explanation of the menu bar

The corresponding function key is shown to the right of each menu item.

[File-Menu]

[Load Texture]
Reads texture files (currently only DGT files).
The imported texture can be checked in the entry window.
Multiple texture files can be loaded at once.

 

[Load Model]
Read the model file. Currently supports HRC (ASCII, Binary).

[SAVE Model]
Save the model file. Currently supports HRC (ASCII, Binary).

[Quit (Ctrl + q)]
Exit SMAP.

How to select a list

Multiple selections are possible when selecting a list in the texture file and entry window.

● Single selection

Press the mouse button to highlight the selected list.

-Multiple selection by dragging

If you move the mouse while holding down the mouse button, the list of the range from the position where you pressed the mouse to the current mouse pointer will be highlighted, and when you release the mouse button, the list of that range will be selected. Will be. The next time you press the mouse button, the selection is canceled.

● Multiple selection using the “Shift” key

If you hold down the “Shift” key and press the mouse button, the currently selected range will be canceled, and the new selection range will be from the position where you previously pressed the mouse until you release the mouse. The For example, first select the top of the list, then use the slider to display the end of the list, hold down the “Shift” key and press the mouse button on the last list to select the entire list. .

● Adding a list using the “Ctrl” key

Hold down the “Ctrl” key and press the mouse button to add the newly selected list to the currently selected range. However, if you press the mouse button on an already selected list, the newly specified range will be deselected.

[Window]

[Entry Window]
Opens and closes the entry window.

[Info Window]
Opens and closes the information window.

[Render Window]
Opens and closes the render window.

[Setup]

[Initialize]
Reset the Zoom rate and View values ​​to default. By default, the Zoom rate is 1000 and the View Z Depth is 200.

[Setup]
Opens a dialog for changing the Zoom rate and View (Z Depth) values.
The larger the Zoom rate, the larger the zoom rate.
View is a clipping region with depth in the z direction.

[Center Trans]
Align the center of the model with the center of the axes.
However, once selected, it will not return.

[Fitting]
Move the model to the center of the window and resize it to fit the window size.

[Entry]

[Open]
Displays the texture selected in the entry window.

[Delete]
The texture selected in the entry window is deleted from the entry. If the texture is displayed, the window is closed.

Caution
If the deleted texture is pasted to the model, the texture registered in the polygon will be automatically deleted.

[Polygon]

[Reverse Check]
Process the hidden surface of the display polygon
Default value: on

[Hide Texture]
Rotate the model and display / hide the texture while moving.
Default value: on (hidden)

[Previous]
The display polygon counts down using the number of polygons set in Polygons as an offset value.

[Next]
The display polygon is counted up using the number of polygons set in Polygons as an offset value.

[Polygons]
Set the number of display polygons.

[Help]

[About]
Displays version information.

[Help]
Displays the function key assignments and shortcut key assignments for each function.
