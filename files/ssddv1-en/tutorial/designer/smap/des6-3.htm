6-3. Explanation of mode select button

There are buttons for setting the various modes between the menu bar and the display. When you press the button, a menu will pop up. Click the mode you want to change to change the mode. It is also possible to pop up the menu with the space key and select the mode with the ↑ ↓ key.

You can also change to texture-related modes by key operation. In texture-related modes, you can temporarily change to the model-related mode by pressing and holding the key. For example, in DrawTexture Mode, you can rotate the model by pressing and holding the “o” key, which is useful when pasting the same texture onto multiple polygons.

Each mode is described below.

● Rotate Model (o)
Rotate the model. The rotation axis can be selected with the mouse button, and it rotates by dragging the mouse.
This mode is interrupted while the “o” key is pressed during texture handling mode.

● Rotate Texture (r)
Rotate the pasted texture. You can select rotation with the left and right mouse buttons, and return with the middle mouse button.

● Reverse Texture (f)
Inverts the pasted texture. Invert can be selected with the left and right mouse buttons, and it returns with the middle mouse button.

● Change Overlap (g)
This function is for triangle polygons only, and the overlapping vertices are changed.
Check the texture in the Saturn Render Window, not the Main Window.

● Zoom Model (z)
Zoom in and out of the model. However, the model moves with the left mouse button and scales while moving the mouse.
This mode is interrupted while the “z” key is pressed while in texture handling mode.

● Check Texture (c)
Paste the confirmation texture to the polygon. However, the confirmation texture cannot be pasted where the original texture is pasted. Since the check texture can be rotated and flipped in the same way as the original texture, if you paste the original texture with Draw Texture after that, the rotation and flip information will be inherited and the original texture will be pasted. In other words, first determine the state of rotation or flipping with the confirmation texture, and then paste the original texture.

Select the desired polygon with the right mouse button:
When the polygon you want to paste is overlapping on the screen, you may not be able to select the desired polygon well. In such a case, click the right mouse button to enter Another polygon mode. Select again. Another polygon mode continues until you click the right mouse button.

Delete texture with middle mouse button: You can delete the confirmation texture and pasted original texture with the middle mouse button. However, the deleted texture will disappear, but its rotation and flip information will remain.

● Draw Texture (d)
Pastes the texture selected in the entry to the selected polygon. If multiple entries are selected, only the first texture is valid.
You can overwrite the polygon with the confirmation texture, but for safety, you cannot overwrite it if the original texture is already pasted.

Select the desired polygon with the right mouse button:
When the polygon you want to paste is overlapping on the screen, you may not be able to select the desired polygon well. In such a case, click the right mouse button to enter Another polygon mode. Select again. Another polygon mode continues until you click the right mouse button.

Delete texture with middle mouse button:
However, the deleted texture will disappear, but its rotation and flip information will remain.

● Translate Model (t)
Move the model. The movement axis can be selected with the mouse button.
This mode is interrupted while the “t” key is pressed while in texture handling mode.
