Designer’s Tutorial

How to use SMAP

This chapter explains how to paste a texture onto a polygon model using Motif / SMAP FOR SATURN (hereafter called SMAP).
In Saturn, one texture is attached to one polygon. The designer can create a complete texture model by loading polygon model data and texture data pasted into SMAP and rotating and inverting the texture.

6-1. Explanation of each window

●Main Window
SMAP is the central window where most of the work is done. From the top, the menu bar, mode select button, display, and mouse button help display.

●Entry Window
Displays a list of textures registered for pasting to the model. Use the “F2” key to pop up and pop down. The registered texture can be displayed and checked by either of the following methods.

  1. Double click the mouse button on the texture name you want to display.
  2. Click and select the texture name you want to display with the mouse button. Next, from Entry on the menu bar When EntryOpen is selected, a texture display window pops up. With this method, you can open multiple textures at once.

●Infomatoion Window
Displays the following information: Use the “F3” key to pop up and pop down.

  • ModelName: The name of the model you are currently working on.
  • TotalPolygons: The total number of polygons in the model.
  • DisplayPolygons: The polygon number of the display polygon (starting from 1).
  • TotalTextures: Number of polygons with textures.
  • CheckTextures: Number of polygons with check textures.
  • SelectPolygonNumber: The selected polygon number.
  • Attribute: The attribute attached to the polygon (default is SNN).
  • TextureName: Name of the texture stretched on the selected polygon (if not stretched) NonTexture).

About editing attributes

Click the “Edit” button to the right of “Attribute” to display the “Attribute” change dialog. “Attribute” displays the first three letters of the “Material” name, but you can also change “Attribute” here. The status of “Attribute” can be confirmed with “RenderWindow”.

●TextureDisplayWindow
This window displays registered textures. When you press the right mouse button in the window, a menu pops up, allowing you to zoom in and close the texture.

●Saturn Render Window
This is the window for rendering for Saturn. With the right mouse button, a menu pops up to enable real-time rendering on / off, wireframe on / off, and close the window.
