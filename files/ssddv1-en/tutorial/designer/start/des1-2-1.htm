1-2. Basic operation of SOFTIMAGE

Caution
To start SOFTIMAGE, you need to enter a startup command. Ask the system administrator about the startup command in advance.

until launching SOFTIMAGE (how to create a directory)

  1. Open a UNIX shell and enter:
    mkdir SOFT [line feed]
    mkdir CHECK [line feed]
    (Mkdir: Make Directory)

    You now have SOFT and CHECK directories under your home directory (the directory that appears when you open the shell).

    Example) When [irs073: / usr1 / people / osa: 1]% is displayed when the shell is opened, "osa" is the home directory.

    Enter

  2. ll (or ls -al) [line feed].
    The following is displayed:

    drwxrwxr-x 2 (user name) (group name) 512 Nov 29 1994 SOFT/
    drwxrwxr-x 2 (user name) (group name) 512 Nov 29 1994 CHECK/
    The first d in drwxrwxr-x means a directory.

  • SOFT / Directory
    Use it when launching SOFTIMAGE in the future. When outputting data, SOFTIMAGE records data in the starting directory, so it is always better to start SOFTIMAGE in the same directory. Otherwise, the data will be output to various directories.

  • CHECK / Directory
    After creating the model, it is used when converting the model and checking errors using the program Slcon. The contents are explained in “Data Transfer, Section 1-2: SOFTIMAGE Data Conversion / Check”.
