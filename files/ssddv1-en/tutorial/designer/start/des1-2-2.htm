Start SOFTIMAGE

  1. cd Enter SOFT [line feed]. The following prompt will appear:
    [(Name of machine logged in) :( Home directory) / SOFT: 2]%

    Example) [irs073: / usr1 / people / osa / SOFT: 2]%

  2. Enter the startup command you received from the system administrator.
    SOFTIMAGE starts up and the following message is displayed on the UNIX shell. Ignore this message.
    ERROR:Database SI_Material_lib non-existent or invalid
    ERROR:Database SI_Channels_lib non-existent or invalid
    ERROR:Database SI_Dynamics_lib non-existent or invalid
    ERROR:Database SI_Animation_lib non-existent or invalid

  3. When the SOFTIMAGE title screen appears on the display, press any mouse button.
    This completes the SOFTIMAGE startup operation.
