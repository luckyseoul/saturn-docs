Sound Tutorial

The Sega Saturn Sound Tutorial has been created to give the sound designers the knowledge they need to develop sound for the Sega Saturn.
This book is written so that if you have used Macintosh and are not familiar with DTM (desktop music) knowledge, you can play songs with Saturn.
Note that the contents described in this manual are limited to the point where the “Sega Sound Tool” is used to create a sound data file for use with Saturn.
To actually play a song in a game using a sound data file, use the sound functions of the Sega Graphic Library (SGL) in the program, or use the sound control commands directly.
For more information on sound control commands, see “SATURN Sound Driver System Interface”.
