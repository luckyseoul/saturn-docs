Sound Tutorial

Make a song

This chapter explains how to create songs using the Sega Sound Tool and notes on using the tool.
I won't cover creating sound effects here, but sound effects can be created in exactly the same way as songs.
You may be confused at the beginning with a lot of terms, but since only the basic editing method is posted, please try it out for the time being.

About song creation tools

  1. Sega Sound Tool does not provide software for creating songs (sequencer, etc.). Use commercially available software.
  2. 1 can be performed using commercially available tools. Choose something that is easy for you to use.
  3. If you use only notation software, use the one that can edit MIDI event (at least, controller, program).
