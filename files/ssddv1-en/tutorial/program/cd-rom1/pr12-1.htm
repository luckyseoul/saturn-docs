Programmer’s Tutorial

CD-ROM library

This chapter explains how to access the CD-ROM using the CD-ROM library. By using the CD-ROM library, you can read data and programs from the CD-ROM and play music.

This chapter also includes a list of function references for the CD-ROM library.

12-1. About the CD-ROM library

SGL provides functions for accessing CD-ROMs and virtual CDs. By using these functions, you can achieve the following functions:

  • Reading programs and data from CD-ROM
  • Reading data using CD-ROM XA standard
  • Music playback using CDDA files

Caution
The CD-ROM library functions are listed later in this chapter, not in the separate “Function Reference”.

For details on how to burn a CD-ROM, refer to “Chapter 3: How to burn a CD-ROM”.
