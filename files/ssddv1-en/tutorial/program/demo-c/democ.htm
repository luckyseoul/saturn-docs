[Demo Program C: Walking Akira]

demo_C

Here, we will introduce a demo program (demo_C) that animates walking of a human body model. The model is Akira of Virtua Fighter.
Akira is composed of 22 polygon objects, and each object has a hierarchical structure as shown below.

Figure C-1 Akira's parent-child structure

Note) Akira is facing you now.

By providing angle data between Akira's parent and child objects, you can create a “joint”. By changing this angle data, you can move the jointed Akira. The angle data between each parent and child object is called “motion data”.

Complex motion data such as the human body is usually created by 3D animation tools.
