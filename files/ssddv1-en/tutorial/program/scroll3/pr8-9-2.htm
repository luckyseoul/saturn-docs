Enlargement / reduction of rotating scroll screen

With SGL, you can also zoom in and out on the rotating scroll screen. Unlike the normal scroll screen, the rotary scroll screen can always be scaled at any magnification.
In addition, in the case of a rotary scroll screen, it can be used in combination with the scroll rotation operation, enlargement / reduction operation, and movement operation described later.
Use the library function “slZoomR” if you want to execute scaling of the rotary scroll screen in SGL.

[void slZoomR (FIXED scale_x, FIXED scale_y);]
Enlarges / reduces the rotation scroll screen “RBG0” and saves the current state as the current rotation parameter (the current parameter can be switched with the function “slCurRpara”).
For the parameter, substitute the reciprocal of the horizontal and vertical magnification.
For example, if you want to enlarge to 2 times, assign 1/2 to the parameter, and if you want to reduce it to 1/2, assign 2.
For rotary scrolling, scaling can always be set at any magnification.
