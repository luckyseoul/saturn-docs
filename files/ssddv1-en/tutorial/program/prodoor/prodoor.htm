Programmer’s Tutorial

Sega Saturn Programmer's Tutorial can learn the knowledge that programmers need for 3D software development for Sega Saturn. This document is premised on programming using the Sega 3D Game Library (SGL), and the procedures necessary for 3D software development are explained using sample programs. This manual also explains the basic concepts of 3D software, so that even programmers with no 3D software programming experience can understand it. This book is basically written for 3D software programming, but by handling these two-dimensionally, it can be applied to conventional two-dimensional games.
