Introduction

Purpose of this manual

This document was created as a manual for developers who develop software for Sega Saturn using the Sega Graphic Library (SGL).

SGL is a function library with enhanced 3D graphic functions. This book is also designed to be useful as an introduction to 3D graphics, so it is fully understandable even for those who have no experience in developing software using 3D graphics.

Structure of this manual

This manual can be used to learn the knowledge required to develop software for Sega Saturn using SGL in a tutorial format.
The contents are divided according to the business of the developer as follows.

  • Development environment

    Manual for system administrators. For each business person in charge, the necessary knowledge for development equipment configuration and software development system configuration is written.

  • Programmer's Tutorial

    Explains the basic knowledge of 3D software programming and how to use SGL functions, including sample programs. This chapter is closely related to the SGL software package.

    Note) For programmers who have learned the basics of SGL in this book, please refer to the separate volume “SGL Developer's Manual, Reference”.
  • Designer's Tutorial

    You can learn basic knowledge of 3D polygon modeling and how to use Sega recommended design tools “SOFTIMAGE” and “SMAP”.

  • Sound Tutorial

    You can learn the knowledge that sound designers need for sound development for Sega Saturn.

  • Data transfer

    It contains information necessary for passing data between designers and programmers.
